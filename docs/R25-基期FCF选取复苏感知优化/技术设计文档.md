# R25 基期 FCF 选取复苏感知优化 技术设计文档

> 需求依据：`docs/R25-基期FCF选取复苏感知优化/需求文档.md`（FR-1 ~ FR-11、AC-1 ~ AC-14）。
> 设计范围：只改「AI 估值推荐中基期 FCF 的选取方式与窗口」，即 `recommendBaseFCF` 的内部规则、少量新增私有辅助函数、`aiCacheSchema` 版本常量与测试；不改 `FCF = NETCASH_OPERATE − maintenanceCapex` 公式、`selectBaseFCF` 的手动选取语义、`detectFCFCycle`、DCF 四模型、WACC/CAPM、增长锚、终值、敏感性矩阵、API 字段与前端控件。
>
> **决策基线（用户已拍板，本文不再讨论替代方案）**
>
> | 编号 | 决策 |
> | --- | --- |
> | Q1 | 不改 `detectFCFCycle`；复苏门只作用于基期 FCF 选取路径，不写回 `fcfCycle`，不波及 `isCyclical` / β / 终值 / 历史锚。 |
> | Q2 | 周期股使用 3/5 自适应 `trim_mean`：默认 5 年；满足「最新 > 上年 > 0 且最新 > 近 5 年正值中位数」的复苏加速时用 3 年。 |
> | Q3 | 自动选取全局封顶 5 年（`U=5`）；10 年只保留给周期判定、手动选取与 `fcf_series` 展示。 |
> | Q4 | 复苏门严格式：`available>=3 && mean5>0 && latest>0 && mean10<=0`。 |
> | Q5 | 波动大（RF）改为「先缩短窗口再取中位数」：`N=min(m,5)`；`N=5` 且近 5 年非正年数 ≥2 时 `N=min(3, available)`；不新增模式。 |
> | Q6 | `trim_mean` 保持固定去 1 高 1 低，不做比例去极值。 |
> | Q7 | 不做借壳/重组年显式剔除，靠 3–5 年短窗口自然稀释。 |
>
> **实现层默认约定（需求未展开，按此落地）**
>
> 1. **保留 `fcfWindowYears` 的行为不变**，把它视为「名义窗口」；实际自动窗口在 `recommendBaseFCF` 内统一与 5 年、可用年数取小。这样 `TestFCFWindowYears` / `TestDetectFCFCycle` 零改动，且 10 年语义仍可解释为「周期判定/展示上界」。
> 2. **`prev` 取 `years` 的倒数第二个年报**（`years[len(years)-2]`），而不是 `latestYear-1`。原因：`annualRows` 的年度可能不连续，需求写的是「上一年报」；这也与「最近 3/5 个年报」的窗口语义一致。
> 3. **FR-5 第 4 条用 `selectBaseFCF` 复算后再判断**，不在推荐函数里另写一套聚合。这样守卫本身即满足「推荐 `(mode, years)` 必须能被 DCF 侧复算」的契约。
> 4. **全局 5 年封顶同样作用于 custom 中枢的 `center` 计算窗口**。`center` 由多年度窗口派生，属于自动选取的一部分；若保留 10 年 `center` 会留下「自定义值仍向后看 10 年」的同类入口。该约定不影响任何既有非周期 fixture（其窗口本就 ≤5）。
> 5. 3 年周期/复苏路径的内部 `Rationale` 统一为「近 3 年复苏窗口去极值平均。」；5 年为「近 N 年去极值平均。」。`Rationale` 不对外，仅用于单测与排查（FR-11）。

## 1. 设计目标与影响面

### 1.1 目标

1. 自动推荐的多年度基期 FCF（average / median / trim_mean）最终窗口不超过 5 年；可用年数不足 5 时取全部可用。
2. 周期股（`cycle.Cyclical=true`）默认取最近 5 年 `trim_mean`，复苏加速时取 3 年；不再出现 10 年去极值平均。
3. 深亏后复苏公司（`Evaluated=false`，但近 5 年均值 >0、最近一年 >0、近 10 年均值 ≤0）进入同一套 3/5 年 `trim_mean` 路径，不再被 Evaluated 门挡回 10 年。
4. RF（`gSpread>40`）从「整 10 年中位数」改为「最近 ≤5 年中位数」；近 5 年非正年数 ≥2 时缩短到 3 年。
5. 任何多年度聚合结果为非正、而最近一年为正时，退回最近一年，避免 DCF 明明有正 FCF 却判「基期 FCF≤0 不适用」。
6. 非周期稳定/温和/成长否决路径的 `Mode`、`Years`、`CustomYuan`、`Rationale` 关键措辞与改动前逐字段一致。
7. 推荐结果仍可由 `(mode, years)` 通过 `selectBaseFCF` 原样复算；不新增模式、API 字段、前端控件、IO 或依赖。

### 1.2 非目标

- 不改 `detectFCFCycle` 的窗口、均值、CV、符号翻转、`Evaluated/RawCyclical/Cyclical/GrowthVeto` 语义。
- 不改 `fcfWindowYears` 的返回值（仅改注释，明确其「名义窗口」定位）。
- 不改 `selectBaseFCF`、`trimMeanOf`、`fcfGrowthPoints`、40pp 阈值、`maintenanceCapex`、`operatingFreeCashFlow`。
- 不改 `RecommendValuation` 的输入窗口 `fcfYears = yearWindow(..., valFCFRecMaxYears)`（仍 ≤10，供周期判定与 `fcf_series` 使用）。
- 不改 `FCFWindowYears`、`FCFSeries`、`CapexCheck`、`FCFProfitCheck`、敏感性矩阵、AI 提示词模板、估值历史结构。
- 不做借壳/重组年识别或告警。

### 1.4 兼容性结论

- **无 API 变化**：不新增/删除 query 参数与 JSON 字段；`fcf_mode` 仍只能取 `latest/average/median/trim_mean/custom`；`fcf_years` 仍为 1–10。
- **无 model 变化**：`model.ValuationRecommendation` 与 `model.AIValuation` 字段不动；`fcf_base_value`、`fcf_base_before_rd`、`fcf_years`、`fcf_window_start/end`、`fcf_note`、`capex_check`、`fcf_profit_check` 的语义不变，只是取值随新窗口变化。
- **手动选取不变**：`selectBaseFCF` 完全不动；用户手动选 1–10 年、任意既有方式的结果与旧行为一致。
- **旧缓存主动失效**：`aiCacheSchema` 升版后 r24 条目不再命中，重算即得到新推荐；无数据迁移。
- **旧估值历史可回填**：历史记录保存的是当时的 `fcf_mode/fcf_years`，回填时 `selectBaseFCF` 未变，结果与记录时一致。
- **非周期零回归**：稳定（3 年）、温和（5 年）、成长否决（5 年）路径的判定规则、窗口、方式、文案不变；唯一有意的变化是「周期状态未知且可用 >5 年」时由 10 年降为 5 年（FR-1）。

## 2. 总体架构

### 2.1 分层与调用链（不变）

```
api 层
  GET /api/stock/:code/ai-analysis       GET /api/stock/:code/valuation
        │                                      │
        ▼                                      ▼
service.RecommendValuation              service.ComputeValuation
  ├─ annualRows / 基期年                    ├─ selectBaseFCF(mode, years)
  ├─ fcfYears = 最近 ≤10 年                 └─ DCF
  ├─ detectFCFCycle（≤10 年，不变）
  ├─ recommendBaseFCF ← R25 唯一改动点
  ├─ selectBaseFCF(mode, years) 取实际值
  └─ 派生 FCFWindow / CapexCheck / FCFProfitCheck / FCFSeries
        │
        ▼
model.ValuationRecommendation / AIValuation（JSON / 缓存）
```

- 所有改动仍在 `internal/service` 的纯函数内：无 IO、无随机、无时间依赖、无新增依赖。
- `recommendBaseFCF` 只读取 `fcfByYear`、`years`、`cycle`，**不写回** `cycle`；`RecommendValuation` 在调用前后使用的 `cycle` 是同一个值，因此 `FCFCyclical`、`FCFCV`、`FCFSignChanges`、`isCyclical`、β、终值、历史锚逐字段不变。
- `recommendBaseFCF` 的新守卫会调用同包的 `selectBaseFCF`（纯函数），用于保证「推荐值 = DCF 侧复算值」；不跨层、不引入 client。

### 2.2 `recommendBaseFCF` 新分支顺序

```
available = len(years)
  ├─ available == 0 → latest（无数据）
  ├─ cycle.Cyclical || recoveryEligible
  │     ├─ n = 3（复苏加速）或 5（否则），再与 available 取小
  │     ├─ n < 3 → latest（可用年度不足）
  │     ├─ 窗口全非正 → latest（均为非正）
  │     ├─ trimMean(n) > 0 → trim_mean / n
  │     ├─ latest > 0 → latest（多年度结果非正）
  │     └─ latest ≤ 0 → latest（最近一年非正）
  └─ 通用路径（非周期、非复苏）
        ├─ m = min(available, fcfWindowYears(cycle), 5)
        ├─ m < 3 → latest（可用年度不足）
        ├─ 窗口全非正 → latest（均为非正）
        ├─ latest ≤ 0 → latest（最近一年非正）
        ├─ R4 逐年增长且可持续 → latest
        ├─ R6 最近一年明显偏高 → custom（取整后 <1 亿 → median）
        ├─ R7 逐年下滑 → latest
        ├─ R8 最近一年明显偏低 → median
        ├─ RF gSpread > 40 → median / N（N = 5，或含 ≥2 非正时 3）
        ├─ CV > 0.30 或 SignChanges ≥1 → median
        └─ 其余 → average / m
```

与旧实现的差异只有三处：

1. 周期分支从「`m = fcfWindowYears(cycle)`（10 年）」改为「3/5 年，先于通用守卫」。
2. 新增「复苏门」作为周期分支的并列触发条件。
3. 通用路径的 `m` 统一封顶 5 年，RF 的窗口可再缩到 3 年，且所有多年度结果增加非正回退守卫。

## 3. 数据模型

R25 不新增/删除/重命名任何 `model` 字段。继续使用：

### 3.2 字段语义不变，取值随窗口变化

| 字段 | 语义 | R25 变化 |
| --- | --- | --- |
| `fcf_mode` | 既有五模式之一 | 周期/复苏改为 `trim_mean`；RF 仍为 `median`；不加新模式 |
| `fcf_years` | 实际选取年数 N | 周期/复苏为 3 或 5；其他多年度 ≤5；latest/custom 仍省略 |

| `fcf_window_years`（内部） | `len(fcfYears)`，即可用序列长度 ≤10 | **不变**；不得与 `fcf_years` 混淆（FR-9） |
| `capex_check.window_*` | 与基期 FCF 同窗口 | 自动跟随新的 `usedYears` |
| `fcf_profit_check.window_*` | 与基期 FCF 同窗口 | 同上 |
| `fcf_cyclical/cv/sign_changes` | `detectFCFCycle` 输出 | **不变**（隔离约束 AC-6） |

| 经营活动现金流量净额 | 现金流量表 | `NETCASH_OPERATE`，`v0` 读取 | 元 |
| 保全性资本支出 | 现金流量表补充资料 | R3 `maintenanceCapex(cf)`（`analysis.go`，全项目唯一实现） | 元 |

### 4.2 窗口语义

| 窗口 | 长度 | 用途 | R25 是否变化 |
| --- | --- | --- | --- |
| `fcfYears` | 最近 ≤10 个年报 | 周期判定、`fcf_series`、手动选择上界 | 否 |
| `m`（通用自动路径） | `min(available, fcfWindowYears, 5)` | average/median 的自动聚合、custom 中枢 | **是**（封顶 5） |
| `n`（周期/复苏） | 3 或 5，再与 available 取小 | `trim_mean` | **是**（原 10） |
| `N`（RF） | `min(m,5)`；`N=5` 且近 5 年非正 ≥2 → `min(3,available)` | `median` | **是**（原 10） |
| `usedYears` | `selectBaseFCF` 实际返回 | `fcf_window_*` / Capex / FCF-NP 校验 | 自动跟随 |
| `fcf_series` | 最近 ≤10 年 | 前端展示 | 否 |

### 4.3 单位与精度

- `fcfByYear` 全流程为「元」；样本验收值以「亿元」给出，测试中统一 `× 1e8`，容差 ±0.01 亿元（`1e6` 元）。
- 聚合全部用 `float64`；`selectBaseFCF` 的 `trim_mean` 与 `median` 不额外取整。
- 对外输出 `round2`（元，保留 2 位小数）沿用现状；`FCFBaseValue` 与 `FCFProfitCheck.FCF` 使用同一个 `round2(baseFCF)`，保证卡片与校验分子一致（`:420–421`）。
- 不输出 NaN/Inf：所有除法前均有非空/非零守卫；`meanOf` 空切片返回 0，`medianOf` 空切片返回 0，`spread` 少于 2 点返回 0。

### 4.4 字段易错提醒（沿用项目既有结论）

- 现金流量表经营现金流是 `NETCASH_OPERATE`；利润表营业总收入是 `TOTAL_OPERATE_INCOME`，没有 `OPERATE_INCOME` / `NETPROFIT`。
- 保全性资本支出必须走 `maintenanceCapex(cf)`，不要回填利润表减值字段，也不要重复计 `OILGAS_BIOLOGY_DEPR`（已含于 `FA_IR_DEPR`）。
- `fcf_years` 是「实际选取年数」，`fcf_window_years` 是「可用序列长度（≤10）」，两者不可混用。
- `fcf_growth_points` 只对「上一年 FCF > 0」的年度计算同比；单个坏年会放大极差，这是 RF 的触发来源，本次不改该口径。

## 6. 核心实现细节

### 6.1 关键不变量与零回归证明

在 `RecommendValuation` 中，`cycle = detectFCFCycle(fcfByYear, fcfYears, gp)` 与 `recommendBaseFCF(fcfByYear, fcfYears, cycle)` 使用**同一个** `fcfYears`（最近 ≤10 年）。因此：

1. **`recoveryEligible ⇒ !cycle.Evaluated`**：`detectFCFCycle` 的 `Evaluated = m>=3 && mean10>0`；复苏门要求 `mean10<=0`。两者互斥。
2. **`cycle.GrowthVeto ⇒ cycle.Evaluated`**：`GrowthVeto = RawCyclical && gp.Veto`，而 `RawCyclical` 以 `Evaluated` 为前提。因此成长否决不会被复苏门抢走。
3. **稳定/温和路径 `⇒ cycle.Evaluated`**：两者都以 `Evaluated=true` 为前提。因此它们的 `fcfWindowYears` 仍为 3/5，且不会进入复苏分支。
4. 结论：复苏门只可能在 `!cycle.Evaluated` 时命中；非周期稳定/温和/成长否决路径的代码分支、窗口与方式完全不变（FR-8 零回归）。
5. `cycle.Cyclical=true` 时直接进入周期分支，与复苏门无关；`detectFCFCycle` 不被修改，`cycle` 的所有字段原样输出到 `FCFCyclical/FCFCV/FCFSignChanges`。

补充推论（写入测试与已知限制）：

- 复苏门要求 `mean5>0` 且 `mean10<=0`。当 `available<=5` 时，`mean5` 与 `mean10` 是同一个窗口（全部可用年），不可能同时满足 `>0` 与 `<=0`。因此**复苏门实际只在 `available>=6` 时可能命中**。需求中的 `available>=3` 是必要守卫，但 3–5 年数据不会触发复苏路径；这是数学结果，不是实现遗漏。

### 6.2 新增辅助函数

```go
// fcfRecentWindow 取 years 末尾 n 个年报及对应 FCF 值（升序）。
// n<=0 或 years 为空时返回 nil；n 超过可用年数时取全部。
func fcfRecentWindow(fcfByYear map[int]float64, years []int, n int) ([]int, []float64) {
	if n <= 0 || len(years) == 0 {
		return nil, nil
	}
	if n > len(years) {
		n = len(years)
	}
	win := years[len(years)-n:]
	vals := make([]float64, len(win))
	for i, y := range win {
		vals[i] = fcfByYear[y]
	}
	return win, vals
}

func meanOf(vals []float64) float64 {
	if len(vals) == 0 {
		return 0
	}
	sum := 0.0
	for _, v := range vals {
		sum += v
	}
	return sum / float64(len(vals))
}

func countNonPositive(vals []float64) int {
	n := 0
	for _, v := range vals {
		if v <= 0 {
			n++
		}
	}
	return n
}

// positiveMedianOf 正值中位数；无正值时 ok=false。
func positiveMedianOf(vals []float64) (float64, bool) {
	pos := positiveValues(vals)
	if len(pos) == 0 {
		return 0, false
	}
	return medianOf(pos), true
}

// fcfRecoveryEligible R25 FR-3：深亏后复苏的可评估门。
// available>=3 && mean(最近<=5)>0 && latest>0 && mean(最近<=10)<=0。
// 只读 FCF 序列，不写回 cycle（Q1）。
func fcfRecoveryEligible(fcfByYear map[int]float64, years []int) bool {
	if len(years) < valFCFRecMinYears {
		return false
	}
	_, recent := fcfRecentWindow(fcfByYear, years, valFCFRecoveryLookback)
	_, long := fcfRecentWindow(fcfByYear, years, valCycleWindowYears)
	return meanOf(recent) > 0 && recent[len(recent)-1] > 0 && meanOf(long) <= 0
}

// fcfRecoveryAccelerating R25 FR-2：最近一年高于上一年且高于近 5 年正值中位数。
func fcfRecoveryAccelerating(fcfByYear map[int]float64, years []int) bool {
	if len(years) < 2 {
		return false
	}
	latest := fcfByYear[years[len(years)-1]]
	prev := fcfByYear[years[len(years)-2]]
	if latest <= 0 || prev <= 0 || latest <= prev {
		return false
	}
	_, recent := fcfRecentWindow(fcfByYear, years, valFCFRecoveryLookback)
	pm, ok := positiveMedianOf(recent)
	return ok && latest > pm
}

// fcfRecoveryWindowYears 周期/复苏路径窗口：加速 3 年，否则 5 年。
// 调用方再与可用年数取小（FR-1）。
func fcfRecoveryWindowYears(fcfByYear map[int]float64, years []int) int {
	if fcfRecoveryAccelerating(fcfByYear, years) {
		return valFCFRecoveryAccelYears
	}
	return valFCFRecoveryYears
}

// fcfRecMultiYearGuard R25 FR-5 第 4 条：
// 多年度聚合结果 <=0 且 latest>0 时退回最近一年。
// 用 selectBaseFCF 复算，保证推荐 (mode, years) 与 DCF 侧完全一致。
func fcfRecMultiYearGuard(rec fcfRecommendation, fcfByYear map[int]float64, years []int) fcfRecommendation {
	if len(years) == 0 {
		return rec
	}
	switch rec.Mode {
	case valFCFAverage, valFCFMedian, valFCFTrimMean:
	default:
		return rec
	}
	v, _, _, err := selectBaseFCF(fcfByYear, years, rec.Mode, rec.Years, 0)
	if err != nil || v > 0 {
		return rec
	}
	if latest := fcfByYear[years[len(years)-1]]; latest > 0 {
		return fcfRecLatest("多年度结果非正，退回最近一年。")
	}
	return rec
}
```

说明：

- `fcfRecoveryEligible` 中 `recent` 长度至少为 3（`len(years)>=3`），`recent[len-1]` 安全。
- `fcfRecoveryAccelerating` 的 `prev` 取「上一年报」，与 `years` 的升序年报序列一致；不要求年份连续。
- `fcfRecMultiYearGuard` 只对 average/median/trim_mean 生效；custom 结果由构造保证 `>0`，其兜底 median 已被守卫覆盖。

### 6.3 `recommendBaseFCF` 完整实现

```go
// recommendBaseFCF 按序命中的规则主体。
// R25：周期/复苏 3–5 年自适应 trim_mean；自动多年度窗口全局封顶 5 年；
// RF 取近期中位数；多年度结果为非正且最近一年为正时退回最近一年。
func recommendBaseFCF(fcfByYear map[int]float64, years []int, cycle fcfCycle) fcfRecommendation {
	available := len(years)
	if available == 0 {
		return fcfRecLatest("无可用经营自由现金流数据，退回最近一年。")
	}
	latest := fcfByYear[years[available-1]]

	// R25 FR-2/FR-3：周期股与深亏后复苏共用 3/5 年自适应 trim_mean。
	// 复苏门只读 FCF 序列，不写回 cycle（Q1）；mean10<=0 与 cycle.Evaluated=true 互斥，
	// 因此稳定/温和/成长否决路径不会进入本分支（FR-8 零回归）。
	if cycle.Cyclical || fcfRecoveryEligible(fcfByYear, years) {
		n := fcfRecoveryWindowYears(fcfByYear, years)
		if n > available {
			n = available
		}
		if n < valFCFRecMinYears {
			return fcfRecLatest("可用年度不足，退回最近一年。")
		}
		win, vals := fcfRecentWindow(fcfByYear, years, n)
		if allNonPositive(vals) {
			return fcfRecLatest("近年经营自由现金流均为非正，退回最近一年。")
		}
		if trim := trimMeanOf(vals); trim > 0 {
			rationale := fmt.Sprintf("近 %d 年去极值平均。", len(win))
			if len(win) == valFCFRecoveryAccelYears {
				rationale = "近 3 年复苏窗口去极值平均。"
			}
			return fcfRecommendation{
				Mode: valFCFTrimMean, ModeName: valFCFModeNames[valFCFTrimMean], Years: len(win),
				Rationale: rationale,
			}
		}
		// FR-2：trimMean<=0 时一律退回最近一年，不再落入通用多年度规则。
		if latest > 0 {
			return fcfRecLatest("多年度结果非正，退回最近一年。")
		}
		return fcfRecLatest("最近一年经营自由现金流为非正，退回最近一年。")
	}

	// R25 FR-1：自动多年度窗口全局封顶 5 年；fcfWindowYears 的 10 年只作名义上界。
	m := available
	if w := fcfWindowYears(cycle); w < m {
		m = w
	}
	if m > valFCFAutoMaxYears {
		m = valFCFAutoMaxYears
	}
	if m < valFCFRecMinYears {
		return fcfRecLatest("可用年度不足，退回最近一年。")
	}
	win, vals := fcfRecentWindow(fcfByYear, years, m)
	if allNonPositive(vals) {
		return fcfRecLatest("近年经营自由现金流均为非正，退回最近一年。")
	}

	median := medianOf(vals)
	if latest <= 0 {
		return fcfRecLatest("最近一年经营自由现金流为非正，退回最近一年。")
	}

	growth := fcfGrowthPoints(fcfByYear, win)
	gSpread := spread(growth)
	gMedian := medianOf(growth)

	if allPositive(vals) && monotoneUp(vals) && gSpread <= valFCFGrowthSpread && latest <= valFCFHighRatio*median {
		return fcfRecLatest("近年现金流逐年增长且增速可持续，取最近一年。")
	}

	high := latest > valFCFHighRatio*median
	if high && (gMedian < 0 || gSpread > valFCFGrowthSpread) {
		center := medianOf(positiveValues(vals))
		gS := clampFloat(gMedian, 0, valFCFCustomGrowthCap)
		disp := math.Round(center * (1 + gS/100) / 1e8)
		if disp > 0 {
			return fcfRecommendation{
				Mode: valFCFCustom, ModeName: valFCFModeNames[valFCFCustom],
				CustomYuan: disp * 1e8, CustomUnit: "yi",
				Rationale: "最近一年明显高于多年中枢，按可持续中枢下调。",
			}
		}
		return fcfRecMultiYearGuard(fcfRecMedian(win, "可持续中枢不足 1 亿元，退回中位数。"), fcfByYear, years)
	}

	if monotoneDown(vals) {
		return fcfRecLatest("经营自由现金流逐年下滑，取最近一年。")
	}
	if latest < valFCFLowRatio*median {
		return fcfRecMultiYearGuard(fcfRecMedian(win, "最近一年明显低于多年中枢，取中位数。"), fcfByYear, years)
	}
	if gSpread > valFCFGrowthSpread {
		n := m
		if n == valFCFAutoMaxYears {
			_, rfVals := fcfRecentWindow(fcfByYear, years, valFCFAutoMaxYears)
			if countNonPositive(rfVals) >= valFCFRFNonPositiveYears {
				n = valFCFRecoveryAccelYears
			}
		}
		if n < valFCFRecMinYears {
			return fcfRecLatest("可用年度不足，退回最近一年。")
		}
		rfWin, _ := fcfRecentWindow(fcfByYear, years, n)
		rec := fcfRecMedian(rfWin, fmt.Sprintf("增速波动较大，取近 %d 年中位数。", n))
		return fcfRecMultiYearGuard(rec, fcfByYear, years)
	}
	if cycle.CV > valFCVMildThreshold || cycle.SignChanges >= 1 {
		return fcfRecMultiYearGuard(withCycleNote(fcfRecMedian(win, "波动较大，取中位数。"), cycle), fcfByYear, years)
	}
	return fcfRecMultiYearGuard(withCycleNote(fcfRecommendation{
		Mode: valFCFAverage, ModeName: valFCFModeNames[valFCFAverage], Years: m,
		Rationale: "近年现金流总体平稳，取平均值。",
	}, cycle), fcfByYear, years)
}
```

### 6.4 周期/复苏分支的命中与回退表

| 场景 | 判定 | 结果 |
| --- | --- | --- |
| `cycle.Cyclical=true`，加速 | `latest>0 && prev>0 && latest>prev && latest>positiveMedian5` | `trim_mean / min(3,available)` |
| `cycle.Cyclical=true`，非加速 | 其余 | `trim_mean / min(5,available)`（可用 4 年 → 4） |
| `cycle.Cyclical=true`，`trimMean>0` 且 `latest<=0` | FR-2 先于最近一年非正守卫 | 仍返回 `trim_mean`（保留旧顺序） |
| `cycle.Cyclical=true`，`trimMean<=0` | — | `latest`（`latest>0` 时为「多年度结果非正」，否则「最近一年非正」） |
| `!cycle.Cyclical`，复苏门命中 | `available>=3 && mean5>0 && latest>0 && mean10<=0` | 同上，按加速 3/5 年 `trim_mean` |
| 复苏门未命中，`available<3` | — | `latest`（可用年度不足） |
| 复苏门未命中，窗口全非正 | — | `latest`（均为非正） |

关键点：

- 周期/复苏分支**先于** `latest<=0` 守卫；只有 `trimMean<=0` 才回退，与现行 RA「周期股先于最近一年非正守卫」一致。
- 周期分支的 `n` 先与 `available` 取小；因此 4 年可用时非加速为 4 年（FR-2 的「不足 5 年取全部可用」），加速为 3 年。
- 复苏门不检查 `cycle.Cyclical=false` 之外的字段，也不修改 `cycle`；`RecommendValuation` 后续的 `FCFCyclical/FCFCV/FCFSignChanges` 仍直接取 `cycle` 原值。

### 6.5 RF（波动大）收缩算法

进入 RF 分支时，`m` 已由 FR-1 封顶为 `≤5`，因此：

```text
N = m                          // 等价于 min(m, 5)
if N == 5:
    if countNonPositive(最近 5 年) >= 2:
        N = min(3, available)
if N < 3: 退回 latest           // 实际不会发生，m>=3
返回 median / N
```

| 场景 | 旧行为 | R25 行为 |
| --- | --- | --- |
| `!Evaluated`，可用 10 年，`gSpread>40` | `median / 10` | `median / 5`（近 5 年非正 <2） |
| 同上，近 5 年非正 ≥2 | `median / 10` | `median / 3` |
| 稳定股 3 年窗口，`gSpread>40` | `median / 3` | `median / 3`（不被拉长到 5） |
| 温和/成长否决 5 年窗口 | `median / 5` | `median / 5` |
| 4 年可用（`Evaluated=false`），`gSpread>40` | `median / 4` | `median / 4`（`N!=5` 不收缩） |

补充：

- 只有 `N==5` 时才检查非正年数；这是需求 FR-4 的字面规则，避免把 4 年窗口再缩到 3 年。
- RF 结果若非正且 `latest>0`，由 `fcfRecMultiYearGuard` 退回 `latest`（FR-5 第 4 条）。
- `fcfGrowthPoints` 与 40pp 阈值不改；单个坏年仍会触发 RF，只是触发后的窗口改为近期。

### 6.6 全局 5 年封顶的影响面

`m = min(available, fcfWindowYears(cycle), 5)`：

| `cycle` 状态 | `fcfWindowYears` | 旧实际窗口 | R25 实际窗口 | 是否变化 |
| --- | --- | --- | --- | --- |
| `Evaluated=true, Cyclical=false, CV<=0.30` | 3 | 3 | 3 | 否 |
| `Evaluated=true, Cyclical=false, 0.30<CV<=0.50` | 5 | 5 | 5 | 否 |
| `Evaluated=true, RawCyclical=true, GrowthVeto=true` | 5 | 5 | 5 | 否 |
| `Evaluated=true, Cyclical=true` | 10 | 10 | 周期分支 3/5 | **是**（FR-2） |
| `Evaluated=false`，复苏门未命中 | 10 | 10 | `min(available,5)` | **是**（FR-1） |
| `Evaluated=false`，复苏门命中 | 10 | 10 | 3/5 `trim_mean` | **是**（FR-3） |
| `available<5`（任意非周期） | 3/5/10 | `min(available, w)` | `min(available, w, 5)` | 否（本来就 ≤available） |
| `available=4`（`!Evaluated`） | 10 | 4 | 4 | 否 |
| `available>=6`（`!Evaluated`） | 10 | 6..10 | 5 | **是** |

- `custom` 不涉及「Years」输出，但其 `center` 由 `vals`（已封顶 5 年）计算；这是本设计的默认约定（见文首第 4 条）。
- `latest` 路径不受封顶影响。
- `fcf_series`、`FCFWindowYears`、`detectFCFCycle` 的 10 年窗口不受影响。

### 6.7 FR-5 非正回退守卫

守卫顺序（与需求一致）：

1. `available == 0` → `latest`（无数据）。
2. 选定窗口全非正 → `latest`（「近年经营自由现金流均为非正」）。
3. 未命中周期/复苏分支且 `latest <= 0` → `latest`（「最近一年经营自由现金流为非正」）。
4. 未命中周期/复苏分支，多年度结果 `<=0` 且 `latest > 0` → `latest`（「多年度结果非正，退回最近一年」）。
5. `custom` 中枢取整后 <1 亿元 → 退回 `median`；若 `median` 也非正，由第 4 条兜底。

第 4 条只通过 `fcfRecMultiYearGuard` 实现，覆盖：

- `latest < 0.7*median` 的 median 结果；
- RF 的 median/3 或 median/5 结果；
- CV 分支的 median 结果；
- 兜底 average 结果；
- custom 中枢不足 1 亿元时的 median 兜底。

不覆盖：

- 周期/复苏分支的 `trim_mean>0`（优先返回，符合 FR-2）；
- 周期/复苏分支 `trimMean<=0` 的 `latest`（已直接回退）；
- `latest` 路径本身。

### 6.10 边界与 nil 处理

| 场景 | 行为 |
| --- | --- |
| `years == nil` / 空 | `latest`，理由「无可用经营自由现金流数据」。 |
| 可用 <3 年 | `latest`，理由「可用年度不足」。 |
| 窗口全非正 | `latest`，理由「近年经营自由现金流均为非正」。 |
| 未被周期/复苏命中且 `latest<=0` | `latest`（负值），DCF 判不适用。 |
| 周期/复苏 `trimMean>0` 且 `latest<=0` | 返回 `trim_mean`（有意保留旧顺序）。 |
| 周期/复苏 `trimMean<=0`、`latest>0` | `latest`，理由「多年度结果非正」。 |
| 多年度结果 `<=0`、`latest>0` | 守卫退回 `latest`。 |
| `available=4`，非周期未知 | 窗口 4 年（不封顶到 3）。 |
| `available=5`，非周期未知 | 窗口 5 年（旧为 5，本就未超上限）。 |
| `available>=6`，非周期未知 | 窗口 5 年（旧为 available）。 |
| RF 且 `N=5`、非正 ≥2 | 窗口 3 年；结果非正再退回 `latest`。 |
| RF 且 `m=4` | 窗口 4 年，不收缩。 |
| `positiveMedian5` 无正值 | 加速判定为 false（但 `latest>0` 时必有正值，实际不会发生）。 |
| `mean5/mean10` 窗口为空 | `meanOf` 返回 0；调用前已保证 `available>=3`。 |
| 浮点 NaN/Inf | 无除法分母为 0；`spread` 空/单点返回 0；不输出 NaN/Inf。 |

### 6.11 确定性与性能

- 所有判定只依赖 `fcfByYear` 与 `years`，无随机数、当前时间、AI 输出。
- 窗口 ≤10，排序/遍历 O(10)；新增 helper 均为常数级；无新增 IO、网络、AI token。
- `fcfRecMultiYearGuard` 额外调用一次 `selectBaseFCF`（O(N)），N≤10，可忽略。
- 同一输入连续调用结果逐字段相同（`fcfRecommendation` 可比较；`selectBaseFCF` 纯函数）。

## 11. 风险、限制与回滚

### 11.1 已知限制

- **借壳/重组年无法显式剔除**：重组完成不足 5 年的公司，5 年窗口仍可能包含重组前年度；不足 3 年则退回 `latest`。
- **5 年封顶对超长周期不友好**：真实周期 >5 年的行业可能只覆盖半个周期；本次以消除 10 年历史包袱优先。
- **3 年 `trim_mean` 等价中位数**：结果偏保守，不取 3 年平均；需求已接受。
- **复苏门实际要求 ≥6 年数据**：3–5 年数据下 mean5 与 mean10 同窗，`mean5>0 && mean10<=0` 不可能成立；深亏公司若只有 5 年数据，仍走常规规则。
- **中孚实业仍低于现价**：按 6.09 亿粗算每股约 2.8–3.0 元，低于现价 5.53 元；剩余差距来自 FCF 口径与折现/增长假设，不在本次范围。
- **`mean5<=0` 的深亏公司不会变好**：短窗口无法凭空造出正 FCF，最终可能退回 `latest`，DCF 仍可能不适用。
- **最近 5 年全非正的公司失去 10 年前正值支撑**：按 FR-5 退回最新一年（可能为负），DCF 判不适用；这是「不向后看 10 年」的必然结果。
- **RF 根因未修**：单个坏年仍会产生 −300% 级离群同比；本次只改触发后的窗口。

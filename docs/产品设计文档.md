# 产品设计文档：A股财报分析工具

> 版本：v0.5（已合并产品设计 + 需求，作为统一 PRD）
> 关联文档：技术设计文档、公司财务指标分析、公司股票估值

## 1. 产品定位

面向个人投资者的 A 股财报分析工具：输入股票代码，自动获取财报数据并计算分析指标，以清晰的可视化页面呈现单只股票的财务与估值全貌。

## 2. 目标用户与使用场景

- **目标用户**：个人投资者（当前仅个人使用，无需账号体系、多用户、权限管理）。
- **核心场景**：单股深度分析 —— 输入一只 A 股代码，查看其指标数值与三大报表，辅助投资决策。

## 3. 核心问题与价值

- **痛点**：财报数据分散、手动查找与计算指标繁琐且口径易不一致。
- **价值**：一站式完成「拉取财报数据 → 计算指标 → 可视化呈现」，省时且口径统一。

## 5. R1：单股指标分析

### 5.1 功能

| 功能 | 说明 |
| --- | --- |
| 股票查询 | 输入 A 股代码/名称，识别并加载目标股票 |
| 数据获取 | 自动获取三张报表（资产负债表、利润表、现金流量表）+ 行情数据 |
| 指标计算 | 计算常见估值指标（占位方案，见 5.3） |
| 结果展示 | 单页呈现指标表 |

### 5.2 核心用户流程

1. 用户输入股票代码
2. 系统拉取财报 + 行情数据
3. 计算分析指标
4. 页面展示指标表

### 5.3 分析指标（占位实现）

> 当前为占位方案，待用户给定正式分析方法与指标后替换。

当前实现：

- 总市值
- 市盈率 PE（静态，按最新年报）
- 市净率 PB
- ROE
- 毛利率、净利率
- 资产负债率
- 每股收益 EPS、每股净资产 BPS

### 5.4 边界（明确不做）

- PDF 财报上传 / OCR 解析
- 多用户、账号、权限体系
- 数据持久化 / 数据库（数据实时拉取即可）
- 批量筛选、横向对比
- 实时行情推送

## 6. R2：三大报表浏览与同比分析

### 6.1 背景与目标

R1 只展示计算后的指标，用户无法查看原始财报科目。本需求提供三大报表的原始数据浏览，支持按年份范围筛选（仅年报），并展示各科目相对上一年的同比增长率。

### 6.2 功能点

#### F1 三大报表数据展示
- 展示资产负债表、利润表、现金流量表的**全部财务科目**（排除接口返回的元数据与派生比例字段，如代码、名称、日期、`*_RATIO` 等）。
- 三张表用 Tab 页签切换展示。

#### F2 年份范围筛选
- 用户选择起始年份与结束年份，仅展示该范围内的年报（报告期以 `12-31` 结尾）。
- 默认展示最近 5 个年报，可调整。

#### F3 同比上年增长率
- 对每个数值科目计算相对上一年的增长率：`(当年 − 上年) / 上年 × 100%`。
- 展示时各年数值旁标注同比（红涨绿跌）。
- 范围内最早年份无上年数据，不显示同比。

#### F4 页面归属
- 与 R1 共用同一页面：顶部搜索框，下方依次为指标区（R1）与三大报表区（R2）。

### 6.3 展示形态（示意）

```
利润表                    2021      2022      2023      2024
营业总收入(亿)            1275.5    1505.6    1741.4    1720.5
  同比                       —      +18.0%    +15.7%     -1.2%
归母净利润(亿)             627.2     747.3     862.3     823.2
  同比                       —      +19.1%    +15.4%     -4.5%
```

### 6.4 科目范围

展示三大报表的**全部财务科目**。接口（东财 datacenter `columns=ALL`）返回内容包含三类字段，需在展示前过滤：

1. 财务科目（展示）：如 `TOTAL_ASSETS`、`OPERATE_COST`、`NETCASH_OPERATE` 等。
2. 元数据（排除）：代码、名称、行业、报告期、公告日期、报告类型等。
3. 派生比例（排除）：如 `DEBT_ASSET_RATIO`、`*_RATIO` 等。

### 6.5 边界与规则

- 同比计算：上年值为 `0` → 显示「—」；上年值为负 → 增长率符号失真，仅显示数值、不显示百分比。
- 所选年份范围无数据（如超出上市年限）→ 返回空并提示。
- 数据来源复用现有东财 datacenter 接口（三张表，年报过滤逻辑同 R1）。

### 6.6 验收标准

1. 输入股票代码后，可查看三张报表的全部财务科目数据。
2. 选择任意年份范围，仅显示对应年报数据。
3. 每个科目正确展示同比上年增长率。
4. 边界情况（上期为 0/负、缺年份）不报错，并有合理提示。

### 6.7 已确认决策

- 科目范围：**全科目**
- 同比展示：**数值旁标注**
- 三张表布局：**Tab 切换**
- 页面归属：**与 R1 共用页面**

## 7. R3：六维财务指标分析

### 7.1 背景与目标

依据《公司财务指标分析》文档，从六个维度对公司做结构化分析，输出**派生指标 + 解读**，把「报表数据」转化为「投资判断」。六大维度均已实现：「投资活动现金流分析」「筹资活动现金流分析」「资产资本分析」「股权价值增加值分析」「股东权益回报分析」「经营活动现金流分析」。

### 7.2 六大维度

| # | 维度 | 状态 |
| --- | --- | --- |
| 1 | 投资活动现金流分析 | ✅ 已实现 |
| 2 | 筹资活动现金流分析 | ✅ 已实现 |
| 3 | 资产资本分析 | ✅ 已实现 |
| 4 | 股权价值增加值分析 | ✅ 已实现 |
| 5 | 股东权益回报分析 | ✅ 已实现 |
| 6 | 经营活动现金流分析 | ✅ 已实现 |

### 7.3 投资活动现金流分析（已实现）

基于**选定年份范围**（默认最近 5 个年报），提炼核心指标输出（不展示原始现金流科目明细与计算公式）：

1. **购建和处置长期经营资产**：长期经营资产净投资额、保全性资本支出、扩张性资本支出、扩张性资本支出比例。
2. **取得和处置子公司（并购）**：并购活动净合并额。
3. **战略投资活动规模扩张**：战略投资活动的总体规模扩张。

### 7.4 筹资活动现金流分析（已实现）

基于**选定年份范围**（默认最近 5 个年报），提炼核心指标输出（不展示原始现金流科目明细与计算公式）：

1. **现金供给及投资需求分析**：战略投资活动综合现金需求、现金自给率。
2. **外源性筹资分析**：筹资需求、股东筹资净额、债务筹资净额。
3. **资本成本分析**：债务资本成本、加权平均资本成本（WACC）。

### 7.5 资产资本分析（已实现）

基于**选定年份范围**（默认最近 5 个年报），按《公司财务指标分析》文档的「标准资产负债表的重新归类划分」，把资产负债表重构为资产资本表并计算占比与融资结构指标（不展示原始科目与计算公式）：

1. **资产结构**：金融资产、经营资产（=周转性经营投入+长期经营资产）、周转性经营投入（=营运资产−营运负债）、营运资产、营运负债、长期经营资产、长期股权投资、资产合计。
2. **资本结构**：短期债务、长期债务、有息债务、股东权益、资本合计。
3. **资产资本占比**：金融资产/营运资产/营运负债/周转性经营投入/长期经营资产/长期股权投资占比，短期/长期资产占比，短期/长期资本占比，有息债务占比，股权占比。
4. **融资结构与流动性**：财务杠杆倍数、长期融资净额、短期融资净额、周转性经营长期化率。

> 重分类为近似口径：自由裁量科目（其他应收款、一年内到期的非流动资产、其他应付款、预计负债）无法区分时一律归入经营资产（营运资产/营运负债），当其占总资产比例过大（>10%）时在该维度顶部给出提示、供人工核实；未分类科目差额并入营运资产/营运负债以保证「资产合计 = 资本合计」恒成立；递延所得税资产计入长期经营资产、递延所得税负债计入营运负债；金融资产递延所得税调整需附注明细、暂不计入。

### 7.6 股权价值增加值分析（已实现）

基于**选定年份范围**（默认最近 5 个年报），按《公司财务指标分析》文档「四 股权价值增加分析」把利润表按资产/资本来源重构为**股权价值增加表**，输出各来源的收益、真实财务费用、净利润及**股权价值增加值**（不展示原始科目与计算公式）：

1. **经营利润**：营业收入、营业成本、营业成本率、毛利、毛利率、税金及附加、税金及附加率、销售费用、销售费用率、管理费用、管理费用率、研发费用、研发费用率、资产减值损失、信用减值损失、资产减值损失率、资产处置收益、其他收益、营业外收入、营业外支出、营业外收支及其他占营业收入比例、总费用率、息税前经营利润。
2. **金融资产收益**：息税前金融资产收益，及其构成——短期投资收益、利息收入、净敞口套期收益、公允价值变动净收益、汇兑净收益、其他综合收益。
3. **长期股权投资收益**：对联营企业和合营企业的投资收益。
4. **利润汇总与所得税**：息税前利润总额、真实财务费用、财务费用抵税效应、税后真实财务费用、税前利润、所得税费用、实际所得税税率、净利润。
5. **息前税后利润与财务成本**：经营利润所得税、息前税后经营利润、金融资产收益所得税、息前税后金融资产收益、息前税后利润总额、息前税后营业收入利润率、财务成本负担率、债务资本成本率。
6. **股权价值增加值**：股权资本成本、股权价值增加值（=净利润 − 股权资本成本）。

> 重构为近似口径：资产减值损失/信用减值损失全部归经营（不细分金融/长投，文档特别说明许可）；净敞口套期收益按文档计入金融资产收益；其他综合收益（税后净额）按统一实际所得税税率还原为税前后计入金融资产收益；利息收入取财务费用明细的利息收入（`FE_INTEREST_INCOME`，独立「利息收入」科目为财务公司放贷利息、已含于营业总收入），并用于还原真实财务费用（= 财务费用 + 利息收入）；净利润取重构口径（≈ 利润表净利润，含少数股东损益），与股东权益（`TOTAL_EQUITY`，含少数股东）口径一致；股权资本成本 = 股东权益 × 8%（股东预期回报率默认 8%）。

### 7.7 股东权益回报分析（已实现）

基于**选定年份范围**（默认最近 5 个年报），把资产资本表与股权价值增加表结合，输出股东回报、经营效率、财务杠杆、偿债能力与税负等综合指标（不展示原始科目与计算公式）：

1. **股东权益回报率分析**：股东权益回报率（ROE，= 净利润 ÷ 股东权益，杜邦五因素分解）。
2. **投资和经营活动的管理效率及盈利能力分析**：盈利能力——息税前资产回报率、息税前经营资产回报率（含息税前经营利润率子项）、长期股权投资收益率、金融资产收益率；管理效率——周转率（资产周转率、经营资产周转率（含长期经营资产/周转性经营投入周转率子项，其中长期经营资产周转率下含固定资产周转率、固定资产成新率）、应收账款/存货/应付账款周转率）与周期天数（营业周期、现金周期及应收账款/存货/应付账款周转天数）。
3. **财务杠杆效应分析**：财务成本效应比率、财务杠杆倍数、财务杠杆效应。
4. **债权人保障程度分析**：债务对股东权益比率、利息保障倍数。
5. **企业所得税效应分析**：企业所得税效应比率。

> 近似口径：资产总额取资产负债表总计（`TOTAL_ASSETS`，含全部负债，用于杜邦财务杠杆倍数 = 资产总额 ÷ 股东权益，区别于资产资本维度「资本合计 ÷ 股东权益」的有息债务口径）；经营资产 = 周转性经营投入 + 长期经营资产；周转率分母取对应资产，固定资产/存货/应收/应付账款用「(期初+期末)÷2」平均余额（上期缺失则无法计算）；应收账款净额 = 应收账款 + 应收票据 − 预收账款、应付账款净额 = 应付账款 + 应付票据 − 预付账款；销货成本/采购成本用营业成本替代、赊销收入净额用营业收入替代；周转天数 = 365 ÷ 周转率（计算期天数取 365）；利息保障倍数的「利息费用」取真实财务费用（= 财务费用 + 利息收入，与财务成本负担率口径一致）；固定资产成新率需固定资产原值（财报附注），免费接口不可得，指标保留但恒显示「—」。

> 无意义标注：指标某年因分母 ≤ 0、上期数据缺失、原值不可得等原因无法计算/无意义时，该年显示「—」，并在指标名旁用琥珀色 `!` 徽标标注原因（悬停/点击查看，如「2025 年真实财务费用≤0，未显示」）。

### 7.8 经营活动现金流分析（已实现）

基于**选定年份范围**（默认最近 5 个年报），把经营活动现金流量表与利润表结合，输出收入现金含量、成本付现、利润现金含量与净额等指标（不展示原始科目与计算公式）：

1. **营业收入现金含量分析**：营业收入现金含量。
2. **成本费用付现率分析**：成本费用付现率。
3. **经营利润现金含量分析**：息前税后经营利润现金含量、净利润现金含量。
4. **经营活动现金流量净额分析**：经营活动现金流量净额。

> 近似口径：增值税销项/进项税率需税务明细、免费接口不可得，营业收入现金含量与成本费用付现率采用**未剔除增值税**的简化口径（文档许可：能查到税率时优先用「÷(1+税率)」口径）；息前税后经营利润复用股权价值增加值维度的口径（息税前经营利润 × (1 − 实际所得税税率)）、净利润取重构口径（税前利润 − 所得税费用）；现金含量指标的利润分母 ≤ 0（亏损）时显示「—」。

### 7.9 展示形态

- 与 R1/R2 共用页面，新增「财务指标分析」卡片，六大维度以**横向 Tab 页签**呈现（与三大报表的 Tab 切换一致），一次只看一个维度，避免多维度同时展开时眼花。
- 卡片头部提供**年份范围选择**（起始年/结束年），变更后重新计算。
- 指标表按年展示：**指标（含解读）/ 各年份数值**，每个数值下方标注**同比上年增长率**（红涨绿跌，规则同 R2）。
- **指标趋势图**：每个指标行左侧提供趋势图图标，点击后弹出该指标的**柱状图 + 增速折线**（柱状=各年数值、折线=同比增速，双轴），tooltip 显示数值与增速；指标无数据时点击提示「该指标暂无数据」。
- 指标存在包含关系时（如「周转性经营投入」包含「营运资产/营运负债」，「有息债务」包含「短期债务/长期债务」），按**父项在前、子项缩进在后**的树形层级展示，而非平铺：子项（`sub`）名称左缩进并弱化显示，合计/净额（`subtotal`/`net`）加粗并加顶部分隔线，直观体现归属与勾稽关系。
- 默认选中第一个已实现维度；待补充维度显示「待补充」标签与提示；无年报数据显示「无年报数据」标签。

> 待优化（见《需求文档/指标趋势图移动端显示优化》）：移动端（≤768px）图例与轴名重叠、百分比单位只显示裸刻度、绘图区被挤压；该需求要求刻度标签自带单位后缀、图例随宽度自适应、移动端容器高度与边距收窄。

### 7.10 边界与规则

- 分析基准：**选定范围内的年报**（报告期以 `12-31` 结尾），年份升序；默认最近 5 个年报，最多支持 10 个年报。
- 同比规则复用 R2：范围内最早年无上年数据不显示；上年为 0 或负时仅显示数值不显示百分比。
- 全量报表接口对**金融股（银行/保险/券商）**采用不同报表口径，当前暂不支持，返回友好提示。
- 派生指标中，现金流量表主表科目无交易时（接口返回 null）按 **0** 处理，避免「无并购活动」被误判为「无数据」。
- 筹资维度需额外拉取**利润表全量接口**（所得税费用、利润总额、长期股权投资收益，用于税率；以及财务费用明细的利息支出，用于偿付利息）。（R10 起不再拉取分红送配接口，见 7.11。）
- 经营活动现金流分析复用**现金流量表 + 利润表全量接口**（无需资产负债表）；增值税销项/进项税率需税务明细、免费接口不可得，营业收入现金含量与成本费用付现率采用未剔除增值税的简化口径。
- 金融资产、有息债务为按文档归类表的重分类近似口径：金融资产取 19 个明确科目（含交易性金融资产新字段 `TRADE_FINASSET_NOTFVTPL`，及拆出资金、存放中央银行款项、结算备付金等财务公司类科目，金融资产递延所得税影响需附注明细、暂不计入）；有息债务 = 短期债务 12 科目（含吸收存款及同业存放、拆入资金、卖出回购、向央行借款等财务公司类）+ 长期债务 5 科目（含「其他非流动负债」），无该科目按 0 处理。
- 营运资产/营运负债同样为近似口径：营运资产取应收票据、应收账款、应收款项融资、预付款项、存货（含消耗性生物资产）、合同资产、其他流动资产、长期应收款 9 个核心科目；营运负债取应付票据、应付账款、预收款项、合同负债、应付手续费及佣金、应付职工薪酬、长期应付职工薪酬、应交税费、递延收益（流动+非流动）、其他流动负债、递延所得税负债 12 个核心科目。
- 自由裁量科目（其他应收款、一年内到期的非流动资产、其他应付款、预计负债）无法区分时一律归入营运；当其占总资产比例 >10% 时仍在维度顶部给出「重分类口径提示」，供人工核实。未分类科目差额（资产总计 − 已分类资产、负债总计 − 已分类负债）并入营运资产/营运负债，以保证「资产合计 = 资本合计」恒成立。递延所得税资产计入长期经营资产、递延所得税负债计入营运负债，其按附注的营运/金融/长期经营拆分暂不区分。

### 7.11 指标口径（对应《公司财务指标分析》文档）

**投资活动现金流分析**

- 保全性资本支出：为保持长期经营资产规模不变而必须支出的费用，暂以现金流量表补充资料的「折旧 + 摊销（含使用权资产摊销）+ 资产减值准备 + 固定资产报废损失」近似。
- 长期经营资产期初净额：期初经营规模与生产能力，取上期末长期经营资产合计（固定资产 + 在建工程 + 工程物资 + 固定资产清理 + 生产性生物资产 + 油气资产 + 使用权资产 + 无形资产 + 开发支出 + 商誉 + 长期待摊费用 + 其他非流动资产 + 递延所得税资产）。

**筹资活动现金流分析**

- 战略投资活动综合现金需求 = 长期经营资产净投资额 + 并购活动净合并额（净投资额含保全性＋扩张性资本支出，区别于投资维度「战略投资活动的总体规模扩张」只计扩张性资本支出）。
- 现金自给率 = 经营活动现金流量净额 ÷ 战略投资活动综合现金需求 × 100%（>100% 视为自给）。
- 筹资需求 = 期初金融资产 + 经营活动现金流量净额 − 战略投资活动综合现金需求。
- 股东筹资净额 = 吸收投资收到的现金 − 分配股利、利润支付的现金；债务筹资净额 = 借款+发债收到的现金 − 偿还债务+偿付利息支付的现金。
- 偿付利息支付现金 = 期初应付利息 + 当期利息支出 − 期末应付利息（**文档方法二，R10 起**；应付利息字段常年为空时按 0，退化为「= 当期利息支出」；当期利息支出取利润表财务费用明细的利息支出，口径为**费用化利息**近似）。相关指标在「利润表利息支出字段缺失」的年份显示「—」并标注原因。
- 债务资本成本 = 偿付利息支付现金 ÷ 平均有息债务余额 × 100%（平均有息债务 ≤ 0、偿付利息缺失或 ≤ 0 时显示「—」）；加权平均资本成本 = (有息债务/投入资本)×税后债务资本成本 + (股东权益/投入资本)×股权资本成本（默认 8%）。
- 实际所得税税率 = 所得税费用 ÷ (利润总额 − 长期股权投资收益)，缺失时回落 25%。

**资产资本分析**

- 周转性经营投入 = 营运资产 − 营运负债；营运资产/营运负债为核心科目 + 占比不过大的自由裁量科目（见 7.10 边界）。
- 经营资产 = 周转性经营投入 + 长期经营资产（资产资本表中「经营资产」这一层级）。
- 资产合计 = 金融资产 + 周转性经营投入 + 长期经营资产 + 长期股权投资；资本合计 = 有息债务 + 股东权益（`TOTAL_EQUITY`）；二者恒相等（未分类差额并入营运资产/营运负债）。
- 占比 = 各类资产（资本）÷ 资产合计（资本合计）× 100%；短期资产占比 = 金融资产占比 + 周转性经营投入占比；长期资产占比 = 长期经营资产占比 + 长期股权投资占比。
- 财务杠杆倍数 = 资本合计 ÷ 股东权益（倍）。
- 长期融资净额 = 长期债务 + 股东权益 − 长期经营资产 − 长期股权投资；为负表示「短融长投」（激进），接近零为匹配，为正为稳健。
- 短期融资净额 = 短期债务 − 金融资产 − 周转性经营投入。
- 周转性经营长期化率 =（股东权益 + 长期债务 − 长期经营资产 − 长期股权投资）÷ 周转性经营投入 × 100%；周转性经营投入 ≤ 0（营运负债 ≥ 营运资产）时该比率无意义，显示为「—」。

**股权价值增加值分析**

- 息税前经营利润 = 营业收入 − 营业成本 − 税金及附加 − 销售费用 − 管理费用 − 研发费用 − 资产减值损失 − 信用减值损失 + 资产处置收益 + 其他收益 + 营业外收入 − 营业外支出。
- 息税前金融资产收益 = 短期投资收益（投资收益 − 长期股权投资收益）+ 利息收入 + 净敞口套期收益 + 公允价值变动净收益 + 汇兑净收益 + 其他综合收益。其中**其他综合收益为税后净额，按统一实际所得税税率还原为税前**（= 税后其他综合收益 ÷ (1 − 税率)，近似口径，各分项实际税负可能不同）。
- 息税前利润总额 = 息税前经营利润 + 息税前金融资产收益 + 长期股权投资收益。
- 真实财务费用 = 财务费用 + 利息收入（利息收入在财务费用中被抵减，需还原为金融资产收益）。
- 财务费用抵税效应 = 真实财务费用 × 实际所得税税率；税后真实财务费用 = 真实财务费用 − 财务费用抵税效应 = 真实财务费用 × (1 − 实际所得税税率)。
- 税前利润 = 息税前利润总额 − 真实财务费用；净利润 = 税前利润 − 所得税费用（重构口径，≈ 利润表净利润；亦 = 息前税后利润总额 − 税后真实财务费用）。
- 经营利润所得税 = 息税前经营利润 × 实际所得税税率；金融资产收益所得税 = 息税前金融资产收益 × 实际所得税税率。
- 息前税后经营利润 = 息税前经营利润 × (1 − 实际所得税税率)；息前税后利润总额 = 息前税后经营利润 + 息前税后金融资产收益 + 长期股权投资收益（被投资企业已缴所得税，长投收益不再计税）。
- 各类比率（分母均为营业收入，为 0 时显示「—」）：营业成本率 = 营业成本 ÷ 营业收入；毛利率 = (营业收入 − 营业成本) ÷ 营业收入；税金及附加率 = 税金及附加 ÷ 营业收入；销售费用率 = 销售费用 ÷ 营业收入；管理费用率 = 管理费用 ÷ 营业收入；研发费用率 = 研发费用 ÷ 营业收入；资产减值损失率 = (资产减值损失 + 信用减值损失) ÷ 营业收入；营业外收支及其他占营业收入比例 = (资产处置收益 + 其他收益 + 营业外收入 − 营业外支出) ÷ 营业收入；总费用率 = (税金及附加 + 销售费用 + 管理费用 + 研发费用 + 资产减值损失 + 信用减值损失 − 营业外收支及其他) ÷ 营业收入。
- 息前税后营业收入利润率 = 息前税后经营利润 ÷ 营业收入 × 100%；财务成本负担率 = 真实财务费用 ÷ 息税前利润总额 × 100%。
- 债务资本成本率 = 真实财务费用 ÷ 平均有息债务余额 × 100%（平均有息债务 =（期初有息债务 + 期末有息债务）÷ 2）；无有息债务、上期缺失或真实财务费用 ≤ 0（净利息收入）时显示「—」。区别于筹资维度「偿付利息支付现金」的口径：此处分子为**真实财务费用**（`FINANCE_EXPENSE + FE_INTEREST_INCOME`，另含手续费、汇兑等财务费用项），筹资维度分子为财务费用明细的**利息支出**（`FE_INTEREST_EXPENSE`）。
- 实际所得税税率 = 所得税费用 ÷ (利润总额 − 长期股权投资收益) × 100%（同筹资维度，缺失回落 25%）。当某年基数 ≤ 0、所得税为负、或比率 > 100% 时，该年税率为失真值，数值不显示（显示「—」），并在指标旁标注原因（如威孚高科利润主要由联营/合营企业投资收益构成、基数过小）。
- 股权资本成本 = 股东权益 × 8%（股东预期回报率，**取期末股东权益**，用户确认）；股权价值增加值 = 净利润 − 股权资本成本，为正创造超预期回报、为负损毁价值。

**股东权益回报分析**

- 股东权益回报率 = 净利润 ÷ 股东权益 × 100%；杜邦分解 = 息税前资产回报率（息税前利润 ÷ 资产总额）× 财务成本效应比率（税前利润 ÷ 息税前利润）× 财务杠杆倍数（资产总额 ÷ 股东权益）× 企业所得税效应比率（净利润 ÷ 税前利润）。
- 息税前资产回报率 = 息税前利润 ÷ 资产总额 × 100%（全公司口径，杜邦四因素分解的首项）。
- 经营资产 = 周转性经营投入 + 长期经营资产；经营资产周转率 = 营业收入 ÷ 经营资产；长期经营资产周转率 = 营业收入 ÷ 长期经营资产；周转性经营投入周转率 = 营业收入 ÷ 周转性经营投入。
- 息税前经营资产回报率 = 息税前经营利润 ÷ 经营资产 × 100% = 息税前经营利润率 × 经营资产周转率；息税前经营利润率 = 息税前经营利润 ÷ 营业收入 × 100%（纯经营口径，区别于含金融/长投收益的息税前利润率）。
- 固定资产周转率 = 营业收入 ÷ 平均固定资产净值（期初/期末 `FIXED_ASSET` 平均）；固定资产成新率 = 平均固定资产净值 ÷ 平均固定资产原值，原值需财报附注、免费接口不可得，指标恒显示「—」。
- 应收账款周转率 = 营业收入 ÷ 平均应收账款净额（净额 = 应收账款 + 应收票据 − 预收账款）；存货周转率 = 营业成本 ÷ 平均存货余额；应付账款周转率 = 营业成本 ÷ 平均应付账款净额（净额 = 应付账款 + 应付票据 − 预付账款）。
- 周转天数 = 365 ÷ 周转率（计算期天数取 365）；营业周期 = 存货周转天数 + 应收账款周转天数；现金周期 = 营业周期 − 应付账款平均付账期。
- 长期股权投资收益率 = 长期股权投资收益 ÷ 长期股权投资 × 100%；金融资产收益率 = 息税前金融资产收益 ÷ 金融资产 × 100%。
- 财务成本效应比率 = 税前利润 ÷ 息税前利润 × 100% = 1 − 财务成本负担率；财务杠杆效应 = 财务成本效应比率 × 财务杠杆倍数。
- 债务对股东权益比率 =（短期借款 + 长期借款）÷ 股东权益；利息保障倍数 = 息税前利润 ÷ 真实财务费用（「利息费用」取真实财务费用，用户确认）。
- 企业所得税效应比率 = 净利润 ÷ 税前利润 × 100% = 1 − 实际所得税税率。
- 各比率分母 ≤ 0（如经营资产/股东权益/真实财务费用/长期股权投资/金融资产等）或上期数据缺失时显示「—」。

**经营活动现金流分析**

- 营业收入现金含量 = 销售商品、提供劳务收到的现金 ÷ 营业收入 × 100%（未剔除增值税销项税额的简化口径；平稳期约 100%）。
- 成本费用付现率 =（采购商品、接受劳务支付的现金 + 支付给职工以及为职工支付的现金）÷（营业成本 + 税金及附加 + 销售费用 + 管理费用 + 研发费用）× 100%（未剔除增值税进项税额的简化口径；平稳期应低于 100%，扩张期可高于 100%）。
- 息前税后经营利润现金含量 = 经营活动现金流量净额 ÷ 息前税后经营利润；净利润现金含量 = 经营活动现金流量净额 ÷ 净利润。二者衡量利润是否「真金白银」，成熟稳定公司应大于 1（倍）。利润分母 ≤ 0（亏损）时显示「—」。
- 经营活动现金流量净额：直接取现金流量表净额，按文档五档解读（<0 经营危机 → 恰能补偿非付现成本仅维持现有规模 → 补偿后仍有剩余可支撑投资与发展）。

> 资产减值损失/信用减值损失符号约定：非金融股取 `ASSET_IMPAIRMENT_INCOME`/`CREDIT_IMPAIRMENT_INCOME`（收益口径，负值=损失）取反；金融股（暂不支持）取 `*_IMPAIRMENT_LOSS`（损失口径）。

> 保全性资本支出为「近似口径」；长期经营资产期初净额按《公司财务指标分析》文档「长期经营资产」定义（13 科目）取值。金融资产、有息债务、营运资产、营运负债均为重分类近似口径（见 7.10）。

## 8. R4：公司股票估值

### 8.1 背景与目标

依据《公司股票估值》文档，采用**现金流贴现模型（DCF）**对公司股票估值。把公司价值分解为金融资产价值、长期股权投资价值与经营资产价值三部分分别估值后加总，再减去债务价值得到股权价值。提供**四种估值模型**（零增长、永续增长、两阶段、三阶段），所需的增长率、折现率、年数由用户自行输入。

### 8.2 估值模型

对经营资产自由现金流 FCF（基期 = 最新年报）按所选模型贴现得到经营资产价值：

| 模型 | 经营资产价值公式 | 参数 |
| --- | --- | --- |
| 零增长模型 | FCF ÷ r | 折现率 r |
| 永续增长模型（戈登） | FCF × (1+g) ÷ (r−g) | 永续增长率 g、折现率 r |
| 两阶段模型 | Σ_{t=1..n1} FCF×(1+g1)^t/(1+r)^t + [FCF×(1+g1)^n1×(1+g2)/(r−g2)]/(1+r)^n1 | 高增长 g1、年数 n1、稳定增长 g2、r |
| 三阶段模型 | 高增长 g1(n1 年) → 过渡 g2(n2 年) → 永续 g3 | g1、n1、g2、n2、g3、r |

### 8.3 公司价值定义与各部分估值口径

- **公司价值 = 金融资产价值 + 长期股权投资价值 + 经营资产价值**。
- **股权价值 = 公司价值 − 债务价值**（债务价值取**有息债务**，与资产资本维度的「资本合计 = 有息债务 + 股东权益」口径一致）。

各部分估值口径：

1. **金融资产价值**：直接取财报账面价值（公允价值/摊余成本已反映估值日价值）。
2. **长期股权投资价值**：收益资本化 = 账面价值 × (长期股权投资收益率 ÷ 折现率)。收益率 = 折现率 → 账面价值；低于 → 折价；高于 → 溢价；收益率为负 → 折价至 0。当长期股权投资占总资产比例较高（>10%）时给出「建议对投资公司单独进行详细分析与估值」提示。
3. **经营资产价值**：对经营资产自由现金流按所选模型贴现（见 8.2）。

### 8.4 经营资产自由现金流

经营资产自由现金流 = 经营活动现金流量净额 − 保全性资本支出。

保全性资本支出按文档近似 = 长期经营资产减值损失 + 信用减值损失 + 固定资产折旧、油气资产折耗、生产性生物资产折旧、使用权资产折旧 + 无形资产摊销 + 长期待摊费用摊销 + 处置长期资产的损失 + 固定资产报废损失。

**基期自由现金流选取**（估值者自行选择，四种方式）：

1. 最近一年的自由现金流；
2. 近几年自由现金流的**平均值**（自行指定年数）；
3. 近几年自由现金流的**中位数**（自行指定年数）；
4. 近几年自由现金流**去掉最高和最低值后的平均值**（去极值平均值，自行指定年数，少于 3 年时退化为普通平均值）。

**研发费用调整（成长科技股选项）**：对成长型科技股，研发投入与传统行业的机器设备、土地厂房投入对长远发展的影响性质相同，可勾选「研发费用调整」——把研发投入的扩张部分（本年度研发费用 − 上年度研发费用，>0 时）加回自由现金流：本年度与上年度相同金额的研发投入视同保全性资本支出（已扣除），增加部分视同扩张性资本支出（加回）。

### 8.5 展示形态

- 与 R1/R2/R3 共用页面，新增「公司估值」卡片。
- **模型单选 + 动态参数**：按所选模型显示对应的增长率/年数输入框（零增长仅折现率；永续增长含增长率；两阶段含 g1/n1/g2；三阶段含 g1/n1/g2/n2/g3）。
- **基期自由现金流选取**：最近一年 / 近几年平均值 / 近几年中位数 / 去极值平均值（后三者时可指定年数）。
- **研发费用调整**：开关，勾选后把研发投入扩张部分加回自由现金流（适用成长科技股）。
- 所有参数修改后点击「计算估值」按钮统一计算，不逐项自动重算。
- 结果展示：基期经营资产自由现金流（含研发调整提示）、金融资产价值、长期股权投资价值（含账面与收益率）、经营资产价值、公司价值、债务价值、股权价值、每股股权价值。

### 8.6 边界与规则

- 估值基于**最新年报**（单点估值），复用全量报表接口（现金流/资产负债/利润表）+ 行情（总股本）。
- 基期自由现金流取「平均值/中位数」时需多期现金流数据（约 10 个年报）；指定年数超过可用年份时按可用年份截断。
- 研发费用调整取利润表「研发费用」（`RESEARCH_EXPENSE`）近似研发投入；上年度数据缺失时不调整。
- 折现率需大于 0；各模型的永续（终值）增长率需小于折现率，否则返回提示。
- 基期经营资产自由现金流 ≤ 0 时，现金流贴现法不适用，返回提示。
- 金融股（银行/保险/券商）全量报表口径不同，暂不支持（与 R3 一致）。
- 长期股权投资收益率为负或长期股权投资为 0 时，长期股权投资价值按 0 计。

## 9. R5：AI 智能分析（大模型财务诊断）

### 9.1 背景与目标

六维财务指标分析（R3）输出了大量派生指标与解读，但对个人投资者而言，把「一屏指标」转化为「这家公司质地如何、该用什么模型估值」仍需经验。本需求接入大模型，对已计算出的财务指标做整体诊断：按五维百分制打分 + 雷达图 + 干练结论 + 行业分析 + 业务板块分析 + 估值模型推荐。

### 9.2 功能点

- **一键分析（用户触发）**：仅在用户点击「一键分析」时发起大模型调用，不随搜索自动触发（避免无谓消耗）。
- **指标喂给大模型**：把 R3 计算所得的全部派生指标（**仅《公司财务指标分析》文档中定义的指标**，不含原始报表科目）连同各年度数值、单位发送给大模型。
- **指标含义作为 skill**：把每个指标的名称与解读提炼为「指标含义字典」注入系统提示词，帮助大模型正确理解指标口径。
- **输出维度**：盈利能力、偿债能力、现金获取能力、经营效率、成长能力，五个维度百分制打分（0-100）+ 一句话点评 + 财务指标雷达图。
- **结论**：总体结论分段分点，覆盖质地/护城河/财务健康/风险/评级，长度随分析模式变化（简洁约 100 字 / 标准约 200 字 / 详细约 300 字）；行业分析（前景、竞争格局、应用方向）各 1-2 句；业务板块分析（据主营构成列出主要板块、所处阶段、营收/利润贡献占比与毛利率、前景、风险）；估值模型推荐（模型 + 折现率/各阶段增长率/年数 + 选择理由），可一键套用到 R4 估值表单。
- **估值推荐口径**：参数**严格依据实际财务指标、据实预估**——先算近三年营收/净利/经营现金流同比增速取基准增速 X%，g1 必须贴近 X% 且偏差不超过 ±3%（分档：≥20%→三阶段、8%-20%→两阶段、0%-8%→永续、负增长/剧烈波动→零增长或两阶段低 g1）；折现率按实际风险指标分档 8%-12%；行业分析仅做 ±1-2% 微调；结果再按固定档位归一化（增长率整数 %、折现率 0.5% 档），保证多次分析参数稳定。
- **模型与鉴权**：固定接入 DeepSeek，apikey 作为**程序启动参数** `-apikey` 传入（未填则回落环境变量 `DEEPSEEK_API_KEY`）；模型名 `-model`、接口地址 `-baseurl` 也可启动指定（缺省 `deepseek-v4-pro` + 官方地址）。
- **分析模式**：前端「一键分析」旁提供下拉选择 `简洁(low)` / `标准(medium)` / `详细(high)`，作为请求参数 `reasoning` 传入，同时控制结论详略与推理强度（简洁更快、详细更深入），缺省「简洁」。同一股票相同年份与模式下**结果缓存复用**，不重复调用大模型消耗 token。

> 待优化（见《需求文档/AI 估值模型参数确定性约束》）：当前量化约束（增长率取整、折现率 0.5% 档）未能消除大模型随机性，多次分析参数仍有较大跳变；该需求要求估值模型与参数改由后端按财报数据确定性推导、锁定到固定参数网格，大模型只负责理由文案。

### 9.3 展示形态

- 新增「AI 智能分析」卡片：「一键分析」按钮（apikey 由服务端启动参数提供，前端无需输入）；分析中 loading。
- 结果区自上而下：五维雷达图 → 五维评分条（含一句话点评）→ 总体结论 → 行业分析（前景/竞争格局/应用方向）→ 业务板块分析（板块/阶段/贡献占比/前景/风险）→ 估值模型推荐（含「套用到估值」按钮）→ 底部小字显示本次 token 用量。

### 9.4 边界与规则

- 大模型输出存在不确定性，结果仅作参考、不构成投资建议。
- 行业名称由大模型依据公司名称推断（免费接口未提供行业字段），可能不精确。
- 分析基准与 R3 一致：选定年份范围内的年报，缺省最近 5 年。
- 大模型调用失败（网络/超时/鉴权/返回格式异常）返回明确错误提示，可重试。
- 大模型以 `response_format=json_object` 输出 JSON，后端校验五个评分维度完整且顺序正确，否则报错。

## 10. 颜色语义规范（全局）

全站统一两条颜色语义，避免同一页面出现冲突：

| 语义 | 颜色 | 色值 | 适用 |
| --- | --- | --- | --- |
| 好坏 / 健康（向好=绿、走弱=红） | 绿 / 红 | `#149a5e` / `#d64040` | 指标趋势信号灯、六维分析同比、AI 评分进度条（90+ 绿 → <60 红）、指标趋势图柱色（负值恒红、中性灰 `#998c8c`）、雷达图 |
| 数值涨跌 / 行情（涨=红、跌=绿） | 红 / 绿 | `#d64040` / `#149a5e` | 股票行情卡片（股价 / 涨跌幅）、三大报表同比 |

- **好坏语义**：信号灯圆点仅在「向好 / 走弱」时点亮，中性指标不渲染；六维分析同比按「方向映射表 × 相邻两年变化」着色，中性指标不着色。
- **数值 / 行情语义**：三大报表是原始科目、无统一好坏方向，同比保持「涨红跌绿」；股价涨跌遵循 A 股市场惯例。
- **颜色令牌**：`--good` / `--bad`（好坏）、`--up` / `--down`（数值涨跌），JS 侧由 `PALETTE` 统一引用，禁止散落硬编码。
- **方向映射**：指标「越高越好 / 越低越好 / 中性」见 `docs/需求文档/indicator-trend-signal.md` 附录 A，同时驱动信号灯与六维同比色。

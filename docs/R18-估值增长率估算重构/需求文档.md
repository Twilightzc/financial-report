## 1. 背景与目标

### 1.1 现状（R15 已实现）

R15 已实现 P1~P5，增长率估算当前链路为：

1. **基准增速 X（纯向后看）**：营业收入、重构净利润、经营资产自由现金流三项稳健增速等权；5 年窗口、同比去极值中位数；FCF 序列不稳定（原始强周期 / 有效同比点不足 / 增速极差 >40pp）时不计入 X。
2. **模型分档**：增速 0.6 + 稳定性 0.2 + ROE 0.2 三信号评分，门槛 70/45/25；硬闸门 `X≥12` 三阶段、`X≥6` 两阶段、`X<3` 零增长。
3. **g1 生成**：`g1 = X × (1 − clamp(增速离散度 × 0.004, 0, 0.40))`，再受 `floor(SGR)` 硬上限约束；`SGR = ROE × 留存率`，留存率用「(期末股东权益 − 期初股东权益) ÷ 净利润」近似。
4. **阶段路径**：`n1/n2` 由 X 分档；两阶段 `g2 = gk`，三阶段 `g2 = gk + 1`、`g3 = gk`；`gk = min(4%, f(r))`，`f(r)` 为 `{4,3,2}`；`g1 ≤ g2` 时逐级降级为永续/零增长。
5. **基期 FCF 与周期识别（P3/P5）**：FCF 变异系数 / 正负交替识别强周期；`fcf_years` 动态 3/5/7；强周期走 `trim_mean`；成长性否决（营收 CAGR、最小同比、强增长年、毛利率极差）避免把成长股误判为周期股。

### 1.2 用户反馈与问题定义

用户明确反馈：**增长率估算整体「偏向极端保守」**，估值参数不合理。根因不是某一处算错，而是结构性的：

| 编号 | 结构性缺陷 | 后果 |
| --- | --- | --- |
| G-A | **纯向后看**：X 只吃历史财报，没有前瞻锚定 | 成长股的近期高增长被中位数与折减系统性压低；行业/公司未来 1~3 年的可见增长未被利用 |
| G-B | **没有周期位置意识**：只判断「是不是周期股」，不判断「现在处在周期的高点还是低点」 | 周期股在景气高点用高点增速做锚 → 高估；在低点用低点增速做锚 → 低估 |
| G-C | **SGR 硬上限 + 连续折减 + 模型降级三重压制** | 高分红公司（茅台留存率约 0.14、长电约 0.32、美的约 0.20）SGR≈4~5% → g1 被压到 4 → 两阶段降级为永续；成长股（如睿创微纳）即使 X 已修复，g1 仍可能被 SGR 压住 |
| G-D | **阶段路径是「平台 + 断崖」**：g1 恒定若干年，然后直接跳到 g2 | 没有均值回归的平滑衰减；g1 略高于 gk 时又容易因「无严格递减解」被降级 |
| G-E | **保守调整可叠加**：离散度折减、SGR 上限、成长性否决、模型降级可能同时发生 | 单个信号都「合理」，叠加后结果过度保守，且不可解释 |
| G-F | **终值 gk 与长期经济增速的关系只体现在常量名上** | 缺少「宏观锚 → 终值 → 阶段路径」的自上而下结构；`gk=4` 时三阶段 `g2=5` 虽修复了递减，但缺少与宏观锚的显式衔接 |

### 1.3 目标

| 编号 | 目标 | 可衡量口径 |
| --- | --- | --- |
| O-1 | **估值适中**：不过分保守、不过分乐观 | 见 FR-1 的「适中」量化定义；在 20 只样本回测中，`g1` 相对复合锚的偏差中位数 ≤2.5pp，P90 ≤6pp；终值满足 `g∞ ≤ min(动态名义 GDP, r−1pp, SGR)` 且 `g∞ ≥ 0` |
| O-2 | **增长率估算具备「周期位置意识 + 前瞻锚定」结构** | 输出可解释的三层锚（历史锚 / 前瞻锚 / 宏观锚）与周期位置修正；周期股在高点被下调、低点被上调；成长股可用一致预期修正历史锚；负增长先区分「结构性衰退」与「周期低谷」 |
| O-3 | **参考业界通用做法** | 终值动态锚定名义 GDP；高增长期参考行业/公司一致预期；增长率路径均值回归；周期股用正常化盈利与周期位置修正 |
| O-4 | **保持确定性纪律** | 同一份财报 + 同一外部数据快照下，参数逐位可复现；AI 仍只产出定性行业分类与理由，不产出数值 |
| O-5 | **不破坏 R15 已实现部分** | WACC/β、基期 FCF 选取、研发调整、C5/C6/C7 的结构与口径保持不变；仅按本需求调整与增长率相关的接口与 C4 语义 |

## 2. 用户故事 / 使用场景

- **作为个人投资者**，我希望成长股的高增长不要被历史中位数和 SGR 一刀切压到接近 GDP，以便估值结果能反映公司和行业未来 1~3 年的可见增长。
- **作为个人投资者**，我希望周期股在景气高点不要用高点利润给出过高的增长假设，在景气低点也不要因为当期利润差就给出过低增长假设，以便估值不被周期位置误导。
- **作为个人投资者**，我希望 AI 分析里能看懂「增长率是怎么来的」：历史多少、一致预期多少、周期位置修正多少、最终为什么是 g1，以便判断是否套用到估值表单。
- **作为个人投资者**，我希望高分红公司不会仅仅因为留存率低就被降级成永续增长/零增长，同时也不要假设它长期高速增长。

## 3. 术语与口径

| 术语 | 定义 | 单位/范围 |
| --- | --- | --- |
| `A_hist` 历史锚 | 沿用 R15/P2/P5 的基准增速 X：营收、重构净利润、经营 FCF（不稳定时剔除）三项稳健增速等权 | %，建议 [-30, 50] |
| `A_fwd` 前瞻锚 | 东财一致预期：归母净利润预测 CAGR 与营业总收入预测 CAGR 的加权 | %，建议 [-20, 50] |
| `A_macro` 宏观锚 | 长期名义 GDP 增速（动态跟随；稳定数据源不可得时回退常量 4.5%），代表整个经济的长期名义增长中枢 | % |
| `A` 复合锚 | `A_hist`、`A_fwd`、`A_macro` 按可靠性加权的合成值，是 g1 的主输入；周期修正已内含于历史锚 | %，收口到 [-5, 30] |
| `A_norm` 正常化 A | 负增长归因语境下对 A 的称呼：已剔除周期位置影响、用于判断「结构性衰退 vs 周期低谷」的复合锚；数值上 `A_norm = A` | % |
| `CyclePosition` 周期位置 | 周期股当前毛利率/净利率相对 5~7 年区间中枢的位置；正=景气偏高，负=景气偏低 | [-0.5, +0.5] |
| `Δ_cycle` 周期修正 | 只作用于 `A_hist` 的周期位置修正量 | pp，建议 [-6, +6] |
| `g∞` 终值增长率 | 永续增长阶段的 g3（或永续模型的 g）；动态锚定名义 GDP，并满足 `g∞ < r`、`g∞ ≤ SGR`（SGR 可用时） | %，[0, min(G_GDP, r−1pp)] |
| `G_GDP` 动态名义 GDP 增速 | 近 4 个季度名义 GDP 同比；稳定数据源不可得时回退常量 4.5% | % |
| `gap` 增长缺口 | `gap = A − g∞`，决定高增长阶段的长度与是否值得分段 | pp |
| `n_total` 回归年限 | 从 g1 平滑衰减到 g∞ 所需的总年数 | 年，[3, 10] |
| 结构性负增长 | `A_norm < 0` 且满足 FR-4.5 的结构性衰退判据（全周期营收/利润负增长、毛利率趋势下行、前瞻仍为负等） | — |
| 周期性负增长 | `A_norm < 0` 但公司为周期股、周期位置处于低位，且全周期增速或前瞻预期显示可恢复 | — |
| 「适中」 | 见 FR-1：参数落在独立锚构成的合理包络内、保守调整不叠加、终值不超动态名义 GDP 与 `r−1pp` | — |

> 口径纪律：任何新增量必须能由「财报 + 外部快照 + 常量表」确定性算出；不可得时写明「不可用」并降级，不编造、不补 0、不猜数。

## 4. 功能需求

### FR-1（P0）「适中」的可操作定义

「适中」不是「估值结果等于股价」，而是**参数层面的可验证包络**。必须同时满足：

**M1 锚定包络**：最终生效的 `g1` 必须落在复合锚 `A` 的邻域内：

```
A − 5pp ≤ g1 ≤ A + 5pp
```

- 低于 `A−5pp` 判为「过保守」；高于 `A+5pp` 判为「过乐观」。
- 若因 SGR、周期位置或数据质量必须越界，必须在 `Warning` 中写明**唯一主导原因**与调整量，不允许静默越界。
- `A` 本身必须由至少两个独立锚构成（历史 + 前瞻，或历史 + 宏观）；只有一个锚时，`g1` 包络收窄为 `A ± 3pp`。
- `A_norm < 0` 时 M1 不适用（不存在正的高增长期），改由 FR-4.5 的负增长归因与低永续取值约束。

**M2 保守调整不叠加**：

- 周期位置修正（`Δ_cycle`）在合成 A 之前作用于历史锚，**已内含于 A**，不作为 A 之后的第二次扣减。
- 在 A 之后施加的向下调整只有两项：**增速离散度折减**、**SGR 软上限**。两者最多只有一个实际生效（取绝对值较大者），且合计向下不得超过 5pp；SGR 软上限按构造不会低于 A，因此实际能压低的只有离散度折减。离散度折减的绝对幅度必须按 `min(5pp, A × clamp(D × 0.004, 0, 0.40))` 计算，确保不突破 `A − 5pp` 包络。
- 若周期修正已使 `A_hist_adj` 比 `A_hist` 低 ≥2pp（景气高位），增速离散度折减**减半**，避免「周期高点 + 波动大」重复惩罚同一件事。
- 一致预期可靠性只通过 A 的权重体现，不作为额外扣减。
- 向上调整只有景气低位修正（同样内含于 A），不得再额外叠加「一致预期上调」。

**M3 终值合理（动态 GDP 口径）**：

```
0 ≤ g∞ ≤ min(G_GDP, r − 1.0pp, SGR)     // SGR 不可用时省略 SGR 项
```

- `G_GDP` = 动态名义 GDP 增速（见 FR-3.1）；**不设固定的 4%/5% 上限**。
- 若动态 GDP 数据源不可得，回退常量 `G_GDP = 4.5%`，并在响应与文档中标注「回退常量」；该回退值须回报用户确认后才能作为长期默认。
- 零增长模型 `g∞=0` 合法；`g∞` 不得为负（持续通缩的极端情形也以 0 处理）。
- 不允许 `g∞ ≥ r`；`g∞ ≤ r−1pp` 始终成立。

**M4 模型与缺口一致**：

- `A − g∞ ≥ 3pp` 的公司，不得仅因 SGR 被降级为永续；
- `A − g∞ < 1pp` 的公司，不应强行构造两阶段/三阶段（应使用永续，g 取 `round(A, 0.5)` 或 `g∞`）。

**M5 横截面校准**：在 §8 的 20 只样本上满足：

- 一致预期可用率 ≥80%（非金融样本）；
- `|g1 − A|` 中位数 ≤2.5pp，P90 ≤6pp；
- `g1 < A − 5pp` 的样本占比 ≤20%；`g1 > A + 5pp` 的样本占比 ≤10%；
- 终值 100% 满足 `0 ≤ g∞ ≤ min(G_GDP, r−1pp, SGR)`；回退常量时 `G_GDP=4.5%` 且响应标注；
- 高分红/成熟样本（5 只）不再仅因 SGR 降级为永续/零增长。

> 说明：本需求不把「DCF 结果接近市值」作为验收标准。DCF 内在价值与市价背离是正常现象；「适中」约束的是**参数选取方法**，不是市场定价。

### FR-2（P0）前瞻锚定：一致预期取数与可靠性分级

**FR-2.1 取数**

- 数据源：东方财富个股「盈利预测」页接口
  `GET https://emweb.securities.eastmoney.com/PC_HSF10/ProfitForecast/PageAjax?code={SH|SZ|BJ}{6位代码}`
- 关键字段（实测 2026-10-17 可用）：
  - `yctj_list[]`：`YEAR`、`YEAR_MARK`（`A` 实际 / `E` 预测）、`PARENT_NETPROFIT`（归母净利润，元）、`TOTAL_OPERATE_INCOME`（营业总收入，元）、`ROE`。
  - `ycmx[]`：`ORG_CODE`、`PUBLISH_DATE`、`YEAR1..4`、`PARENT_NETPROFIT1..4`、`RATING`；用于计算覆盖机构数与预测离散度。
- 备用源：`RPT_WEB_RESPREDICT`（`RATING_ORG_NUM`、`YEAR1..4`、`EPS1..4`、`YEAR_MARK1..4`）。仅在主接口不可用时用 EPS CAGR 近似；必须在口径说明中标注「EPS 口径」。

**FR-2.2 前瞻锚计算**

设基期年为 `baseYear`（沿用 R15/P4 的「利润表 ∩ 现金流量表最新共同年」），一致预期中最新的实际年为 `Y_A`，可用的预测年为 `Y_E1 … Y_Ek`（k ≤ 3）：

- 若 `Y_A ≠ baseYear`：视为**口径不一致**，`A_fwd` 不可用，写 `Warning`，不猜算。
- `G_np = (NP_Ek ÷ NP_YA)^(1/(Y_Ek − Y_A)) − 1`，要求 `NP_YA > 0` 且 `NP_Ek > 0`；否则 `G_np` 不可用。
- `G_rev = (REV_Ek ÷ REV_YA)^(1/(Y_Ek − Y_A)) − 1`，要求两端 >0。
- `A_fwd = 0.7 × G_np + 0.3 × G_rev`（两项均可用时）；仅一项可用时取该项；都不可用 → `A_fwd` 不可用。
- 收口：`A_fwd = clamp(A_fwd, −20, 50)`；若 `baseYear` 净利润 ≤0，`A_fwd` 不可用（负基数上的增长无经济意义）。

**FR-2.3 可靠性分级**

| 等级 | 判据 | 合成权重 |
| --- | --- | --- |
| 高 | 覆盖机构数 ≥5；至少 2 个预测年；各机构最新预测的 3 年 CAGR 四分位距 ≤15pp | `A_fwd` 权重 0.45 |
| 中 | 覆盖机构数 2~4；或预测年只有 1 个；或离散度 15~25pp | `A_fwd` 权重 0.35 |
| 不可用 | 覆盖机构数 <2；无预测年；基数非正；`Y_A ≠ baseYear`；离散度 >25pp | 权重 0，回落历史锚 |

- 覆盖机构数按 `ycmx[].ORG_CODE` 去重、每机构取 `PUBLISH_DATE` 最新一条。
- 离散度 >25pp 时 `A_fwd` 不可用，而不是取一个不可信的平均值。

**FR-2.4 降级与可观测**

- 接口超时（建议 2s）、网络失败、返回空、字段缺失 → `A_fwd` 不可用，**不得阻塞 AI 分析**；写 `Warning`：「一致预期不可用，增长率仅按历史与宏观锚定」。
- 响应必须携带：`consensus_as_of`（快照日期，取接口返回的最新 `PUBLISH_DATE` 或请求日期）、`consensus_institutions`、`consensus_years`、`consensus_reliability`、`growth_forward`。
- 同一份一致预期快照下，多次分析结果必须一致；快照变化导致的参数变化必须在响应中可归因（见 NFR-1）。

### FR-3（P0）复合增长锚 A 的合成规则

- 高可靠前瞻锚：

  ```
  A = 0.45 × A_hist + 0.45 × A_fwd + 0.10 × A_macro
  ```

- 中可靠前瞻锚：

  ```
  A = 0.55 × A_hist + 0.35 × A_fwd + 0.10 × A_macro
  ```

- 前瞻锚不可用：

  ```
  A = 0.85 × A_hist + 0.15 × A_macro
  ```

- 历史锚不可用（X 样本不足）但前瞻锚可用：

  ```
  A = 0.85 × A_fwd + 0.15 × A_macro
  ```

- 两者都不可用：沿用 R15 的「样本不足 → 零增长」路径，`A=0`，`insufficient=true`。
- `A` 收口到 `[−5, 30]`；输出保留 0.5pp 网格。
- **周期修正只作用于历史锚**：`A_hist_adj = A_hist + Δ_cycle`（见 FR-4），前瞻锚不再叠加周期修正，避免与分析师已计入的周期预期重复。

**FR-3.1 宏观锚**

- `A_macro` 为**动态名义 GDP 增速** `G_GDP`：从季度 GDP 计算「近 4 个季度名义 GDP 同比」，按 0.5pp 网格收口，并记录快照日期 `gdp_as_of`。
- **数据源要求**：由 `techexpert` 在技术设计阶段探源「稳定、免费、可复现」的名义 GDP 接口（优先东财 `RPT_ECONOMY_GDP` 的 `DOMESTICL_PRODUCT_BASE`/`SUM_SAME`，或其它可长期稳定访问的公开源）。
  - 若探源成功：按动态口径实现，`G_GDP` 随季度数据更新，**不设固定上限**。
  - 若探源失败或数据不稳定：回退常量 `G_GDP = 4.5%`，在响应中标注 `growth_macro_basis = "fallback_constant"`，并**回报用户确认**该回退值；确认前不得把其它数值（如 4.0%）当作默认。
- 动态 GDP 收口规则：`G_GDP = clamp(近 4 季度名义 GDP 同比, 0, 10)`；只做数据异常保护，不改变「动态跟随」的语义。
- 宏观锚的作用是「长期中枢/终值锚」，不是短期增速预测；不得用它替代公司或行业的前瞻判断。
- **宏观利率与长期经济增速的分工**：宏观利率（无风险利率）用于折现率 `r` 的 WACC 基线（沿用 R15 的 `Rf=2.5%`），不直接进入增长率；增长率侧只使用动态名义 GDP 增速作为宏观锚。这样避免把「利率下行」误读为「公司增长上升」。

**FR-3.2 行业增速的定位**

- 本迭代**不新增**独立行业增速数据源：A 股缺乏稳定、免费、可复现的行业级增速口径，按公司一致预期近似（一致预期本身已包含分析师对行业景气的判断）。
- 若后续需要，可用「同行业市值前 5 公司的共识增速中位数」作为行业锚；但这需要 N 次额外请求，列为后续可选增强，不在本迭代范围。

### FR-4（P0）周期位置意识：识别、度量与修正

**FR-4.1 周期股识别**

按优先级：

1. AI 输出的 `industry_type = cyclical` → 直接视为周期股（AI 定性优先，延续 R15 §19.12/§19.14 的纪律）。
2. AI 未分类时，用确定性判据兜底：
   - 复用 R15/P5 的 FCF 强周期判定（`RawCyclical`：CV>0.50 或正负交替 ≥2 次），且**未被成长性否决**（`growthPattern.Veto=false`）；
   - 或新增「盈利周期」判据：5~7 年窗口内，毛利率极差 ≥8pp，且营收/净利润同比同时出现过 ≤−5% 与 ≥+10% 的年份。
3. `growthPattern.Veto=true`（持续高增长、毛利率稳定）→ 不判周期股，避免成长股被误修正。

**FR-4.2 周期位置度量**

在最近 5~7 年窗口（至少 3 年）内，分别计算毛利率位置与净利率位置：

```
GMpos = clamp((GM_latest − median(GM_window)) ÷ max(max(GM) − min(GM), 4pp), −0.5, +0.5)
NMpos = clamp((NM_latest − median(NM_window)) ÷ max(max(NM) − min(NM), 2pp), −0.5, +0.5)
CyclePosition = (GMpos + NMpos) ÷ 2
```

- `GM = (营业总收入 − 营业成本) ÷ 营业总收入 × 100`；`NM = 重构净利润 ÷ 营业总收入 × 100`。
- 若毛利率与净利率的区间都低于最小分母（4pp / 2pp）→ `CyclePosition=0`（利润结构稳定，不认为有可辨识的周期位置）。
- 位置解释：`≥+0.2` 景气偏高；`−0.2 ~ +0.2` 中位；`≤−0.2` 景气偏低。
- 不使用「当期利润 ÷ 历史均值」直接做位置：成长趋势会把中枢抬高，导致长期成长股永远被判为「高位」。

**FR-4.3 修正规则**

```
Δ_cycle = −clamp(CyclePosition × λ, −cap, +cap)     // 只作用于 A_hist
λ = 10pp（位置满幅 ±0.5 → ∓5pp）
cap = 6pp
```

- 景气高位（`CyclePosition>0`）→ 下调历史锚；景气低位（`CyclePosition<0`）→ 上调历史锚。
- 周期修正已内含于 A；若其绝对值 ≥2pp，后续的增速离散度折减减半（FR-1/M2），避免重复惩罚。
- 成长性否决命中的公司 `CyclePosition` 强制为 0，不修正。
- 输出：`cycle_position`、`cycle_position_label`（高位/中位/低位）、`growth_cycle_adjust`、`cycle_basis`（毛利率/净利率位置与窗口）。

**FR-4.4 与基期 FCF 周期处理的分工**

- 基期 FCF 的周期处理仍由 R15/P3 的 `trim_mean + fcf_years=7` 负责，**不改**。
- 本需求的周期位置只修正**增长率锚**，不修改基期 FCF 的选取方式；两者可同时生效，但不得把同一周期信号重复用于「降增长 + 降基期」之外的第二重扣减。

**FR-4.5 负增长归因：结构性衰退 vs 周期低谷**

`A_norm < 0` 时**不得直接归零**，必须先做归因；这是对 R15「X<3 → zero」的明确替代。

**FR-4.5.1 正常化 A**

- `A_norm` 即本需求合成的复合锚 `A`（历史锚已含 `Δ_cycle` 周期位置修正、前瞻锚与宏观锚已加权）。命名为 `A_norm` 只用于负增长归因语境，数值上 `A_norm = A`，不引入第二套计算。
- 对周期股，`A_hist` 已按 FR-4.3 做过周期位置修正，因此 `A_norm` 代表「剔除当前景气位置后的增长中枢」，而不是「当期增速」。

**FR-4.5.2 结构性负增长判据（确定性，满足以下任一组即成立）**

全周期窗口取最近 5~7 年（与 FR-4.2 周期窗口一致），要求首末值为正才计算 CAGR：

```
RevenueCAGR_full = 全周期营收 CAGR
NProfitCAGR_full = 全周期归母净利润 CAGR
GMTrendDown      = GM_latest ≤ median(GM_window) − 2pp，或窗口内毛利率线性斜率 < 0
ForwardNegative  = A_fwd < 0（前瞻锚可用且仍为负）
```

| 组 | 判据 | 含义 |
| --- | --- | --- |
| S1 | `RevenueCAGR_full < 0` 且 `NProfitCAGR_full < 0` | 收入与利润在全周期内都在萎缩 |
| S2 | `GMTrendDown` 且（`RevenueCAGR_full < 0` 或 `NProfitCAGR_full < 0`） | 盈利能力趋势性下行叠加规模萎缩 |
| S3 | `ForwardNegative` 且（`RevenueCAGR_full < 0` 或 `NProfitCAGR_full < 0`） | 历史与前瞻同时指向萎缩 |
| S4 | `A_norm < 0` 且 `CyclePosition > −0.2` 且 `A_fwd` 不可用 | 不在周期低位、又无前瞻恢复证据 |

- 任一组成立 → `StructuralDecline=true`。
- 若 CAGR 因首末值非正而不可算，用窗口内同比中位数替代；仍不可算时不得据此判结构性，转入 S4 或按「无法归因」处理。

**FR-4.5.3 周期性负增长判据**

同时满足：

```
isCyclical = true（FR-4.1：AI 行业分类或确定性兜底）
A_norm < 0
StructuralDecline = false
且满足以下任一：
  CyclePosition ≤ −0.2          // 处于周期低位
  A_fwd > 0                     // 分析师预期恢复
  Δ_cycle ≥ 2pp                 // 周期修正已显著上修历史锚
```

- 周期性负增长**不归零**：使用正常化 `A_norm` 走**低永续**，`g = clamp(round(A_norm, 0.5), 0, g∞)`；`A_norm<0` 时 `g=0`（仍保留 `perpetual` 模型语义，表示「当前负增长是周期性的，长期按低增长/零增长处理」）。
- 输出 `negative_growth_type = "cyclical"`、`negative_growth_basis`，Warning 文案：「当前增速为负但处于周期低位/前瞻预期恢复，按正常化 A=x% 走低永续，不归零」。
- **不得命中旧 `g1<=0 → zero` 分支**：模型选择阶段必须先完成归因，再构造参数；低永续由归因结果直接产出。

**FR-4.5.4 无法归因的默认**

- `A_norm < 0`、`StructuralDecline=false`、但 `isCyclical=false` → 按结构性负增长处理（归零），Warning 说明「非周期股负增长，按结构性衰退处理」。
- `A_norm < 0`、`isCyclical=true`、但既不满足周期负增长条件也不满足结构性条件（数据不足）→ 归零并 Warning「周期/结构无法区分，保守按零增长处理」；不得编造正常化增速。

**FR-4.5.5 输出字段**

- `negative_growth_type`：`none` / `structural` / `cyclical`。
- `growth_normalized`：`A_norm`（%）。
- `negative_growth_basis`：判据说明（全周期 CAGR、毛利率趋势、周期位置、前瞻方向）。

### FR-5（P0）均值回归路径：从「平台 + 断崖」改为平滑衰减

**FR-5.1 回归年限**

```
gap = A − g∞
n_total = clamp(round(gap ÷ fadeRate), 3, 10)
fadeRate = 1.5pp/年（默认常量）
```

- 含义：增长缺口越大，高增长跑道越长；缺口小则快速回归。示例：gap=12pp → 8 年；gap=4pp → 3 年；gap=1pp → 3 年（下限）。
- `gap < 1pp` → 不构造高增长阶段，直接永续（见 FR-5.3）。
- 本小节只适用于 `A_norm ≥ 0`；`A_norm < 0` 先按 FR-4.5 归因：结构性 → 零增长；周期性 → 低永续（`g=clamp(round(A_norm,0.5), 0, g∞)`），不进入 `gap/n_total` 计算。

**FR-5.2 阶段构造**

- **两阶段**：`g1 = A`，`n1 = n_total`，`g2 = g∞`。
- **三阶段**：`n1 = ceil(n_total/2)`，`n2 = floor(n_total/2)`，`g2 = round(g∞ + gap/2, 0.5)`，`g3 = g∞`；必须满足 `g1 > g2 > g3`，否则降为两阶段（再不行降为永续）。
- 所有增长率参数输出到 **0.5pp 网格**；R4 的 `dcfValue` 已支持小数增长率，前端输入步长也是 0.5，无需改公式。
- 三阶段只在 `gap ≥ 4pp` 且模型得分支持时使用；两阶段在 `gap ≥ 1.5pp` 时使用；其余用永续。具体门槛见 FR-5.3。

**FR-5.3 模型选择与降级链**

- 分档输入由「原始 X」改为「复合锚 A」，并同时看 `gap`；评分模型中的增速分 `Sg` 的输入同步由 X 改为 A，稳定性分与 ROE 分的口径不变：

  | 模型 | 条件（按序命中） |
  | --- | --- |
  | `zero` | `insufficient`，或（`A_norm < 0` 且 `StructuralDecline=true`，见 FR-4.5） |
  | `perpetual`（低永续） | `A_norm < 0` 且 `negative_growth_type=cyclical`（见 FR-4.5）；`g = clamp(round(A_norm,0.5), 0, g∞)` |
  | `three_stage` | `A_norm ≥ 6` 且 `gap ≥ 4pp` 且得分 ≥70 |
  | `two_stage` | `A_norm ≥ 2` 且 `gap ≥ 1.5pp` 且得分 ≥45 |
  | `perpetual` | `A_norm ≥ 0`（含 `0 ≤ A_norm < 3` 的低速增长；`g = round(A_norm,0.5)`，但 `≤g∞`） |
  | `zero` | 兜底 |

- 降级链保持 `three_stage → two_stage → perpetual → zero`；每次降级写 `Warning` 与 `model_degraded=true`。
- **取消「仅因 SGR 导致两阶段降级为永续」**：SGR 不再硬压 g1（见 FR-6），因此 `g1 ≤ g2` 只可能来自真实增长缺口不足或数据缺失，而不是留存率口径。
- 保留 R15 的「三阶段严格递减」与「两阶段 `g1>g2`」构造约束。
- **负增长优先归因**：模型选择的第 0 步是 FR-4.5 归因；周期性负增长直接产出低永续，不得先经过旧 `g1<=0 → zero` 分支。结构性负增长才归零。
- `0 ≤ A_norm < 3` 不再归零：按低永续处理，`g = clamp(round(A_norm,0.5), 0, g∞)`；这是对 R15「X<3→zero」的替代（已由用户确认）。

### FR-6（P0）SGR 约束重构与留存率口径

**FR-6.1 SGR 的角色调整**

SGR 的经济含义是「不依赖外部融资、ROE 不变时的长期内生增长上限」，适合约束**永续阶段**，不适合硬性封顶 3~8 年的高增长期（高增长期可以通过留存、杠杆、增发、ROE 提升获得超过 SGR 的增长）。

- **不再用 `floor(SGR)` 硬压 `g1`**。
- `g1` 采用**软上限**：

  ```
  g1_cap = min(30, max(SGR, A_fwd_or_A) + 5pp)
  ```

  - `A_fwd` 可用时用 `A_fwd`，否则用 `A`；SGR 不可用时只用 `A + 5pp`。
  - `g1` 超过软上限才收口，并写 `Warning`：「高增长期增速超过内生可持续增速/前瞻锚 5pp，已收口至 x%」。
- **SGR 仍约束终值**：若 SGR 可用且 `SGR < g∞`，则 `g∞ = max(0, floor(SGR × 2)/2)`（0.5pp 向下收口），并写 `Warning`；这表示长期永续增长不能超过内生可持续增速；SGR ≤ 0 时终值取 0。
- 若 `SGR` 不可用（ROE/留存率/权益数据不足）→ 不对终值施加 SGR 约束，写 `Warning`，不编造。
- 响应中 `SGR` 语义改为「长期内生增速参考」，不再显示为「SGR 上限」；前端文案同步调整。

**FR-6.2 留存率口径（已确认替换为 payout）**

- 主口径（已确认）：`留存率 = 1 − 现金分红总额 ÷ 归母净利润`，clamp [0,1]。
  - 现金分红总额按**报告期**（`REPORT_DATE` 的年度）汇总，而不是按除权除息日汇总；这是为了避免 R10 曾出现的「分红按除权除息日年份汇总、与报告年度错位」问题。
  - 数据源：`RPT_SHAREBONUS_DET`（`REPORT_DATE`、`PRETAX_BONUS_RMB`（元/10 股）、`TOTAL_SHARES`、`ASSIGN_PROGRESS`）。只计 `ASSIGN_PROGRESS=实施分配` 的记录；同一报告年度内的中期分红与年度分红**相加**；`PRETAX_BONUS_RMB ÷ 10 × TOTAL_SHARES` 为税前现金分红。
  - 若当年同时有「预披露」与「实施分配」，只取实施分配，避免重复。
- 备用口径（分红数据缺失/异常）：沿用「(期末权益 − 期初权益) ÷ 净利润」，clamp [0,1]；必须在响应中标注口径为「权益增长近似」。
- 若两种口径都不可用 → 不约束 SGR，写 `Warning`。
- **注意**：特别分红会计入对应报告年度，从而降低留存率与 SGR；这是符合经济含义的（特别分红确实减少了内部留存），不得剔除。

**FR-6.3 与 C4 的关系**

- R15 的 C4「`g1 ≤ SGR`」语义调整为：
  - C4a（硬约束）：`g∞ ≤ SGR`（SGR 可用时），且 `g∞ < r`；
  - C4b（软约束）：`g1 > SGR` 时只告警，不降级、不重算参数；
  - C4c（防御复核）：若出口仍出现 `g1 > g1_cap`，用 `g1_cap` 重建参数并复核严格递减。
- 原「参数出口复核发现 g1 超过 SGR 就按 SGR 重建」的逻辑必须删除或改为按 `g1_cap` 重建，否则本需求失效。

### FR-7（P0）终值增长率锚定（动态 GDP）

- **取消 R15 的折现率反相关映射**（原 `r≤9 → 4%`、`r≤11 → 3%`、`else → 2%`）。该映射本质上是「长期 GDP 的代理」，在动态 GDP 口径下不再需要。
- `g∞` 直接锚定动态名义 GDP：

  ```
  g∞ = min(G_GDP, r − 1.0pp, SGR)     // SGR 不可用时省略 SGR 项
  g∞ = max(0, floor(g∞ × 2) / 2)      // 0.5pp 网格、向下取整，保证不越上限
  ```

- `g∞` 不设固定 4%/5% 上限；`G_GDP` 的动态值就是上限来源。若 `G_GDP = 4.5%`（回退常量），则 `g∞` 通常为 4.5%，但仍受 `r−1pp` 与 `SGR` 约束。
- **动态 GDP 源不可得时的回退**：`G_GDP = 4.5%`，响应标注 `growth_macro_basis = "fallback_constant"`、`gdp_as_of` 省略；`techexpert` 须把回退值回报用户确认。
- `g∞` 不得为负；不得出现 `g∞ ≥ r`。
- 三阶段的 `g2` 是第二阶段增速、不是终值，可以高于 `g∞`，但必须 `< r` 且 `g2 ≤ g1`。
- 由于 `g∞` 可能高于原 4%，FR-1/M1 的 `g1` 包络与 FR-5 的 `gap` 计算必须使用**同一个** `g∞`，不得一处用动态值、一处用常量。

### FR-8（P0）缺失、异常与降级规则

| 场景 | 处理 |
| --- | --- |
| 一致预期接口失败/超时 | `A_fwd` 不可用，`A` 回落历史 + 宏观；不阻塞 AI 分析；Warning |
| 一致预期基数年为负/为 0 | `A_fwd` 不可用；不编造增速 |
| 一致预期实际年 ≠ baseYear | `A_fwd` 不可用；Warning「一致预期基准年与基期年不一致」 |
| 覆盖机构 <2 或离散度 >25pp | `A_fwd` 不可用；Warning |
| 历史 X 样本不足 | 若前瞻可用，按前瞻 + 宏观；否则 `insufficient=true`，零增长 |
| 周期股但周期窗口 <3 年 | `CyclePosition=0`，不修正；Warning |
| 周期位置指标区间过窄 | `CyclePosition=0`，按非周期处理 |
| 分红数据缺失 | 留存率回落权益增长口径；再不可用则不约束 SGR |
| SGR 不可用 | 不约束终值；Warning；`g1_cap` 只用 `A_fwd/A + 5pp` |
| 软上限触发 | 收口 g1 并写 Warning；不降级模型 |
| 动态 GDP 数据源不可得 | `G_GDP=4.5%` 回退常量；标注 `growth_macro_basis=fallback_constant`；techexpert 回报用户确认 |
| 动态 GDP 数据异常（同比 <0 或 >10%） | 收口到 [0,10] 并标注异常；连续两期异常时回退常量并 Warning |
| `A_norm < 0` | 先按 FR-4.5 归因：结构性 → zero；周期性 → 低永续；无法归因 → zero + Warning |
| `A` 与 `A_hist`、`A_fwd` 方向冲突（一正一负） | 正常加权；若结果接近 0，按 FR-4.5 归因后处理（不可直接套 `A<0→zero`）；Warning 说明分歧 |

- 所有 Warning 必须说明「哪个锚不可用/哪个调整生效」，不得只写「数据不足」。
- 同一原因只出现一次；Warning 顺序稳定（同输入逐字一致）。

### 5.2 沙箱/免费接口限制下的取舍

1. **一致预期是唯一新增的必需数据源**：它是「前瞻锚定」最直接、覆盖最好、成本最低的来源；其余宏观/行业数据要么不稳定，要么成本过高。
2. **10Y 国债收益率不做动态化**：当前没有稳定、可解析的免费接口；为保持确定性，继续用常量并在文档标注生效日期。
3. **行业增速不做独立数据源**：公司一致预期已包含行业判断；独立行业锚需要多次请求且口径不稳定，本迭代不做。
4. **GDP 必须动态化（已确认决策 D1）**：`g∞` 动态跟随名义 GDP 增速，不设固定上限（仍受 `r−1.0pp` 与 SGR 约束）。数据源使用 `RPT_ECONOMY_GDP` 的季度口径（近 4 个季度名义 GDP 同比，0.5pp 网格），带 `gdp_as_of` 标识数据截止季度。**稳定免费数据源待 techexpert 探源确认**；若探源失败或运行时不可用，回退常量 4.5%，并在响应字段 `growth_macro_basis="fallback_constant"` 与日志中标注，**必须回报用户确认**后再定长期方案。禁止为「确定性」而默认关闭动态 GDP。
5. **分红数据仅在采用 payout 留存率时新增**：按报告期汇总可修复 R10 的年份错位问题；若用户选择保留权益增长口径，则不需要该请求。
6. **所有新增请求必须可失败、可降级、不阻塞主链路**：AI 分析的主耗时在 LLM，新增请求应与财报请求并发，失败只降级不报错。

## 6. 非功能需求

- **NFR-1 确定性**：同一份财报 + 同一外部快照（`consensus_as_of`、分红报告期、GDP 快照）下，`recommendValuation` 输出逐字段一致；同一进程内 24h 缓存命中时结果完全相同。缓存未命中导致的快照更新必须在响应中体现。
- **NFR-2 性能**：新增请求不超过 3 个（一致预期 + 现金分红 + 宏观 GDP），单请求超时 ≤2s，与现有财报请求并发；三者均走 24h 进程内缓存，缓存命中时不得产生网络请求；AI 分析总耗时增加目标 ≤1.5s（P90），失败不重试超过 1 次。
- **NFR-3 可用性**：任一新增数据源失败时，主分析仍返回成功（`code=0`），估值推荐降级为历史 + 宏观锚，并带 Warning；不得因外部接口失败返回 5xx。
- **NFR-4 兼容性**：不新增 API 路由、不改变请求参数；新增响应字段全部 `omitempty`；旧前端/旧缓存响应可正常渲染。
- **NFR-5 移动端**：新增展示沿用 `.ai-v` 换行，不新增横向滚动；小屏下三层锚可分两行展示。
- **NFR-6 可解释性**：每个最终参数都能追溯到「哪个锚 + 哪个修正 + 哪个上限」；Warning 不得使用无法归因的笼统措辞。
- **NFR-7 安全与依赖**：不新增第三方依赖、不新增密钥；仅访问公开接口；不把外部原始 JSON 直接透传给前端。
- **NFR-8 可观测性**：服务端日志记录一致预期可用性、机构数、`consensus_as_of`、`gdp_as_of` 与 `growth_macro_basis`、周期位置、`negative_growth_type` 与归因判据、实际生效调整、最终 g1/g∞，便于回测与排查。GDP 走回退常量时必须单独打 Warning 日志，便于发现探源/接口退化。

## 7. 边界与约束

- **不做**：不改变 DCF 公式与 R4 的 `dcfValue`；不新增模型类型（H 模型不直接落地，用三阶段近似）；不改变金融股「不适用」判定；不引入 AI 数值修正层（AI 仍只输出 `industry_type` 与 `rationale`）；不新增独立行业增速表；**终值不设固定 4%/5% 上限**，改由 `0 ≤ g∞ ≤ min(G_GDP, r−1.0pp, SGR)` 收口，`G_GDP` 动态跟随名义 GDP；动态数据源不可得时回退常量 4.5% 并回报用户确认。
- **依赖**：东财一致预期接口、分红接口的可用性；财报字段 `TOTAL_OPERATE_INCOME` / `OPERATE_COST` / `PARENT_NETPROFIT` / `TOTAL_EQUITY` 的既有口径。
- **已知限制**：
  - 一致预期对次新股、小市值、北交所公司覆盖可能不足；不可用时只能回落历史锚。
  - 一致预期是分析师观点，可能系统性乐观或滞后；本需求用「可靠性分级 + 软上限 + 权重 0.45」约束，不把它当真理。
  - 周期位置用毛利率/净利率区间位置近似，对成本结构变化、会计口径变化敏感；区间过窄时强制归零。
  - 分红按报告期汇总仍可能受特别分红、中期分红影响；这是经济含义的一部分，不视为误差。
  - 「适中」是参数层定义，不保证 DCF 结果贴近市价。
- **口径延续**：金额单位元、比率单位 %、g 在公式内除以 100；增长率参数统一 0.5pp 网格；所有常量标注生效日期。

## 9. 已确认决策记录

> 本章为 2026-10-17 用户拍板结果，全部 10 项已确认，**无遗留待确认项**。D1、D5 为用户实质修改项，其余按原推荐值执行；正文各章已按本章口径落笔。

### D1 终值增长率锚定值（用户修改：动态 GDP）

- **决策**：`g∞` 动态跟随**名义 GDP 增速** `G_GDP`，**不设固定上限**（不保留原 4.0% 上限，也不设 5% 上限）。
- **实现口径**：`0 ≤ g∞ ≤ min(G_GDP, r − 1.0pp, SGR)`，0.5pp 网格；`G_GDP` = 近 4 个季度名义 GDP 同比（FR-3.1），响应带 `gdp_as_of`、`growth_macro_basis="dynamic_gdp"`。
- **数据源要求**：稳定免费数据源**待 `techexpert` 探源确认**（候选 `RPT_ECONOMY_GDP`）；若探源失败或运行时不可用，回退常量 `G_GDP = 4.5%`，标注 `growth_macro_basis="fallback_constant"`，并**回报用户确认**后才能作为长期默认。
- **落地位置**：FR-1/M3、FR-3.1、FR-7、FR-8、§5.1/§5.2、§7、AC-6。

### D2 引入一致预期（按推荐）

- **决策**：引入东财一致预期作为前瞻锚；主接口 `PC_HSF10/ProfitForecast/PageAjax`，失败回退 `RPT_WEB_RESPREDICT`（仅 EPS），再失败则 `A_fwd` 不可用、回落历史 + 宏观。
- **缓存**：24h 进程内缓存（按股票代码 + 数据源），响应携带 `consensus_as_of`。
- **落地位置**：FR-2、FR-3、FR-8、§5.1、AC-2/AC-3/AC-12。

### D3 周期位置口径（按推荐，方案 A）

- **决策**：`CyclePosition = (GMpos + NMpos)/2`，毛利率与净利率各自在 5~7 年窗口内做区间归一化到 [−0.5, 0.5]；`λ=10pp`、cap ±6pp，仅作用于 `A_hist`；成长性否决公司强制为 0。
- **落地位置**：FR-4、AC-4、AC-17。

### D4 SGR 语义与留存率（按推荐，方案 A）

- **决策**：`g1` 去掉 SGR 硬上限，改为软上限 `min(30, max(SGR, A_fwd/A) + 5pp)`（`A_fwd` 不可用时退化为 `max(SGR, A) + 5pp`）；SGR 只约束**终值**；留存率改为 payout 口径 `1 − 现金分红/净利润`，按 `REPORT_DATE` 报告年度汇总；分红数据不可用时回落权益增长口径。
- **特别分红**：接受「特别分红计入报告年度」，从而降低该年留存率/SGR（经济含义正确，不视为误差）。
- **落地位置**：FR-6、FR-8、§5.1、AC-7、AC-16。

### D5 分档 / 均值回归 + 负增长归因（用户修改：结构性 vs 周期性）

- **决策（参数按推荐）**：
  - 复合锚权重：高可靠 `0.45/0.45/0.10`、中可靠 `0.55/0.35/0.10`、无前瞻 `0.85/0.15`；历史不可用时 `0.85 A_fwd + 0.15 A_macro`。
  - 回归速度 `1.5pp/年`，`n_total = clamp(round(gap/1.5), 3, 10)`；两阶段 `g2=g∞`；三阶段 `g2=g∞+gap/2`。
  - 分档输入改为 `A_norm` + `gap`；三阶段 `A_norm≥6 且 gap≥4pp 且 score≥70`；两阶段 `A_norm≥2 且 gap≥1.5pp 且 score≥45`；`A_norm≥0` 走永续。
- **决策（用户修改）**：取消 R15「`X<3 → zero`」，替换为：
  - **正常化 `A_norm < 0` 且判定为「结构性负增长」→ 归零（zero）**；
  - **周期性负增长 → 用正常化 `A_norm` 走低永续（perpetual）**，不得落入旧 `g1<=0 → zero` 分支。
- **判据与联动（与 D3 打通）**：负增长必须先做周期位置识别（D3/FR-4），区分「周期低谷」与「结构性衰退」。结构性判据 S1~S4（FR-4.5）任一命中即结构性；周期性需 `isCyclical=true`、`A_norm<0`、非结构性，且满足 `CyclePosition≤−0.2` / `A_fwd>0` / `Δ_cycle≥2pp` 之一。结构性优先于周期性；`A_norm≥0` 必须为 `none`。
- **周期性低永续取值**：`g = clamp(round(A_norm,0.5), 0, g∞)`；`A_norm<0` 时 `g=0`，档位仍为 `perpetual`。
- **落地位置**：FR-3、FR-4.5、FR-5、FR-7、FR-8、FR-9、AC-12a~AC-12d、AC-18。

### D6 不引入独立行业增速锚（按推荐）

- **决策**：不新增行业增速数据源；用户举例的「行业上市公司增长率」用公司一致预期近似（分析师预测已含行业判断）。同行业前 5 家共识中位数列为后续可选增强，本迭代不做。
- **落地位置**：§5.1、§5.2-3。

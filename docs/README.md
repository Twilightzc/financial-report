# 文档索引

本目录按「一个需求一个目录」组织：`R<编号>-<中文名>/` 内放该需求的「需求文档.md + 技术设计文档.md」，通用/跨需求内容放 `全局/`，历史测试报告放 `测试报告/`。

## 全局（通用/跨需求）

- [全局/产品定位与需求总览.md](全局/产品定位与需求总览.md) — 产品定位、目标用户、核心问题、需求列表总览与待确认事项（源自产品设计文档 §1~§4 + §12）。
- [全局/技术栈与总体架构.md](全局/技术栈与总体架构.md) — 技术栈选型、总体架构、后端设计、前端设计与常用命令（源自技术设计文档 §1~§5）。
- [全局/颜色语义规范.md](全局/颜色语义规范.md) — 全站「好坏」与「数值涨跌」两套颜色语义（源自产品设计文档 §10）。
- [全局/后续规划.md](全局/后续规划.md) — 非 MVP 后续规划与扩展点（源自产品设计文档 §11 + 技术设计文档 §20）。

- [R17-AI相关公司推荐](R17-AI相关公司推荐/) — AI 分析补充全局行业龙头（后端按行业市值榜确定性获取、不含本公司）+ 各细分业务龙头与相关公司 + AI 产业链上下游与合作公司（名称解析跳转）。含 需求文档.md + 技术设计文档.md。
- [R19-估值模型参数重构](R19-估值模型参数重构/) — 推翻 R15/R18，取消保守/基准/乐观三档，只输出单一「适中基准」估值参数；统一 WACC/CAPM、复合锚 A、Capex 覆盖率、FCF/净利润口径，并约束输出洁净（禁止工具说明与过程话术）。基期 FCF 公式（经营活动现金流净额 − 保全性资本支出）原样保留，只改两个比值指标口径；R3 六维 `maintenanceCapex` 不在范围。**其中保全性资本支出与 FCF/净利润分母口径已由 R23 修订为与 R3 财务指标分析一致。** 含 需求文档.md + 技术设计文档.md。
- [R20-估值增长与终值保守化](R20-估值增长与终值保守化/) — 在 R19 基础上只修订两条口径：g1 上限改为 SGR+1pp（去掉前瞻锚抬升），周期/商品股终值增长率以长期通胀 2% 封顶（该上限已由 R21 调整为 2.5%）；FCF 口径、WACC、复合锚 A、Capex 覆盖率等均不变。含 需求文档.md + 技术设计文档.md。
- [R21-周期股终值基准与估值敏感性分析](R21-周期股终值基准与估值敏感性分析/) — 周期/商品股终值上限由 2.0% 调整为 2.5%（2.0%–3.0% 区间中点）；公司估值卡片新增 5×3 估值敏感性矩阵（终值增长率基准 ±1pp × 折现率基准 ±0.5pp，格子为每股股权价值），只做数值 what-if、不引入三档，并保持 R19/R20 其余口径不变。含 需求文档.md + 技术设计文档.md。
- [R22-估值参数平滑与终值连续化](R22-估值参数平滑与终值连续化/) — 在 R19/R20/R21 基础上修订两条口径：SGR 由单年改为近 5 年（至少 3 个有效年度）平均 ROE × 平均留存率；终值上限由「周期 2.5% / 非周期 GDP」硬二分改为 `2% + (宏观锚−2%) × 稳定度` 连续映射（稳定度由行业类型、FCF 变异系数、盈利周期推导），仍受 `r−1pp` 与 SGR 约束。含 需求文档.md + 技术设计文档.md。
- [R23-估值口径对齐财务指标分析](R23-估值口径对齐财务指标分析/) — 全项目「保全性资本支出」只保留财务指标分析（R3）的 `maintenanceCapex` 一套实现；DCF、AI 估值关键校验、逐年 FCF、公司价值卡片全部复用该口径；AI「FCF/净利润」分母改为重构净利润（含少数股东损益）。FCF 公式结构与 R19/R20/R21/R22 其他估值口径不变。含 需求文档.md + 技术设计文档.md。

# 需求文档索引

本目录存放按迭代流水线（prodexpert 步骤）产出的需求文档。每条对应一个功能/迭代，由 `techexpert` 据此产出技术设计、`coder` 实现。

- [指标趋势图移动端显示优化](mobile-indicator-chart.md) — 修复手机上趋势图图例与轴名重叠、百分比单位只显示裸刻度、绘图区被挤压的问题。
- [AI 估值模型参数确定性约束](ai-valuation-determinism.md) — 把 AI 推荐的估值模型与参数锁定到由财报数据确定性推导的参数网格，消除多次分析的跳变。
- [估值表单与 AI 分析界面打磨](ui-polish-and-ai-rd-adjust.md) — 修估值输入框值看不全并保持对齐、AI 套用时按研发费用占比联动研发调整开关、AI 雷达图维度名移动端显示完整。
- [股票搜索支持名称与模糊匹配](stock-search.md) — 搜索框除 6 位代码外支持按股票名称（任意子串，精确>前缀>子串）与拼音/首字母检索，输入时下拉联想「代码+名称+市场」候选，唯一命中直进、多命中回车取排序第 1 条、无命中给可读提示；检索数据源选型待技术设计确定。
- [估值基期现金流自定义与单位选择](valuation-custom-fcf.md) — 「基期现金流」新增「自定义」选项，可手填基期自由现金流并按千/万/亿（或不选单位按元）换算，换算后以元参与 DCF；保留研发调整叠加、与「选取年数」互斥，输入区保持既有对齐约定、移动端不溢出。
- [指标趋势信号灯](indicator-trend-signal.md) — 每个指标名前用三态圆点标出趋势（绿=向好、红=走弱、灰=中性/无信号，全行对齐），tooltip 措辞按变化幅度分级（<20% 用「略有改善/略有走弱」），AI 评分配色、图表主色统一到该「好坏」语义；六维同比与三大报表、行情保留红涨绿跌（增长百分比区分数值正负，与信号灯的「整体状态」语义分开）。

> 说明：已落地功能的完整产品说明见 `docs/产品设计文档.md`，技术方案见 `docs/技术设计文档.md`；本目录只登记新增/待实现的需求。

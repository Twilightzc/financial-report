## 1. 背景与目标

### 1.1 背景

- 页面现有「财务指标分析」卡片，以**六个维度**的 Tab 页签呈现（投资活动现金流、筹资活动现金流、资产资本、股权价值增加值、股东权益回报、经营活动现金流），每个维度下列若干小节与指标，按年份列逐年展示数值（`docs/产品设计文档.md` 7.2）。
- 「公司股票估值」卡片（R4，现金流贴现法）把**公司价值**分解为三部分单独估值后加总：**公司价值 = 金融资产价值 + 长期股权投资价值 + 经营资产价值**，再减去债务价值得到股权价值（`docs/公司股票估值.md`）。其口径为：
  - 金融资产价值 = 财报账面（`financialAssets`）；
  - 长期股权投资价值 = 收益资本化 = 账面 × (长期股权投资收益率 ÷ 折现率)，收益率 ≤ 0 时取 0；
  - 经营资产价值 = 经营资产自由现金流按所选模型贴现；
  - 经营资产自由现金流 = 经营活动现金流量净额 − 保全性资本支出（`operatingFreeCashFlow`）。
- 现有估值只输出**最新年报单点**的上述数值。用户希望能在页面上**逐年**观察「与公司价值最相关的三个量」的变化趋势，但当前无处查看：估值卡片只有一个时点，资产资本维度虽展示「金融资产」「长期股权投资」账面，但不含经营资产自由现金流，也没有把它们组织成「公司价值构成」的视角。

### 1.2 目标

- 新增一张**独立卡片**「公司价值」，与「财务指标分析」卡片并列，其下列出**三个逐年数值**：经营资产自由现金流、金融资产价值、长期股权投资价值。
- 三个数值按年份列展示，可直接观察逐年变化。
- 口径与「公司股票估值」模块保持一致，避免同一名词在两处出现不同数值。
- **不新增对外部数据源的拉取**：复用财务指标分析已获取的资产负债表、利润表、现金流量表。
- 现有「六维财务指标分析」卡片的维度数量、顺序、文案与「公司估值」卡片均保持不变。

## 2. 用户故事 / 使用场景

- 作为分析公司价值的投资者，我想要在页面上逐年查看「金融资产价值 / 长期股权投资价值 / 经营资产自由现金流」，以便观察这三部分随年份的变化趋势，判断公司价值构成的演变。
- 作为已用估值模块算过公司估值的用户，我想要这张卡片的口径与估值模块一致，以便两者对照、互不矛盾。

## 3. 功能需求

### FR-1 新增独立「公司价值」卡片（P0）

- **触发**：加载 / 打开页面。
- **要求**：
  - 新增一张**独立卡片**（不是「财务指标分析」卡片内的新 Tab），标题「公司价值」，卡片样式与页面其它卡片一致。
  - 卡片与「财务指标分析」卡片**并列排布**（建议紧随「财务指标分析」卡片之后；最终排布位置由技术设计/UI 确定）。
  - **现有「六维财务指标分析」卡片不改动**：维度数量（仍为六）、顺序、Tab 文案、数值全部不变；卡片副标题「六维」与欢迎语等「六维」措辞**保持不变**。
  - 卡片**自带年份范围选择**（起始年 / 结束年，默认最近 5 个年报），与「财务指标分析」卡片的筛选相互独立、互不影响；变更后重新计算。
  - 卡片状态：无年报数据时显示「无年报数据」提示（沿用页面既有空态样式）。
- **输出**：页面多出一张「公司价值」卡片，内含 FR-2 的三个指标。

### FR-2 卡片内并列展示三个子项（P0）

- **触发**：卡片加载完成。
- **要求**：卡片内**并列**展示 3 个指标，展示顺序固定为：
  1. 经营资产自由现金流；
  2. 金融资产价值；
  3. 长期股权投资价值。
- **输出**：3 行指标 × 各年份列的表格，与既有分析表观感一致（含解读 tooltip、年份列、同比）。

### FR-3 不提供「公司价值」合计行（口径约束）（P0）

- **要求**：本卡片**不设**把三个子项相加的合计行。
- **理由（须写入口径说明）**：三个子项中「经营资产自由现金流」是**流量**（年度现金流），「金融资产价值」「长期股权投资价值」是**存量**（时点余额），流量与存量直接相加无经济含义。估值模块中「公司价值 = 金融资产价值 + 长期股权投资价值 + 经营资产价值」相加的是**经营资产价值（自由现金流按模型折现后的结果）**，而非现金流本身。本卡片展示的是可逐年观察的原始量，故不汇总。
- **输出**：卡片内给出上述口径提示（沿用页面既有提示样式）。

### FR-4 三个子项的逐年计算口径（P0）

#### FR-4.1 经营资产自由现金流（P0）

- **口径**：该年 = 经营活动现金流量净额 − 保全性资本支出，**复用估值模块 `operatingFreeCashFlow` 的口径**。保全性资本支出 = 资产减值损失 + 信用减值损失 + 固定资产折旧、油气资产折耗、生产性生物资产折旧（`FA_IR_DEPR`）+ 使用权资产摊销 + 无形资产摊销 + 长期待摊费用摊销 + 处置长期资产的损失（仅计损失，收益按 0）+ 固定资产报废损失。
- **逐年**：对年份范围内每个年报年份分别计算。
- **口径衔接说明**：本项**采用估值口径**（减值为利润表「资产减值损失 + 信用减值损失」），区别于投资维度「保全性资本支出」（仅用现金流量表科目近似）。因本项需与公司估值一致，以上述估值口径为准；两者数值可能不同，属预期。
- **是否含研发调整**：**不叠加**（已决策，见第 7 节 Q5）——展示报表口径的原始自由现金流；研发调整为估值时点的可选假设，本卡片无对应开关。
- **输出**：逐年自由现金流（元），可为负。

#### FR-4.2 金融资产价值（P0）

- **口径**：该年 = 资产负债表重分类的**金融资产账面合计**，**复用 `financialAssets`**（与估值模块 `finValue`、资产资本维度「金融资产」同源同值：19 个金融资产科目求和）。
- **逐年**：对年份范围内每个年报年份分别取值。
- **输出**：逐年金融资产价值（元）。

#### FR-4.3 长期股权投资价值（P0）

- **口径**：该年 = 资产负债表「长期股权投资」**账面价值**（`LONG_EQUITY_INVEST`，复用 `longEquityInvest`），**逐年取值**（已决策，见第 7 节 Q2）。
- **说明（重要）**：估值模块的「长期股权投资价值」是**收益资本化**（账面 × 长投收益率 ÷ 折现率），依赖**折现率 r**——r 是估值参数、不是本卡片的输入，无法逐年独立报告；且用户诉求是「观察每年变化」，账面价值才是可直接逐年计算、可解释的口径。故本卡片取**账面价值**。
- **输出**：逐年长期股权投资价值（元，账面口径）。

### FR-5 单位与展示（P0）

- **单位**：统一为「元」（`unit="元"`），沿用现有分析表格式化——前端 `fmtAnalysisVal` 对「元」调用 `fmtYi`，≥0.01 亿按「X.XX亿」、否则按「X.XX万」，保留 2 位小数。与现有各「元」指标展示一致。
- **逐年列**：按年份列展示，表头为年份，与「财务指标分析」表一致。
- **负数**：原值展示（如「-12.34亿」）；经营资产自由现金流可为负。
- **缺失**：无法计算的年份显示「—」（沿用对 nil 的处理）。
- **同比**：沿用既有规则（红涨绿跌、首年/上期缺失/上期为 0 或负时「—」）。

### FR-6 边界与缺失处理（P0）

- **该年资产负债表缺失** → 金融资产价值 / 长期股权投资价值显示「—」，**不得显示 0**（0 与「无数据」须可区分）。
- **资产负债表存在、某科目缺失**（公司不持有该科目）→ 该科目计 0（与既有重分类一致：nil 视为 0）。
- **该年现金流量表缺失** → 该年本就**不在年份范围内**（年份由现金流量表年报年份派生），不会出现，无需特殊处理。
- **该年利润表缺失** → 经营资产自由现金流**仍计算**，其中减值损失项计 0（沿用估值口径的简化）；建议在该指标 note 中标注，提示该年 FCF 未扣减值。
- **保全性资本支出的各科目缺失**（无减值 / 无摊销等）→ 计 0，自由现金流 = 经营活动现金流量净额 − 0（未扣该项，可能偏高），沿用估值口径。

### FR-7 展示一致性：趋势信号灯与同比（P1）

- **要求**：本卡片的三个指标沿用既有分析表的**三态趋势信号灯（绿/红/灰）+ 同比**展示，保持页面观感一致。三个指标须纳入趋势方向映射（`trend_signal.go` 的 `indicatorDirections`），方向取值：
  - 经营资产自由现金流 → `higher_better`（已决策，见第 7 节 Q4）；
  - 金融资产价值 → `neutral`；
  - 长期股权投资价值 → `neutral`。
- 趋势信号灯、同比色由既有 `applyTrendSignals` 回填，未纳入映射的 key 默认 `neutral`（本项目兜底约定）。
- 说明：方向映射的总数断言（`trend_signal_test.go` 的计数）会随新增 key 变化，需同步更新（属实现层注意事项）。

## 4. 非功能需求

- **性能**：不新增对外部数据源的请求；复用财务指标分析已并发拉取的三张全量报表（资产负债表约 11 个年报、利润表/现金流量表约 10 个年报），新卡片为纯计算/展示，接口与页面耗时基本不变。接口形态（复用 `/api/stock/:code/analysis` 还是新增独立接口）由技术设计确定，但**无论哪种都不得新增对外部数据源的额外拉取**。
- **兼容性**：
  - 现有「六维财务指标分析」卡片的返回结构、顺序、数值与「六维」文案**完全不变**；「公司估值」卡片不变。
  - 前端为 CDN 方式加载的 Vue 3 + Element Plus，无构建步骤；新卡片复用既有卡片/表格渲染方式，不引入新依赖。
- **一致性**：金融资产价值、经营资产自由现金流须与估值模块**同口径同算法**，保证同一公司两处数值一致、不矛盾。
- **移动端**：沿用现有表格横向滚动策略，窄屏（≥320px）不溢出、年份列可横向滚动查看。
- **易用性**：三个指标的解读文案（tooltip）说明其口径（尤其「长期股权投资价值取账面」「经营资产自由现金流为流量、不与存量相加」），避免误读。

## 5. 边界与约束

- **只新增展示**：不改动公司估值模块的计算逻辑、DCF 模型、参数，也不改动现有「六维财务指标分析」的任何指标与文案。
- **本卡片不引入估值参数输入**：不要求折现率 / 增长率 / 年数等参数（这也是长期股权投资价值取账面而非收益资本化的原因）。
- **不提供合计行**（见 FR-3）。
- **与资产资本维度的数值重叠属预期**：「金融资产价值」等于资产资本维度的「金融资产」，「长期股权投资价值」等于资产资本维度的「长期股权投资」（均为账面）；两处服务于不同视角（公司价值构成 vs 资产负债表重分类），不要求去重。
- **不改动「六维」措辞**：卡片为独立卡片，不改变现有六个维度的数量与文案。
- **不涉及的模块**：三大报表、AI 智能分析等。
- **已知限制**：利润表缺失年份的经营资产自由现金流未扣减值损失项（沿用估值口径的简化），可能偏高；单年自由现金流可为负。

## 7. 已决策记录

以下 6 项已于 2026-10-11 经用户拍板确认，作为定稿口径；正文相关 FR 已同步。

- **Q1 呈现方式 → 独立卡片（已决策）**：新增一张与「财务指标分析」卡片并列的**独立卡片**「公司价值」，**不是**第 7 个 Tab；现有六个维度与「六维」措辞保持不变。对应 FR-1。
- **Q2 长期股权投资价值口径 → 账面（已决策）**：取资产负债表「长期股权投资」账面价值（`LONG_EQUITY_INVEST`）。收益资本化依赖折现率 r、分析侧无该输入且无法逐年独立报告，故不采用。对应 FR-4.3。

# 技术栈与总体架构

## 1. 技术栈选型

| 层 | 选型 | 说明 |
| --- | --- | --- |
| 后端语言 | Go | 已确认 |
| 后端框架 | Gin | Go 最主流 HTTP 框架 |
| 前端框架 | Vue 3 | 组合式 API |
| 构建工具 | Vite | 现代主流，一键脚手架 + 热更新 |
| 前端语言 | TypeScript | 类型安全 |
| UI 组件库 | Element Plus | 表格/表单/布局现成 |
| 图表库 | ECharts | 指标趋势图（柱状+增速折线，CDN） |
| 状态/路由/请求 | Pinia / Vue Router / Axios | Vue 3 官方配套 |

## 2. 总体架构

前后端分离，Go 提供 REST JSON API，Vue SPA 通过 Axios 调用。

```
┌─────────────────────────────────────────────────────┐
│  Vue 3 SPA（浏览器）                                  │
│  输入代码 → 指标表                                    │
└───────────────────────┬─────────────────────────────┘
                        │ Axios / REST JSON
                        ▼
┌─────────────────────────────────────────────────────┐
│  Go 后端（Gin）                                       │
│  handler（API 层）→ service（指标计算）→ client（数据获取）│
└───────────────────────┬─────────────────────────────┘
                        │ HTTP GET（免费接口）
                        ▼
┌─────────────────────────────────────────────────────┐
│  东方财富免费数据接口                                  │
│  三大报表（datacenter）+ 行情（push2）                 │
└─────────────────────────────────────────────────────┘
```

## 3. 后端设计

### 3.1 目录结构

```
backend/
├── cmd/server/main.go        # 入口，启动 Gin 服务
├── internal/
│   ├── api/                  # HTTP 层：路由 + handler
│   │   ├── router.go
│   │   └── handler.go
│   ├── service/              # 指标计算引擎（纯函数）
│   │   └── indicator.go
│   ├── client/               # 东财数据获取（HTTP 客户端）
│   │   ├── eastmoney.go
│   │   └── models.go         # 东财返回结构体
│   └── model/                # 领域模型：标准化报表结构体
│       └── financial.go
├── go.mod
└── go.sum
```

### 3.2 分层职责

- **model**：标准化的三张表结构体 + 指标结果结构体，全项目通用。
- **client**：封装东财接口调用，负责原始 JSON → 标准化结构体的映射。只依赖 `model`。
- **service**：指标计算纯函数，输入 `model` 报表 + 行情，输出指标值。无网络、无 IO。
- **api**：Gin 路由与 handler，解析参数、调用 service、返回 JSON。

依赖方向单向：`api → service → model`，`api → client → model`。

### 3.3 数据源（东方财富免费接口）

- **三大报表**：`datacenter-web.eastmoney.com` 接口，用 `reportName` 参数区分资产负债表 / 利润表 / 现金流量表，返回结构化 JSON。
- **行情**：`push2.eastmoney.com` 接口，获取最新股价、总股本（用于计算市值、PE/PB 分母）。
- **字段映射**：东财接口字段较多且部分科目有行业差异，实现时需对真实返回逐字段核对，再映射进 `model` 结构体。

> 注意：东财接口非官方文档化，字段名与可用性需在实现阶段实测确认；若遇不稳定，备选 Tushare Pro HTTP API（需 token + 积分）。

### 3.4 标准化报表结构体（示意）

```go
type BalanceSheet struct {
    ReportDate       time.Time // 报告期
    TotalAssets      float64   // 资产总计
    TotalLiabilities float64   // 负债合计
    TotalEquity      float64   // 所有者权益合计
    // ... 按需补充科目
}

type IncomeStatement struct {
    ReportDate       time.Time
    Revenue          float64 // 营业收入
    NetProfit        float64 // 净利润
    NetProfitParent  float64 // 归母净利润
    // ...
}

type CashFlowStatement struct {
    ReportDate        time.Time
    OperatingCashFlow float64 // 经营活动现金流量净额
    // ...
}
```

### 3.5 指标计算引擎（service）

- 指标设计为「纯函数 + 明确入参」，便于后续替换为用户指定的分析方法。
- 返回统一的 `IndicatorResult`，key 为指标名，value 为数值 + 单位/口径。

```go
func CalcPE(price, eps float64) float64        // 市盈率
func CalcPB(price, bps float64) float64        // 市净率
func CalcPS(marketCap, revenue float64) float64 // 市销率
func CalcDividendYield(dividend, price float64) float64 // 股息率
```

### 3.6 API 设计（REST）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/stock/:code/indicators` | 返回该股票全部指标（含行情） |
| GET | `/api/stock/:code/financials` | 返回三张表全科目（范围内年报，含年份筛选），见第 6 节 R2 |
| GET | `/api/stock/:code/analysis` | 返回六维财务指标分析（最近年报），见第 7 节 R3 |
| GET | `/api/stock/:code/valuation` | 返回公司股票估值（DCF），见第 8 节 R4 |
| GET | `/api/stock/:code/ai-analysis` | 一键 AI 财务诊断（大模型），见第 9 节 R5；估值参数改为后端确定性推导，见第 11 节 R7 |
| GET | `/api/stock/:code/quote` | 返回最新行情 |

- 统一返回结构：`{ "code": 0, "data": ..., "message": "" }`
- 股票代码格式：`600519` / `000001`（不带交易所前缀，内部映射 secid）

## 4. 前端设计

### 4.1 目录结构

```
frontend/
├── index.html
├── package.json
├── vite.config.ts
└── src/
    ├── main.ts            # 入口，挂载 Vue + Element Plus
    ├── App.vue
    ├── router/            # 路由
    ├── api/               # Axios 封装，对应后端接口
    ├── stores/            # Pinia 状态
    ├── views/
    │   └── StockDetail.vue  # 单股分析页
    └── components/
        └── IndicatorTable.vue  # 指标表格
```

### 4.2 页面与交互

- 顶部输入框：输入股票代码 → 触发查询。
- 指标表：展示当前指标值（Element Plus Table）。
- MVP 仅单页，路由可先保留单条或后续扩展。

### 4.3 开发代理

Vite `server.proxy` 将 `/api` 转发到 Go 后端（默认 `http://localhost:18080`），避免跨域。

## 5. 常用命令

### 后端

```bash
cd backend
go run ./cmd/server          # 启动服务（默认 0.0.0.0:18080，-addr 指定 ip:port）
go run ./cmd/server -apikey=sk-xxx -model=deepseek-v4-pro -baseurl=https://api.deepseek.com/v1   # 带 AI 分析鉴权启动
go build ./...               # 构建
go test ./...                # 全部测试
go test ./internal/service -run TestCalcPE -v  # 单个测试
go vet ./...                 # 静态检查
gofmt -l .                   # 格式检查
```

### 前端

```bash
cd frontend
npm install                  # 安装依赖
npm run dev                  # 启动开发服务器
npm run build                # 生产构建
npm run lint                 # 代码检查
```

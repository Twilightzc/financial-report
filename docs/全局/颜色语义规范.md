# 颜色语义规范（全局）

全站统一两条颜色语义，二者表达的不是同一件事，避免混淆：

| 语义 | 颜色 | 色值 | 适用 |
| --- | --- | --- | --- |
| 好坏 / 健康（向好=绿、走弱=红） | 绿 / 红 | `#149a5e` / `#d64040` | 指标趋势信号灯、AI 评分进度条（90+ 绿 → <60 红）、指标趋势图柱色（负值恒红、中性灰 `#998c8c`）、雷达图 |
| 数值涨跌 / 行情（涨=红、跌=绿） | 红 / 绿 | `#d64040` / `#149a5e` | 股票行情卡片（股价 / 涨跌幅）、三大报表同比、六维分析同比 |

- **好坏语义**：信号灯圆点「向好 / 走弱 / 中性」三态（绿 / 红 / 灰）；AI 评分进度条与指标趋势图柱色、雷达图按「好坏」取色。表征**整体状态**。
- **数值 / 行情语义**：三大报表与六维分析表的**同比百分比统一「红涨绿跌」**（正增长=红字、负增长=绿字），只区分**数值正负**、不表达好坏；股价涨跌遵循 A 股市场惯例。
- **颜色令牌**：`--good` / `--bad`（好坏）、`--up` / `--down`（数值涨跌），JS 侧由 `PALETTE` 统一引用，禁止散落硬编码。
- **方向映射**：指标「越高越好 / 越低越好 / 中性」见 `docs/R9-指标趋势信号灯与颜色语义重构/需求文档.md` 附录 A，**只驱动信号灯与 tooltip 措辞**，不再参与同比着色。

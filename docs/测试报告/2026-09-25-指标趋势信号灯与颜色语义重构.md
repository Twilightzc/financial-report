## 4. 发现与修复

- **Issue A（已修复）**：近零残差端点产生误导性信号。600519 `debt_capital_cost` 首值 `2.088e-07`（浮点残差）未命中 `first==0` 守卫，`R≈−1.0 → falling → lower_better → improving` 误报「向好」。修复：新增 `residualEpsilon = 1e-6` 绝对阈值，`|first| < ε` 或 `last != 0 && |last| < ε` → 无信号（恰好为 0 的末值保持合法）。补 1 组单测 + 2 个真实序列用例；三窗口验收均无信号。
- **Issue B（越界发现，未在 R9 范围修复）**：600519 `debt_capital_cost` 数值本身畸高（2022=155.1%、2023=187%，该公司几乎无有息负债），根因在 `interestPaidCash = ASSIGN_DIVIDEND_PORFIT − 母公司股利 − SUBSIDIARY_PAY_DIVIDEND` 的分红跨年残差，连带抬高 `wacc`。属 R9 之前的 R3 既有缺陷，建议另立修复（校验 `interestPaidCash` 占比超限则置 nil）。

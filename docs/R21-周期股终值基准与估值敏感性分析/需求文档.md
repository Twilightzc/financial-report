# 周期股终值基准与估值敏感性分析

> 需求编号：R21
> 状态：需求分析完成，待用户确认「待确认问题」后进入技术设计
> 修订关系：本文档只修订 R20《估值增长与终值保守化》中的**周期/商品股终值上限**（2.0% → 2.5%），并新增**公司估值卡片的敏感性分析**。R19、R20 的其余全部口径继续有效；两文档冲突时，以本文档对这两处的修订为准，其余以 R19/R20 为准。

## 1. 背景与目标

### 1.1 背景

R19 已完成估值参数重构：取消保守/基准/乐观三档，只输出单一「适中基准」参数，并统一了 WACC/CAPM、复合锚 A、Capex 覆盖率、FCF/净利润、风险溢价等口径。R20 在此基础上把高增长期增长率收口到 `SGR + 1pp`，并把周期/商品股的终值增长率 g∞ 封顶在 2%（长期通胀假设）。

R20 完成后，用户将周期股（天山铝业）的估值参数结果交给外部评审。评审反馈：

1. **2% 合理但偏保守**。周期行业的永续增长不应高于长期通胀，但把长期通胀固定取在区间下沿，会让终值系统性偏低。
2. **更稳妥的基准是 2.0%–3.0%**，而不是单点 2.0%。
3. **建议补充敏感性分析**，让估值结果对终值增长率、折现率的敏感程度可见，而不是只给一个单点数值。

用户认可上述意见，并明确以下决策（硬约束）：

- 周期/商品股终值基准从 2.0% 调整为 **2.5%**（2.0%–3.0% 的中点），回应「偏保守」；非周期股仍用 GDP（当前约 4.5%）。
- 新增**估值敏感性分析**：透明 what-if 表，**不是**三档情景，不引入保守/基准/乐观叙事。
- 矩阵固定 **5 行 × 3 列**：行 = 终值增长率 g∞（基准 ±1pp、0.5pp 步长），列 = 折现率 r（基准 ±0.5pp），格子填**每股股权价值**。
- 展示在公司估值卡片（DCF 结果处），保持 R19/R20 的输出洁净风格。

### 1.2 现状（已核对代码与文档）

- **周期股终值上限**：`internal/service/growth.go` 中 `r20CyclicalTerminalPP = 2.0`；`terminalGrowth` 对 `isCyclical=true` 使用 `g∞ = max(0, floorHalf(min(2.0%, r−1.0pp, SGR)))`，`terminal_constraint=cyclical`，文案为「终值增长率按周期股长期通胀 2% 封顶。」
- **非周期股终值**：仍按 R19 `g∞ = max(0, floorHalf(min(宏观锚, r−1.0pp, SGR)))`，宏观锚为动态 GDP TTM，不可用时 4.5%。
- **周期判定**：沿用 `detectCyclical` 的 `isCyclical`，与 β 档位、周期位置、负增长归因共用，不新增第二套判定。
- **公司估值卡片**：`internal/web/app.js` 的「公司估值」卡片（`#valuation`）当前只输出单点估值结果表：经营资产自由现金流（基期）→ 金融资产价值 → 长期股权投资价值 → 经营资产价值（DCF）→ 公司价值 → 债务价值 → 股权价值 → 每股股权价值；没有任何敏感性或 what-if 展示。
- **估值参数来源**：卡片参数由用户手工填写，或由 AI 分析「应用估值参数」写入；单点结果中的 `model`、`discount_rate`、`growth_rate` / `stage2_growth` / `terminal_growth` 即本次敏感性表的基准参数。
- **既有约束**：R19/R20 已定「只输出单一适中基准」「禁止三档」「输出洁净」「不新增取数请求」「参数确定性」等原则，本次不得破坏。

### 1.3 目标

- **G1 周期股终值基准更稳妥**：周期/商品股的 g∞ 上限由 2.0% 调整为 2.5%，作为 2.0%–3.0% 区间的中点；2.5% 仍是上限而非目标值，SGR 或 `r−1pp` 更低时取更低者。
- **G2 敏感度可见**：公司估值卡片在单点结果之外，直接展示 5×3 敏感性矩阵，让用户看到终值增长率 ±1pp、折现率 ±0.5pp 对每股股权价值的影响。
- **G3 透明且不叙事**：只给数值网格与「仅调整终值增长率与折现率，其余参数不变」这一句口径说明；不引入三档、不写保守/乐观判断、不做逐格解读。
- **G4 不回归**：FCF 口径、WACC/CAPM、复合锚 A、g1 = SGR+1pp、模型分类与降级链、n1 规则、Capex 覆盖率、FCF/净利润、输出洁净等 R19/R20 口径全部不变。

可衡量的达成标准：

- 任一被判定为周期/商品股的公司，终值上限真正生效时 `g∞ = 2.5%`，且 `g∞ ≤ 2.5%`；非周期公司的 g∞ 与 R20 公式逐位一致。
- 任一成功计算的公司估值，敏感性表固定为 5 行 × 3 列（零增长模型等明确例外见 FR-2/FR-6），共 15 个格子；基准格数值与单点「每股股权价值」一致（保留 2 位小数）。
- 敏感性表随单次估值结果一并产出，不新增任何行情/财报/AI 取数请求；同一输入多次计算完全一致。
- 页面与文案中不出现「三档」「保守」「乐观」「情景」「带宽」等已废除概念。

### 1.4 非目标

- **不恢复三档情景**：不做保守/基准/乐观三档，不做逐档参数重算、叙事、带宽或概率加权。
- **不改 FCF 口径**：基期自由现金流仍为「经营活动现金流量净额 − 保全性资本支出」，不扣扩张性资本支出；五种基期 FCF 选取方式与研发扩张加回不变。
- **不改 WACC/CAPM**：β 档位、股权风险溢价、公司特定风险溢价、市值权重、折现率取整与区间约束不变。
- **不改复合锚 A**：三锚构成、权重、周期位置修正、取整与区间约束不变。
- **不改 g1 口径**：仍为 `min(30%, SGR + 1pp)`，前瞻锚不参与 g1 上限；SGR 不可用时的兜底不变。
- **不改模型分类与降级链**：`gap = A − g∞` 的定义、`n1` 规则、三级降级链不变；因 g∞ 从 2.0% 调到 2.5% 导致的模型变化属于规则内结果，不做额外抑制。
- **不做动态通胀**：2.5% 为固定常量，不接通胀数据源，不做公司/行业特定通胀。
- **不改非周期股终值**：非周期股仍用 GDP 口径（不可用 4.5%），不得被本次 2.5% 误伤。
- **不在 AI 分析卡片新增敏感性**：本次只改「公司估值」卡片的 DCF 结果区。
- **不做可编辑矩阵、导出、概率分布、情景解读、终值占比面板**。
- **不新增数据源、不新增第三方依赖、不新增 AI 调用**。

## 2. 用户故事 / 使用场景

- 作为分析周期股（铝、钢、煤炭等）的投资者，我希望终值增长率取 2.0%–3.0% 区间的中点 2.5%，以便估值不会因为把长期通胀压在区间下沿而系统性偏低。
- 作为核对估值结果的投资者，我希望直接看到终值增长率 ±1pp、折现率 ±0.5pp 时每股股权价值分别是多少，以便判断当前估值对这两个最不确定的假设有多敏感。
- 作为使用手工参数的投资者，我希望敏感性表以我刚算出的参数为中心，并且基准格就等于当前单点结果，以便我能沿着同一套口径外推，而不是面对另一套情景叙事。

## 3. 功能需求

### FR-1 周期/商品股终值上限调整为 2.5%（P0）

- **触发**：每次生成 AI 估值参数、计算 g∞ 时。
- **周期/商品股口径**：

  ```
  g∞ = max(0, floor0.5(min(2.5%, r − 1.0pp, SGR)))
  ```

  - SGR 可用时仍作为上限参与；SGR 不可用时只受 `2.5%` 与 `r − 1.0pp` 约束。
  - `r − 1.0pp ≤ 0` 时 g∞ 取 0。
  - 2.5% 在 0.5pp 网格上，`floor0.5(2.5%) = 2.5%`。
  - **2.5% 是上限而非目标值**：SGR 或 `r−1pp` 更低时取更低者，不得向上补到 2.5%。
  - 该上限作用于最终永续段：永续模型的 g、两阶段的 g2、三阶段的 g3；三阶段中间段 g2 的构造规则不变。
- **周期判定不变**：沿用 `detectCyclical` 的 `isCyclical`（含 AI 行业分类、成长性否决、FCF 强周期、盈利周期兜底），不新增关键词表或第二套判定；`isCyclical=true` 时统一适用 2.5%。
- **非周期股不变**：

  ```
  g∞ = max(0, floor0.5(min(宏观锚, r − 1.0pp, SGR)))
  ```

  宏观锚仍为动态 GDP TTM，不可用时 4.5%；不得因本次修改把非周期股也压到 2.5%。
- **依据句**：当 2.5% 是真正生效的最小约束时，输出「终值增长率按周期股长期通胀 2.5% 封顶。」；2.5% 未生效（SGR 或 `r−1pp` 更低）时不得写成受 2.5% 约束，仍按 R20「只显示真正生效的约束项」处理。`terminal_constraint=cyclical` 枚举保持不变。
- **现有实现点**：`r20CyclicalTerminalPP` 由 2.0 改为 2.5，并同步 `terminalGrowth` 的周期股上限、文案与 `cyclical` 分支；允许等价改动，但口径必须与上式一致。R20 的 AC-6（`g∞ ≤ 2.0%`）与 AC-9（文案含 2%）由本条取代。
- **边界沿用 R20**：负增长归因路径（`A < 0` 且周期性负增长走永久零增长）、模型分类、降级链均不变；2.5% 不改变这些路径。

### FR-2 敏感性矩阵的生成规则（P0）

- **触发**：公司估值卡片每次成功返回单点估值结果后，同步生成敏感性矩阵；无需用户额外点击、无需二次请求。
- **基准参数**：
  - **基准 g∞**：取单点结果实际使用的终值增长率——永续模型取「永续增长率」（g）、两阶段模型取「永续增长率」（g2）、三阶段模型取「永续增长率」（g3，即终值段）。
  - **基准 r**：取单点结果实际使用的折现率。
  - 其余 DCF 输入（基期 FCF、模型、g1、n1、g2、n2、金融资产、长期股权投资账面与收益率、有息债务、总股本）保持单点结果所用值不变。
- **行网格（g∞）**：以基准 g∞ 为中心，按 0.5pp 步长取 5 档：

  ```
  g∞ − 1.0pp, g∞ − 0.5pp, g∞, g∞ + 0.5pp, g∞ + 1.0pp
  ```

  - 例：周期股基准 g∞ = 2.5% → {1.5%, 2.0%, 2.5%, 3.0%, 3.5%}。
  - 例：非周期股基准 g∞ = 4.5% → {3.5%, 4.0%, 4.5%, 5.0%, 5.5%}。
  - 行按数值升序自上而下排列，标题保留 1 位小数并带 `%`。
- **列网格（r）**：以基准 r 为中心，按 0.5pp 步长取 3 档：

  ```
  r − 0.5pp, r, r + 0.5pp
  ```

  - 例：基准 r = 8.5% → {8.0%, 8.5%, 9.0%}。
  - 列按数值升序自左向右排列，标题保留 1 位小数并带 `%`。
- **网格数量**：标准情形固定 5 × 3 = 15 个格子。零增长模型、基准 g∞ < 1.0pp 等例外见 FR-6 与「待确认问题」。
- **泛化规则**：网格始终相对「该股本次基准参数」生成，不写死 8.0%–9.0% 或 1.5%–3.5%；用户手工修改参数并重新计算后，网格随新的基准参数重新生成。
- **不重新套用上限**：矩阵是参数 what-if，格子里的 g∞ 就是行标题数值；不得在格内再次套用 R20 的周期性 2.5% 上限、GDP 宏观锚、SGR 或 `r−1pp` 约束（否则行 3.0%/3.5% 或非周期 5.0%/5.5% 会被悄悄改值，失去敏感性含义）。格内只保留 DCF 自身的有效性条件（见 FR-3）。

### FR-3 单元格计算口径（P0）

- **计算方式**：每个格子复用与单点估值相同的 DCF 折现公式，只把「终值增长率」和「折现率」替换为该格的行、列取值，其余输入不变：

  ```
  经营资产价值(格) = DCF(基期 FCF, 模型, g1, n1, g2, n2, 终值增长率=行值, r=列值)
  公司价值(格)     = 金融资产价值 + 长期股权投资价值(按列值 r 重算) + 经营资产价值(格)
  股权价值(格)     = max(0, 公司价值(格) − 债务价值)
  每股股权价值(格) = 股权价值(格) ÷ 总股本
  ```

  - **经营资产 DCF**：永续模型替换 g；两阶段模型替换 g2（终值段）；三阶段模型替换 g3（终值段）；g1、n1、g2、n2 均固定。
  - **长期股权投资价值**：随列的折现率 r 按现有「收益资本化」公式重算（账面 × 收益率 ÷ r，收益率 ≤ 0 时取 0）；账面与收益率固定。这是「只改 r」在现有估值公式中的必然结果，也保证基准格与单点结果一致。
  - **金融资产价值、债务价值、总股本、基期 FCF**（含研发扩张加回、基期选取方式与年数）全部固定，不随格子变化。
  - **模型不变**：不因 g∞ 或 r 变化重新分类模型、不改变 n1/n2、不触发降级链。
- **基准格**：行 = 基准 g∞、列 = 基准 r 的格子，其每股股权价值必须与单点结果「每股股权价值」一致（保留 2 位小数后相等）；这是验收的硬条件。
- **无效格**：当列折现率 `r ≤ 行终值增长率`（或 `r ≤ 0`）时，该格 DCF 无经济意义，显示「—」，不得显示 0、负值或报错；同一张表的其他格子照常展示。
- **股权价值下限**：与单点口径一致，公司价值低于债务价值时股权价值按 0 计，格子显示 `0.00`，不做额外告警或标记。
- **精度与展示**：格子内部按完整精度计算，展示保留 2 位小数、单位「元」；不得在中间步骤先四舍五入再计算。
- **不做的事**：不计算终值占比、不计算涨跌幅、不标注「高估/低估」、不排序、不高亮最大/最小值；只展示数值与基准格。

### FR-4 敏感性矩阵的展示与交互（P0）

- **位置**：公司估值卡片内，紧随单点估值结果表之后；若存在「资不抵债」告警，则置于该告警之后、`notes` 提示之前。直接可见，不默认折叠、不需要额外点击。
- **标题与说明**：
  - 区块标题：「估值敏感性」。
  - 说明行：「每股股权价值（元）· 仅调整终值增长率与折现率，其余参数不变」。
  - 可另起一行展示当前基准：「当前参数：终值增长率 2.5%，折现率 8.5%」；该行只复述当前参数，不做判断。
- **表格结构**：
  - 左上角表头单元可写「终值增长率 ＼ 折现率」或留空。
  - 列标题：`折现率 8.0%`、`折现率 8.5%`、`折现率 9.0%`（数值随基准变化）。
  - 行标题：`1.5%`、`2.0%`、`2.5%`、`3.0%`、`3.5%`（数值随基准变化）；行标题按模型可加注「永续增长率」或「终值增长率」，但不得改变数值口径。
  - 单元格：2 位小数的每股股权价值，单位在表头说明，不再逐格重复「元」。
- **基准格高亮**：以 `--brand` 描边 + `--brand-soft` 底色标识基准格，并在表下注明「描边为当前估值参数」。**不得**使用「基准档」字样，避免与已废除的三档混淆。
- **主题与样式**：沿用深色红主题与现有估值表样式（首列/行标题用 muted 文字、数值右对齐、数字等宽感、无阴影、1px 边框）；不新增颜色语义，不用红绿表达好坏，不引入图表。
- **移动端**：表格外层使用横向滚动容器；375px 宽度下表格可横向滚动，页面本身不出现横向溢出。行标题列在滚动时保持可读（可选 sticky 首列，不作为硬性要求）；字号不小于 12px。
- **只读**：格子不可点击、不可编辑、不弹 tooltip 展开推导；不因鼠标悬停重算。
- **空态**：没有成功的单点估值结果时，不渲染敏感性区块，也不显示「暂无数据」占位；沿用现有错误提示。
- **输出洁净**：不出现公式行、内部字段名、函数名、阈值表、规则元语言或工具说明；不出现「三档」「保守」「乐观」「情景」「带宽」等字样。

### FR-5 不回归与兼容（P0）

- **R19/R20 口径不变**：FCF 口径、WACC/CAPM、复合锚 A、g1 = SGR+1pp、模型分类与降级、n1 规则、Capex 覆盖率、FCF/净利润、五种基期 FCF 选取、研发扩张加回均不回归。
- **2.5% 之外的 R20 终值规则不变**：SGR 上限、`r−1pp` 上限、生效约束判定、`cyclical` 枚举、非周期 GDP 口径均保持 R20 行为。
- **单点结果不变**：除周期股 g∞ 由 2.0% 变为 2.5% 及其文案外，单点估值结果表的字段、顺序、含义、数值口径不变；敏感性表是附加展示。
- **R16 历史记录兼容**：历史快照仍可正常打开与回填；敏感性表不依赖历史记录持久化，回填后重新计算估值时按当前参数重新生成。旧记录缺少敏感性字段时不得报错。
- **接口兼容**：新增敏感性数据必须是附加性的，不改变既有字段含义；旧客户端忽略新增数据仍可正常工作。
- **无新增取数**：不新增行情、财报、宏观、分红或 AI 请求；敏感性在已有估值计算链路内完成。
- **确定性**：同一公司、同一期财报、同一组参数、同一快照，任何时候生成的矩阵完全一致；不引入随机数、当前时间或 AI 参与计算。
- **测试同步**：R20 中所有断言 2.0% 上限与「2%」文案的用例需同步更新为 2.5%；新增敏感性用例，覆盖 5×3 网格、基准格一致、无效格、零增长模型、非周期中心值等。

### FR-6 异常与边界处理（P0）

- **单点估值失败**（基期 FCF ≤ 0、金融股/现金流缺失、未知模型、自定义 FCF 非法、基准 `r ≤ g` 等）：沿用现有错误提示，不展示敏感性表。
- **总股本缺失或 ≤ 0**：单点「每股股权价值」本就不展示；敏感性表同样不展示（具体见 Q4）。
- **零增长模型**：没有终值增长率参数，标准 5×3 网格不适用；按 Q1 的推荐默认值降级为「仅折现率敏感性」的 1×3 表（或隐藏，待确认）。
- **基准 g∞ < 1.0pp**：`g∞ − 1.0pp` 可能为负；按 Q2 的推荐默认值保留 5 档并允许负值，或按确认结果在 0 处截断并去重。无论哪种，格子仍须满足 `r > g∞`，否则显示「—」。
- **基准 r 较低**：`r − 0.5pp` 可能 ≤ 0 或 ≤ 行 g∞；对应格子（或整列）显示「—」，不得报错、不得留空、不得显示负股价。
- **股权价值被 floor 到 0**：格子显示 `0.00`，与单点结果一致；不额外添加资不抵债告警。
- **用户改了表单但未点「计算估值」**：敏感性表继续反映上一次成功计算的参数，不随表单输入实时变化；与现有单点结果的行为一致。
- **切换股票**：敏感性表随估值结果一起重置，不残留上一只股票的矩阵。
- **模型切换**：永续/两阶段/三阶段的终值参数位置不同，切换后重新计算即按新模型的基准 g∞ 生成网格；不得沿用旧模型的网格。

## 4. 非功能需求

- **性能**：一次估值最多额外执行 15 次纯 DCF 计算，无 IO、无网络、无 AI 调用；对现有接口响应时间的影响可忽略。
- **确定性**：矩阵只依赖单点估值的输入参数与固定公式，同输入同输出；不依赖当前时间、随机数或外部状态。
- **兼容性**：不改变既有估值接口字段语义；R16 历史记录、AI 分析卡片、三大报表、六维分析均不受影响。
- **移动端**：375px 宽度下敏感性表在自身容器内横向滚动，页面无横向溢出；行标题、列标题与数值在滚动后仍可辨认。
- **易用性**：基准格一眼可辨；表头单位与口径说明清晰；不要求用户理解内部公式即可读出「终值/折现率变化 → 每股价值」。
- **可访问性**：使用语义化表格（表头 `th`、行标题 `th scope="row"`）；高亮不只靠颜色，配合描边和表下说明；对比度满足深色主题现有水平。
- **输出洁净**：不出现工具话术、推导过程、内部变量名、公式行、阈值表或规则元语言；不出现三档/保守/乐观/情景/带宽。
- **安全**：不新增外部输入、不新增网络请求，无新增安全面。

## 5. 边界与约束

- **不做三档**：敏感性矩阵是参数网格，不是情景分析；没有保守/基准/乐观标签，没有概率、没有叙事、没有带宽。
- **不做预测**：矩阵只回答「在其他假设不变时，这两个参数变化会怎样」，不构成对股价的预测或投资建议；不在界面上写判断性结论。
- **不持久化**：敏感性矩阵不写入 R16 历史快照；历史回填后重新计算即可。
- **不新增参数输入**：用户不能编辑矩阵的行列范围、步长或中心值；中心值固定取本次单点估值的参数。
- **2.5% 为固定常量**：不接动态通胀，不做行业/公司特定通胀；2.5% 的调整只影响周期/商品股，不影响非周期股。
- **依赖**：
  - 周期判定依赖现有 `detectCyclical` 与 `isCyclical`，判定链不变。
  - 终值计算依赖现有 `terminalGrowth` 与 `floorHalf` 取整规则。
  - 敏感性计算依赖现有四种 DCF 公式与长期股权投资「收益资本化」公式。
  - 前端展示依赖现有公司估值卡片与深色主题样式。
- **已知限制**：
  - 2.5% 是长期通胀假设的中点，不是对某一年通胀的预测；无可靠数据源时不做动态化。
  - 敏感性只覆盖终值增长率与折现率两个维度，不覆盖 g1、n1、FCF、长投收益率等参数；这是有意收窄，避免矩阵膨胀。
  - 对周期股行 3.0%/3.5% 的格子，数值是 what-if 结果，不代表系统认可该终值假设；界面不对此做额外标注。
  - 若单点估值本身已落入资不抵债区间，矩阵可能大量为 `0.00`，信息量有限但口径一致。

## 7. 待确认问题

以下问题均已给出推荐默认值，可先按推荐推进；如用户有不同意见，再在技术设计前调整。

- **Q1 零增长模型没有终值增长率，敏感性表如何展示？**
  - 影响：零增长模型（结构性负增长公司常用）是否显示敏感性区块，以及显示几行。
  - 推荐：**降级为 1×3「仅折现率敏感性」**，行标题注明「终值增长率不适用」，只展示基准 r ±0.5pp 三列。理由：折现率敏感度仍有信息量，且不伪造一个不存在的终值参数；同时避免整块隐藏导致用户以为功能缺失。
  - 备选：整块隐藏，只保留单点结果。

- **Q2 基准 g∞ < 1.0pp 时，行网格的负值怎么处理？**
  - 影响：手工参数或零增长附近公司的 5 行网格是否出现负终值增长率，是否破坏「5×3」的固定形状。
  - 推荐：**保留 ±1pp 的 5 档网格，允许出现负值**（例如基准 0% → {−1.0%, −0.5%, 0%, 0.5%, 1.0%}）。理由：估值表单本身允许负增长率，DCF 在 `r > g` 时数学有效；敏感性是 what-if，不受 AI 推荐「g∞ ≥ 0」的约束；保留 5×3 也符合本次硬约束。
  - 备选：在 0 处截断并去重，行数可能少于 5 行，形状随基准变化。

- **Q3 折现率变化时，长期股权投资价值是否随格子 r 重算？**
  - 影响：同一行不同列的数值差异，以及基准格与单点结果的一致性。
  - 推荐：**按格子列值的 r 重算长期股权投资价值**（账面 × 收益率 ÷ r，收益率 ≤ 0 取 0），其余输入固定。理由：现有单点估值的长投价值本身就是 r 的函数；若固定长投价值，列间差异只来自经营资产 DCF，与单点公式不一致，且容易在复算时对不上。
  - 备选：长投价值固定为单点结果值，只变经营资产 DCF；口径更「纯粹」，但与单点公式不完全一致。

- **Q4 总股本缺失、无法计算每股股权价值时，敏感性表怎么办？**
  - 影响：少数行情数据异常股票的展示。
  - 推荐：**不展示敏感性表**，与单点「每股股权价值」行不展示的行为一致；不额外报错。理由：本次矩阵的格子口径就是每股价值，没有总股本就无法给出同一口径，换成「股权价值（亿元）」会引入第二套单位与表结构。
  - 备选：降级为展示股权价值（亿元）的矩阵，但需另行确认表头与单位。

- **Q5 敏感性表放在公司估值卡片内，还是独立区块？是否默认折叠？**
  - 影响：页面信息层级与移动端长度。
  - 推荐：**放在公司估值卡片内、单点结果之后，默认展开、不折叠**。理由：敏感性是对当前单点结果的直接补充，放在同一卡片内最符合「DCF 结果处」的使用场景；5×3 表在移动端只占一块可横向滚动的区域，不足以需要折叠。独立区块会让用户误以为是另一项功能，折叠则会削弱「透明可见」的目标。
  - 备选：卡片内折叠区（默认展开），或独立卡片；均不推荐。

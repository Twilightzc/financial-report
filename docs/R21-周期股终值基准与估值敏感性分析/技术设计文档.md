## 1. 设计目标与影响面

### 1.1 设计目标

- **FR-1（终值基准 2.5%）**：`r20CyclicalTerminalPP` 由 `2.0` 改为 `2.5`；周期/商品股 `g∞ = max(0, floorHalf(min(2.5%, r−1.0pp, SGR)))`；2.5% 是上限而非目标值，SGR 或 `r−1pp` 更低时取更低者；非周期股完全沿用 R19/R20 的宏观锚口径。
- **FR-2/FR-3（敏感性矩阵）**：`ComputeValuation` 在同一次纯函数调用内生成 5×3（零增长模型 1×3）敏感性网格，格子为**每股股权价值（元，完整精度）**；只替换终值增长率与折现率，其余输入固定；基准格必须与单点「每股股权价值」逐位一致。
- **FR-4（展示）**：公司估值卡片内、单点结果表（及资不抵债告警）之后渲染矩阵，默认展开；基准格用 `--brand` 描边 + `--brand-soft` 底色；无效格显示「—」；375px 下容器横向滚动、页面无横向溢出。
- **FR-5/FR-6（不回归与边界）**：不新增取数、不新增依赖、不改变既有字段语义；零增长模型降级 1×3，无总股本不展示矩阵，`r ≤ g` 或 `r ≤ 0` 的格子置空。

### 1.2 非目标

- 不恢复三档情景，不提供保守/基准/乐观叙事、概率、带宽或逐格解读。
- 不改 FCF 口径、WACC/CAPM、复合锚 A、g1 上限、模型分类/降级链、n1 规则、Capex 覆盖率、FCF/净利润。
- 不改 AI 分析卡片；敏感性只属于「公司估值」卡片。
- 不做动态通胀、不新增数据源/AI 调用/第三方依赖。
- 不持久化敏感性矩阵到 R16 历史记录。

## 2. 总体架构

### 2.1 数据流

```
api.GetValuation
  ├─ parseValuationParams（不变）
  ├─ FetchQuote(code)                    → TotalShares（每股价值分母）
  ├─ fetchValuationReports(code)         → balance / cashflow / income（不变）
  └─ service.ComputeValuation(...)       ← 唯一新增计算点
        ├─ 基期 FCF / 研发调整 / 长投账面与收益率 / 金融资产 / 有息债务   [不变]
        ├─ dcfValue(params, r, fcf)      → 经营资产价值                     [不变]
        ├─ 公司价值 / 股权价值 / 每股股权价值                               [不变]
        └─ buildSensitivity(...)         → SensitivityGrid                 ← 新增（纯计算）
  └─ 返回 {code, data, message}（data.sensitivity 为附加字段）
```

敏感性计算**不新增任何取数请求**：全部输入来自 `ComputeValuation` 已计算出的 `params`、`fcf`、`finValue`、`longBook`、`longRet`、`debt`、`totalShares`。

### 2.2 分层职责

- `service`：终值常量/文案与敏感性网格全部在 `growth.go`、`valuation.go` 内完成，纯函数，无 IO。
- `model`：只新增结果结构体与 JSON tag，不含业务计算。
- `api`：无需改动，仅序列化透传。
- `web`：只读 API 返回的矩阵，不重算数字、不推导公式；格式化与高亮由前端完成。

## 3. 数据模型

### 3.1 新增 `SensitivityGrid`（`internal/model/valuation.go`）

```go
// SensitivityGrid 估值敏感性矩阵（what-if）。
// 标准情形：Rows = 终值增长率基准 ±1pp（5 档，升序），Cols = 折现率基准 ±0.5pp（3 档，升序），
// Cells[row][col] = 每股股权价值（元，完整精度；nil 表示该格无经济意义）。
// 零增长模型没有终值增长率：Rows 为空数组、Cells 只有一行（1×3），BaseRow=0。
type SensitivityGrid struct {
	Unit               string      `json:"unit"`                // 固定 "元"
	TerminalApplicable bool        `json:"terminal_applicable"` // false：零增长模型，仅折现率敏感性
	Rows               []float64   `json:"rows"`                // 终值增长率 %，升序；零增长为 []
	Cols               []float64   `json:"cols"`                // 折现率 %，升序
	Cells              [][]*float64 `json:"cells"`              // [行][列]，每股股权价值元；null = 无效格
	BaseRow            int         `json:"base_row"`            // 基准格行下标
	BaseCol            int         `json:"base_col"`            // 基准格列下标
}
```

约束：

- `Rows`、`Cols`、`Cells` 恒为数组（非 `null`）；零增长模型 `Rows` 为 `[]`、`Cells` 长度为 1。
- `Cells` 元素用 `*float64`：`null` 表达无效格，避免与真实 `0.00` 混淆。有效格不返回四舍五入后的值，保留完整精度。
- `Unit` 固定 `"元"`，供前端表头说明与后续扩展。

### 3.2 `ValuationResult` 扩展

在 `internal/model/valuation.go:69` 的 `Notes` 之前增加：

	// 估值敏感性（what-if）：行=终值增长率、列=折现率；零增长模型为 1×3。

- 零增长模型的 `Rows` 显式初始化为空切片，序列化为 `[]`，不是 `null`。

### 6.2 敏感性网格生成

#### 6.2.1 常量（`internal/service/valuation.go` 常量区）

```go
// R21 估值敏感性矩阵（what-if）：
// 行 = 终值增长率基准 ±1pp（0.5pp 步长，5 档）；列 = 折现率基准 ±0.5pp（3 档）。
const (
	valSensitivityGrowthStepPP   = 0.5
	valSensitivityDiscountStepPP = 0.5
)
```

#### 6.2.2 基准终值增长率与参数替换

```go
// terminalGrowthParam 返回单点估值实际使用的终值增长率（%）。
// 永续取 g、两阶段取 g2（稳定期永续）、三阶段取 g3（终值段）；零增长无终值参数。
func terminalGrowthParam(p model.ValuationParams) float64 {
	switch p.Model {
	case valModelPerpetual:
		return p.GrowthRate
	case valModelTwoStage:
		return p.Stage2Growth
	case valModelThreeStage:
		return p.TerminalGrowth
	}
	return 0
}

// paramsWithTerminalGrowth 复制单点参数，只替换终值增长率（%）；零增长保持不变。
func paramsWithTerminalGrowth(p model.ValuationParams, g float64) model.ValuationParams {
	switch p.Model {
	case valModelPerpetual:
		p.GrowthRate = g
	case valModelTwoStage:
		p.Stage2Growth = g
	case valModelThreeStage:
		p.TerminalGrowth = g
	}
	return p
}
```

#### 6.2.3 单格计算

```go
// sensitivityCell 计算一个格子的每股股权价值（元）。
// 只替换终值增长率 gPct 与折现率 rPct；长投价值按列 r 重算；其余输入固定。
// 返回 nil 表示该格无效（r ≤ 0，或非零增长模型下 r ≤ g），前端显示「—」。
func sensitivityCell(p model.ValuationParams, rPct, gPct, fcf, finValue, longBook float64,
	longRet *float64, debt, totalShares float64) *float64 {
	if rPct <= 0 {
		return nil
	}
	if p.Model != valModelZero && rPct <= gPct {
		return nil
	}
	r := rPct / 100
	op, err := dcfValue(paramsWithTerminalGrowth(p, gPct), r, fcf)
	if err != nil {
		return nil // 防御：单点已校验过阶段参数，正常只可能因 r ≤ 终值增长率
	}
	longValue := 0.0
	if longBook > 0 && longRet != nil {
		longValue = math.Max(0, longBook*(*longRet/100)/r) // 与单点 valuation.go:176-178 同一表达式
	}
	equity := math.Max(0, finValue+longValue+op-debt) // 与单点同口径 floor 到 0
	v := equity / totalShares
	return &v
}
```

#### 6.2.4 网格组装

```go
// buildSensitivity 生成估值敏感性矩阵。
// 标准情形：rows = 基准 g∞ −1.0/−0.5/0/+0.5/+1.0pp，cols = 基准 r −0.5/0/+0.5pp。
// 零增长模型降级为 1×3（仅折现率），rows 为空数组、Cells 只有一行。
// totalShares ≤ 0 时返回 nil（与单点不展示每股价值的行为一致）。
func buildSensitivity(p model.ValuationParams, fcf, finValue, longBook float64,
	longRet *float64, debt, totalShares float64) *model.SensitivityGrid {
	if totalShares <= 0 {
		return nil
	}
	grid := &model.SensitivityGrid{
		Unit: "元",
		Cols: []float64{
			p.DiscountRate - valSensitivityDiscountStepPP,
			p.DiscountRate, // 基准列使用精确入参，保证基准格与单点一致
			p.DiscountRate + valSensitivityDiscountStepPP,
		},
		BaseCol:            1,
		TerminalApplicable: p.Model != valModelZero,
		Rows:               make([]float64, 0, 5),
		Cells:              make([][]*float64, 0, 5),
	}
	if !grid.TerminalApplicable {
		row := make([]*float64, len(grid.Cols))
		for j, rPct := range grid.Cols {
			row[j] = sensitivityCell(p, rPct, 0, fcf, finValue, longBook, longRet, debt, totalShares)
		}
		grid.Cells = append(grid.Cells, row)
		grid.BaseRow = 0
		return grid
	}

	base := terminalGrowthParam(p)
	// 基准行使用精确入参（不取整）；相邻行 = 基准 ± 0.5pp / ±1.0pp。
	for i := -2; i <= 2; i++ {
		grid.Rows = append(grid.Rows, base+float64(i)*valSensitivityGrowthStepPP)
	}
	grid.BaseRow = 2
	for _, gPct := range grid.Rows {
		row := make([]*float64, len(grid.Cols))
		for j, rPct := range grid.Cols {
			row[j] = sensitivityCell(p, rPct, gPct, fcf, finValue, longBook, longRet, debt, totalShares)
		}
		grid.Cells = append(grid.Cells, row)
	}
	return grid
}
```

关键点：

1. **行/列升序**：`i = -2..2` 天然升序；列固定 `r−0.5, r, r+0.5`。
2. **中心值取精确入参**：基准行 = `terminalGrowthParam(p)` 原值，基准列 = `p.DiscountRate` 原值；相邻档位为精确加减。UI 输入为 0.5pp 步长，因此网格值天然落在 0.5pp 网格上；若通过 query 传入非网格值（如 8.55），基准行/列仍保留精确值，前端按 1 位小数展示。
3. **矩阵不再套用任何终值上限**：`buildSensitivity` 不调用 `terminalGrowth`，不读取 `isCyclical`、宏观锚、SGR、`r−1pp`。行值 3.0%/3.5%（周期股）或 5.0%/5.5%（非周期股）原样参与 DCF。
4. **模型不重新分类**：不调用 `classifyGrowthModel`，不改变 `n1/n2`，不触发降级链。
5. **零增长 1×3**：`Rows=[]`、`Cells` 一行、`BaseRow=0`；行标题由前端写「终值增长率不适用」。

### 6.3 每格 DCF 复用口径

| 模型 | 行值替换字段 | DCF 公式（现有函数） | 有效性条件 |
|---|---|---|---|
| zero | 无（`Rows=[]`） | `dcfZero(fcf, r)` | `r > 0` |
| perpetual | `GrowthRate` | `dcfPerpetual(fcf, g, r)` | `r > g` |
| two_stage | `Stage2Growth`（稳定期永续 g2） | `dcfTwoStage(fcf, g1, n1, g2, r)` | `r > g2` |
| three_stage | `TerminalGrowth`（终值 g3） | `dcfThreeStage(fcf, g1, n1, g2, n2, g3, r)` | `r > g3` |

- 复用 `dcfValue`（`valuation.go:335-365`）而不是复制公式，保证与单点完全同源。
- `g1`、`n1`、`g2`、`n2` 固定；两阶段只替换 g2，三阶段只替换 g3（三阶段的中间段 g2 不变）。
- 长投价值按列 r 重算：`max(0, longBook × longRet/100 ÷ r)`，与单点 `valuation.go:176-178` 同一表达式；`longRet` 为 `nil` 或 `longBook ≤ 0` 时为 0。
- 金融资产、债务、总股本、基期 FCF（含研发扩张）全部固定。
- 股权价值下限：`max(0, 公司价值 − 债务)`，格子可为 `0.00`，不加额外告警。

### 6.4 边界处理

| 场景 | 处理 |
|---|---|
| 单点估值失败 | `ComputeValuation` 返回 error，不产生结果，前端沿用现有错误提示，不渲染区块 |
| 总股本缺失/≤0 | `buildSensitivity` 返回 nil；`sensitivity` 字段省略；前端不渲染（Q4） |
| 零增长模型 | 1×3，`terminal_applicable=false`、`rows=[]`、`base_row=0`；行标题「终值增长率不适用」（Q1） |
| 基准 g∞ < 1.0pp | 保留 5 档且允许负值，例如基准 0% → `[-1.0,-0.5,0,0.5,1.0]`；不做 0 截断（Q2） |
| 基准 g∞ 为负 | 同上，负值原样作为行标题；只要 `r > g` 即有效 |
| 列 r ≤ 0 | 该格 nil → 前端「—」；列标题仍按计算值展示（可能为负），保持 3 列形状 |
| 列 r ≤ 行 g∞ | 该格 nil → 前端「—」；同表其他格正常 |
| 基准 r 很低（如 0.5%） | `r−0.5pp = 0` 的整列为「—」，其余列正常；不报错 |
| 公司价值 < 债务价值 | 与单点一致 floor 到 0，格子显示 `0.00` |
| 表单已修改但未点「计算估值」 | 矩阵仍反映上一次成功计算的参数（与单点行为一致） |
| 切换股票 | `fetchValuation` 重置/覆盖 `valuation`，矩阵随结果一起更新，无残留 |
| 切换模型后重新计算 | 基准 g∞ 按新模型重新取（g / g2 / g3），不沿用旧模型网格 |
| 非 0.5pp 网格的手工 query | 基准行/列保留精确值，相邻档 ±0.5pp；前端 1 位小数展示，不影响基准格一致性 |

### 6.5 基准格一致性保证

基准格 `Cells[BaseRow][BaseCol]` 与单点 `EquityValuePerShare` 走完全相同的运算链：

1. 基准行 = `terminalGrowthParam(params)` 原值；`paramsWithTerminalGrowth` 替换后与 `params` 逐位相同。
2. 基准列 = `params.DiscountRate` 原值；`rPct/100` 与单点 `r := params.DiscountRate / 100` 结果一致。
3. 经营资产价值：同一个 `dcfValue`、同一组参数、同一个 `fcf`。
4. 长投价值：同一个表达式 `max(0, longBook*(*longRet/100)/r)`。
5. 公司价值/股权价值/每股价值：加项顺序与 `math.Max` 一致。

因此基准格与单点值在浮点层面逐位相等，前端两者都使用 `toFixed(2)`，展示必然一致。**不在代码里用单点值覆盖基准格**，以保证矩阵确由 DCF 计算得出；由单元测试断言 `|cell − perShare| < 1e-9` 守护。

### 6.6 确定性与性能

- 敏感性只依赖 `params` 与已计算的报表派生值；无时间、随机数、AI、网络。
- 最多额外 15 次纯 DCF（每格一次 `dcfValue` + 一次长投除法），量级为微秒，接口响应时间影响可忽略。
- 所有格子内部使用完整精度；后端不做中途四舍五入。

## 10. 关键决策、假设与风险

### 10.1 需求默认项的落地

| 编号 | 采纳默认 | 实现位置 |
|---|---|---|
| Q1 | 零增长降级 1×3，行标题「终值增长率不适用」 | `buildSensitivity` 的 `!TerminalApplicable` 分支 |
| Q2 | 基准 g∞ < 1.0pp 保留 5 档并允许负值 | `Rows = base + i×0.5`，不做 0 截断 |
| Q3 | 长投价值随列 r 重算 | `sensitivityCell` 内与单点同表达式 |
| Q4 | 总股本缺失/≤0 不展示矩阵 | `buildSensitivity` 返回 nil + `omitempty` |
| Q5 | 卡片内、单点结果之后、默认展开 | 模板位置（§7.1），无折叠控件 |

### 10.2 实现假设（不阻塞开发）

1. **轴值不取整**：基准行/列直接使用入参精确值，相邻档位精确 ±0.5pp；前端按 1 位小数展示。理由：UI 与 AI 参数均为 0.5pp 网格，取整无实际差异；不取整可保证基准格与单点逐位一致。若未来开放任意精度手工参数，轴标题可能出现 1 位小数四舍五入后的展示差（不影响格子数值）。
2. **零增长的空 `rows`**：用空数组而非 `null`，前端用 `terminal_applicable` 分支渲染单行，避免在 `rows` 中塞入 sentinel 值。
3. **后端返回完整精度**：不在 `model` 层做 2 位小数舍入，展示统一由前端 `toFixed(2)` 完成，符合「不得中途四舍五入」。
4. **不持久化矩阵**：R16 记录结构不变；历史回填后重新计算即可，避免快照与最新口径不一致。
5. **行标题固定「终值增长率」**：两阶段/三阶段的终值段语义一致；零增长写「终值增长率不适用」。若后续希望按模型显示「永续增长率」，只需改前端文案，不影响数值口径。

### 10.3 风险与规避

| 风险 | 说明 | 规避 |
|---|---|---|
| 周期股 g∞ 由 2.0% 上调导致模型/参数变化 | 终值上调可能使 `gap = A − g∞` 变小，模型分类或 g1/n1 随规则变化 | 需求明确「规则内结果不抑制」；R20 既有确定性/模型测试继续通过 |
| 非周期股被误伤 | 2.5% 误用于非周期 | `terminalGrowth` 仅在 `isCyclical=true` 时使用该常量；§9.4 非周期用例断言 4.5% |
| 矩阵格子被二次套上限 | 行 3.0/3.5% 被悄悄改值 | `buildSensitivity` 不调用 `terminalGrowth`；§9.2 `TestSensitivityNoCapReapplied` |
| 基准格与单点不一致 | 长投/r/终值替换路径不同 | 复用 `dcfValue` 与同一表达式；基准行/列取精确入参；单测 1e-9 |
| r≤g 或 r≤0 产生除零/负值 | DCF 无意义或 panic | `sensitivityCell` 前置守卫返回 nil；前端「—」 |
| 无总股本的股票 | 无法算每股价值 | 不输出矩阵，与单点行为一致 |
| 移动端横向溢出 | 5×3 表格较宽 | 容器 `overflow-x: auto` + 表格 `min-width`；页面级不改 |
| 历史记录字段膨胀 | 矩阵写入快照 | 前端白名单构建记录，后端结构不变 |
| 测试期望值大面积变化 | R20 断言 2.0% | 仅更新明确的 2.0%/2% 断言；其余 R19/R20 测试作为不回归证据 |

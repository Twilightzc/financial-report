# R21 测试报告

## 测试范围
周期股终值基准 2.5% + 公司估值卡片 5×3 敏感性矩阵。方法：单元测试 + 边界用例 + 静态/构建检查 + Vue 模板编译 + 确定性 + 逐格手算复算。

## 结论
全部通过，未发现需要修复的代码缺陷。

### A. 终值基准 2.5%
- `r20CyclicalTerminalPP = 2.5`；`terminalGrowth` 周期股上限取 2.5%、非周期取宏观锚，`g∞ = max(0, floorHalf(min(上限, r−1pp, SGR)))` 口径不变。
- 2.5% 生效时 `constraint=cyclical` + 文案「终值增长率按周期股长期通胀 2.5% 封顶。」；SGR 或 r−1 更紧时不误报；非周期股不被压到 2.5%。

### B. 敏感性矩阵（buildSensitivity）
- 形状 5×3：行 = 基准 g∞ ±1pp（0.5 步长、允许负值），列 = 基准 r ±0.5pp；中心按模型取 g / g2 / g3，`base_row=2`、`base_col=1`；零增长降级 1×3（`terminal_applicable=false`、`rows=[]`）。
- **基准格与单点「每股股权价值」浮点严格相等**（perpetual/two_stage/three_stage/zero/非周期 5 组配置）。
- 逐格用独立公式（经营资产 = FCF×(1+g)/(r−g) 或对应模型、长投 = 账面×收益率÷r、股权 = max(0, 金融+长投+经营−债务)）手算复算，逐位一致。
- 无效格：`r≤0` 或（非零增长）`r≤g` 置 nil；`null` 与 `0.00` 严格区分。
- **矩阵不重新套用 2.5%/GDP/SGR/r−1pp 上限**；非周期 `rows=[3.5,4,4.5,5,5.5]` 全部有效。
- 总股本缺失/≤0 → 返回 nil，JSON `omitempty` 省略 `sensitivity` 字段。
- 确定性：同入参两次 `reflect.DeepEqual` 相等。

### C. 不回归
- `operatingFreeCashFlow`/`preservationCapex`/`dcf*` 未改动；WACC/CAPM、复合锚 A、g1=SGR+1pp、模型分类/降级、n1、Capex 覆盖率、FCF/净利润逻辑未动。
- R19/R20 全量既有测试通过；R16 历史记录前端白名单不含 `sensitivity`，旧快照兼容。

## 遗留风险
1. **真实数据端到端未验证（环境限制，非代码缺陷）**：沙箱禁止绑定 127.0.0.1，且 Go HTTPS 经代理报 `x509: OSStatus -26276`（curl 正常、Go 访问东财/腾讯失败），无法启动服务或 httptest 拉真实行情。已用 fixture 覆盖完整 `ComputeValuation` 链路及 handler 下游逻辑。
2. **375px 横向滚动仅静态验证**：CSS 容器与 `min-width` 符合设计，未在浏览器实测页面无横向溢出。
3. **技术设计文档 3 处示例数值笔误**（实现与测试均按公式，正确）：`技术设计文档.md:610` 的 `10.644722` 实为 `9.530526`；`:688` 的 `8.6485` 实为 `9.5305`、`8.6285` 实为 `7.9068`。同表其余数值正确，建议后续修订文档。
4. **并列约束文案边界（非缺陷）**：SGR 恰为 2.5% 时按 R20 优先级 `sgr` 为主约束，输出「与周期股长期通胀 2.5% 上限相同」而非固定封顶句，与 R20 既有并列规则一致。

# R20 估值增长与终值保守化 技术设计文档

> 需求编号：R20
> 状态：技术设计完成，待开发

> 修订关系：本设计只修订 R19《估值模型参数重构》§5.5 的两条口径——**g1 上限**与**周期/商品股终值增长率 g∞**。R19 其余口径（FCF、WACC/CAPM、复合锚 A、Capex 覆盖率、FCF/净利润、模型分类、0.5pp 网格、输出洁净、三档已废除）继续有效；两文档冲突时，以 R20 需求文档及其本设计为准。

## 1. 设计目标与影响面

### 1.1 设计目标

- **FR-1（g1 与 FCF 自洽）**：SGR 可用时，`capG1 = min(30%, SGR + 1pp)`，`g1 = floorHalf(clamp(A, g∞, capG1))`。前瞻锚退出 g1 上限，不再通过 `max(前瞻锚, SGR)` 抬升上限；前瞻锚仍按 R19 权重参与复合锚 A。
- **FR-2（周期股终值保守化）**：周期/商品股 `g∞ = max(0, floorHalf(min(2.0%, r − 1.0pp, SGR)))`；非周期股沿用 R19 的 `min(宏观锚, r − 1.0pp, SGR)`。
- **FR-3（依据可观测且洁净）**：g1 被压低、周期股 2% 真正生效时，只在现有 `g1_note` / `terminal_note` 中输出一句带数字的业务语言依据；不新增推导表、公式行、内部字段名。
- **FR-4/FR-5（不回归与边界）**：FCF、WACC、复合锚 A、模型分类、降级链、n1 规则、0.5pp 网格均不变；SGR 不可用、SGR 非正、上限低于终值、负增长等边界按需求文档处理。

### 1.2 非目标

- 不改 FCF 口径：`operatingFreeCashFlow = NETCASH_OPERATE − preservationCapex` 原样保留，不扣扩张性资本支出。
- 不改 WACC/CAPM、β 档位、公司特定风险溢价、折现率取整/区间。
- 不改复合锚 A 的三锚、权重、周期位置修正、取整与区间约束。
- 不改宏观锚本身（动态 GDP TTM，不可用 4.5%）。
- 不改 Capex 覆盖率、FCF/净利润、五种基期 FCF 选取、研发扩张加回。
- 不改模型分类阈值、`gap = A − g∞` 定义、`n1 = clamp(round((g1 − g∞)/1.5), 3, 10)`、三级降级链。
- 不新增行业名称关键词表、不新增动态通胀数据源、不新增终值占比展示/告警、不恢复三档情景。
- 不新增取数请求，不引入第三方依赖。

## 6. 核心实现细节与算法

### 6.1 新增常量（`growth.go` 常量区）

```go
// R20 估值增长与终值保守化。
r20G1SGRBufferPP      = 1.0 // g1 相对 SGR 的近似误差缓冲（用户确认，不得扩大）
r20CyclicalTerminalPP = 2.0 // 周期/商品股终值上限 = 长期通胀
```

均放在既有 `r18*` 常量旁，保持编译期常量、无配置项。

### 6.2 `growthG1`：签名不变，逻辑重写

```go
// growthG1 由复合锚 A 得到 g1 与唯一上限约束（R20）。
// SGR 可用：capG1 = min(30, max(0, SGR + 1))；
// SGR 不可用：前瞻锚可用时 min(30, max(0, 前瞻锚) + 2)，否则 30。
// g1 = floorHalf(clamp(A, g∞, capG1))。
func growthG1(A, gInf, fwd, sgr float64, fwdOK, sgrOK bool) (g1 float64, constraint, note string) {
    capG1 := 30.0
    capSource := "none" // 内部使用，不输出
    switch {
    case sgrOK:
        capG1 = math.Min(30.0, math.Max(0, sgr+r20G1SGRBufferPP))
        capSource = "sgr"
    case fwdOK:
        capG1 = math.Min(30.0, math.Max(0, fwd)+2.0)
        capSource = "forward"
    }

    // 上限低于终值：g1 按终值收口，不得出现 g1 < g∞ 或负值。
    if capG1 < gInf {
        return gInf, "cap_below_terminal", "上限低于终值，g1 按终值收口。"
    }

    g1 = floorHalf(clampFloat(A, gInf, capG1))

    // 注意：约束判定比较 A 与 capG1，而不是 g1 与 A。
    // 否则 A=0.2%、cap=0.5% 这类仅被 0.5pp 网格向下取整的情况会被误报为「上限约束」。
    switch {
    case A > capG1+1e-9:
        return g1, "upper", r20G1UpperNote(capSource, sgr)
    case A < gInf-1e-9:
        return g1, "terminal", "g1 按终值收口。"
    default:
        return g1, "none", ""
    }
}
```

新增内部 helper `func r20G1UpperNote(capSource string, sgr float64) string`（仅 `growthG1` 使用，返回上表文案）。`r20G1UpperNote` 文案表（`sgr` 数值保留 1 位小数；`capSource` 不进输出）：

| 条件 | `g1_note` |
|---|---|
| `capSource=sgr`，SGR>0 且 `SGR+1 ≤ 30` | `高增长期增长率受自筹资金可持续增速 8.0% + 1pp 上限约束。` |
| `capSource=sgr`，SGR>0 且 `SGR+1 > 30` | `自筹资金可持续增速 32.0%，高增长期增长率按 30% 上限约束。` |
| `capSource=sgr`，`-1 < SGR ≤ 0` | `自筹资金可持续增速非正（0.0%），高增长期增长率按 1pp 上限收口。` |
| `capSource=sgr`，`SGR ≤ -1` | `自筹资金可持续增速非正（-1.2%），高增长期增长率按 0 收口。` |
| `capSource=forward` | `自筹资金可持续增速不可用，高增长期增长率按前瞻锚 + 2pp 上限（且不超过 30%）约束。` |
| `capSource=none` | `自筹资金可持续增速不可用，高增长期增长率仅受 30% 上限约束。` |

约束语义：

- SGR 可用（`sgrOK=true`）时，**无论 SGR 正负**都走 `SGR + 1pp` 公式；前瞻锚完全不参与 `capG1`。
- `g1` 仍为 0.5pp 网格向下取整，仍满足 `g1 ≥ g∞`、`g1 ≥ 0`。
- 只有 `A > capG1` 才输出上限依据；`A ≤ capG1` 且 `A ≥ g∞` 时输出空 note。
- `constraint` 取值集合保持 `none/upper/terminal/cap_below_terminal`，不新增枚举，避免前端/历史判断分支变化。

### 6.3 `terminalGrowth`：新增 `isCyclical` 入参

```go
// terminalGrowth g∞（R20）：
//   周期/商品股：cap = 2.0%；非周期股：cap = 宏观锚。
//   g_raw = min(cap, r − 1.0, SGR if available)
//   g∞    = max(0, floorHalf(g_raw))
// constraint 取真正生效的 sgr / discount / cyclical / macro / zero。
func terminalGrowth(macro, discount, sgr float64, sgrOK, isCyclical bool) (g float64, constraint, note string) {
    cap, capKey, capName := macro, "macro", "宏观锚"
    if isCyclical {
        cap, capKey, capName = r20CyclicalTerminalPP, "cyclical", "周期股长期通胀 2% 上限"
    }

    gRaw := math.Min(cap, discount-1.0)
    if sgrOK {
        gRaw = math.Min(gRaw, sgr)
    }
    g = math.Max(0, floorHalf(gRaw))
    if gRaw <= 0 {
        return g, "zero", "终值按 0。"
    }

    // 主约束优先级：sgr > discount > cap（周期股 2% 或宏观锚）；同值取先出现者。
    type source struct {
        key string
        val float64
    }
    sources := []source{{key: "discount", val: discount - 1.0}, {key: capKey, val: cap}}
    if sgrOK {
        sources = []source{{key: "sgr", val: sgr}, {key: "discount", val: discount - 1.0}, {key: capKey, val: cap}}
    }
    // 沿用 R19 terminalGrowth 926-954 行的并列判定逻辑（不新造 helper）。
    primary := sources[0]
    ties := make([]string, 0, 2)
    for _, s := range sources[1:] {
        switch {
        case s.val < primary.val-1e-9:
            primary = s
            ties = ties[:0]
        case math.Abs(s.val-primary.val) <= 1e-9:
            ties = append(ties, s.key)
        }
    }

    names := map[string]string{
        "sgr":      fmt.Sprintf("长期内生增速 %.1f%%", sgr),
        "discount": "折现率−1pp",
        capKey:     capName,
    }
    if primary.key == "cyclical" {
        note = "终值增长率按周期股长期通胀 2% 封顶。"
    } else {
        note = fmt.Sprintf("终值受%s约束，向下取整至 %.2f%%。", names[primary.key], g)
    }
    if len(ties) > 0 {
        tieNames := make([]string, 0, len(ties))
        for _, k := range ties {
            tieNames = append(tieNames, names[k])
        }
        // 例：「与长期内生增速 2.0% 相同。」
        note += "与" + strings.Join(tieNames, "、") + "相同。"
    }
    return g, primary.key, note
}
```

要点：

1. **周期股不读宏观锚**：`cap = 2.0`，严格按 FR-2 公式 `min(2.0%, r−1, SGR)`；宏观锚只参与非周期股终值。
2. **2% 是上限不是目标**：SGR 或 `r−1` 更低时取更低者，`floorHalf` 向下取整，不向上补到 2%。
3. **2% 在 0.5pp 网格上**：`floorHalf(2.0)=2.0`；当 `cyclical` 为主约束时 `g∞` 恒为 2.0。
4. **文案洁净**：SGR 生效时使用「长期内生增速 X.X%」，不出现 `SGR`、`sgr`、`macro` 等键名；周期股使用固定业务句。
5. **并列**：沿用 R19 的 `1e-9` 同值判定与优先级 `sgr > discount > cap`；并列项追加「与 X 相同」。当 SGR 与 2% 并列时，主约束为 SGR，note 同时注明 2% 上限，避免把并列误写成单一约束。

### 8.5 天山铝业（002532）复算方法（AC-17）

1. **修改前基线**：在 R19 代码上启动服务，对 002532 触发一次 AI 分析，记录同一快照下的 `growth_terminal`、`params`（g1/n1/g2/n2/g3）、`discount_rate`、`fcf_base_value`、`model`、`g1_note`、`terminal_note`。
2. **修改后复算**：在同一交易日、同一期财报、同一行业分类下再次触发，记录同组字段。
3. **口径断言**：
   - `growth_terminal ≤ 2.0`；
   - `g1 ≤ SGR + 1.0`（SGR 可由 `g1_note` 或复算 ROE×留存率得到）；
   - `gap = A − g∞`、`n1 = clamp(round(gap/1.5), 3, 10)`、模型分类符合 R19 阈值；
   - 输出不含公式行/内部字段名。
4. **终值占比复算**（用卡片参数与基期 FCF 手工计算）：
   - 两阶段：`V = Σ_{t=1..n1} FCF(1+g1)^t/(1+r)^t + [FCF(1+g1)^n1(1+g2)/(r−g2)]/(1+r)^n1`，终值项为第二项；
   - 三阶段：把 g2/n2 插入后同理，终值项按 `g3` 折现 `n1+n2` 期；
   - `终值占比 = 终值项 ÷ V`。
5. **验收**：`占比_after < 占比_before`；若模型因 `gap` 变大而升级，按升级后的参数计算，仍要求占比下降。
6. 复算过程与数字写入 `docs/测试报告/`，作为 AC-17 证据。

## 9. 关键决策、假设与风险

### 9.1 需求待确认项的落地

| 编号 | 采纳默认 | 实现位置 |
|---|---|---|
| Q1 | SGR 不可用：前瞻锚可用用 `min(30, max(0, 前瞻锚)+2)`；否则 30% | `growthG1` |
| Q2 | 不新增关键词表，沿用 `detectCyclical`；全未命中按非周期 | `terminalGrowth(isCyclical)` |
| Q3 | 2% 仅适用于 `isCyclical=true`（含 FCF 强周期/盈利周期命中）；公用事业/金融仍 GDP | `terminalGrowth` |
| Q4 | 2% 固定常量，不接动态通胀 | `r20CyclicalTerminalPP` |
| Q5 | 不新增终值占比展示/告警 | 前端不改 |
| Q6 | g∞ 下调引起的模型变化不抑制 | `classifyGrowthModel` 不改 |

### 9.2 实现假设

- **A-1**：周期股终值不使用宏观锚。严格按 FR-2 公式 `min(2.0%, r−1, SGR)`；即使动态 GDP 低于 2%，周期股仍以 2% 为上限（正常年份 GDP≈4.5%，无实际差异）。
- **A-2**：`g1_constraint` 不新增枚举，用 note 区分 SGR 主路径/前瞻兜底/30% 兜底；前端与历史记录无需适配。
- **A-3**：SGR 数值只写入 `g1_note`，不扩大 `sgr` 字段输出条件，减少 API 行为变化。
- **A-4**：删除 `capTerminalGrowth` 死代码，避免终值出现两套口径。
- **A-5**：note 中 SGR 数值按 1 位小数展示；上限计算使用未取整原值，保证「先算上限、再按 0.5pp 向下取整」可复算。

### 9.3 风险与规避

| 风险 | 说明 | 规避 |
|---|---|---|
| 周期误判导致 g∞ 被压到 2% | `isCyclical` 含 FCF 强周期/盈利周期兜底，可能覆盖非大宗商品公司 | 需求已确认按现有 `isCyclical` 统一执行；判定链不变，误判风险与 β/周期位置共用、可追溯 |
| SGR 不可用时的兜底比 R19 更保守/更宽松 | Q1 兜底为 `max(0, 前瞻锚)+2`，负前瞻锚不再压低上限 | 与需求 Q1 一致；仅异常公司路径，主路径不受影响 |
| 模型因 gap 变大而升级 | 终值下调使两阶段/三阶段更容易命中 | 需求 Q6 明确不抑制；输出「已降级」逻辑不变 |

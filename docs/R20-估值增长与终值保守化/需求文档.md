# 估值增长与终值保守化

> 需求编号：R20
> 状态：需求分析完成，待用户确认「待确认问题」后进入技术设计
> 修订关系：本文档只修订 R19《估值模型参数重构》§5.5 中的两条口径——**g1 上限**与**周期/商品股终值增长率 g∞**。R19 其余全部口径继续有效；两文档冲突时，以本文档对这两条的修订为准，其余以 R19 为准。

## 1. 背景与目标

### 1.1 背景

R19 已完成估值参数重构：取消保守/基准/乐观三档，只输出单一「适中基准」参数，并统一了 WACC、复合锚 A、Capex 覆盖率、FCF/净利润、风险溢价等口径。本次是在 R19 基础上的进一步修正。

用户将「天山铝业」的 AI 估值参数结果交给外部评审，评审提出 3 点问题，用户认可其结论：

1. **FCF 未扣扩张性资本支出，但增长率却按扩张后的收益计算**。基期自由现金流是保全口径（只扣维持现有经营能力的支出），高增长期增长率却按营收/净利润口径给出，等于假设扩张所需资金凭空可得，增长与 FCF 不一致，整体偏乐观。
2. **历史锚与 FCF 表矛盾**。历史锚用营业收入、净利润增速，重资本开支行业里营收、净利润在涨，FCF 却因持续大额资本开支不涨；用营收/净利润推出来的增长率去贴现一个不反映扩张的 FCF，两套口径互相矛盾。
3. **终值占比过高**。周期股给满额 GDP 永续增长（约 4.5%），在折现率约 8% 时永续乘数约 29 倍（1 ÷ (8% − 4.5%)），终值占经营资产价值约 80%，估值结果主要由一个最不确定的远期假设决定。

### 1.2 现状与根因

**现状代码事实**（已核对）：

- **FCF 口径**：`operatingFreeCashFlow` = `NETCASH_OPERATE` − 保全性资本支出（`internal/service/valuation.go`），不扣扩张性资本支出。这是 R19 明确保留的口径，本次不改。
- **g1 上限**：`growthG1` 的 `capBase = min(30%, max(前瞻锚, SGR) + 2pp)`；只有前瞻锚时 `min(30%, 前瞻锚+2pp)`，只有 SGR 时 `min(30%, SGR+2pp)`（`internal/service/growth.go`，调用点 `valuation_recommend.go`）。即增长上限可以由前瞻锚（卖方一致预期）抬升。
- **g∞ 口径**：`terminalGrowth` = `max(0, floor0.5(min(宏观锚, r−1.0, SGR)))`，宏观锚为动态 GDP TTM 同比（不可用时 4.5%）；对所有公司一视同仁，周期股也按 GDP 给永续增长（`internal/service/growth.go`，调用点 `valuation_recommend.go`）。
- **周期判定入口**：`detectCyclical`，优先级为「AI 行业分类 `industry_type=cyclical`（命中即判周期）→ 成长性否决（仅在前者未命中时生效，命中则不判周期）→ FCF 强周期 → 盈利周期」（`internal/service/growth.go`）。同一份结果 `isCyclical` 已用于周期位置修正与负增长归因。

**根因**：

- 增长上限的两个来源（前瞻锚、SGR）与 FCF 口径都不自洽：前瞻锚来自卖方对净利润/营收的预测，本身已包含扩张带来的增量；SGR 是自筹资金可持续增速，只与留存收益有关，与保全口径 FCF 更接近，但被 `max` 抬升后失去了约束力。
- 历史锚的输入是营收/净利润增速，而贴现对象是保全口径 FCF。重资本开支行业的营收/净利润增长与 FCF 增长可以长期背离，历史锚因此系统性高估。
- 周期股用宏观 GDP 作为永续增长率，等于假设周期行业在永续期仍能跑赢长期通胀；这与周期行业的长期定价特征不符，也把终值乘数推到了不合理的水平。

### 1.3 目标

- **G1 增长与 FCF 自洽**：高增长期增长率只由自筹资金可持续增速（SGR = ROE × 留存率）支撑，最多上浮 1pp，不再由前瞻锚直接抬升上限。
- **G2 周期股终值保守化**：周期/商品股的终值增长率 g∞ 以长期通胀 2% 封顶，显著压降其终值占经营资产价值的比例；非周期股保持 R19 的 GDP 口径不变。
- **G3 依据可观测**：g1 受自筹资金约束、周期股终值按 2% 封顶时，输出各一句可复算的依据，符合 R19 的输出洁净原则。
- **G4 不回归**：R19 已定的 FCF 口径、WACC/CAPM、复合锚 A 与权重、Capex 覆盖率、FCF/净利润、模型分类规则、0.5pp 网格、三档已废除、输出洁净等均不改变。

可衡量的达成标准：

- 任一 SGR 可用且为正的公司，最终 `g1 ≤ min(30%, SGR + 1pp)`。
- 任一被判定为周期/商品股的公司，最终 `g∞ ≤ 2.0%`；非周期公司的 `g∞` 与 R19 公式逐位一致。
- 以天山铝业为样本，修改后的 g∞ 从约 4.5% 降至不超过 2.0%，终值占经营资产价值比例低于修改前同输入结果。
- 同一输入多次调用输出完全一致；不新增任何取数请求。

### 1.4 非目标

- **不改 FCF 口径**：基期自由现金流仍为「经营活动现金流量净额 − 保全性资本支出」，不扣扩张性资本支出，不改为「FCF − 扩张 Capex」。本次不追求「FCF 反映扩张」，而是让增长率收敛到与保全口径 FCF 自洽的水平。
- **不改 WACC/CAPM、β 档位、公司特定风险溢价**。
- **不改复合锚 A 的构成与权重**：历史锚、前瞻锚、宏观锚仍按 R19 权重合成 A；本次只改变前瞻锚对 g1 上限的作用，不改变前瞻锚参与 A 的权重与算法。
- **不改宏观锚本身**：非周期股与复合锚 A 中的宏观锚仍为动态 GDP TTM 同比（不可用时 4.5%）。
- **不改 Capex 覆盖率、FCF/净利润口径**。
- **不改模型分类阈值与降级链**、**不改 0.5pp 网格与 floor 取整规则**、**不改 n1 均值回归规则**。
- **不恢复三档情景**，不新增「保守/乐观」参数。
- **不改输出洁净原则**：不新增推导表、公式行、内部变量名、规则元语言与工具说明。
- **不新增根据行业名称关键词（铝/钢/煤等）硬编码的周期判定表**；周期判定沿用现有入口。

## 2. 用户故事 / 使用场景

- 作为使用 AI 估值参数的投资者，我希望高增长期增长率不超过公司靠自身留存收益能支撑的水平，以便我看到的增长假设不需要假设外部融资或扩张性资本开支凭空出现。
- 作为分析周期股的投资者，我希望周期股（铝、钢、煤炭等）的永续增长率不要套用宏观 GDP，以便终值不会因为一个偏高的永续假设而占到经营资产价值的绝大部分。
- 作为核对参数的投资者，我希望在 g1 被自筹资金约束、周期股终值按 2% 封顶时，看到一句带数字的依据，以便我能判断这个参数是怎么来的，而不用看到推导过程和工具话术。

## 3. 功能需求

### FR-1 g1 上限改为 SGR + 1pp（P0）

- **触发**：每次生成 AI 估值参数、计算 g1 时。
- **口径**：当 SGR 可用且为正时：

  ```
  capG1 = min(30%, SGR + 1pp)
  g1    = floor0.5(clamp(A, g∞, capG1))
  ```

  - `SGR = ROE × 留存率 × 100%`，沿用 R19 既有口径（归母净利润优先，缺失/非正时回落重构净利润并标注；留存率优先现金分红口径，否则权益增长口径）。
  - `A` 仍为复合锚最终值，仍按 R19 的 `clamp(round0.5(A_raw), −5, 30)` 计算；本次不改变 A 的构成、权重与取整。
  - `g1` 仍按 0.5pp 网格向下取整，仍不得低于 g∞、不得为负。
  - **SGR 可用时，前瞻锚不再参与 g1 上限**：前瞻锚仍按 R19 权重参与复合锚 A 的合成，但不得再作为 `capG1` 的输入，也不得通过 `max(前瞻锚, SGR)` 抬升上限。SGR 不可用时的兜底见下条，属于唯一例外。
  - 1pp 是 SGR 近似误差的缓冲，由用户确认；不得扩大到 2pp，也不得再叠加其他上限。
- **上限低于终值时**：若 `capG1 < g∞`，`g1 = g∞`，并输出「上限低于终值，g1 按终值收口」类依据；不得输出负 g1 或高于 g∞ 的 g1。
- **SGR 为 0 或负时**：`capG1` 仍按公式计算。SGR=0 时 `capG1=1%`、g∞=0，`g1 ≤ 1%`；SGR<0 时 g∞=0，`g1 = clamp(A, 0, max(0, SGR+1))`，SGR≤−1% 时 `g1=0`，−1%<SGR<0 时 `g1 ≤ SGR+1`。均不得出现负 g1；输出「自筹资金可持续增速非正，g1 按 1pp 上限/终值收口」类依据。
- **SGR 不可用时**（详见 Q1，推荐默认值）：
  - 前瞻锚可用：`capG1 = min(30%, max(0, 前瞻锚) + 2pp)`，即回落到 R19 的单一前瞻锚上限；输出「自筹资金可持续增速不可用，g1 按前瞻锚 + 2pp 上限约束」类依据。
  - 前瞻锚也不可用：`capG1 = 30%`；输出「自筹资金可持续增速不可用，g1 仅受 30% 上限约束」类依据。
  - 该兜底只在 SGR 不可用时生效，不得反向影响 SGR 可用时的主路径。
- **g1 未被上限压低时**（`A ≤ capG1` 且 `A ≥ g∞`）：不输出上限依据句，避免每条参数都出现无信息量的提示。
- **软告警口径**：现有代码中 `verifyC4b` 定义的「g1 高于 SGR」软告警（当前未接入主链路）若启用或保留，阈值应同步改为「g1 高于 SGR + 1pp」。1pp 缓冲本身是设计内的，不得对每家公司都输出「g1 高于 SGR」的材料性警告。

### FR-2 周期/商品股终值增长率以 2% 封顶（P0）

- **触发**：每次生成估值参数、计算 g∞ 时。
- **周期/商品股的判定**：沿用现有 `detectCyclical` 的结果 `isCyclical`，不新增第二套判定；该结果同时用于 β 档位、周期位置修正与负增长归因，本次只新增其终值含义，不改变原用途。判定优先级保持现状：
  1. AI 输出的行业分类 `industry_type` 归一化为 `cyclical`，命中即判周期；
  2. 未命中第 1 条时，成长性否决命中则不判为周期股；
  3. 未命中成长性否决时，FCF 强周期（变异系数、符号翻转次数命中）；
  4. 仍未命中时，盈利周期命中。
- **周期/商品股口径**：

  ```
  g∞ = max(0, floor0.5(min(2.0%, r − 1.0pp, SGR)))
  ```

  - SGR 可用时仍作为上限参与，不可用时只受 `2.0%` 与 `r − 1.0pp` 约束。
  - `r − 1.0pp ≤ 0` 时 g∞ 取 0。
  - 2.0% 本身在 0.5pp 网格上，取整不改变其值。
  - 2.0% 是上限而非目标值：SGR 或 `r−1` 更低时，g∞ 取更低者，不得向上补到 2.0%。
  - 该上限作用于最终永续段：永续模型的 g、两阶段的 g2、三阶段的 g3；不改变三阶段中间段 g2 的构造规则。
- **非周期股口径不变**：仍按 R19：

  ```
  g∞ = max(0, floor0.5(min(宏观锚, r − 1.0pp, SGR)))
  ```

  宏观锚仍为动态 GDP TTM 同比（不可用时 4.5% 常量），不得因本次修改把非周期股也压到 2%。
- **与负增长归因的关系**：`A < 0` 且周期性负增长的，仍按 R19 走永续模型且永续增长取 0；本次 2% 上限不改变该路径。
- **模型分类与年限**：模型分类阈值、`gap = A − g∞` 的定义、`n1 = clamp(round((g1 − g∞)/1.5), 3, 10)`、三级降级链均不变。因 g∞ 下调导致 `gap` 变大、模型由永续变为两阶段/三阶段的，属于规则内结果，不做额外抑制。

### FR-3 输出依据句（P0）

- **g1 受自筹资金约束时**：当 `g1` 因 `capG1` 被压低，输出一句可复算的依据，至少包含实际 SGR 数值与「+1pp」口径，例如：
  - 「高增长期增长率受自筹资金可持续增速 8.0% + 1pp 上限约束。」
- **周期股终值按 2% 封顶时**：当 2.0% 是真正生效的最小约束，输出一句：
  - 「终值增长率按周期股长期通胀 2% 封顶。」
- **终值受其他约束时**：仍按 R19「只显示真正生效的约束项」：
  - SGR 生效：「终值受长期内生增速 X.X% 约束。」
  - `r−1` 生效：「终值受折现率−1pp 约束。」
  - `g_raw ≤ 0`：「终值按 0。」
  - 2.0% 未生效（SGR 或 `r−1` 更低）时，不得写成「受 2% 约束」。
  - 多个约束并列时，沿用 R19 的主约束优先级（SGR > 折现率−1pp > 宏观锚/周期股 2% 上限），并可按 R19 方式注明并列项。
- **SGR 不可用兜底时**：输出 FR-1 对应的一句依据；不得把兜底说成「受 SGR 约束」。
- **措辞约束**：使用「自筹资金可持续增速」「长期通胀 2%」等业务语言；不得出现内部字段名、函数名、`capBase`、`macro`/`sgr` 等键名、公式行、阈值表、规则元语言或工具说明。
- **展示位置**：复用现有 `g1_note`、`terminal_note` 字段与前端注脚位置，不新增推导表，不新增可折叠过程区。

### FR-4 保持 R19 既有口径不回归（P0）

- 基期 FCF 仍为 `经营活动现金流量净额 − 保全性资本支出`；本次不扣扩张性资本支出，也不因 g1/g∞ 修改而调整 FCF。
- 复合锚 A 的三锚、权重、周期位置修正、取整与区间约束不变。
- WACC/CAPM、β 档位、公司特定风险溢价、折现率取整与区间约束不变。
- Capex 覆盖率、FCF/净利润的分子分母与基期口径不变。
- 五种基期 FCF 选取方式、研发扩张加回不变。
- 模型分类阈值、降级链、0.5pp 网格、floor 取整、n1 规则不变。
- 三档情景仍为已废除状态，不得以任何形式恢复。

### FR-5 异常与边界处理（P0）

- **SGR 不可用**：按 FR-1 兜底；终值仍按 FR-2 公式（此时只受 2.0% 与 `r−1` 约束）。
- **SGR 为 0 或负**：g∞ 取 0；SGR=0 时 g1 ≤ 1%，SGR≤−1% 时 g1=0，−1%<SGR<0 时 g1 ≤ SGR+1，不得为负。
- **股东权益为负 / 归母净利润为负 / 留存率不可得**：SGR 视为不可用，不得硬算负 SGR 后得到误导性的正上限；按 FR-1 兜底，并在依据句中说明「自筹资金可持续增速不可用」。
- **g∞ 触顶**：`r − 1.0pp` 小于 0 时，g∞ 取 0，不得为负。
- **周期判定不可用**：`industry_type` 缺失或无法归一化时，仍按 `detectCyclical` 的 FCF 强周期与盈利周期兜底；全部未命中时按非周期股处理，使用 GDP 口径。
- **成长性否决**：在 AI 行业分类未判定为周期股的前提下，命中成长性否决的公司不判为周期股，终值使用非周期口径；AI 已明确归类为周期股的，仍按周期股处理。这是现有规则，本次不修改。
- **A 为负**：结构性负增长走零增长模型；周期性负增长走永续且增长取 0；2% 上限不改变该结果。
- **上限低于终值**：g1 取 g∞，并输出对应依据，不得出现 `g1 < g∞` 或负值。
- **模型降级**：g1 与 g∞ 相等导致两阶段/三阶段降级时，仍按 R19 规则在模型名后标注「已降级」并给一句原因。

## 4. 非功能需求

- **确定性**：同一公司、同一期财报、同一行业分类、同一快照，任何时候输出完全一致；本次修改不引入随机数、当前时间或 AI 参与计算。
- **性能**：g1 与 g∞ 仍在现有纯函数链路内计算，不新增数据请求；单次参数推导的额外开销可忽略。
- **兼容性**：API 复用现有 `g1`、`g1_note`、`g1_constraint`、`g∞`、`terminal_note`、`terminal_constraint` 字段，不新增前端必填字段；R16 历史记录中的旧快照仍可正常展示，不因本次口径变化而报错。
- **展示与移动端**：依据句最多增加 1–2 行，375px 宽度下正常换行，不出现横向滚动；不新增表格、公式行或折叠推导区。
- **输出洁净**：估值参数区只保留参数、口径、数据年份与材料性依据；不出现工具说明、推导过程、规则元语言、内部变量名。
- **可复算**：用户能用卡片上的 SGR、g1、g∞、r 与一句依据，手工验证 `g1 ≤ SGR + 1pp`、`g∞ ≤ 2.0%`。

## 5. 边界与约束

- **不做**：把扩张性资本支出从 FCF 中扣除；用「扩张后 FCF」重算增长；新增动态通胀数据源；新增行业名称关键词表；对公用事业、金融业套用 2% 终值；恢复三档；新增终值占比展示面板。
- **依赖**：
  - SGR 依赖现有 `sustainableGrowthR18`（ROE × 留存率），其口径不变。
  - 周期判定依赖现有 `detectCyclical` 与 `industry_type` 归一化，其判定链不变。
  - 宏观锚依赖现有动态 GDP 快照与 4.5% 兜底，其口径不变。
- **已知限制**：
  - SGR 是自筹资金增长的近似值，1pp 缓冲只能覆盖近似误差，不能覆盖公司通过外部融资实现的高增长；这是本次有意接受的保守化取舍。
  - 2% 是长期通胀的固定假设，不是公司特定通胀或行业特定通胀；无可靠数据源时不做动态化。
  - 周期判定仍可能漏判（AI 分类缺失且 FCF/盈利周期信号不明显），漏判时按非周期股处理，属于已知边界。
  - 2% 上限按现有 `isCyclical` 统一执行，包含 FCF 强周期/盈利周期兜底命中的公司，不只限于铝、钢、煤等大宗商品；若未来要收窄到「仅商品股」，需要另立判定口径，不在本次范围。
  - 本次不改变终值的折现计算方式，只改变 g∞ 输入；终值占比的下降幅度取决于公司自身 r、g1 与增长路径，不承诺统一比例。

## 7. 待确认问题

- **Q1 SGR 不可用时，g1 上限如何兜底？**
  - 影响：负权益、亏损、留存率不可得公司的 g1 与模型选择；也影响「增长只由自筹资金支撑」这一原则在异常场景下的严格程度。
  - 推荐：**前瞻锚可用时回落到 R19 的「前瞻锚 + 2pp、≤30%」；前瞻锚也不可用时只受 30% 上限约束**。理由：SGR 不可用时无法验证自筹资金约束，保留原有单一前瞻上限比直接放到 30% 更保守，也不会对异常公司产生比 R19 更乐观的结果；主路径（SGR 可用）仍是 `SGR+1pp`，不受影响。
  - 备选：SGR 不可用时一律只受 30% 上限约束。该方案更彻底地贯彻「不让前瞻锚抬升上限」，但对负权益/亏损公司的 g1 可能明显高于 R19，保守性下降。

- **Q2 周期判定在 `industry_type` 缺失时是否要新增行业名称关键词兜底？**
  - 影响：铝、钢、煤炭等公司若 AI 未给出 `cyclical` 且 FCF/盈利周期信号不明显，会按非周期股使用 GDP 终值。
  - 推荐：**不新增关键词表，沿用现有 `detectCyclical` 链（FCF 强周期、盈利周期）**。理由：关键词表维护成本高、易误判（同一行业内有成长型公司），且现有链已覆盖大部分强周期特征；漏判按非周期处理是可接受的已知边界。
  - 备选：后续如样本显示漏判明显，再以独立需求补充行业名称映射，不在本次范围。

- **Q3 2% 终值上限是否也适用于公用事业、金融等其他行业？**
  - 影响：公用事业、银行等低增长行业的终值水平。
  - 推荐：**本期只适用于周期/商品股，其他行业保持 R19 的 GDP 口径**。理由：用户本次明确针对铝、钢、煤炭等大宗/周期行业；公用事业与金融业的长期增长逻辑不同，不应在未论证的情况下一起压低。

- **Q4 「2% 通胀」用固定常量还是接动态通胀数据？**
  - 影响：终值上限是否会随年份变化。
  - 推荐：**固定 2.0% 常量**。理由：当前数据源没有可靠、同口径的长期通胀序列；固定常量可复算、可解释，也符合「参数确定性」原则。未来若接入可信通胀数据，再以独立需求替换。

- **Q5 终值占经营资产价值的比例是否需要在界面上展示或告警？**
  - 影响：用户能否直接看到「终值占比过高」这一风险。
  - 推荐：**本期不新增展示，验收用天山铝业样本的前后对比复算记录**。理由：R19 已确立输出洁净原则，新增占比指标会引入新的口径与展示复杂度；本次先用参数约束压降占比，避免范围扩大。
  - 备选：若用户希望显性提示，可在材料性警告中增加一句「终值占比 X%，估值对永续假设敏感」，但需另行确认阈值与措辞。

- **Q6 因 g∞ 下调导致周期股模型由永续变为两阶段/三阶段，是否需要抑制？**
  - 影响：周期股的模型名称与 n1 年限，进而影响估值路径。
  - 推荐：**不抑制，保持 R19 模型分类规则不变**。理由：`gap = A − g∞` 变大是终值下调的自然结果；若为避免模型升级而额外限制 gap，会引入第二套规则，破坏可复算性。验收时只需确认分类结果可由 R19 规则复算。

## 8. 与 R19 的对照摘要

| 项目 | R19 现行口径 | R20 修订后口径 | 是否变更 |
|---|---|---|---|
| 基期 FCF | 经营现金流净额 − 保全性资本支出 | 同左 | 否 |
| 复合锚 A | 历史/前瞻/宏观三锚加权，clamp [−5,30] | 同左 | 否 |
| 宏观锚 | 动态 GDP TTM，不可用 4.5% | 同左（仅非周期股终值仍直接使用） | 否 |
| g1 上限 | `min(30%, max(前瞻锚, SGR) + 2pp)` | SGR 可用时 `min(30%, SGR + 1pp)`；前瞻锚不再参与 | **是** |
| g∞（周期股） | `min(宏观 GDP, r−1, SGR)` | `min(2.0%, r−1, SGR)` | **是** |
| g∞（非周期股） | `min(宏观 GDP, r−1, SGR)` | 同左 | 否 |
| 模型分类/降级 | A/gap/score 阈值 + 三级降级 | 同左 | 否 |
| 0.5pp 网格 / floor | 保留 | 保留 | 否 |
| 输出洁净 | 只给参数、口径、依据 | 同左，新增两句限定依据 | 否（新增依据句） |
| 三档情景 | 已废除 | 仍废除 | 否 |

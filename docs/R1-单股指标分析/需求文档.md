# R1：单股指标分析

### 5.1 功能

| 功能 | 说明 |
| --- | --- |
| 股票查询 | 输入 A 股代码/名称，识别并加载目标股票 |
| 数据获取 | 自动获取三张报表（资产负债表、利润表、现金流量表）+ 行情数据 |
| 指标计算 | 计算常见估值指标（占位方案，见 5.3） |
| 结果展示 | 单页呈现指标表 |

### 5.2 核心用户流程

1. 用户输入股票代码
2. 系统拉取财报 + 行情数据
3. 计算分析指标
4. 页面展示指标表

### 5.3 分析指标（占位实现）

> 当前为占位方案，待用户给定正式分析方法与指标后替换。

当前实现：

- 总市值
- 市盈率 PE（静态，按最新年报）
- 市净率 PB
- ROE
- 毛利率、净利率
- 资产负债率
- 每股收益 EPS、每股净资产 BPS

### 5.4 边界（明确不做）

- PDF 财报上传 / OCR 解析
- 多用户、账号、权限体系
- 数据持久化 / 数据库（数据实时拉取即可）
- 批量筛选、横向对比
- 实时行情推送

## 1. 背景与目标

### 1.1 背景

本项目的现金流贴现法（DCF）估值已经具备完整链路：基期自由现金流（FCF）选取 → 折现率 r → 增长率 g → 模型分档 → 终值 → 参数输出 → 前端套用。但参数推导分散在 R4、R7、R12、R13、R15、R18 多个需求中，存在三类问题：

1. **口径分散、重复解释**：FCF 选取、WACC、三层增长锚、周期修正、SGR、均值回归路径分别写在不同的文档，读者需要自己拼装；同一概念在不同文档有不同叫法（如 `X` / `A_hist` / `growth_history`）。
2. **权重与调整过程不够透明**：复合锚的 0.45/0.45/0.10 等权重、周期修正、离散度折减、软上限、包络、模型得分，最终只以一个 `g1` 呈现，前端和 AI 都难以解释「这个数是怎么来的」。
3. **只有单点参数，没有不确定性区间**：DCF 对 r 和 g 高度敏感，单个「基准值」容易被误读为精确结论；用户需要看到保守/基准/乐观三档，并理解每档的锚定依据。

同时，当前 AI 分析默认模型为 `deepseek-v4-pro`，需要切换为更快、成本更低的 `deepseek-flash`（官方 API 将该名称路由到最新 V4.1-Flash-1017）。

### 1.2 本次要解决的问题

- 问题 1：把 R15 + R18 合并为一份**不重复、可执行、可验收**的参数需求文档，明确所有需要改代码的点。
- 问题 2：复盘基期 FCF 的选取逻辑是否合理，给出行业实践对照、现状优缺点和具体改进要求。
- 问题 3：把最终估值参数从**单点**升级为**保守 / 基准 / 乐观三档**，并贯通后端、AI 输出与前端展示。
- 问题 4：把权重、复合锚、周期修正、折减、收口等计算写成**分步公式 + 数值示例 + 展示模板**，避免「大概、综合、适当」这类模糊表述。
- 问题 5：AI 模型默认值从 `deepseek-v4-pro` 切换为 `deepseek-flash`，并同步相关注释与文档。

### 1.3 目标（可衡量）

- O-1：一份文档覆盖 R15 + R18 的全部有效口径，R18 不再需要单独阅读；文档内同一概念只有一个定义。
- O-2：任一参数（r、A、g1、g∞、模型）都能在文档/前端中按「输入 → 中间量 → 输出」复算，误差不超过 0.5pp（舍入网格）。
- O-3：AI 估值响应新增 `scenarios` 三档，基准档与现有单点输出**逐字段一致**；三档顺序固定为保守、基准、乐观。
- O-4：前端在 AI 估值卡片中展示三档参数，移动端 360px 宽度下可读、可操作。
- O-5：基期 FCF 推荐在强周期、异常值、成长股资本开支三种场景下，至少不劣于现有逻辑；新增规则均有确定性理由。
- O-6：默认启动命令不再出现 `deepseek-v4-pro`；AI 分析在 `deepseek-flash` 下返回合法 JSON，且不再发送不适用的推理参数。

### 1.4 范围与非目标

**范围内：**

## 2. 术语与口径

| 术语 | 符号/字段 | 定义 | 单位/范围 |
|---|---|---|---|
| 经营资产自由现金流 | FCF | 经营活动现金流量净额 − 保全性资本支出 | 元 |
| 基期 FCF | baseFCF | 按 `fcf_mode` / `fcf_years` / `fcf_custom_value` 选取后的 FCF | 元，>0 才可估值 |
| 无风险利率 | Rf | 常量 2.5 | % |
| 股权风险溢价 | ERP | 常量 5.5 | % |
| 股权成本 | Re | `Rf + β × ERP` | % |
| 债务成本 | Rd | 偿付利息现金 ÷ 平均有息债务，税前 | % |
| 加权平均资本成本 | WACC | `D/(D+E) × Rd × (1−t) + E/(D+E) × Re` | % |
| 公司特定风险溢价 | RP | `min(风险点 × 1.0pp, 3.0pp)` | pp，0–3 |
| 折现率 | r | `clamp(round0.5(WACC + RP), 8, 15)` | %，0.5 网格 |
| 历史锚 | A_hist（`growth_history`） | 营收、重构净利润、FCF 三项稳健增速的等权平均（FCF 不稳定时剔除） | % |
| 周期修正 | Δ_cycle（`growth_cycle_adjust`） | `−clamp(周期位置 × 10pp, ±6pp)`，只修正历史锚 | pp |
| 前瞻锚 | A_fwd（`growth_forward`） | 一致预期归母净利润 CAGR × 0.7 + 营收 CAGR × 0.3，最多 3 个预测年 | % |
| 宏观锚 | A_macro（`growth_macro`） | 动态名义 GDP TTM 同比，0.5pp 网格 | % |
| 复合锚 | A（`growth_composite`） | 三层锚按可靠度加权合成 | %，[-5, 30] |
| 归一化复合锚 | A_norm（`growth_normalized`） | 当前等于 A；保留字段兼容，不再额外做行业/规模归一化 | % |
| 可持续增长率 | SGR | `ROE × 留存率` | % |
| 永续增长率 | g∞（`growth_terminal`） | `max(0, floor0.5(min(A_macro, r−1, SGR)))` | %，0.5 网格 |
| 高增长期增长率 | g1 | 复合锚经折减/软上限/包络收口后的值 | %，0.5 网格 |
| 回归年限 | n_total（`growth_fade_years`） | `clamp(round((A−g∞)/1.5), 3, 10)` | 年 |
| 模型得分 | score（`model_score`） | 增速 0.6 + 稳定性 0.2 + ROE 0.2 的加权得分 | 0–100 |
| 保守/基准/乐观 | conservative/base/optimistic | 三档参数情景 | — |

**口径约定：**

- 所有增长率、折现率均为**百分数**（10.5 表示 10.5%），不是小数。
- 所有权重均为 **0–1 小数**（0.45 表示 45%），展示时再乘 100。
- 所有金额在 Go 内部为「元」；前端展示为「亿元」时除以 1e8，保留 2 位小数。
- 增长率路径统一落在 **0.5pp 网格**；终值用 `floorHalf`（向下取到 0.5），其余用 `roundHalf`（四舍五入到 0.5）。
- 同一输入（财报 + 外部快照 + 行业分类）必须得到逐位一致的结果；纯函数不得读时钟、随机数或网络。

## 3. 总体框架与计算顺序

### 3.1 五层结构

```
① 基期 FCF          ② 折现率 r           ③ 增长率 g            ④ 模型与路径          ⑤ 三档情景
FCF 公式/选取   →   WACC + 风险溢价   →   三层锚 → 复合锚 A   →   分档 → g1/g∞/n   →   保守/基准/乐观
周期识别/窗口        β/Re/Rd/资本结构       周期修正/SGR/折减       降级链/一致性        基准档 = 单点输出
```

### 3.2 计算顺序（不可颠倒）

1. **对齐基期年**：利润表 ∩ 现金流量表的最新共同年报；无交集时回退三表最新年并告警。
2. **构造 FCF 序列**：最近 ≤10 年（本次由 7 年延长，见 FR-5），逐年 `NETCASH_OPERATE − 保全性资本支出`。
3. **周期识别**：FCF 变异系数、符号翻转、成长性否决；决定推荐窗口与聚合方式。
4. **折现率**：β → Re → WACC → 风险溢价 → 0.5pp 收口 → [8,15] 截断。
5. **三层锚**：历史锚（含周期修正）→ 前瞻锚 → 宏观锚 → 复合锚 A。
6. **SGR 与终值**：SGR = ROE × 留存率；g∞ = min(宏观, r−1, SGR) 向下取整。
7. **负增长归因**：结构性 → 零增长；周期性 → 低永续。
8. **模型分档**：A、gap=A−g∞、得分、负增长类型共同决定。
9. **向下调整**：离散度折减 → 软上限 → 包络；得到 g1。
10. **路径构造**：两阶段/三阶段/永续/零增长；无严格递减解时降级。
11. **一致性校验**：C1–C7；硬约束修正，软约束只告警。
12. **三档情景**：以基准档为锚，按固定带宽重算 A、r、g∞、模型、g1；基准档不得改变。

### 3.3 确定性约束

- 纯函数层（`growth.go`、`valuation_recommend.go`）**不做 IO**；GDP、一致预期、分红快照由 API 层注入。
- AI 只写解释性文字和定性 `industry_type`，**不得生成或修改任何参数数值**；服务端在 AI 返回后再次确定性回填，覆盖脏值。
- 同一份财报 + 同一份外部快照 + 同一行业分类 → 结果逐位一致；测试用黄金样例锁定。

## 4. 基期自由现金流（FCF）

### 4.1 公式与口径

**经营资产自由现金流：**

```
FCF = NETCASH_OPERATE − 保全性资本支出
```

**保全性资本支出（估值口径）：**

```
保全性资本支出 =
    资产减值损失（assetImpairmentLoss，损失为正）
  + 信用减值损失（creditImpairmentLoss，损失为正）
  + 固定资产折旧与油气折耗（FA_IR_DEPR）
  + 使用权资产摊销（USERIGHT_ASSET_AMORTIZE）
  + 无形资产摊销（IA_AMORTIZE）
  + 长期待摊费用摊销（LPE_AMORTIZE）
  + 处置长期资产损失（DISPOSAL_LONGASSET_LOSS，仅损失；收益按 0）
  + 固定资产报废损失（FA_SCRAP_LOSS）
```

**必须写清楚的口径边界：**

- 这是「**保全口径**」，不是「扩张口径」：不扣减购建长期资产的资本开支，也不扣减营运资本变动。
- 因此，高增长、重资产、营运资本扩张的公司，FCF 可能**高于**可分配给股东的现金流；必须通过 C5/C6 告警和推荐理由提示。
- 资产减值/信用减值采用双字段兼容：非金融股用收益口径字段（负值=损失，取反），金融股用损失口径字段（正值=损失）。
- 研发费用加回是**单独开关** `adjust_rd`：`rdExpansion = max(0, 本年研发费用 − 上年研发费用)`，只加回扩张部分，不是全部研发费用。

### 4.2 五种选取方式

| `fcf_mode` | 中文名 | 计算 | `fcf_years` | 适用场景 |
|---|---|---|---|---|
| `latest` | 最近一年 | 取窗口最后一年 | 不适用（0） | 稳定、单年可代表常态 |
| `average` | 平均值 | 最近 n 年算术平均 | 1–10，缺省 3 | 波动小、无趋势 |
| `median` | 中位数 | 最近 n 年中位数 | 1–10，缺省 3 | 有异常值、周期不强烈 |
| `trim_mean` | 去极值平均 | 最近 n 年去掉 1 个最高、1 个最低后平均；n<3 退化为平均 | 1–10，缺省 3 | 强周期、有单年异常 |
| `custom` | 自定义 | 用户输入金额 × 单位系数 | 不适用（0） | 用户有外部判断 |

**执行口径：**

- `selectBaseFCF` 取「最近 n 年」的升序末尾 n 个；可用年数不足 n 时截断。
- `custom` 的单位支持元/千/万/亿；内部统一转为元，最大 1e14；非正数或解析失败报错。
- `selectBaseFCF` 本身不因 FCF ≤0 报错；由估值入口统一判定「现金流贴现法不适用」。
- 推荐值与执行值必须同口径：前端一键套用后，实际计算使用的 `fcf_mode`、`fcf_years`、`fcf_custom_value` 应与推荐完全一致。

### 4.3 周期识别与推荐窗口

**FCF 周期判据：**

```
CV = 总体标准差(FCF) ÷ 均值(FCF)          # 均值 ≤0 时不判定
符号翻转次数 = 相邻非零 FCF 的符号变化次数（0 跳过）
原始强周期 = CV > 0.50 或 符号翻转次数 ≥ 2
成长性否决 = 营收持续高增长（详见 6.3 的成长性判定）
生效强周期 = 原始强周期 且 未被成长性否决
```

**推荐窗口 `fcfWindowYears`：**

| 状态 | 推荐年数 | 说明 |
|---|---:|---|
| 未评估（数据不足） | 10（本次由 7 延长） | 交给 R1 兜底 |
| 成长性否决 | 5 | 成长股不按强周期取长窗口 |
| 生效强周期 | 10（本次由 7 延长） | 覆盖至少一轮 A 股周期 |
| 非强周期但 CV > 0.30 | 5 | 中等波动，平滑 |
| 其余稳定 | 3 | 保留最新信息 |

> 当前实现为 7/5/3；本次要求强周期上限改为 10，见 FR-5。`fcfWindowYears` 只影响**推荐**，不强制改变用户已选的 `fcf_years`。

### 4.4 当前推荐规则（R0–R10）

`RecommendBaseFCF` 按序命中，命中即返回。`win` 为推荐窗口内的年份，`m = len(win)`。

| 规则 | 条件 | 推荐 | 说明 |
|---|---|---|---|
| R0 | 无可用年度 | `latest` | 现金流表为空 |
| R1 | `m < 3` | `latest` | 年度不足，无法评估可持续性 |
| R2 | 窗口内全部 ≤0 | `latest` | 无法构成可持续中枢 |
| R3 | 生效强周期且 `trim_mean(win) > 0` | `trim_mean`，`years=m` | 单年不代表常态，取完整周期去极值平均 |
| R4 | 最新年 ≤0 | `latest` | 最新年为负，退回最近一年 |
| R5 | 全为正 + 单调不减 + FCF 同比极差 ≤40pp + 最新 ≤1.3×中位数 | `latest` | 逐年增长且增速可持续 |
| R6 | 最新 >1.3×中位数，且（同比中位数 <0 或极差 >40pp） | `custom` = 正数中位数 ×（1 + clamp(同比中位数, 0, 15%)），取整到整亿；若 ≤0 则 `median` | 最新年明显偏高，按可持续中枢下调 |
| R7 | 单调下降 | `latest` | 反映当前水平 |
| R8 | 最新 <0.7×中位数（且非单调不增） | `median`，`years=m` | 避免低估 |
| R9 | 同比极差 >40pp | `median`，`years=m` | 单年不代表常态 |
| R10 | 其余 | `average`，`years=m` | 总体平稳，取平均 |

**补充：**

- R6 的「正数中位数」只对窗口内 >0 的 FCF 取中位数；同比中位数为负时按 0 处理，不外推负增长。
- 非强周期但 CV >0.30 时，R10/R8/R9 的理由末尾追加「已按 m 年窗口平滑」。
- 成长性否决只影响周期判定和窗口，不改变 R0–R10 的其余条件。
- 上表是**当前实现**；FR-4 会把 R10 在不稳定序列上的行为从 `average` 改为 `median`，其余规则不变。

### 4.5 行业实践对照与现状评估

| 维度 | 行业常见做法 | 当前实现 | 评价 |
|---|---|---|---|
| 聚合方式 | 3–5 年 median / trimmed mean；稳定公司用 latest | latest / average / median / trim_mean | **较好**：模式齐全、可解释 |
| 周期处理 | 穿越周期平均、mid-cycle margin | CV + 符号翻转 + 成长性否决 + trim_mean | **较好**：有成长性豁免；但 7 年窗口偏短 |
| 异常值 | 去掉 1 高 1 低、winsorize | trim_mean、R6 中枢下调 | **部分**：无 winsorize，但 R6 有上限 |
| 一次性项目 | 剔除资产处置、诉讼、补贴等 | 无法识别，不剔除 | **缺口**：免费数据无附注，不能臆造 |
| 保全性资本支出 | 维护性 capex 实际值或 D&A 近似 | 减值 + D&A + 摊销 + 处置/报废损失 | **部分**：代理口径，可能低估维护支出 |
| 营运资本 | 扣减 ΔNWC 或做正常化 | 不扣减，仅 C5 告警 | **缺口**：成长股可能高估 FCF |
| 成长股 | latest / 前瞻，capex-heavy 需 owner earnings | 单调增长时 latest；高 capex 仅告警 | **缺口**：高增长 + 高 capex 时 latest 可能偏乐观 |
| 负 FCF | 不适用 DCF | 直接判定不适用 | **合理**：避免无意义估值 |
| 透明性 | 黑箱模型常见 | 确定性规则 + 理由 | **优势**：可复算、可验收 |

**结论：** 现有逻辑的方向是正确的（多模式、周期识别、成长性豁免、确定性理由），不需要推倒重来；需要补的是**强周期窗口、稳健聚合的强制性、成长股资本开支守卫、理由完整性**。不建议本次新增「周期平均」用户模式——`trim_mean` + 10 年窗口已经覆盖该语义，新增模式只会增加选择负担。

### 4.6 改进需求

#### FR-1（P0）FCF 公式与口径必须在接口/前端可解释

**要求：**

- 接口必须暴露以下只读字段（若尚无）：`fcf_formula_note`（口径说明）、`fcf_components`（可选，保全性资本支出分项）、`fcf_profit_ratio`（已有）、`capex_coverage`（已有）、`delta_nwc_ratio`（已有）。
- 前端「基期现金流」区块必须展示：`FCF = 经营现金流净额 X 亿 − 保全性资本支出 Y 亿 = Z 亿`，并注明「未扣扩张性资本开支与营运资本变动」。
- 当 `capex_coverage > 1.3` 或 `fcf_profit_ratio > 1.5` 时，展示黄色提示，文案见 FR-7。

**验收：** 任一股票的基期 FCF 展示可手算复现；提示在阈值触发时出现。

#### FR-2（P0）五种选取方式的语义与执行必须一致

**要求：**

- `latest / average / median / trim_mean / custom` 的界面文案、接口字段、`selectBaseFCF` 行为三者一致。
- `fcf_years` 取值范围 1–10；`latest/custom` 时强制为 0 或不显示。
- `custom` 的单位换算必须可逆：展示值 × 单位系数 = 内部元值 = 套用后解析值。
- 推荐结果中的 `fcf_mode`、`fcf_years`、`fcf_custom_value`、`fcf_custom_unit` 必须能被前端「一键套用」原样写入估值表单。

**验收：** 对每个模式构造一组 FCF，接口返回值与手算一致；一键套用后重新计算，基期 FCF 与推荐展示值一致（允许整亿取整误差）。

#### FR-3（P0）推荐窗口动态化规则保持不变

**要求：**

- 推荐窗口按 4.3 表执行；窗口只用于推荐，不覆盖用户显式选择的 `fcf_years`。
- 当推荐窗口小于用户选择年数时，推荐理由必须写明「推荐按 m 年窗口，套用后以表单年数为准」。
- 当数据不足 3 年时，必须回退 `latest` 并给出理由。

**验收：** 构造 2 年、3 年、5 年、7 年、10 年数据，窗口与理由符合表 4.3。

#### FR-4（P0）稳健聚合优先级：禁止在明显不稳定时使用普通平均

**要求：**

- 当 `CV > 0.30` 或 `符号翻转次数 ≥ 1` 时，R10 不得返回 `average`；必须返回 `median`（窗口 ≥3）或 `trim_mean`（强周期）。
- 当 `CV ≤ 0.30` 且无符号翻转时，允许 `average`。
- 推荐理由必须写明触发原因（CV 值或符号翻转次数）。
- 不新增用户可见的「周期平均」模式；强周期统一用 `trim_mean`。

**代码影响：** `recommendBaseFCF` 的 R10 分支增加稳健性判断；`fcfCycle` 已含 `CV`、`SignChanges`，无需新增取数。

**验收：** 构造 CV=0.35、无符号翻转的序列，R10 返回 `median` 而非 `average`；CV=0.10 时仍返回 `average`。

#### FR-5（P1）强周期窗口由 7 年延长到 10 年

**要求：**

- `valFCFRecMaxYears`：7 → 10。
- `valCycleWindowYears`：7 → 10。
- `valFCFYearsCyclical`：7 → 10。
- 其余不变：稳定 3、中等波动 5、成长性否决 5、未评估 10。
- 前端 `fcf_years` 上限已是 10，不需要改；现金流表 pageSize 已约 10 个年报，不需要新增取数。
- 若可用年数不足 10，按实际年数截断，不报错。

**理由：** A 股很多行业（猪周期、航运、化工、面板）一轮周期 7–10 年；7 年窗口可能只覆盖半轮，导致 trim_mean 仍偏高或偏低。10 年窗口与现有数据能力匹配。

**验收：** 构造 10 年强周期序列，推荐 `trim_mean` 且 `years=10`；构造 7 年数据，`years=7`。

#### FR-6（P0）成长股资本开支守卫：高增长 + 高 capex 时不得用 latest

**要求：**

- 在推荐出口增加后处理：当同时满足以下条件时，若 `fcf_mode == latest`，改为同窗口 `median`（窗口 ≥3）或 `trim_mean`（强周期）：
  - 最终模型为 `two_stage` 或 `three_stage`；
  - `capex_coverage = 购建长期资产现金 ÷ 保全性资本支出 > 1.3`；
  - 推荐原为 `latest`。
- 推荐理由追加：「高增长假设下，保全口径未扣扩张性资本支出（购建/保全 = X 倍），单年 FCF 偏乐观，改用 m 年中位数/去极值平均。」
- 若 `fcf_mode == custom` 且 `capex_coverage > 1.3`，不强制改模式，但推荐理由必须追加同一提示。
- 该守卫只影响**推荐**；用户仍可手动选择 `latest`，但前端必须显示 C5 提示。

**理由：** 现有 C5 只告警，不改变推荐；高增长 + 高 capex 组合下，latest 的 FCF 可能显著高于可持续水平，直接影响 DCF 结果。

**代码影响：** `recommendValuation` 在调用 `RecommendBaseFCF` 前已能计算 `capexCoverage(cf, inc)`；建议在 `recommendValuation` 内做后处理，保持 `RecommendBaseFCF` 公开签名不变（现有单测直接调用它，签名变更会波及测试）。

调用链事实（已核对）：`RecommendBaseFCF` 当前只有 `recommendValuation` 一个生产调用点；对外的 `RecommendValuation` / `RecommendValuationWithIndustry` / `RecommendValuationWithSnapshot` 都汇聚到 `recommendValuation`。R13 的推荐值不是直接调 `RecommendBaseFCF`，而是读 `ValuationRecommendation.FCFMode/FCFYears`（经 `ApplyValuationRecommendation` 落到 AI 结果，供前端一键套用）。因此在 `recommendValuation` 出口做后处理，可同时覆盖 AI 估值卡片与 R13 一键套用，二者不会出现推荐不一致；无需改公开签名。

**验收：** 构造 `capex_coverage=1.5`、模型 `two_stage`、FCF 单调上升的样例，推荐不再是 `latest`，理由含「扩张性资本支出」；构造 `capex_coverage=1.0` 的同样样例，仍可推荐 `latest`。

#### FR-7（P0）基期 FCF 推荐理由必须完整、可复算

**要求：** `fcf_rationale` 至少包含以下信息（按存在性输出，不编造）：

1. 窗口：`近 m 年（YYYY–YYYY）`。
2. 模式与年数：`取 m 年中位数 / 去极值平均 / 最近一年 / 自定义`。
3. 触发依据：CV、符号翻转次数、同比极差、最新/中位数比值、单调性。
4. 成长性豁免：若命中，写明「营收持续高增长，FCF 高波动不视为强周期」。
5. 一次性项目：无法剔除时，固定写「未剔除一次性项目（免费数据无附注）」。
6. 资本开支：`capex_coverage > 1.3` 时写「保全口径未扣扩张性资本支出」。
7. 现金含量：`fcf_profit_ratio > 1.5` 时写「FCF 中位数为净利润的 X 倍，关注折旧摊销/减值/营运资本差异」。
8. 自定义：写明中枢、可持续增速、取整规则。

**验收：** 任一推荐理由可让读者复算出推荐值；不得出现「综合判断」「适当调整」等无依据措辞。

#### FR-8（P1，可 deferred）可选的扩张性资本开支扣减开关

**要求（若本次纳入）：**

- 新增 `adjust_growth_capex` 布尔开关，默认关闭。
- 开启后：`excessCapex = max(0, CONSTRUCT_LONG_ASSET − 保全性资本支出)`；`FCF_adj = baseFCF − excessCapex`。
- 若 `FCF_adj ≤ 0`，判定「现金流贴现法不适用」，并给出原因。
- 前端在「基期现金流」区块提供开关和预览值（扣减前后 FCF），默认关闭；不改变现有默认结果。
- 推荐理由必须说明「已扣减扩张性资本开支 X 亿」。

**产品取舍：** 该开关会让高成长公司的 FCF 大幅下降甚至转负，属于「更保守但可能不适用」的选择。建议 **P1/defer**，先通过 FR-6 的守卫和理由提示解决「误用 latest」的问题；是否本次实现由用户拍板（见 Q5）。

#### FR-9（P0）推荐结果与执行结果同口径

**要求：**

- 前端「套用」后，估值表单的 `fcf_mode`、`fcf_years`、`fcf_custom_value`、`fcf_custom_unit` 必须与推荐一致。
- 重新计算得到的 baseFCF 必须等于推荐理由中展示的 FCF（允许整亿取整误差）。
- 若用户手动改过年数，推荐理由不再声称「当前使用推荐值」，需在 UI 上标注「已手动调整」。

**验收：** 端到端测试：推荐 → 套用 → 计算，baseFCF 与推荐展示值一致。

## 5. 折现率 r

### 5.1 公式分步

**第 1 步：股权成本 Re**

```
Re = Rf + β × ERP
Rf = 2.5%
ERP = 5.5%
```

**第 2 步：β 档位**

| 行业类型 | β | 中文名 | 判定 |
|---|---:|---|---|
| 周期性行业 | 1.2 | 周期性行业 | AI 定性分类 `cyclical`；AI 缺失时由「剧烈波动且非成长否决」或 FCF 强周期兜底 |
| 一般行业 | 1.0 | 一般行业 | AI 分类 `general`；缺省兜底 |
| 公用事业 | 0.8 | 公用事业 | AI 分类 `utility` |

> β 是**常量档位表**，不是回归估计；AI 只做定性行业分类，不改 β 数值。2026-10-16 已确认该决策。

**第 3 步：资本结构**

```
D = 有息债务（短期债务 + 长期债务）
E = 股东权益（TOTAL_EQUITY）
投入资本 = D + E
wD = D ÷ (D + E)
wE = E ÷ (D + E)
```

**第 4 步：税后债务成本**

```
Rd_pre = 偿付利息现金 ÷ 平均有息债务
平均有息债务 = (期初有息债务 + 期末有息债务) ÷ 2
t = 实际所得税税率 = 所得税费用 ÷ (利润总额 − 长期股权投资收益)
    若分母 ≤0 → 25%；结果 clamp 到 [0, 1]
Rd_after = Rd_pre × (1 − t)
```

> 偿付利息采用 R10 方法二：`INTEREST_PAYABLE(期初) + FE_INTEREST_EXPENSE(当期) − INTEREST_PAYABLE(期末)`；不用 `ASSIGN_DIVIDEND_PORFIT` 推算（分红与报告年度错位，已废弃）。

**第 5 步：WACC**

```
WACC = wD × Rd_after + wE × Re
```

**第 6 步：公司特定风险溢价**

```
风险点：
  R1 有息债务 ÷ 资本合计 > 40%
  R2 利息保障倍数 < 3（无息负债时不计）
  R3 财务杠杆 = 资本合计 ÷ 股东权益 > 3（权益为 0 时计风险）
RP = min(风险点数量 × 1.0pp, 3.0pp)
```

**第 7 步：收口**

```
r_raw = WACC + RP
r = clamp(round0.5(r_raw), 8.0, 15.0)
```

> 顺序是「先四舍五入到 0.5 网格，再截断到 [8,15]」；例如 7.8 → 8.0，15.3 → 15.0，14.8 → 15.0。

### 5.2 数值示例

```
Rf = 2.5%，ERP = 5.5%，β = 1.1
Re = 2.5 + 1.1 × 5.5 = 8.55%

D = 100 亿，E = 900 亿 → wD = 10.0%，wE = 90.0%
Rd_pre = 4.0%，t = 25% → Rd_after = 3.0%
WACC = 0.10 × 3.0 + 0.90 × 8.55 = 0.30 + 7.695 = 8.00%

风险点 = 1（有息债务占比 10% 未触发；利息保障 2.5 触发；杠杆 1.1 未触发）
RP = 1.0pp
r_raw = 9.00% → r = 9.00%
```

### 5.3 边界与降级

| 情况 | 处理 | 告警 |
|---|---|---|
| 缺少资产负债表 | `r = 10.0%` | 「缺少资产负债表，无法评估资本结构与财务成本，折现率回落保守默认值 10.0%」 |
| D+E = 0 | WACC = Re | 无 |
| D = 0 | WACC = Re | 无 |
| Rd 不可用且 D > 0 | **本次要求**：`Rd_pre = clamp(Rf + 2.0, 3.0, 8.0)`，并按税后计算；告警「债务成本不可用，按 Rf+2.0pp 保守估计」 | 有 |
| t 分母 ≤0 | t = 25% | 无 |
| 风险点 >3 | RP 上限 3.0pp | 无 |
| r 超出 [8,15] | 截断 | 无（边界值可展示） |

> 当前代码在 Rd 不可用时把税后债务成本按 0 处理，会低估 WACC；本次要求改为保守估计（见 FR-12）。这是一个产品口径变化，需在技术设计中确认对现有样例的影响。

### 5.4 需求条目

#### FR-10（P0）WACC 必须分步可复算

**要求：**

- 接口暴露 `equity_cost`、`debt_weight`、`equity_weight`、`debt_cost_pretax`、`after_tax_debt_cost`、`effective_tax_rate`（均只读，`omitempty` 规则按现有约定）。
- 前端按 5.1 的七步展示，不得只显示一个 `discount_rate`。
- 接口保留现有 `risk_free_rate`、`equity_risk_premium`、`beta`、`beta_tier`、`wacc_baseline`、`risk_premium`，保证旧客户端兼容。

**验收：** 给定 D/E/Rd/t/β，前端展示的每一步与手算一致；`wacc_baseline + risk_premium` 收口后等于 `discount_rate`。

#### FR-11（P0）β/Re 口径固定，AI 不得改数

**要求：**

- β 只按行业类型常量表取值；AI 返回的 `industry_type` 归一化为 `cyclical/general/utility`，非法值回落 `general`。
- AI 不得返回或覆盖 `beta`、`risk_free_rate`、`equity_risk_premium`、`wacc_baseline`、`risk_premium`；服务端确定性回填覆盖。
- β 兜底逻辑保持：AI 缺失时，`volatile && !growthVeto` 或 FCF 强周期 → `cyclical`。

**验收：** AI 返回非法 `industry_type` 时 β 仍为 1.0；AI 返回 `beta=2.0` 被覆盖。

#### FR-12（P0）债务成本不可用时采用保守估计

**要求：**

- `debtCapitalCost` 返回 nil 且 `D > 0` 时，`Rd_pre = clamp(Rf + 2.0, 3.0, 8.0)`，并输出告警。
- `D = 0` 时不估计 Rd，WACC = Re。
- 该变化必须记录在技术设计与测试样例中，避免静默改变存量结果。

**理由：** 把缺失债务成本按 0 处理会系统性低估 WACC（尤其高杠杆公司），与「保守估值」目标冲突。

**验收：** 构造 `D>0` 且利息支出缺失的样例，`after_tax_debt_cost > 0`，WACC 高于旧逻辑，告警存在。

#### FR-13（P0）风险溢价与收口规则不变

**要求：**

- 风险点仍为 3 项，阈值 40% / 3 倍 / 3 倍；RP 上限 3.0pp。
- 先 `round0.5` 再 `clamp [8,15]`；顺序不可交换。
- 结果必须落在 0.5pp 网格。

**验收：** 边界样例：raw=7.74→8.0（先 grid 7.5 再截断）；raw=8.24→8.0（grid 8.0）；raw=8.26→8.5（grid 8.5）；raw=14.76→15.0（grid 15.0）；raw=15.24→15.0（截断）。

#### FR-14（P0）缺表/异常降级路径可解释

**要求：**

- 缺资产负债表 → 10.0% + 告警；不得静默使用 0。
- 股东权益为 0/负 → 杠杆风险计 1 点；不得除零。
- 所有 nil/负值路径不得产生 NaN/Inf。

**验收：** 空表、零权益、负利润、零债务四类样例均返回有限数值；缺表与零权益必须有告警，负利润/零债务不得产生 NaN/Inf。

#### FR-15（P0）折现率展示必须包含「权重 × 成本 = 贡献」

**要求：**

- 前端展示至少三行：
  ```
  股权成本 Re = 2.5% + 1.10 × 5.50% = 8.55%
  资本结构：D 100 亿（10.0%） / E 900 亿（90.0%）
  税后债务成本 = 4.00% × (1 − 25.0%) = 3.00%
  WACC = 10.0% × 3.00% + 90.0% × 8.55% = 8.00%
  + 风险溢价 1.0pp → 9.00% → 收口 9.00%
  ```
- 数值统一 2 位小数；权重 1 位小数；β 2 位小数。

**验收：** 前端文本与接口字段一致；移动端可换行，不出现横向溢出。

## 6. 增长率 g

### 6.1 三层锚

#### 6.1.1 历史锚 A_hist

**输入：** 最近 ≤5 年营收、重构净利润、FCF 的同比增速。

**单指标稳健增速：**

```
优先：同比增速去掉最大、最小各 1 个后取中位数（样本 ≥4）
退化：样本 <4 时直接取同比中位数
再退化：无有效同比点时，取窗口 CAGR（首末均为正）
无效：上年 ≤0 的同比点跳过；有效样本 <2 → 不可用
```

**合成：**

```
A_hist = (g_营收 + g_净利润 + g_FCF) ÷ 可用项数
```

- 三项**等权**，缺项不补 0，按可用项数归一化。
- FCF 仅在稳定时计入：若 FCF 原始强周期、有效同比点不足、或同比极差 >40pp，则剔除，并在理由中写明。
- 成长性否决时，FCF 高波动不视为强周期，但仍需满足「同比极差 ≤40pp」才计入。
- 字段口径：顶层 `base_growth` 沿用历史锚 X（兼容旧前端与旧缓存），`growth_history` 同值；`growth_composite` 才是最终复合锚 A，三者不得混用。

#### 6.1.2 前瞻锚 A_fwd

**输入：** 东财一致预期快照（归母净利润、营收、机构数、预测年、离散度）。

**计算：**

```
基准年 yA 必须等于 A 股基期年，否则不可用
取 yA 之后最多 3 个预测年
g_NP = (末预测年归母净利润 ÷ yA 归母净利润)^(1/年数) − 1
g_Rev = (末预测年营收 ÷ yA 营收)^(1/年数) − 1
A_fwd = 0.7 × g_NP + 0.3 × g_Rev
若仅一项可用，则取该项
A_fwd = clamp(A_fwd, −20, 50)
```

**可靠度：**

| 可靠度 | 条件 |
|---|---|
| `high` | 主接口 `profit_forecast`，机构 ≥5，预测年 ≥2，离散度可用且 ≤15pp |
| `medium` | 机构 ≥2，预测年 ≥1，离散度不可用或 ≤25pp |
| `unavailable` | 其余；不参与合成，输出原因 |

> 备用源 `web_respredict` 用 EPS CAGR；机构数取 `RatingOrgNum`。基准年不一致、基期净利润 ≤0、预测年缺失 → 不可用。

#### 6.1.3 宏观锚 A_macro

**输入：** 东财宏观 GDP 快照（`RPT_ECONOMY_GDP`）。

**计算：**

```
取最近连续 4 个季度名义 GDP，TTM = 4 季合计
A_macro = (TTM_本期 ÷ TTM_去年同期 − 1) × 100
A_macro = clamp(round0.5(A_macro), 0, 10)
```

- 数据缺失/异常/季末不连续 → 回退常量 **4.5%**，`growth_macro_basis = fallback_constant`，`gdp_as_of` 为空。
- 数据可用 → `growth_macro_basis = dynamic_gdp`，`gdp_as_of = 季末 yyyy-mm-dd`。
- 宏观锚是**长期终值锚**，不直接作为 3–5 年高增长假设；它只在复合锚中占 0.10 权重，并约束 g∞。

### 6.2 复合锚 A 与权重

**合成公式：**

```
A_hist_adj = A_hist + Δ_cycle        # 仅历史锚加周期修正
A_raw = w_hist × A_hist_adj + w_fwd × A_fwd + w_macro × A_macro
A = clamp(round0.5(A_raw), −5, 30)
A_norm = A        # 当前不做额外归一化，保留字段兼容
```

**权重表（按可用性与可靠度）：**

| 可用锚 | w_hist | w_fwd | w_macro | 说明 |
|---|---:|---:|---:|---|
| 历史 + 前瞻（高可靠） | 0.45 | 0.45 | 0.10 | 历史与分析师同等重要，宏观做长期约束 |
| 历史 + 前瞻（中可靠） | 0.55 | 0.35 | 0.10 | 前瞻可靠性下降，历史权重提高 |
| 仅历史 | 0.85 | 0 | 0.15 | 宏观补充长期中枢 |
| 仅前瞻 | 0 | 0.85 | 0.15 | 历史不足，前瞻为主 |
| 都不可用 | 0 | 0 | 0 | `A=0`，模型退化零增长，告警 |

**数值示例：**

```
A_hist = 10.0%，Δ_cycle = −3.0pp → A_hist_adj = 7.0%
A_fwd = 15.0%（高可靠）
A_macro = 4.5%
A = 0.45 × 7.0 + 0.45 × 15.0 + 0.10 × 4.5
  = 3.15 + 6.75 + 0.45 = 10.35 → 10.5%
```

**包络（M1）：**

```
有效独立锚数量 = 历史可用 + 前瞻可用 + 动态宏观可用
≥2 个 → 包络 ±5.0pp
=1 个 → 包络 ±3.0pp
```

包络约束 g1 的合理邻域 `[A − envelope, A + envelope]`；由于折减只会让 g1 低于 A，实际上界自然满足，重点是下限。包络不约束 g∞；详见 6.5。

### 6.3 周期识别与周期位置

**成长性判定（用于周期豁免）：**

以下条件**同时满足**时 `GrowthVeto=true`：

```
至少 3 个营收年报观测（≥2 个同比点）
营收窗口 CAGR ≥ 15%
单年营收同比最小值 ≥ −10%
至少 2 个「强增长年」（单年营收同比 ≥ 10%）
毛利率极差 ≤ 20pp（毛利率不可用时此条不阻塞）
```

- `GrowthVeto=true` 时：不判 FCF 强周期、不判盈利周期、不做周期位置修正；FCF 推荐窗口取 5 年。
- 成长性判定只看利润表营收，不依赖 FCF，避免循环依赖。

**盈利周期（独立于 FCF 推荐窗口）：**

```
窗口 ≤7 年（r18CycleMaxWindowYears），至少 3 年
毛利率极差 ≥8pp
且营收/净利润同比同时出现 ≤−5% 与 ≥+10%
```

**周期位置：**

```
GMpos = clamp((最新毛利率 − 窗口中位毛利率) ÷ max(毛利率极差, 4pp), −0.5, 0.5)
NMpos = clamp((最新净利率 − 窗口中位净利率) ÷ max(净利率极差, 2pp), −0.5, 0.5)
位置 = 两者平均（只有一个可用时取该值；都不可用 → 0）
标签：≥0.2 高位；≤−0.2 低位；其余中位
Δ_cycle = −clamp(位置 × 10pp, ±6pp)
```

**数值示例：**

```
GMpos = 0.30，NMpos = 0.20 → 位置 = 0.25 → 高位
Δ_cycle = −min(0.25 × 10, 6) = −2.5pp
A_hist 10.0% → A_hist_adj 7.5%
```

> 周期修正是「高位下调、低位上调」，只作用于历史锚；前瞻锚和宏观锚不修正，避免重复惩罚。

### 6.4 SGR（可持续增长率）

```
SGR = ROE × 留存率
ROE = 归母净利润 ÷ 期末股东权益 × 100
留存率主口径 = 1 − 报告年度现金分红 ÷ 归母净利润
  若分红 > 净利润 → 留存率按 0，告警
  留存率 clamp 到 [0, 1]
留存率备选口径 = (期末权益 − 期初权益) ÷ 归母净利润，clamp [0,1]
  仅当分红数据不可用时使用，标注 equity_growth
归母净利润缺失/非正 → 回退重构净利润，并标注
权益 ≤0 或净利润 ≤0 → SGR 不可用
```

**数值示例：**

```
ROE = 18%，现金分红/净利润 = 40% → 留存率 60% → SGR = 10.8%
```

> SGR 是**长期约束**，不是高增长期目标；g1 可以高于 SGR（只告警），g∞ 必须 ≤ SGR（硬约束）。

### 6.5 向下调整：A → g1

**顺序（不可交换）：**

```
① 离散度折减
   factor = clamp(离散度 × 0.004, 0, 0.40)
   d = min(5.0pp, A × factor)
   若 |Δ_cycle| ≥ 2pp → d = d ÷ 2（周期高点不重复惩罚）
   candidate = A − d

② 软上限
   base = A_fwd（可用）否则 A
   cap = min(30, max(base, SGR) + 5.0pp)     # SGR 可用时
   cap = min(30, base + 5.0pp)               # SGR 不可用时
   g1 = min(candidate, cap)

③ 0.5pp 网格
   g1 = round0.5(g1)
   若 g1 > cap → g1 = floor0.5(cap)

④ 包络下限
   lower = A − envelope（5 或 3pp）
   若 g1 < lower → g1 = lower
   若 cap < lower，最终按 lower 收口（唯一主导原因：软上限）

⑤ 出口复核（C4c）
   若 g1 > cap 且 cap ≥ lower → 按 floor0.5(cap) 重建；否则保留 lower
```

**数值示例：**

```
A = 10.5%，离散度 = 40pp，Δ_cycle = 0
① factor = min(40 × 0.004, 0.40) = 0.16
   d = min(5, 10.5 × 0.16) = 1.68
   candidate = 8.82
② A_fwd = 15，SGR = 5 → cap = max(15, 5) + 5 = 20
   g1 = min(8.82, 20) = 8.82
③ g1 = round0.5(8.82) = 9.0%，未超过 cap
④ lower = 10.5 − 5 = 5.5 → 9.0% 未低于下限，未触发
⑤ 出口复核：9.0% ≤ cap，无需重建
```

> 小于 0.25pp 的折减可能被 0.5pp 网格吸收，这是预期精度，不额外补偿。调整说明必须按「折减 → 软上限 → 包络」顺序拼接，未触发的步骤也要写明「未触发」。

### 6.6 负增长归因

**仅当 A < 0 时执行。**

**结构性（S1–S4，命中任一即结构性）：**

| 编号 | 条件 |
|---|---|
| S1 | 营收 CAGR <0 且归母净利润 CAGR <0 |
| S2 | 毛利率趋势下行，且营收或净利润 CAGR <0 |
| S3 | 前瞻锚 <0，且营收或净利润 CAGR <0 |
| S4 | A <0 且无前瞻锚，且周期位置 > −0.2 |

- 结构性 → `model = zero`，不估值增长。
- 命中 S1–S4 的，输出具体依据。

**周期性：**

```
A <0 且 isCyclical
且（周期位置 ≤−0.2 或 前瞻锚 >0 或 Δ_cycle ≥ +2pp）
→ model = perpetual，g = max(0, round0.5(A))
```

- 周期性负增长不归零，但永续增长取 0（低永续），避免假设长期萎缩。
- 无法区分周期/结构时，**保守按结构性处理**（零增长）。

### 6.7 终值 g∞

```
g∞_raw = min(A_macro, r − 1.0)
若 SGR 可用：g∞_raw = min(g∞_raw, SGR)
g∞ = max(0, floor0.5(g∞_raw))
```

**约束：**

- g∞ < r（硬约束；构造上由 `r−1` 保证）。
- g∞ ≤ SGR（SGR 可用时，硬约束）。
- g∞ ≥ 0（不允许负永续；负增长已在模型层处理）。
- 终值受上限约束时，输出原因：`SGR` / `折现率−1pp` / `宏观`。

**数值示例：**

```
A_macro = 4.5%，r = 9.0%，SGR = 10.8%
g∞ = max(0, floor0.5(min(4.5, 8.0, 10.8))) = 4.5%
```

### 6.8 模型分档

```
gap = A − g∞
score = 加权得分（见 6.8.1）

若 数据不足 → zero
若 A <0 且 结构性 → zero
若 A <0 且 周期性 → perpetual
若 A ≥6 且 gap ≥4 且 score ≥70 → three_stage
若 A ≥2 且 gap ≥1.5 且 score ≥45 → two_stage
若 A ≥0 → perpetual
其余 → zero
```

#### 6.8.1 模型得分

```
Sg = clamp(20 + 2.5 × A, 0, 100)
Sst = clamp(100 − 2 × 下行离散度, 0, 100)     # 只惩罚下行波动
Sroe = clamp(中位ROE ÷ 25 × 100 + 稳定加成, 0, 100)
       稳定加成 = 10（ROE 样本 ≥2、全为正、极差 ≤10pp），否则 0

score = (0.6 × Sg + 0.2 × Sst + 0.2 × Sroe) ÷ 可用权重之和
```

- 稳定性不可用 → 分母去掉 0.2；ROE 不可用 → 分母去掉 0.2；至少保留增速 0.6。
- 缺失信号按剩余权重归一化，不补 0。

**数值示例：**

```
A = 15.0，下行离散度 = 5pp，中位 ROE = 20%、稳定
Sg = 20 + 37.5 = 57.5
Sst = 100 − 10 = 90
Sroe = 20/25×100 + 10 = 90
score = (0.6×57.5 + 0.2×90 + 0.2×90) ÷ 1.0 = 34.5 + 18 + 18 = 70.5
→ 若 gap ≥4，三阶段
```

### 6.9 均值回归路径

**回归年限：**

```
n_total = clamp(round((A − g∞) ÷ 1.5), 3, 10)
```

**两阶段：**

```
g1 = 向下调整后的值
n1 = n_total
g2 = g∞
要求 g1 > g2 且 g2 < r；否则降级为永续
```

**三阶段：**

```
n1 = ceil(n_total ÷ 2)
n2 = floor(n_total ÷ 2)
g2 候选 1 = min(round0.5(g∞ + (A − g∞) ÷ 2), r − 0.5)
g2 候选 2 = g∞ + 1.0
取第一个满足 g1 > g2 > g∞ 且 g2 < r 的候选
否则降级为两阶段
```

**永续：**

```
g = clamp(round0.5(A), 0, g∞)
若 A <0（周期性）→ g = 0
```

**零增长：**

```
DCF 按 g=0 处理，params 为空
```

**降级链：** `three_stage → two_stage → perpetual → zero`。每次降级必须写原因，并设置 `model_degraded=true`。

**严格递减：** 三阶段必须 `g1 > g2 > g∞`；两阶段必须 `g1 > g2`。不满足时不得输出原模型。

### 6.10 一致性校验

| 编号 | 类型 | 内容 | 处理 |
|---|---|---|---|
| C1 | 构造保证 | 参数与模型匹配（zero 无参数；perpetual 有 g；两/三阶段有 g1/n1/...） | 不通过则报错 |
| C2 | 构造保证 | 增长率在 0.5pp 网格 | 不通过则报错 |
| C3 | 构造保证 | 年数为正整数，n_total 3–10 | 不通过则报错 |
| C4a | 硬约束 | g∞ < r 且 g∞ ≤ SGR | 修正 g∞ 并重建路径 |
| C4b | 软约束 | g1 > SGR | 只告警，不降级 |
| C4c | 防御 | g1 > cap 且 cap ≥ A−envelope | 按 cap 重建 |
| C5 | 软约束 | 高增长模型且（capex_coverage >1.3 或 ΔNWC/baseFCF >0.3） | 只告警 |
| C6 | 软约束 | FCF 中位数 ÷ 净利润中位数 >1.5 | 只告警 |
| C7 | 硬约束 | 基期年 = 利润表 ∩ 现金流量表最新共同年 | 无交集时回退三表最新年并告警 |

> C5/C6 只告警，不改变参数；FR-6 的 capex 守卫是在推荐层的额外约束，不替代 C5。

### 6.11 可解释输出

#### FR-16（P0）历史锚的构成必须逐项可见

**要求：** 输出 `growth_revenue`、`growth_profit`、`growth_fcf`、`growth_revenue_ok`、`growth_profit_ok`、`growth_fcf_ok`、`growth_fcf_excluded`/`growth_fcf_exclude_reason`；前端展示三项值和「等权平均」公式，FCF 被剔除时写明原因。

**验收：** 三项可用时 `A_hist = (a+b+c)/3`；剔除 FCF 时 `A_hist = (a+b)/2`。

#### FR-17（P0）前瞻锚的可靠度与来源必须可见

**要求：** 输出 `consensus_as_of`、`consensus_institutions`、`consensus_years`、`consensus_reliability`、`growth_forward`；不可用时 `growth_forward` 省略，前端显示「一致预期不可用」及原因，不得显示 0%。

**验收：** 机构数 1 家 → 不显示前瞻锚；5 家且离散度 ≤15 → 显示「高可靠」。

#### FR-18（P0）宏观锚的来源与回退必须可见

**要求：** 输出 `growth_macro`、`growth_macro_basis`、`gdp_as_of`；回退常量时显示「动态 GDP 不可用，按 4.5% 常量」，不得伪装成实时数据。

**验收：** 无 GDP 快照时 `growth_macro_basis=fallback_constant` 且 `gdp_as_of` 为空。

#### FR-19（P0）复合锚权重必须显式输出

**要求：**

- 新增 `growth_weights` 对象：`{history, forward, macro}`，三者之和为 1 或全为 0。
- 新增 `growth_anchor_count`（有效独立锚数量）。
- 前端展示「值 × 权重 = 贡献」的表格，最后一行求和，再展示四舍五入到 0.5pp 的 A。
- 权重必须与 6.2 表一致；不得前端自行猜测。

**验收：** 高可靠前瞻样例显示 0.45/0.45/0.10；仅历史样例显示 0.85/0/0.15；贡献之和（舍入前）等于 `A_raw`。

#### FR-20（P0）周期修正只作用于历史锚且可解释

**要求：**

- 输出 `cycle_position`、`cycle_position_label`、`cycle_basis`、`growth_cycle_adjust`。
- 非周期/成长性否决时 `growth_cycle_adjust=0`，并写明「不修正」。
- 前端展示 `GMpos`、`NMpos`、位置、`Δ_cycle` 的计算式。
- 不得把周期修正同时施加到前瞻锚或终值。

**验收：** 高位样例 `Δ_cycle<0`；低位样例 `Δ_cycle>0`；非周期样例 `Δ_cycle=0`。

#### FR-21（P0）SGR 的 ROE、留存率、口径必须可见

**要求：**

- 输出 `sgr`、`retention_rate`、`retention_basis`（`payout`/`equity_growth`/`unavailable`）、`sgr_role`。
- 前端展示 `SGR = ROE X% × 留存率 Y% = Z%`，并注明分红口径或权益增长口径。
- `retention_basis=unavailable` 时显示「SGR 不可用，终值不施加 SGR 约束」。

**验收：** 分红数据可用时 `retention_basis=payout`；分红缺失但权益增长可用时 `equity_growth`；两者都缺失时 `unavailable`。

#### FR-22（P0）向下调整必须按顺序展示，未触发也要显示

**要求：**

- 输出 `growth_damping`（实际折减 pp）、`growth_cap`（软上限 %）、`growth_envelope`（5 或 3pp）。
- 前端按「① 离散度折减 → ② 软上限 → ③ 包络 → ④ g1」四行显示；每行写明触发/未触发。
- 不得只显示最终 `g1` 或「综合调整」。

**验收：** 构造 cap 未触发、包络触发、两者都未触发三种样例，文案与数值一致。

#### FR-23（P0）负增长归因必须给出类型与依据

**要求：**

- 输出 `negative_growth_type`（`none`/`structural`/`cyclical`）、`negative_growth_basis`。
- 结构性必须列出命中的 S1–S4；周期性必须列出周期位置/前瞻/修正依据。
- 前端用一句话展示，不得只显示「负增长」。

**验收：** A<0 且营收/净利润 CAGR 均负 → `structural`；周期低位 + 前瞻为正 → `cyclical`；无法区分 → `structural`。

#### FR-24（P0）终值必须显示约束来源

**要求：**

- 输出 `growth_terminal`，并在 `growth_adjustment` 中写明 `SGR`/`折现率−1pp`/`宏观` 哪个约束生效。
- 前端展示 `g∞ = min(宏观, r−1, SGR) → 向下取整`，并标注生效约束。
- 不得把受约束的终值显示成「模型预测」。

**验收：** 三个约束分别绑定的样例，文案正确；g∞ 始终在 0.5pp 网格且 ≥0。

#### FR-25（P0）模型分档必须显示分项得分与阈值

### 6.12 「适中」的量化验收（M1–M5）

「适中」不是「DCF 结果等于股价」，而是**参数层面的可验证包络**。R18 的 M1–M5 继续有效，整合后如下：

| 编号 | 要求 | 判定 |
|---|---|---|
| M1 锚定包络 | `A − envelope ≤ g1 ≤ A + envelope`；`envelope=5pp`（≥2 个独立锚）或 `3pp`（仅 1 个锚） | 低于下限判「过保守」，高于上限判「过乐观」；越界必须在 `warning` 写**唯一主导原因**与调整量，不得静默越界；`A<0` 时 M1 不适用，改由负增长归因约束 |
| M2 保守调整不叠加 | 周期修正 `Δ_cycle` 在合成 A 之前作用于历史锚，已内含于 A；A 之后只允许「离散度折减」和「SGR/前瞻软上限」两项向下调整，合计 ≤5pp；`|Δ_cycle|≥2pp` 时折减减半；一致预期可靠度只通过权重体现，不额外扣减；不得额外叠加向上调整 | 同一事项不得被扣两次；实际生效的向下幅度可复算 |
| M3 终值合理 | `0 ≤ g∞ ≤ min(G_GDP, r−1.0pp, SGR)`；SGR 不可用时省略 SGR 项；`G_GDP` 为动态名义 GDP，不设固定 4%/5% 上限；回退常量 4.5% 时必须标注 | 终值 100% 满足约束；`g∞ ≥ r` 不允许；负值按 0 |
| M4 模型与缺口一致 | `A−g∞ ≥3pp` 的公司不得仅因 SGR 被降级为永续；`A−g∞ <1pp` 的公司不应强行构造两/三阶段，应使用永续，`g=round0.5(A)` 或 `g∞` | 分档结果与 6.8 一致；降级原因不是「仅 SGR」 |
| M5 横截面校准 | 20 只样本（非金融）：一致预期可用率 ≥80%；`|g1−A|` 中位数 ≤2.5pp、P90 ≤6pp；`g1<A−5pp` 占比 ≤20%、`g1>A+5pp` 占比 ≤10%；高分红/成熟 5 只不再仅因 SGR 降级 | 回测报告；M5 依赖样本，列为 P1 |

> M1–M4 是 P0 的构造性约束；M5 是 P1 的横截面校准，不阻塞本次实现，但必须在后续回测中验收。

#### FR-46（P0）建立「适中」M1–M5 的可验证约束

**要求：**

- M1–M4 必须在代码/测试中可验证：M1 检查 g1 包络；M2 检查调整顺序与总幅度；M3 检查终值三重约束；M4 检查分档与 gap。

## 7. 三档情景参数

### 7.1 定义

| 档位 | key | 中文 | 折现率 | 增长率 | 终值 | 直觉 |
|---|---|---|---|---|---|---|
| 保守 | `conservative` | 保守 | 基准 +1.0pp | 基准 A − band_g | 基准 −0.5pp | 要求更高回报、假设更低增长 |
| 基准 | `base` | 基准 | 基准 r | 基准 A（clamp 到 [−5,30]） | 基准 g∞ | 现有确定性输出 |
| 乐观 | `optimistic` | 乐观 | 基准 −1.0pp（下限放宽到 7） | 原始复合锚 rawA + band_g（上限放宽到 40） | 基准 +0.5pp | 要求回报更低、假设增长更高 |

**原则：**

- 三档是**参数情景**，不是概率预测；不输出概率权重。
- **「适中」只约束基准档**：基准档的 A/r 仍收口在 [−5,30]/[8,15]；乐观档必须真正比基准更乐观，不得因基准档已触边界而 collapse 成与基准相同。因此乐观档以**未截断的原始复合锚 rawA** 为基准、增长锚上限放宽到 **40**，折现率下限放宽到 **7**；保守档只向下，仍在 [−5,30]/[8,15]。
- 终值 g∞ 三档共用 `min(宏观、r_s−1、SGR)` 收口，不因乐观档而抬高；乐观档 r 变低后 `r−1` 约束会自然收紧，这是 Gordon 模型正确行为。
- 基准档必须与现有单点输出逐字段一致（包括模型、g1、g∞、n1、n2、params）。
- 三档顺序固定：保守、基准、乐观；前端不得重排。
- 折现率、增长率、终值按上表变化；基期 FCF 也按 7.8 FR-38 的离散锚分三档。后端不输出逐档股价、不参与每档估值计算（P0）；P1 前端「套用到估值」选择档位后，会把该档 `base_fcf` 作为自定义基期 FCF 写入估值表单再计算（见 7.7 / FR-36）。
- 其余输入（研发调整、周期位置、SGR、宏观锚、一致预期快照）三档共用；A、r、g∞ 及由其派生的模型/路径逐档独立重算。
- 模型可以因档位不同而不同（例如保守档降为永续、乐观档升为三阶段）；必须逐档显示模型名。

### 7.2 带宽锚定

#### 7.2.1 增长率带宽 band_g

```
若 A < 0 或 base 模型 == zero：
    band_g = 0
否则若 A_hist 可用 且 A_fwd 可用：
    D = |A_hist_adj − A_fwd|
    band_g = clamp(round0.5(D), 1.5, 4.0)
否则：
    D = 0.20 × max(A, 0)
    band_g = clamp(round0.5(D), 1.5, 4.0)
```

**理由：**

- 当历史与分析师出现分歧时，分歧本身就是最直接的不确定性度量；比固定 ±3pp 更有信息量。
- 下限 1.5pp 避免「伪精确」；上限 4.0pp 避免带宽过大导致三档失去参考意义。
- 宏观锚不参与带宽：它是长期锚，不是 3–5 年增长预测；纳入会人为缩窄带宽。
- A<0 或零增长模型时，增长参数没有可解释的上下调空间，带宽置 0，只让折现率变化。

#### 7.2.2 折现率带宽 band_r

```
band_r = 1.0pp（固定）
```

**理由：** WACC 的主要不确定性来自 β 档位、股权风险溢价和公司特定溢价，1.0pp 对应一个风险档位的量级；固定带宽保证不同公司之间可比。折现率本身已被收口到 [8,15]，边界处实际变化可能小于 1.0pp，需在 `note` 中标注。

#### 7.2.3 终值调整 band_terminal

```
band_terminal = 0.5pp（固定）
```

**理由：** 终值由宏观 GDP、SGR、r−1 三重约束，长期不确定性不应与 3–5 年高增长期同幅度；0.5pp 是网格精度，足以体现方向。若上限约束生效，乐观档终值可能不变；这是正确结果，不是 bug，需显示「受 GDP/SGR 上限约束」。

### 7.3 情景内重算规则

对每个档位 `s ∈ {conservative, base, optimistic}`：

```
A_conservative = clamp(A − band_g, −5, 30)
A_optimistic   = clamp(rawA + band_g, −5, 40)   // rawA = 基准 clamp 前的原始复合锚
r_conservative = clamp(r + 1.0, 8, 15)
r_optimistic   = clamp(r − 1.0, 7, 15)          // 乐观档下限放宽到 7
g∞_s = max(0, floor0.5(min(g∞ + Δg∞_s, A_macro, r_s − 1.0, SGR（若可用）)))

gap_s = A_s − g∞_s
score_s = 用 A_s 重算 Sg，Sst/Sroe 不变，按可用权重重归一化
negType_s = A_s < 0 ? attributeNegativeGrowth(A_s, ...) : "none"
model_s = classifyGrowthModel(A_s, gap_s, score_s, insufficient, negType_s)
g1_s = applyDownwardAdjustments(A_s, gap_s, dispersion, Δ_cycle, A_fwd, SGR, envelope)
path_s = constructGrowthPath(model_s, A_s, g∞_s, gap_s, g1_s, r_s)
params_s = paramsFromPath(path_s)
```

其中：

```
ΔA_conservative = −band_g；Δr_conservative = +1.0pp；Δg∞_conservative = −0.5pp
ΔA_base         = 0；      Δr_base         = 0；      Δg∞_base         = 0
ΔA_optimistic   = +band_g（基于 rawA）；Δr_optimistic = −1.0pp；Δg∞_optimistic = +0.5pp
```

**必须保持不变的量：**

- 基期 FCF、`fcf_mode`、`fcf_years`、`adjust_rd`、研发扩张额。
- 周期位置 `position`、周期修正 `Δ_cycle`、包络 `envelope`、离散度 `dispersion`。
- 前瞻锚 `A_fwd`、宏观锚 `A_macro`、SGR、留存率。
- C4a/C4c 的硬约束逻辑：每档都要复核，不能只对基准档复核。

**每档输出：**

| 字段 | 说明 |
|---|---|
| `key` | `conservative` / `base` / `optimistic` |
| `name` | 保守 / 基准 / 乐观 |
| `discount_rate` | `r_s` |
| `model` / `model_name` | `model_s` |
| `growth_anchor` | `A_s` |
| `terminal_growth` | `g∞_s` |
| `delta_growth` | `A_s − A_base` |
| `delta_discount` | `r_s − r_base` |
| `params` | 该档的 g1/n1/g2/n2/g3 |
| `note` | 生效约束/退化说明 |
| `capped_by` | 可选：`gdp`/`sgr`/`discount`/`range` |

### 7.4 边界与退化

| 情况 | 处理 |
|---|---|
| `A < 0` 或基准模型 `zero` | `band_g=0`；三档 A、g∞、模型相同；只有 r 不同；`note` 说明「增长参数不设区间，仅折现率分档」 |
| 基准 `A` 接近 +30（原始 rawA 更高） | 基准档仍截断到 30；乐观档以 rawA + band_g 计算并截断到 40，因此 `A_o > A_b`；仅当 `rawA + band_g > 40` 时 `capped_by=range`，`note` 标注「受 [−5,40] 区间约束」 |
| 乐观 `A_s` 未触 40 | 即使基准档已触 30 上限，乐观档也**不得**记 `range`（未真正截断），`delta_growth` 按实际差值输出 |
| `A` 接近 −5 | 保守档被截断；但 A<0 时 band=0，通常不触发 |
| 基准 `r` 接近 8 | 乐观档 `r_s` 下限放宽到 7（如基准 8 → 乐观 7），不再截断到 8；仅当 `r − 1 < 7` 时才记 `capped_by=discount` |
| `r` 接近 15 | 保守档被截断到 15；`note` 标注「受折现率上限约束」 |
| `g∞ + 0.5 > A_macro` | 乐观档终值不变，`capped_by=gdp`；`delta_growth` 仍按 A 变化 |
| `g∞ − 0.5 < 0` | 保守档终值取 0（但基准 g∞ 通常 ≥0，−0.5 后被 max(0) 截断）；`capped_by=range` |
| 三阶段降级 | 每档独立降级；`model_degraded` 逐档输出；不得因为基准档是三阶段就强制其他档也是三阶段 |
| 数据不足 | 三档仍输出，但 `applicable=false`；前端禁用「套用」 |
| 金融股/负 FCF | 同上；三档只作透明展示，不构成估值建议 |
| `fcf_series` 为空 | 三档 `base_fcf` 均取当前推荐值，依据记「无离散」 |
| `median ≤ 0` / `latest ≤ 0` | 对应档 `base_fcf` 退回当前推荐值，不得锚到非正值 |
| `custom` 模式 | 基期 FCF 由规则直接给出，不参与离散锚定；三档均取推荐值，依据记「无离散（自定义）」 |

### 7.5 数值示例

#### 示例 A：高增长 + 分析师分歧

```

保守：A = 3.5%，r = 10.0%，g∞ = 3.0%
乐观：A = 6.5%，r = 8.0%，g∞ = 4.0%
```

- 基准 A=5.0、gap=1.5 → 两阶段（若 score ≥45）。

- 三档增长参数相同，只有折现率不同。

```json
      "delta_growth": 4.0,
      "delta_discount": -1.0,
      "params": [
        {"key": "g1", "label": "高增长期增长率", "value": 12.0},

```

**约束：**

- `scenarios` 恒为长度 3，顺序固定；即使 `applicable=false` 也输出。
- `base` 档的 `discount_rate`、`model`、`growth_anchor`、`terminal_growth`、`params` 必须与顶层字段一致（`growth_anchor` 对应 `growth_composite`）。
- 顶层字段保持现有语义，不改为基准档之外的值。
- `delta_growth`、`delta_discount` 允许为 0；不得用 `omitempty` 省略 0（否则前端无法区分「未变化」和「缺字段」）。
- `capped_by` 取值集合：`gdp`、`sgr`、`discount`、`range`；无约束为空数组。
- 数值精度：率 2 位小数，pp 1 位小数，年数为整数；`base_fcf` 保持元值，不额外舍入。
- `base_fcf` / `base_fcf_basis` 每档必出（不带 `omitempty`）；基准档 `base_fcf` 必须等于顶层 `fcf_base_value`。
- `base_fcf` 仅作展示，不参与每档估值计算，也不改变顶层基准估值。
- 可选 P1：每档增加 `equity_value`、`equity_value_per_share`（若产品需要直接展示三档估值结果）；本次 P0 只要求参数。

### 7.8 需求条目

#### FR-30（P0）三档定义与方向固定

**要求：** 保守 = 更高折现率 + 更低增长 + 更低终值；基准 = 现有输出；乐观 = 更低折现率 + 更高增长 + 更高终值。顺序固定，不得出现「中性/激进」等别名。

**验收：** 任一有效样例满足 `r_c ≥ r_b ≥ r_o`、`A_c ≤ A_b ≤ A_o`、`g∞_c ≤ g∞_b ≤ g∞_o`（边界截断时允许相等）。

#### FR-31（P0）带宽按 7.2 计算并可解释

**要求：**

- 输出 `scenario_band_growth`、`scenario_band_discount`、`scenario_terminal_adjust`、`scenario_method`。
- `band_g` 优先用历史与前瞻的分歧；不可用时用 20% × max(A,0)；A<0/zero 模型时为 0。
- 带宽必须 clamp 到 [1.5,4.0]；折现率固定 1.0pp；终值固定 0.5pp。
- 前端展示带宽来源：「历史与前瞻分歧 8.0pp → 收窄/放大到 4.0pp」。

**验收：** 分歧 8.0 → band 4.0；分歧 0.5 → band 1.5；无前瞻 A=12 → band 2.5；A<0 → band 0。

#### FR-32（P0）每档独立重算，基准档不得改变

**要求：**

- 按 7.3 重算 A、r、g∞、score、负增长归因、模型、g1、路径、params。
- 基准档必须与现有单点输出逐字段一致；不得因为引入三档而改变任何现有数值。
- 每档独立执行 C4a/C4c 硬约束；不得复用基准档的 g∞ 或模型。
- 模型可逐档不同，必须输出 `model`/`model_name`。

**验收：** 黄金样例：`scenarios[1]` 与顶层字段逐字段相等；保守/乐观档的 `g1` 与手算一致；三档模型允许不同。

#### FR-33（P0）边界截断必须显式说明

**要求：**

- 当 A、r、g∞ 被 [−5,30]、[8,15]、≥0 或 GDP/SGR 上限截断时，`delta_growth`/`delta_discount` 输出**实际**差值，而不是名义带宽。
- `capped_by` 列出约束；`note` 用人话说明。
- 不得把「被截断所以没变化」显示成「模型认为没有差异」。

**验收：** r=8.0 时乐观档 `delta_discount=0` 且 `capped_by` 含 `discount`；g∞=4.5 且 macro=4.5 时乐观档 `delta_growth` 仍为 +band，但终值不变且 `capped_by` 含 `gdp`。

#### FR-34（P0）API 字段 additive 且兼容旧客户端

**要求：**

- 保留所有现有字段与语义；新增字段全部为追加，不重命名、不删除。
- `AIValuation` 与内部 `ValuationRecommendation` 都增加 `Scenarios []ValuationScenario`；`ApplyValuationRecommendation` 必须拷贝。
- `ValuationScenario` 定义在 `internal/model`，含 7.3 表字段。
- 旧客户端忽略 `scenarios` 不受影响；新客户端在字段缺失时回退到顶层单点，不报错。

**验收：** 旧响应 JSON（无 `scenarios`）仍能被前端渲染；新响应三档齐全。

#### FR-35（P0）前端三档展示必须清晰、移动端可用

**要求：**

- 桌面端表格 + 移动端卡片；基准档高亮；数值格式统一（率 2 位、pp 1 位）。
- 每档显示模型名、折现率、A、g1、g2、g∞、相对基准变化、说明。
- 三档增长相同时显示统一说明，不隐藏区块。
- 不在表格中塞长段落；说明最多 2 行，超出折叠或换行。
- 颜色语义遵循项目规范：保守/乐观不使用红绿表示「好坏」，只用中性色 + 基准高亮。

**验收：** 360px 宽度下无横向滚动；三档信息完整；基准档与顶层单点一致。

#### FR-36（P1，本次实现）套用支持三档选择，默认基准

**要求：**

- 三档情景总结区块在「套用到估值」旁提供保守/基准/乐观三选一（`el-radio-group`），默认选中「基准」；新分析结果（含缓存复用）一律重置为基准档。
- 点「套用到估值」时，从 `scenarios` 取 `key` 匹配所选档的那条 `ValuationScenario`，把该档 `model`、`discount_rate`、`params`（g1/n1/g2/n2/g3，映射与现有基准套用一致）与 `base_fcf` 写入估值表单并重新计算。
- 基期 FCF 用「自定义」口径套用（`fcf_mode=custom`）：`base_fcf` 单位为元，按「亿」写入表单并四舍五入 2 位，使保守档用更低 FCF、乐观档用更高 FCF、基准档用推荐值；`base_fcf` 缺失/非正，或换算为亿后四舍五入为 0（< 50 万元）时回退顶层 FCF 推荐字段（顶层口径可精确复算）。
- `adjust_rd` 三档共用，始终取顶层推荐值。
- 套用成功后提示「已按{保守/基准/乐观}档套用参数并计算」。
- 旧响应/旧缓存无 `scenarios` 时不显示选择器，套用回退顶层基准字段（现状逻辑），不报错。
- 不改后端三档计算与输出字段。

**验收：** 默认点「套用到估值」与旧版结果一致（基准档）；选保守/乐观档后，表单 r、模型、g1/n1/g2/n2/g3 与对应档一致，且基期 FCF（自定义值 × 1e8）等于该档 `base_fcf`（允许 0.01 亿舍入误差）；`node --check` 通过。

#### FR-37（P0）AI 解释三档，但不得生成数字

**要求：**

- `valuationPromptBlock` 增加三档参数摘要（保守/基准/乐观的 r、A、g1、g∞、模型、带宽来源、基期 FCF 及依据）。
- Prompt 明确：「三档参数由后端确定性计算，你只能解释，不得修改任何数字；用 3–5 句话解释基准档，用 1 句话说明保守/乐观差异及主要不确定性来源。」
- AI 返回的 `rationale` 保留；不得让 AI 返回 `scenarios` 数值，若返回则被服务端覆盖/丢弃。
- 可选 P1：新增 `scenario_rationale` 字段，AI 只写一段解释；P0 复用 `rationale`。

**验收：** AI 响应中 `scenarios` 与后端确定性结果一致；AI 编造的数字不进入响应。

#### FR-38（P0）基期现金流三档：FCF 序列离散锚定，仅展示不估值

**要求：**

记 `fcf_series` 为已输出的分年 FCF（`FCFYearPoint.FCF`，按年份升序），`Low = min(各年 FCF)`、`High = max(各年 FCF)`、`base` 为当前推荐基期 FCF（顶层 `fcf_base_value`）。三档取值：

```
Low  = min(fcf_series 各年 FCF)
High = max(fcf_series 各年 FCF)

保守档 base_fcf = min(base, Low)    // 非强周期再下限到 base × 75%
基准档 base_fcf = base              // 依据固定「当前推荐」
乐观档 base_fcf = max(base, High)   // 非强周期再上限到 base × 125%
```

- **周期位置 + 双向 clamp**：强周期（生效 `IsCyclical` 或 FCF 变异系数 CV > 0.5）不做比例 clamp，穿越周期低点/高点即情景；非周期/稳定档位再收口到 `base × [0.75, 1.25]`（常量 `valFCFFlatClampDown=0.75` / `valFCFFlatClampUp=1.25`）。
- **非正守卫**：`Low ≤ 0` 时保守档退回 `base`（依据「近年最低非正，回退基准」）；`High ≤ 0` 时乐观档退回 `base`（依据「近年最高非正，回退基准」）。
- **无离散**：`|High − Low| ≤ base × 5%`（常量 `valFCFNoSpreadRatio=0.05`）时三档都取 `base`，依据记 `无离散`；`base ≤ 0` 时也按无离散处理（避免除零）。
- 每档新增 `base_fcf`（元，与现有 FCF 单位一致、不额外舍入）与 `base_fcf_basis`（依据：`当前推荐` / `近年最低` / `近年最高` / `非周期 clamp（±25%）` / `无离散` / `无离散（自定义）` / `近年最低非正，回退基准` / `近年最高非正，回退基准`）。
- 守卫：`fcf_series` 为空时三档都取 `base`，依据记 `无离散`；`custom` 模式基期 FCF 由规则直接给出，不参与离散锚定，三档都取 `base`，依据记 `无离散（自定义）`。
- 三档 `base_fcf` 是**纯展示字段**，不参与后端每档估值计算（P0 不产出逐档股价），也不改动顶层基准估值。
- P1 前端逐档套用时，所选档的 `base_fcf` 作为「自定义」基期 FCF 写回估值表单（换算口径见 FR-36）；这仍是前端发起的普通 `/valuation` 请求，不改变后端三档计算。
- `valuationPromptBlock` 的三档摘要逐档输出 `base_fcf` 与依据，AI 只能解释、不得改写。
- 前端桌面表格与 ≤760px 移动卡片逐档展示基期 FCF（亿元）与依据标签，基准档中性高亮不变。

**验收：**

- `base=110亿、序列最低 90亿、最高 130亿（非强周期）` → 三档 `base_fcf` 分别为 90/110/130 亿，依据分别为「近年最低」「当前推荐」「近年最高」。
- 强周期 `base=100亿、Low=30亿、High=200亿` → 保守 30 亿、乐观 200 亿，不做 ±25% clamp。
- 非强周期 `base=100亿、Low=20亿` → 保守 clamp 到 75 亿，依据「非周期 clamp（±25%）」；`High=300亿` → 乐观 clamp 到 125 亿，依据「非周期 clamp（±25%）」。
- `|High−Low| ≤ base×5%` → 三档均等于 `base`，依据「无离散」。
- `Low=-5亿` → 保守档退回 `base` 且依据为「近年最低非正，回退基准」；`High=-10亿` → 乐观档退回 `base` 且依据为「近年最高非正，回退基准」。
- `fcf_series` 为空 → 三档均等于 `fcf_base_value`，依据为「无离散」；`custom` → 依据为「无离散（自定义）」。
- 基准档 `base_fcf` 等于顶层 `fcf_base_value`；`ApplyValuationRecommendation` 后三档新字段与后端结果逐字段一致。

## 8. 表达与展示规范

### 8.1 公式展示：输入 → 中间量 → 结果

**要求：**

- 每个参数区块按「输入行 → 中间量行 → 结果行」展示；不得只给最终值。
- 每个变量首次出现时给出中文名、符号、单位。
- 公式中的权重、阈值、常量必须显示实际值，不得写「根据情况调整」。

**折现率模板：**

```
股权成本 Re = Rf 2.5% + β 1.10 × ERP 5.50% = 8.55%
资本结构：有息债务 100 亿（10.0%） / 股东权益 900 亿（90.0%）
税后债务成本 = 4.00% × (1 − 25.0%) = 3.00%
WACC = 10.0% × 3.00% + 90.0% × 8.55% = 8.00%
公司风险溢价 = 1 个风险点 × 1.0pp = 1.0pp
折现率 = 8.00% + 1.0pp = 9.00% → 收口 9.00%
```

**增长率模板：**

```
历史锚 A_hist = (营收 12.0% + 净利润 9.0% + FCF 9.0%) ÷ 3 = 10.0%
周期修正 Δ_cycle = −3.0pp → 调整后历史锚 7.0%
前瞻锚 A_fwd = 15.0%（8 家机构，高可靠，截至 2026-10-17）
宏观锚 A_macro = 4.5%（动态 GDP，截至 2026-09-30）
复合锚 A = 0.45×7.0 + 0.45×15.0 + 0.10×4.5 = 10.35 → 10.5%
```

**向下调整模板：**

```
① 离散度折减：离散度 40.0pp → 折减 1.68pp → 候选 8.82%
② SGR/前瞻软上限：max(SGR 5.0%, A_fwd 15.0%) + 5.0pp = 20.0% → 未触发
③ 0.5pp 网格：round0.5(8.82%) = 9.0%
④ M1 包络：A−5.0pp = 5.5% → 9.0% 未低于下限，未触发
⑤ g1 = 9.0%
```

### 8.2 权重视图：值 × 权重 = 贡献

**要求：**

- 任何加权计算都必须展示三列：`值`、`权重`、`贡献 = 值 × 权重`；最后一行求和。
- 权重之和必须显示（1.00 或归一化分母）。
- 缺失项必须显示「不可用，权重 0」或「未计入，按剩余权重归一化」，不得直接消失。
- 前端不得自行推算权重；必须使用接口 `growth_weights`。

**复合锚表格模板：**

| 锚 | 值 | 权重 | 贡献 |
|---|---:|---:|---:|
| 历史（周期修正后） | 7.0% | 0.45 | 3.15 |
| 前瞻 | 15.0% | 0.45 | 6.75 |
| 宏观 | 4.5% | 0.10 | 0.45 |
| 合计 | — | 1.00 | 10.35 → 10.5% |

**模型得分表格模板：**

| 信号 | 分数 | 权重 | 贡献 |
|---|---:|---:|---:|
| 增速 Sg | 57.5 | 0.6 | 34.50 |
| 稳定性 Sst | 90.0 | 0.2 | 18.00 |
| ROE Sroe | 90.0 | 0.2 | 18.00 |
| 合计 | — | 1.0 | 70.50 |

### 8.3 调整顺序：先列步骤，再给结果

- 复合锚：`A_hist → +Δ_cycle → 加权合成 → clamp → A`。
- g1：`A → 离散度折减 → 软上限 → 0.5pp 网格 → 包络下限 → 出口复核 → g1`。
- 终值：`min(宏观, r−1, SGR) → floor0.5 → max(0) → g∞`。
- 模型：`A/gap/score/负增长类型 → 分档 → 降级链 → model`。
- 每一步必须写明「触发/未触发」；不得跳步或合并描述。

### 8.4 数字、单位、舍入

| 风险溢价/Δ | 1 位小数 | 1.0pp、−3.0pp |
| 权重 | 2 位小数 | 0.45、0.10 |
| β | 2 位小数 | 1.20 |
| 金额（亿元） | 2 位小数 | 123.45 亿 |
| 年数 | 整数 | 7 年 |

## 11. 边界与约束

- 本功能是**估值参数辅助**，不是投资建议；三档是参数区间，不是目标价。
- DCF 仍只适用于有正 FCF、非金融、非亏损的公司；不适用时三档仅作透明展示。
- 不剔除一次性项目：免费数据无附注，不得编造「扣非 FCF」。
- 不扣营运资本变动：仅在 C5 告警和理由中提示；若未来接入附注，再评估。
- 不新增「周期平均」模式：`trim_mean` + 10 年窗口已覆盖；避免用户选择过载。
- 不设行业增速锚：行业差异通过 β、周期判定、成长性豁免体现（R18 D6）。
- 三档不输出概率；不做蒙特卡洛；M5 横截面校准是 P1 回测项，不输出投资结论。
- 阈值（70/45、1.5/4.0、1.5pp/3–10 年等）来自当前项目口径，尚未经过大规模回测；后续校准需另立需求。
- DeepSeek 模型路由由官方控制；本项目只保证模型名与请求参数正确，不保证官方行为不变。

## 13. 待确认问题

> 以下问题会显著影响实现范围或数值口径，请用户拍板。每项已给推荐默认值。

### Q1 三档增长率带宽的锚定方式

- **问题：** `band_g` 用「历史与前瞻分歧」还是固定带宽？
- **影响：** 三档的宽窄、不同公司之间的可比性、前端解释成本。
- **推荐：** 采用 7.2 的「分歧法」：`D=|A_hist_adj−A_fwd|`，clamp [1.5,4.0]；无前瞻时用 `20%×max(A,0)`；A<0/zero 时为 0。理由：分歧是最直接的不确定性来源，且避免所有公司都显示同样的 ±3pp。
- **备选：** 固定 ±3.0pp（更简单、更可比，但信息量低）；或 `20%×A`（随规模缩放，但高增长公司带宽可能过大）。

### Q2 三档是否输出每档估值结果/支持逐档套用

- **问题：** P0 只输出参数，还是同时输出每档 `equity_value_per_share` 并支持「套用此档」？
- **影响：** 后端需为每档跑一次 DCF；前端交互更复杂；但用户可直接看到三档估值区间。
- **推荐：** P0 只输出参数 + 基准档套用（向后兼容）；每档估值与套用列为 P1。理由：先保证参数口径正确，避免三档估值被误读为目标价。

### Q3 强周期 FCF 窗口 7→10 年

- **问题：** 是否把 `valFCFRecMaxYears`、`valCycleWindowYears`、`valFCFYearsCyclical` 从 7 改为 10？
- **影响：** 强周期公司推荐值更平滑；数据不足时无影响；前端 `fcf_years` 上限已 10。
- **推荐：** 是。理由：A 股周期行业一轮 7–10 年，7 年可能只覆盖半轮；现有数据约 10 个年报，成本低。

### Q4 是否禁止不稳定序列使用普通平均/新增「周期平均」模式

- **问题：** R10 在 CV>0.30 或符号翻转 ≥1 时是否必须改用 median？是否新增用户可见的「周期平均」模式？
- **影响：** 推荐结果、用户选择项数量。
- **推荐：** 禁止不稳定时用 average，但**不新增模式**；强周期统一用 `trim_mean`。理由：`trim_mean` 已表达「周期平均」语义，新增模式只增加选择负担。

### Q5 是否本次实现 `adjust_growth_capex`（扣减扩张性资本开支）

- **问题：** 是否新增开关，按 `CONSTRUCT_LONG_ASSET − 保全性资本支出` 扣减 FCF？
- **影响：** 高成长公司 FCF 可能大幅下降甚至转负，导致 DCF 不适用；前端多一个开关；默认关闭可控制影响。
- **推荐：** 本次 P1/defer。先用 FR-6 的 capex 守卫 + 理由提示解决「误用 latest」；若用户希望更保守，再实现开关。若实现，默认关闭，并提供扣减前后预览。

### Q6 DeepSeek flash 是否完全不发送 `reasoning_effort`

- **问题：** `deepseek-flash` 请求是否移除 `reasoning_effort`？`max_tokens=8192` 是否保留？
- **影响：** API 兼容性、计费、输出长度。
- **推荐：** flash 不发送 `reasoning_effort`；保留 `max_tokens=8192` 作为输出上限；推理模型白名单仍发送。理由：避免不支持参数报错，同时保留旧模型能力。
- **待验证：** 官方 API 对 flash 的 `max_tokens` 上限与是否接受该字段；若拒绝，技术设计下调并记录 `finish_reason`。

### Q7 三档折现率/终值带宽是否固定 ±1.0pp / ±0.5pp

- **问题：** `band_r` 与 `band_terminal` 是否固定？
- **影响：** 三档的折现率/终值差异；边界截断频率。
- **推荐：** 固定 1.0pp / 0.5pp。理由：与风险档位、0.5pp 网格匹配；避免随公司规模变化导致不可比。

### Q8 负增长/零增长模型是否只让折现率分档

- **问题：** A<0 或 zero 模型时，三档增长参数是否完全相同？
- **影响：** 三档是否还有增长维度；前端是否需要特别说明。
- **推荐：** 是，`band_g=0`，三档只变 r；说明写「增长参数不设区间，仅折现率分档」。理由：负增长/零增长没有可解释的上下调空间，强行给带宽会制造伪精度。

### Q9 债务成本不可用时的保守估计

- **问题：** Rd 不可用且 D>0 时，是否改为 `clamp(Rf+2.0,3,8)`？
- **影响：** 高杠杆、利息数据缺失公司的 WACC 会上升；存量样例结果变化。
- **推荐：** 是。理由：按 0 处理会系统性低估 WACC；`Rf+2.0` 是常见的信用利差近似。需在技术设计中列出受影响样例。

### Q10 三档模型是否允许逐档不同

- **问题：** 保守档降为永续、乐观档升为三阶段，是否允许？
- **影响：** 展示复杂度；但这是参数变化的自然后果。
- **推荐：** 允许，逐档显示模型名与降级原因。理由：强行统一模型会掩盖参数区间对模型选择的影响。

## 14. 已确认决策记录

### 14.1 R15 既有决策

- **2026-10-16 β 决策：** β 采用行业类型常量表（周期 1.2 / 一般 1.0 / 公用 0.8），AI 只做定性行业分类，不做 β 回归；AI 缺失时按波动/周期兜底。
- **WACC 基线：** `Re=Rf+β×ERP`；`WACC=wD×Rd×(1−t)+wE×Re`；公司风险溢价按财务风险点 0–3pp；收口 0.5pp、[8,15]。
- **基期 FCF：** 保全口径，不扣扩张性资本支出与营运资本；研发只加回扩张部分。
- **不适用：** 最新年 FCF≤0、金融股、最新年净利润≤0 → 不适用。

### 14.2 R18 既有决策（D1–D10）

- D1 动态名义 GDP 作为终值锚；不可用回退 4.5%。
- D2 东财一致预期作为前瞻锚；可靠度分级，基准年必须对齐。
- D3 周期位置修正历史锚；λ=10pp，cap ±6pp。
- D4 SGR 以分红留存率为主口径，权益增长为备选。
- D5 负增长结构性 → 零增长；周期性 → 低永续。
- D6 不设行业增速锚。
- D7 模型门槛：三阶段 A≥6、gap≥4、score≥70；两阶段 A≥2、gap≥1.5、score≥45。
- D8 验收阈值：包络 5/3pp；折减 0.004/0.40；回归 1.5pp/3–10 年；软上限 +5pp。
- D9 快照确定性：外部数据由 API 注入，纯函数不读时钟。
- D10 范围：只重构增长率与参数，不改 DCF 公式。

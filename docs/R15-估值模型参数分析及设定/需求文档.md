# 自由现金流估值模型参数设定方法论

> 关联文档：`docs/R4-公司股票估值/公司股票估值.md`（估值公式与口径定义）、`docs/R4-公司股票估值/需求文档.md`（R4 公司股票估值）与 `docs/R5-AI智能分析/需求文档.md`（R5 AI 智能分析）、`docs/R7-AI估值模型参数确定性约束/技术设计文档.md`（R7 确定性推导）与 `docs/R13-AI基期自由现金流推荐/技术设计文档.md`（R13 基期 FCF 推荐）、`docs/R7-AI估值模型参数确定性约束/需求文档.md`、`docs/R13-AI基期自由现金流推荐/需求文档.md`
>

## 1. 背景与问题

### 1.1 现状

本项目已有两块相关能力：

1. **R4 公司股票估值**（`internal/service/valuation.go`）：现金流贴现法（DCF），四种模型——零增长（`FCF ÷ r`）、永续增长（`FCF×(1+g)÷(r−g)`）、两阶段、三阶段；参数 `model` / `r` / `g` / `g1` / `n1` / `g2` / `n2` / `g3` 由用户在表单输入，点击「计算估值」统一计算。**公司价值 = 金融资产价值 + 长期股权投资价值 + 经营资产价值；股权价值 = 公司价值 − 有息债务**。经营资产自由现金流 = 经营活动现金流量净额 `NETCASH_OPERATE` − 保全性资本支出；基期选取支持 `fcf_mode`（`latest` / `average` / `median` / `trim_mean` / `custom`）+ `fcf_years` + `adjust_rd`（研发费用调整）。
2. **R5 AI 智能分析 + R7/R13 确定性推荐**（`internal/service/ai.go` + `valuation_recommend.go`）：大模型只写 `rationale`，模型 / 折现率 / 各阶段增长率 / 年数 / 基期 FCF 选取**全部由后端按财报数据确定性推导**并回填（`RecommendValuation` / `RecommendBaseFCF`）。

### 1.2 用户反馈与问题定义

用户实测：**AI 分析给出的估值模型参数，套用到估值表单后结果不满意**。这不是「套用链路出错」——R7 之后参数已完全确定性、可复现（多次分析差值为 0）。问题出在**参数设定的方法论**：参数「稳定」了，但「稳定地不合理」。

本方法论要回答的是 5 个子问题：

- **Q-A** 基期自由现金流（FCF）怎么从报表还原并归一化，才算得上「可持续」？
- **Q-B** 折现率 `r` 怎么算出来，而不是拍一个 9%~12% 的档位？
- **Q-C** 增长率 `g` 怎么和个人投资者的常识（增速、生命周期、护城河）对上？
- **Q-D** 模型（零/永续/两阶段/三阶段）和公司的生命周期怎么对应？
- **Q-E** 这些参数彼此之间有哪些必须成立的内在一致性关系？

### 1.3 现状参数的固有问题（后文逐条展开改进方向）

| 编号 | 现状（真实代码） | 问题 |
| --- | --- | --- |
| P1 | 基期 FCF 由 `fcf_mode` 五选一，逐年在同口径 `operatingFreeCashFlow` 上取值 | 只做「时间维度取中枢」，**不做一次性/非经常项目的剔除**；经营现金流里若混入大额非经常项（资产处置、政府补助、票据/保证金占用）会直接抬高基期 |
| P2 | 保全性资本支出用「折旧摊销 + 减值 + 处置/报废损失」近似 | 该口径**不含扩张性资本支出、不含营运资本变动**，对高增长/高营运资本占用的公司会系统性高估 FCF |
| P3 | 折现率 `r` = 财务风险点（0–3）→ `{9.0, 10.0, 11.0, 12.0}` | **完全脱离 WACC 概念**：不含无风险利率、市场风险溢价、股权成本；纯靠财务杠杆/利息保障/有息债务占比三个「类信用风险」指标分档，且区间过窄（真正的股权成本对高波动成长股常在 12%+） |
| P4 | 项目**已实现** `wacc()` 指标（= `(有息债务/投入资本)×税后债务资本成本 + (股东权益/投入资本)×8%`），但估值推荐的 `r` **没有用它** | 同一份财报里「分析」与「估值」两处资本成本口径割裂；`wacc` 内股权成本硬编码 8%，也未与无风险利率/风险溢价挂钩 |
| P5 | 基准增速 `X%` = 营收 / 重构净利润 / 经营现金流 各近 3 年同比增速合并取**中位数** | ①三项权重被「样本数」隐式决定，不是等权；②同比增速对首末年异常敏感；③**取的是「经营现金流净额」增速而非 FCF 增速**，与贴现对象不同口径；④`X%` 直接当高增长期 `g1` 用 |
| P6 | 模型分档硬阈值：`X≥20` 三阶段 / `8≤X<20` 两阶段 / `0≤X<8` 永续 / `X<0` 零增长 | 阈值与「生命周期」无显式映射；一家 `X=19.9%` 的成熟龙头与 `X=20.1%` 的次新股会被分到不同模型；`0≤X<8` 的公司多数其实是「零增长/低速增长」而非永续增长 |
| P7 | 终值 `g`：`discount≤9→4`、`≤11→3`、`else→2`（`perpetualGrowth`） | 「折现率越低假设永续增速越高」的方向正确，但**上下限与长期 GDP/通胀的量化关系未写明**，4% 在部分情形已偏高 |
| P8 | 三阶段 `g2 = min(4, gk+1)` | 当 `gk=4` 时退化为 `g2 = g3 = 4`，**第二阶段增长率与终值相等**，「递减路径」在边界失效 |
| P9 | `RecommendBaseFCF` 的 `custom` 推荐值 = 正 FCF 中位数 ×(1+ 可持续增速)，取整到整亿 | 依赖「最近一年明显偏高 且 业绩不可持续」才触发；对**周期性公司**（行业景气高点）缺少显式识别 |
| P10 | 全部输入只有三张年报 + 行情快照（总股本） | 无历史股价/指数序列 → **β、市场风险溢价、无风险利率均无法直接测算**；分红数据链路已删除 → **留存率/分红率不可得**（影响可持续增长率） |

## 2. 估值参数体系总览（业界标准框架）

业界标准的公司自由现金流（FCFF，本项目称「经营资产自由现金流」）贴现估值，参数分五个层次，且**必须自上而下推导、自下而上校验**：

```
① 基期自由现金流 FCF₀   ── 报表还原 + 归一化（去一次性、平滑周期、资本开支口径）
        │
② 折现率 r              ── WACC = E/(E+D)·Re + D/(E+D)·Rd·(1−t)
        │                     Re = Rf + β·ERP + 特定风险溢价
        │                     Rd = 债务成本（利息 / 有息债务）
        │
③ 增长率 g              ── 可持续增长率 SGR = ROE × 留存率；与生命周期匹配
        │
④ 模型与期限结构        ── 零/永续/两阶段/三阶段 ↔ 导入/成长/成熟/衰退
        │
⑤ 终值增长率 g_term     ── ≤ 长期名义 GDP 增速（≈ 通胀 + 实际增长），且 g_term < r
        │
        └─► 内在一致性校验：r > g；g_term ≤ g(预测期)；Capex 与 g 匹配；FCF 与净利润关系合理
```

各参数与本项目的关系一览：

| 层次 | 业界标准做法 | 本项目现状 | 可确定性化？ |
| --- | --- | --- | --- |
| ① 基期 FCF | 报表还原 + 归一化 | 同口径逐年 FCF 取中枢 | **大部分可**（去一次性、平滑需额外规则） |
| ② 折现率 r | CAPM 股权成本 + 债务成本 → WACC | 财务风险点 → 9/10/11/12% | **可算基线**（Rf/ERP/β 取固定常量或行业默认），公司特定溢价需判断 |
| ③ 增长率 g | SGR = ROE × 留存率；结合增速与生命周期 | 三指标同比增速中位数 X% | **可算**（SGR 需 ROE；留存率受数据限制） |
| ④ 模型 | 与生命周期对应 | X% 硬阈值分档 | **可确定性化**（改用多信号判据） |
| ⑤ 终值 g | ≤ 长期 GDP/通胀 | 折现率反相关映射 {2,3,4} | **可确定性化**（改为与长期增速常量挂钩） |

> **核心原则**：凡是「由财报数据本身决定」的取值，一律确定性算子；凡是「需要市场数据或行业判断」的取值，先给确定性基线，再允许在**受约束的区间内**定性微调，绝不裸奔。

## 3. 基期自由现金流的合理设定

### 3.1 报表还原（口径）

本项目现行口径（《公司股票估值.md》与本项目约定）：

```
经营资产自由现金流 = 经营活动现金流量净额 NETCASH_OPERATE − 保全性资本支出
保全性资本支出 ≈ 资产减值损失 + 信用减值损失
                + 固定资产折旧、油气折耗、生产性生物资产折旧（FA_IR_DEPR）
                + 使用权资产折旧（USERIGHT_ASSET_AMORTIZE）
                + 无形资产摊销（IA_AMORTIZE）+ 长期待摊费用摊销（LPE_AMORTIZE）
                + 处置长期资产的损失（DISPOSAL_LONGASSET_LOSS，仅计损失、收益按 0）
                + 固定资产报废损失（FA_SCRAP_LOSS）
```

**业界标准的等价还原路径**（可作交叉验证）：

```
FCFF = EBIT × (1 − t) + D&A − Capex − ΔNWC
     = 经营活动现金流量净额 − Capex        （当经营现金流已含 D&A、已扣 ΔNWC，且税金已付现）
```

两者在本项目中的数据来源下**大体等价但不等价于「可持续 FCF」**，原因是 3.2–3.4。

### 3.2 一次性 / 非经常项目的剔除（当前缺失）

经营现金流净额包含若干**与经营可持续性无关**的项目，应从基期中剔除或将其中枢化处理：

| 类型 | 典型科目 | 处理建议 |
| --- | --- | --- |
| 处置长期资产的现金流入/流出 | 投资活动；仅「损失」进了保全性资本支出（且仅计损失） | 处置**收益**对应的现金流入应视为一次性，不计入可持续 FCF |
| 大额政府补助、税收返还 | 「收到的其他与经营活动有关的现金」等 | 若无明细不可拆，则**不单独剔除**，但通过 3.3 的中枢/平滑弱化其影响 |
| 减值损失 | `ASSET_IMPAIRMENT_LOSS` / `CREDIT_IMPAIRMENT_LOSS`（本项目已双字段兼容） | 减值是非现金项，加回经营现金流是对的；但**若为短期大额集中计提**，说明当期经营现金被低估、应人工判断 |
| 营运资本一次性占用 | 应付/应收票据、保证金、预收 | 无明细不可拆 → 用多年中枢平滑（见 3.3） |

**定性判断标注**：当单年「非经常性损益」无法从免费接口拆出时，**不应编造剔除值**；正确做法是**改用多年中枢**并在推荐理由中写明「因无法拆分一次性项目，采用中枢以平滑」。这与项目既有纪律一致（不猜数、把口径写进文档）。

### 3.3 周期性 / 波动平滑

- **周期性公司**（钢铁、煤炭、化工、航运、养殖、券商等）：单年 FCF 处在景气高点或低点，**必须用「完整周期」的中枢**，而不是最近一年。
- 业界常用判据：取 **7~10 年（至少覆盖一轮周期）** 的 FCF 均值/中位数；本项目接口可拉约 10 个年报，**具备能力**（`fcf_years` 上限可提高）。
- 与 `fcf_mode` 的关系：`trim_mean`（去最高最低）对周期股**优于** `average`；`median` 更抗极端值。
- **确定性判据建议**：若某公司近 N 年 FCF 的**变异系数（标准差 ÷ 均值）> 某阈值**（如 0.5）或**正负交替出现**，则判定为「强周期/高波动」，强制推荐 `trim_mean` 且 `fcf_years` 取满可用年份。

### 3.4 资本开支：保全性 vs 扩张性（当前口径的偏差点）

- 本项目保全性资本支出用**折旧摊销 + 减值**近似，符合《公司股票估值.md》原文（「很难得到保全性资本支出的金额，通常用长期资产的折旧摊销、减值准备来近似」）。
- 局限：**不含营运资本变动 ΔNWC**。对营运资本占用大的公司（应收/存货/预付款重的制造、零售、工程类），经营现金流已隐含 ΔNWC，但假设「保全性资本支出 = 折旧摊销」仍可能低估扩张期的现金消耗。
- **一致性要求**：基期 FCF 采用的资本开支口径，必须与增长率假设匹配——
  - 若 `g` 假设为高增长（`three_stage`），则**隐含需要扩张性资本支出**，用「保全性口径的 FCF × 高增长」会**双重高估**（既没扣扩张 Capex、又给了高增长）。
  - 业界做法：高增长期要么（a）显式扣除扩张性 Capex 后用较低 FCF 增长，要么（b）用较低增速，二者择一，不能两头都乐观。
- **建议（确定性可算）**：定义 **Capex 覆盖率** = (购建固定/无形/长期资产支付的现金) ÷ 折旧摊销；若某年 > 1.3（明显扩张），在推荐理由中提示「基期 FCF 为保全口径，未含扩张性资本支出，高增长假设下偏乐观」。购建资产现金流出字段现有现金流量表可取（需实测确认字段名）。

### 3.5 研发费用的资本化处理

- 本项目已实现 `adjust_rd`：把研发投入的**扩张部分**（`rdExpansion = max(0, 本年度研发费用 − 上年度研发费用)`）加回基期 FCF，逻辑是「同额研发视同保全性支出（已扣）、增量视同扩张性支出（加回）」。
- **业界一致性**：这与「研发资本化后摊销」的会计处理方向一致，但更简单（只加回增量、不做摊销年限）。适用于研发费用率高的成长科技股。
- **触发条件现状**：最新年报研发费用率（`RESEARCH_EXPENSE ÷ TOTAL_OPERATE_INCOME`）严格 > 5%（`rdAdjustThreshold`）才建议开启。
- **改进方向（确定性可算）**：阈值可从「单一 5%」细化为「研发费用率 × 营收增速」双条件——**只有研发在扩张、且费用率显著高于行业常态时才加回**，避免成熟公司因会计口径波动误加回。

### 3.6 `fcf_mode` 五种方式的适用场景与局限

| 方式 | 口径 | 适用 | 局限 |
| --- | --- | --- | --- |
| `latest`（最近一年） | 最近年报 FCF | FCF 稳定增长、无一次性项 | 单年最易受一次性项影响；周期高点会高估 |
| `average`（近几年平均） | 最近 n 年均值 | 平稳、无极端值 | 受极端年拉偏；高增长公司会低估近况 |
| `median`（近几年中位数） | 最近 n 年中位数 | 有单年异常、抗极值 | 丢失趋势信息；`n` 为偶数时取中间两值平均（本项目口径） |
| `trim_mean`（去极值平均） | 去掉最高最低后均值 | 强周期、有明显极值 | `n<3` 时退化为普通平均（本项目口径）；仍受「次高/次低」影响 |
| `custom`（自定义） | 用户/系统给定值 | 前四者都不合适、需人工判断 | 依赖给定者的判断质量；本项目对 `custom` 有「>0、≤1e14 元、单位换算」校验 |

> **默认年数**：本项目 `defaultFCFYears = 3`。对 A 股常见 3 年小周期偏短，建议默认值上调或按行业给不同默认（见待确认 Q3）。

### 3.7 如何判断 FCF 的「可持续性」（分层）

| 层级 | 判据 | 能否确定性 |
| --- | --- | --- |
| L1 数据层 | FCF 是否全为正 / 单调 / 极差是否过大 | **可确定性**（现有 `allPositive` / `monotoneUp` / `spread`） |
| L2 会计层 | 一次性项、减值集中度、ΔNWC 反转 | 部分可确定性（减值可；一次性项多不可拆） |
| L3 经营层 | FCF 与净利润是否背离（利润含金量）、Capex 覆盖率 | **可确定性**（已有「净利润现金含量」「扩张性资本支出比例」类指标可复用） |
| L4 业务层 | 护城河、市占率、行业天花板、需求可持续性 | **需判断**（大模型定性 / 人工） |

**判据组合建议**：`L1 + L2 + L3` 产出一个确定性「FCF 可持续性档位」（高/中/低），据此推荐 `fcf_mode` 与 `fcf_years`；`L4` 只用于生成文字说明，**不改数**。

### 3.8 现状不足与改进方向（基期 FCF）

| 不足 | 改进方向 | 代码落点 |
| --- | --- | --- |
| 无法剔除一次性/非经常项目 | 无法拆分时改用中枢，并写明理由（不做假数） | `RecommendBaseFCF` 的 `Rationale` 文案 |
| 周期性识别缺失 | 新增「FCF 变异系数 / 正负交替」确定性判据，强周期强制 `trim_mean` + 拉长年数 | `RecommendBaseFCF` 前端判据（在 R3 之前新增规则） |
| 默认年数 3 年偏短 | 按周期性强弱动态给出 `fcf_years`（平稳 3、周期 5~7） | `valFCFRecMaxYears` / 推荐逻辑 |
| 基期口径与增长率不联动 | 高增长假设时校验 Capex 覆盖率，偏高则在 `Warning` 中提示「偏乐观」 | `RecommendValuation` 的 `Warning` |
| 研发调整阈值单一 | 改为「费用率 + 扩张」双条件 | `rdAdjustSuggestion` |

## 4. 折现率 r 的合理设定

### 4.1 业界标准：加权平均资本成本（WACC）

```
WACC = E/(E+D) × Re + D/(E+D) × Rd × (1 − t)

其中：
  E = 股权市值（或账面股东权益近似），D = 有息债务
  Re = 股权成本（CAPM）
  Rd = 债务成本 = 利息支出 ÷ 平均有息债务
  t  = 实际所得税税率
```

**本项目已有完全对应实现**（`internal/service/analysis.go`）：

- `debtCapitalCost` = 偿付利息支付现金 ÷ 平均有息债务余额 × 100%（%）
- `debtCapitalCostRate`（股权价值维度）= 真实财务费用 ÷ 平均有息债务余额 × 100%
- `effectiveTaxRate` = 所得税费用 ÷ (利润总额 − 长期股权投资收益)，基数 ≤ 0 回落 25%
- `wacc` = `(有息债务/投入资本)×税后债务资本成本 + (股东权益/投入资本)×股权资本成本(8%)`

**关键差距**：估值推荐的 `r`（9/10/11/12）**没有引用这套 WACC**。改进的第一要务就是**让 r 与项目的 WACC 口径接轨**。

### 4.2 股权成本 Re（CAPM）

```
Re = Rf + β × ERP + 规模溢价 + 公司特定风险溢价
```

| 分量 | 业界取值（A 股） | 本项目可得性 | 建议 |
| --- | --- | --- | --- |
| 无风险利率 `Rf` | 10 年期国债收益率，近年在 2.0%~3.0% 波动 | **无数据源**（只有三张表 + 行情快照） | 取**固定常量**（如 2.5%），随版本更新；保证确定性 |
| 股权风险溢价 `ERP` | A 股常用 5%~6% | 无数据源 | 取**固定常量** 5.5%（可配置） |
| β | 个股/行业 β | **无历史股价/指数序列** → 不可算 | 用**行业默认 β 表**（周期性 > 1，公用事业 < 1）或统一取 1.0 |
| 规模溢价 | 小市值 +1%~2% | 总市值可得（行情 `[45]`） | 可按市值分档确定性加价 |
| 公司特定风险溢价 | 治理、集中度、财务风险 | 财务风险可确定性（现 riskPoints）；其余需判断 | 沿用 `riskPoints` 转成溢价档 |

**示例计算（全常量确定性版）**：

```
Re = Rf(2.5%) + β(1.0) × ERP(5.5%) = 8.0%
```

——恰好与项目现有硬编码的 8% 股权成本吻合。这说明**现有 8% 并非拍脑袋**，但它假设了 `β=1.0`、无规模/公司溢价，对本项目覆盖面偏窄。

### 4.3 债务成本 Rd

- 优先用 `debtCapitalCostRate`（真实财务费用 ÷ 平均有息债务，与「财务成本负担率」同口径）；退而用 `debtCapitalCost`（偿付利息现金口径）。
- 无有息债务 → `Rd` 项为 0，WACC 退化为纯股权成本（本项目 `wacc` 已如此处理）。
- **注意**：`Rd` 应是**税前**债务成本，乘 `(1−t)` 后进入 WACC。

### 4.4 资本结构（权重）

- 账面口径：`D = 有息债务`、`E = 股东权益（TOTAL_EQUITY）`——本项目 `wacc` 用的就是账面口径。
- 市值口径：`E = 总股本 × 最新价`（行情可得）、`D = 有息债务`。
- 业界更推荐**目标资本结构**（避免当期结构极端）；本项目个人投资场景下**账面口径可接受**，但应在文档写明。

### 4.5 现状与业界标准的差距

| 维度 | 现状（riskPoints → 9/10/11/12） | 业界标准 |
| --- | --- | --- |
| 是否含无风险利率 | 否 | 是（CAPM 起点） |
| 是否含市场风险溢价 | 否 | 是（ERP×β） |
| 是否含股权成本概念 | 否（只有财务风险档位） | 是（Re 为主） |
| 是否按资本结构加权 | 否 | 是（WACC） |
| 区间宽度 | 9%~12%（3 档，步长 1%） | 通常 7%~15%（高波动成长股可更高） |
| 风险信号 | 有息债务占比、利息保障、财务杠杆 | 更全面（经营风险、周期、治理…） |

**结论**：现规则本质是「**信用风险分档**」，不是「**股权要求回报率**」。对低杠杆的轻资产成长股会给出**过低**的 r（8%~9% 偏低），对高杠杆周期股可能给出**过高**的 r（12% 仍不足以覆盖经营风险，或反之因有息债务高而误判）。

### 4.6 建议的分层方案（确定性基线 + 约束微调）

```
第 1 层（确定性基线）：r_base = WACC（复用项目 wacc()，股权成本改用 Rf + β行业×ERP 常量）
第 2 层（确定性溢价）：+ 公司特定风险溢价（由 riskPoints 映射，0%~+3%）
第 3 层（需要判断，受限）：行业/生命周期定性调整，幅度限于 ±1%，且必须在基线附近
                         （若采用 AI 建议，也只能在此区间内取值并给出理由）
第 4 层（确定性收口）：四舍五入到 0.5% 网格，clamp 到 [8.0, 15.0]
```

- **基线可复现**：`Rf`、`ERP`、行业 `β` 全部为常量表 → 同一财报任意次结果一致。
- **溢价可复现**：`riskPoints` 映射沿用既有确定性判据。
- **收口可复现**：网格 + clamp 保证落在允许集。
- 这样既保留「确定性推导」纪律，又让 `r` 有了**经济学含义**（WACC），而非纯档位。

## 5. 增长率 g 的合理设定

### 5.1 可持续增长率（SGR）

```
SGR = ROE × 留存率
留存率 = 1 − 分红率（payout）
```

- `ROE` 本项目已有（`roe()`，杜邦四因素可分解）——**可确定性取用**。
- **留存率受数据限制**：分红数据链路已删除（见项目记忆与《技术设计文档》R10），**payout 不可直接得**。
- **替代口径（确定性可算）**：
  - 用**股东权益增长率**近似留存再投资：`留存率 ≈ (期末股东权益 − 期初股东权益) ÷ 净利润`（剔除增发/回购影响不完美，但对多数公司可用）；
  - 或用 `(1 − 股利支付现金 ÷ 净利润)`——但需确认现金流量表「分配股利、利润或偿付利息支付的现金」是否可拆分股利（该科目常与利息合并，需实测）。
- **意义**：SGR 给出的是**内生增长上限**——一家公司长期增速不可能持续超过 `ROE × 留存率`。可作为 `g` 的**上限约束**，防止推荐出企业自身无法支撑的高增速。

### 5.2 盈利/现金流增速与生命周期匹配

| 生命周期 | 特征 | 增速设定 | 对应模型 |
| --- | --- | --- | --- |
| 导入期 | 营收小、增速极高但不稳定、现金流多为负 | 高增速但不宜长；常直接判「不适用」 | 多为三阶段或**不适用** |
| 成长期 | 营收高增长、再投资率高、FCF 常为负 | `g1` 高（贴近营收增速但打折）、期限长 | 两阶段 / 三阶段 |
| 成熟期 | 增速稳定、现金流充沛、分红率高 | `g` 中低（贴近 GDP 或略高） | 永续增长 |
| 衰退期 | 营收下滑、现金流萎缩 | `g` 为 0 或负 | 零增长 |

**判据（确定性可算）**：用「营收增速 × 现金含量 × 再投资率」三信号定位生命周期，而不是单一 `X%` 阈值。

### 5.3 增速可持续性判断

| 信号 | 确定性? | 用途 |
| --- | --- | --- |
| 近 3~5 年营收/扣非净利增速的**趋势**（加速/减速/稳定） | 可 | 判断 `g1` 是否该衰减 |
| 增速**极差/标准差** | 可 | 波动→打折（现有 `valVolatileSpread=40`） |
| **再投资率** = (Capex + ΔNWC) ÷ 净利润 | 部分可（ΔNWC 近似可行） | 与 SGR 校验：高增速需高再投资支撑 |
| **ROE 水平与稳定性** | 可 | 高 ROE 且稳定 → 增速更可延续（护城河代理） |
| 护城河/市占率/行业天花板 | 需判断 | 只写理由，不改数 |

### 5.4 现状不足（增长率）

1. **`X%` 是「经营现金流增速」而非「FCF 增速」**：贴现对象是 FCF，增长率却来自经营现金流，口径不一致。
2. **中位数混合了三项指标但权重由样本数隐式决定**：若某指标只能取到 2 年、另一项 3 年，则不是等权。
3. **同比增速对首末年敏感**：3 年同比可能因基数效应虚高/虚低；**CAGR** 通常更稳健（见待确认 Q2）。
4. **`X%` 直接当 `g1`**：`g1 = round(X)`，未与 SGR 上限、生命周期约束交叉校验。
5. **无「增速衰减」路径**：两阶段 `g1` 恒为常数 `n1` 年再断崖到 `g2`；三阶段虽有递减但边界失效（P8）。
6. **负增长只落到 `zero`**：对「短期承压但长期仍成长」的公司过于悲观（`X<0` → 零增长模型，隐含 FCF 永续零增长）。

## 6. 模型选择与生命周期的对应

### 6.1 各模型的适用类型

| 模型 | 数学含义 | 适合的公司 | 典型行业/阶段 |
| --- | --- | --- | --- |
| 零增长 `FCF÷r` | FCF 永续不变 | 现金流稳定、无增长，或**估值下限**参考 | 公用事业、成熟衰退期、衰退龙头 |
| 永续增长 `FCF×(1+g)÷(r−g)` | FCF 按 g 永续增长 | 成熟、增速接近长期 GDP | 消费龙头、公用事业、成熟制造 |
| 两阶段 | 高增长 n1 年 → 永续 g2 | 成长期后进入成熟 | 成长科技、扩张期消费/医药 |
| 三阶段 | g1(n1) → g2(n2) → 永续 g3 | 高增长且路径递减 | 高速成长科技、行业渗透期 |

### 6.2 现状 `classifyModel` 的问题与改进

| 问题 | 改进方向 |
| --- | --- |
| 单信号（`X%`）硬阈值分档，`X=19.9` 与 `20.1` 结果不同 | 改为**多信号得分**（增速水平 + 增速稳定性 + ROE 水平 + 行业生命周期），得分落档；边界可用平滑（如 18%~22% 归同一档） |
| `0≤X<8` 一律「永续增长」 | 该区间多数其实是**零增长或极低速增长**，建议 `X<3%` 归零增长、`3%≤X<8%` 归永续（且 `g` 取低档） |
| 未区分「负增长但盈利稳定」与「结构性衰退」 | `X<0` 应细分：ROE 高且稳定 → 永续（低 g）/零增长；ROE 下滑 → 零增长且 `Warning` 提示 |
| 无「不适用」出口 | 负 FCF / 无法还原 FCF / 金融股 → 应明确**判「不适用」**，而不是硬套模型（现有已有部分处理，可强化） |

## 7. 终值增长率（永续增长率）的合理区间

### 7.1 业界标准

- **上限**：长期**名义** GDP 增速（≈ 实际增长 + 通胀）。中国近年名义 GDP 增速约 4%~6%，长期中枢通常取 **2%~4%**。
- **绝不允许**：`g_term ≥ r`（戈登公式发散）；`g_term` 高于长期 GDP 意味着公司永续超过整个经济增长（不可持续）。
- **下限**：可为 0（零增长）甚至负（衰退），但慎用负值（需有明确理由）。

### 7.2 与本项目的映射

- 现状 `gk ∈ {2,3,4}` 落在合理区间，方向（`r` 越低越稳、`g` 越高）也正确。
- 建议：把上限明确为**常量 `longTermGDP = 4%`**（唯一定义在文档与代码常量表），`gk = min(longTermGDP, f(r))`；并保证 `g_term < r` 由构造保证（现有已保证，因 `r ≥ 9 > 4`）。

## 8. 参数的内在一致性约束

以下约束是**必须同时成立**的（可在 `RecommendValuation` 出口做统一校验，违反则不输出、退回降级档并给 `Warning`）：

| 编号 | 约束 | 说明 | 现状 |
| --- | --- | --- | --- |
| C1 | `r > g_term` | 戈登公式分母为正 | 已有（构造保证） |
| C2 | `g_term ≤ g(预测期末段) ≤ g1` | 增速递减路径 | 三阶段 `gk=4` 时 `g2=g3` 违反（P8） |
| C3 | `g_term ≤ 长期名义 GDP` | 永续不可超整体经济 | 隐含（4% 上限未显式化） |
| C4 | `g1 ≤ 可持续增长率 SGR`（或给出超限提示） | 企业自身无法支撑的增速不可用 | **缺失** |
| C5 | 高增长假设需 Capex/再投资支撑 | 高 `g` 而不扣扩张 Capex → 高估 | **缺失**（P2） |
| C6 | `FCF ≤ 净利润` 长期不显著背离 | FCF 不应长期远超净利润（会计现金含量） | **缺失**（可复用「净利润现金含量」） |
| C7 | 基期 FCF、`g`、`r` 三者口径同源 | 均基于最新年报 / 同一年度 | 部分（`r` 取 `latest`，FCF 取 `cfYears`） |

## 9. 行业 / 公司类型差异化

| 类型 | 基期 FCF | 折现率 r | 增长率 g | 模型 | 特别注意 |
| --- | --- | --- | --- | --- | --- |
| **周期股**（钢铁/煤炭/化工/航运/养殖） | 用**完整周期中枢**（`trim_mean`，`fcf_years` 取满） | 高（经营风险大，+2%~3%） | 用周期中枢增速，避免用景气高点 | 两阶段（周期内） | 必须识别景气位置，高点给高 r |
| **成长科技股**（高研发） | 研发扩张部分**加回**（`adjust_rd`） | 中高（股权成本高） | `g1` 高但受 SGR 约束、期限不宜过长 | 三阶段 | 高增长有 Capex 支撑吗？否则下调 |
| **高分红**（公用/银行外红利股） | 稳定，用 `latest`/`average` | 低（业务稳，r 可低） | 低（贴近 GDP） | 永续/零增长 | 留存率低 → SGR 低，`g` 应低 |
| **金融股**（银行/保险/券商） | 报表口径不同，**暂不支持** | — | — | 不适用 | 与 R3/R4 一致，明确提示不支持 |
| **亏损 / 负 FCF** | 无法构成可持续 FCF | — | — | 不适用 / 零增长 | 明确判「不适用」，不硬套 |

> 行业分类数据来源：本项目已有「主营构成」（`SegmentIncome`）与九维行业分析（AI），可用于**定性**标注行业，但**确定性参数不得依赖 AI 行业输出**（否则破坏可复现性）。建议维护一张**行业 → β / 风险溢价 / 默认年数**的常量表，由股票代码前缀或主营构成关键词确定性映射（可作为后续增强）。

## 10. 落地到本项目的 AI 参数推荐（确定性为主 + AI 为辅）

### 10.1 现有确定性规则总览（真实代码）

**`RecommendValuation`（模型/折现率/增长率）**

| 步骤 | 规则 |
| --- | --- |
| 基准增速 X% | 营收 / 重构净利润 / 经营现金流 各取最近 3 个「本年与上年均有年报且上年为正」年度的同比增速 → 合并取**中位数**；无样本则 X=0 |

| 折现率 | `riskPoints`（有息债务占比>40%、利息保障<3、财务杠杆 nil 或 >3）→ `{9,10,11,12}`；无资产负债表→10% |
| `g1` | `= clamp(round(volatile ? floor(X/2) : X), −5, 30)` |
| `gk`（永续） | `r≤9→4`；`r≤11→3`；`else→2` |
| `n1,n2` | `X<12→(5,3)`；`X<20→(6,3)`；`X<30→(8,4)`；`else→(10,5)` |
| 三阶段 `g2` | `min(4, gk+1)` |

**`RecommendBaseFCF`（基期 FCF 选取）**：R0 无数据→`latest`；R1 不足 3 年→`latest`；R2 全非正→`latest`；R3 最近一年≤0→`latest`；R4 全正+单调增+极差≤40+非 volatile+X≥0→`latest`；R5 最近一年明显偏高(>1.3×中位数)且不可持续→`custom`（= 正 FCF 中位数 ×(1+可持续增速)，取整到亿）；R6 单调不增→`latest`；R7 明显偏低(<0.7×中位数)→`median`；R8 增速波动大或 volatile→`median`；R9 兜底→`average`。

### 10.2 现有规则的具体不足与改进方向（可映射落点）

| # | 现状 | 不足 | 改进方向（确定性可落地） | 落点 |
| --- | --- | --- | --- | --- |
| G1 | `r` = 财务风险点→9/10/11/12 | 无 WACC 概念，区间窄，轻资产成长股 r 偏低 | 改为 **WACC 基线（复用 `wacc()`，股权成本改 `Rf+β×ERP` 常量）+ 风险溢价**，网格放宽到 [8,15] | `discountRateFor` / `valuationRiskPoints` |
| G2 | 股权成本硬编码 8% | 隐含 β=1、无规模溢价 | 常量表：`Rf`/`ERP`/行业 β；市值分档 | 新增常量 + `wacc()` 复用 |
| G3 | `X%` 用经营现金流增速 + 同比中位数 | 口径与 FCF 不一致、对首末年敏感、三项非等权 | ①改用 **FCF 增速**；②改用 **CAGR** 或「同比去极值后中位数」；③三项**显式等权** | `growthPoints` / `RecommendValuation` 第 2–3 步 |

### 10.3 架构建议：确定性规则为主 + 可选 AI 判断为辅

保持 R7 已拍板的**方案 A**（确定性推导为主，大模型只写理由）不变，在其上做三点增强：

1. **确定性层（主体，必须）**：新增/改进上述 G1~G11，全部为纯函数、常量表驱动，可单测。**参数值 100% 由此层产出。**
2. **AI 定性层（可选，受限）**：允许大模型在**既定区间内**给出一个「行业修正」建议（如 ±1% 折现率、±2% 增长率），但必须：
   - 只能落在确定性基线附近的**受约束邻域**；
   - 修正后仍过一致性校验（C1~C7）；
   - 作为**独立字段**返回并在前端标注「AI 修正」，**不覆盖**确定性基线，让用户可选择用哪个。
   - 这一步**不改变** R7 的「同股多次分析差值=0」——因为修正值受限、且可被前端固定选择策略忽略。
   - 若采纳，需把 R7 的「大模型不产出任何数值」例外地开一个口子，须由用户拍板（见待确认 Q7）。
3. **校验层（收口，必须）**：参数出口统一跑 C1~C7；任一违反 → 退回相邻更保守档 + `Warning`。

### 10.4 结构体 / 接口落点（仅指位置，不写代码）

- `model.ValuationRecommendation`（`internal/model/ai.go`）：已有 `Model`/`DiscountRate`/`Params`/`BaseGrowth`/`BaseGrowthNote`/`Volatile`/`RiskPoints`/`Warning`/`AdjustRD`/`RDRatio`/`FCF*`。建议新增只读字段承载「参数来源」（如基期是否为 WACC-FCF、生命周期档位、SGR 上限），便于前端解释与排查。

- `internal/service/valuation.go`：DCF 公式与参数校验（`dcfValue`）**不改**；若放宽折现率网格需同步前端 `el-input-number` 范围。
- `internal/service/ai.go`：`valuationPromptBlock` / `baseFCFPromptText` 需同步新增字段（如 WACC 基线、SGR 上限）供大模型写理由。

## 12. 待用户确认 / 拍板的问题

- **Q1 折现率 r 是否改为 WACC 基线？** 影响最大，决定 r 从「信用风险分档」变成「资本成本」。
  - **推荐**：是。复用项目已有 `wacc()`，股权成本改为 `Rf(2.5%) + β行业 × ERP(5.5%)` 常量表 + 风险溢价（0%~3%），网格放宽到 [8%, 15%]，四舍五入到 0.5%。理由：现状 8%~9% 对轻资产成长股偏低、12% 仍可能不足，且与分析模块的 WACC 指标口径割裂。
  - 备选：维持「财务风险分档」，仅把区间放宽到 [8%, 14%]，最小改动。
- **Q2 基准增速 X% 的口径是否调整？**
  - **推荐**：三项（营收/净利/**FCF**）同比增速在**去极值后取中位数**，或直接用 **3 年 CAGR**；三项**显式等权**。
  - 备选：维持现状（营收/净利/经营现金流的同比中位数）。
  - 影响：X% 是所有档位的输入，改动会改变全部推荐参数。
- **Q3 `fcf_years` 默认年数与上限？** 现默认 3 年。
  - **推荐**：默认按波动性动态给（平稳 3 年、强周期 5~7 年），上限从 5 提到 7~10（接口约可拉 10 个年报）。
  - 影响：周期股基期代表性；平稳公司几乎无影响。
- **Q4 模型分档是否从「单阈值」改为「多信号」？**
  - **推荐**：是。增速水平 + 增速稳定性 + ROE 水平三信号打分落档，并把 `X<3%` 归零增长（现归永续）。
  - 影响：模型选择结果会变；但消除 `19.9% vs 20.1%` 的边界抖动。
- **Q5 是否引入一致性校验层（C4~C6：SGR 上限、Capex 与 g 匹配、FCF 与净利润关系）？**
  - **推荐**：引入。违反则降级 + `Warning` 提示，不静默输出。
  - 影响：部分公司推荐会更保守（这通常正是用户想要的「更合理」）。
  - 依赖：ΔNWC / 购建资产现金流出字段需实测确认（沙箱可 curl 东财接口实测，不写代码即可核对）。
- **Q6 金融股 / 负 FCF / 亏损公司如何处置？**
  - **推荐**：明确判「现金流贴现法不适用」并提示，不硬套模型（与 R3/R4 现状一致，仅强化出口）。
- **Q7 是否在确定性基线之外，开放一个受约束的「AI 定性修正」层？**
  - **推荐**：暂不开放（保持 R7 的「大模型不产出任何数值」纪律最省心）；如确需行业判断，再单独评审，且修正必须受限区间、独立字段、不覆盖基线。
  - 影响：开放会削弱「同股多次分析差值=0」的保证，需谨慎。
- **Q8 无风险利率 / ERP / 行业 β 常量表的取值与维护方式？**
  - **推荐**：`Rf=2.5%`、`ERP=5.5%`、`β` 分行业常量表（初始可用「周期性 1.2 / 一般 1.0 / 公用事业 0.8」三档起步，后续细化）；随版本手动更新，写入文档并注明生效日期。
  - 影响：决定 WACC 基线的绝对值。
- **Q9 是否新增数据源以支持 β / 无风险利率的实时测算？**
  - **推荐**：暂不新增（会破坏「免费接口 + 三张表」的轻量定位与确定性）。用常量表替代。
  - 备选：接入指数/国债收益率数据源（需评估接口稳定性，且破坏纯确定性）。

## 13. 已确认决策补充（用户，2026-10-16）

本节**追加**记录用户在技术设计评审中对 β 档位方案的两条决策，**不修改上文任何原有内容**；与之对应的落地方案见 `技术设计文档.md` 的 §19.12（β 三档：AI 行业分类 → 确定性映射）与 §19.3 / §19.5.5。

### 13.1 β 三档改由「AI 行业分类（定性）→ 常量表（数值）」确定

- **用户决策**：**行业类型判断是「定性分类」，不是「AI 产出数值」，应交给 AI 判断**，从而让 β 三档全部生效。具体为：AI 在分析结果中输出一个**固定枚举**「行业类型」（周期性 / 一般 / 公用事业，三选一），后端用**确定性常量表**把该枚举映射为 β（周期 1.2 / 一般 1.0 / 公用 0.8）。
- **配套约束**：
  - **AI 只产出分类、不产出数值**——这是对 §10.3「确定性规则为主」与项目既有 R7 纪律的**精确化**（AI 的产出物是被硬约束为 3 个取值的定性枚举，数值一律由后端常量表确定性映射），**不是**放开 Q7 所指的「AI 数值修正层」。
  - **回落规则**：AI 未给出合法枚举 / 分类缺失 / 不确定时，一律回落「一般型」（β=1.0）。
  - **`volatile` 波动信号保留作为兜底**（作为 β 下限或 AI 缺省时的次要信号，具体优先级由技术设计确定，但必须确定性、可复现）。
- **须知悉的代价**：R7 的「同股多次分析参数完全相同」由「无条件成立」变为「给定相同行业分类时成立」；因枚举空间有界，参数方差被限定在至多 2 个离散档位，且分类缺失时回落路径完全确定。

### 13.2 AI 分析结果新增「行业类型」展示

- **决策**：把公司所属**行业类型**作为**结构化字段**在 AI 分析结果中展示（而不仅是文字描述）。
- **落点**：AI 分析结果的「估值模型推荐」区，与既有的折现率构成（WACC 基线 / 风险溢价 / β）一并呈现——展示**行业类型中文名**与**对应的 β 档位标签**，让用户看清「折现率里的 β 是怎么来的」。
- **实现口径**：该字段由大模型输出（原始串）、经后端枚举归一化后确定性回填到响应；前端沿用现有 AI 分析响应 → 渲染链路读取，**不新增请求**。

## 14. 后续修订：R18 增长率估算重构（2026-10-17）

> 本节只作索引，不修改上文 P1~P5 的方法论与已实现口径。增长率子模块的修订需求见
> [`docs/R18-估值增长率估算重构/需求文档.md`](../R18-估值增长率估算重构/需求文档.md)。

- **背景**：用户反馈增长率估算「偏向极端保守」。根因是纯向后看、无周期位置意识、SGR 硬上限 + 连续折减 + 模型降级三重压制。
- **R18 的替代范围**（与本文件冲突处以 R18 为准）：
  - §5.1 SGR 作为 `g1` 硬上限 → 改为「SGR 只约束终值 + `g1` 软上限」；
  - §10.2 G4 中 `g1 = min(X, SGR上限, 行业增速上限)` 的 SGR 硬上限部分；
  - §10.1 中 `g1 = clamp(round(...))` 的整数网格 → 改为 0.5pp 网格；
  - §8 C4「`g1 ≤ SGR`」→ 拆为 C4a（终值硬约束）/ C4b（g1 软告警）/ C4c（出口复核）；
  - 终值 `gk = min(4%, f(r))` / `f(r) ∈ {4,3,2}` 的折现率反相关映射 → 改为动态名义 GDP 锚定 `g∞ = min(G_GDP, r−1.0pp, SGR)`；
  - 模型分档 `X≥12 / X≥6 / X<3→zero` 硬闸门 → 改为 `A_norm` + `gap`，负增长先区分结构性衰退（归零）与周期低谷（低永续）。
- **R18 保留不变**：WACC 基线 / β 三档、基期 FCF 选取、研发调整、C1~C3 / C5~C7、R7 确定性纪律（在「同一外部快照」口径下）。
- **新增结构**：历史锚 + 前瞻锚（东财一致预期）+ 宏观锚（动态名义 GDP）→ 复合锚 A；周期位置修正；均值回归路径（缺口决定回归年限）；负增长归因。

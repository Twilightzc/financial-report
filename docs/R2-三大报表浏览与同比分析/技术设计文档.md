# R2 技术方案：三大报表浏览与同比分析

> 对应《产品设计文档》第 6 节。在 R1 基础上新增：三张报表全科目展示、年份范围筛选（仅年报）、同比上年增长率，与 R1 共用页面。

### 6.1 总体思路

- **全科目**采用「白名单字典」方案：维护三张表的「字段 key → 中文名」映射表，仅展示映射表中的科目，天然排除接口返回的元数据（代码/名称/报告期等）与派生字段（`*_RATIO`、`*_YOY` 等）。
- **年份范围**由前端传入 `startYear`/`endYear`，后端只返回范围内年报（报告期以 `12-31` 结尾）。
- **同比**在前端计算（纯展示逻辑，含红涨绿跌着色），后端只返回各年原始数值，保持后端轻量。

### 6.2 数据模型（internal/model/financial.go 新增）

```go
// FieldDef 科目字典条目：字段 key → 中文名
type FieldDef struct {
    Key  string
    Name string
}

// ReportRow 单期报表原始行（数值字段，nil=无数据）
type ReportRow struct {
    ReportDate string
    Fields     map[string]*float64
}

// StatementItem 单个科目的跨年度数值（与 Statement.Years 对齐，nil=无数据）
type StatementItem struct {
    Field  string     `json:"field"`
    Name   string     `json:"name"`
    Values []*float64 `json:"values"`
}

// Statement 单张报表：年份正序 + 全科目
type Statement struct {
    Years []int           `json:"years"`
    Items []StatementItem `json:"items"`
}

// Financials 三张表聚合返回
type Financials struct {
    Balance  Statement `json:"balance"`
    Income   Statement `json:"income"`
    Cashflow Statement `json:"cashflow"`
}
```

### 6.4 client 层（internal/client/eastmoney.go 新增）

- 新增 `FetchRawFinancial(reportName, code string, pageSize int) ([]model.ReportRow, error)`：
  - 复用现有 `fetchFinancial`（`columns=ALL`）取原始行；
  - 将每行剔除非数值字段，仅保留数值字段并 `toFloat` 归一为 `Fields map[string]float64`。
- 现有三个 `FetchXxx`（R1 用）保持不变，R2 走 `FetchRawFinancial`。

### 6.5 service 层（internal/service/statement.go 新增）

纯函数、无 IO：

```go
func BuildStatement(rows []model.ReportRow, fields []model.FieldDef, startYear, endYear int) model.Statement
```

逻辑：
1. 过滤：仅保留年报（`ReportDate` 以 `12-31` 结尾）且年份在 `[startYear, endYear]`。
2. 年份去重、升序，生成 `Years`。
3. 按 `fields` 顺序，为每个科目生成与 `Years` 对齐的 `Values`（缺失年份/无数据科目值为 `nil`，前端显示「—」）。
4. 返回 `Statement`。

### 6.6 API 设计（internal/api）

新增路由：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/stock/:code/financials?startYear=2020&endYear=2024` | 返回三张表全科目（范围内年报） |

- 参数：`startYear`、`endYear` 为可选 4 位年份；缺省时后端取「最近 5 个年报」。
- handler `GetFinancials`：
  1. 校验 `code`（6 位）。
  2. 解析/兜底年份范围（缺省 = 数据中最近 5 个年报）。
  3. 分别 `FetchRawFinancial`（`pageSize=40`，约覆盖 10 个年报）取三张表。
  4. 调用 `service.BuildStatement` 组装 `model.Financials`。
  5. 返回统一结构 `{code, data, message}`。
- 边界：范围内无年报 → 返回 `code:0` 且 `years`/`items` 为空，前端提示「所选年份范围无数据」。

响应示例：

```json
{
  "code": 0, "message": "ok",
  "data": {
    "balance": {
      "years": [2020, 2021, 2022, 2023, 2024],
      "items": [
        {"field": "TOTAL_ASSETS", "name": "资产总计", "values": [213395000000, 234500000000, 0, 0, 0]}
      ]
    },
    "income": { "years": [], "items": [] },
    "cashflow": { "years": [], "items": [] }
  }
}
```

### 6.7 前端设计（internal/web/app.js）

- 与 R1 共用页面：顶部搜索框 → R1 指标区 → R2 三大报表区。
- 查询时并行请求 `/indicators` 与 `/financials`。
- **Tab 切换**：`el-tabs` 三个页签（资产负债表 / 利润表 / 现金流量表）。
- **年份筛选**：两个 `el-select`（起始年/结束年）；选项由返回 `years` 生成，默认最近 5 年；变更后重新请求 `/financials`。
- **表格**：行 = 科目，列 = 年份；每格展示「数值（亿元）+ 下方同比（红涨绿跌）」。
- 数值统一 `÷1e8` 显示为亿元。

### 6.8 同比计算与展示规则

- 公式：`(当年 − 上年) / 上年 × 100%`。
- 展示：每年数值下方标注同比；红涨（`#f56c6c`）绿跌（`#67c23a`），复用现有 `style.css`。
- 边界：
  - 当年或上年无数据（`null`，如非金融股的银行专属科目）→ 数值显示「—」、同比显示「—」。
  - 上年 = 0 → 显示「—」。
  - 上年 < 0 → 增长率符号失真，仅显示数值、不显示百分比。
  - 范围内最早年份 → 无上年，显示「—」。

### 6.9 字段中文名映射（一次性实测步骤）

R2 主要工作量在敲定三张表的全科目中文映射。步骤：

1. 对样例股票（如 600519）调用 datacenter 三张表接口（`columns=ALL`）。
2. 导出返回字段清单。
3. 逐字段区分：财务科目（保留，补中文名）／元数据（排除）／派生比例与同比（排除）。
4. 写入 `model/fields.go` 三张白名单。

### 6.10 边界与验收对照

| 产品验收 | 技术实现 |
| --- | --- |
| 三张表全科目展示 | 白名单字典 + `BuildStatement` |
| 年份范围筛选 | `startYear`/`endYear` + 年报过滤 |
| 同比正确 | 前端相邻年计算，规则见 6.8 |
| 边界不报错 | 上期 0/负、缺年份 → 「—」/仅数值/空提示 |

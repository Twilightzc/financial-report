### A. SGR 多年平滑 —— 通过

- 5 年有效：ROE 20/22/18/25/15、留存率 0.5/0.6/0.4/0.5/0.5 → SGR = 20.0% × 0.5 = 10.0%，窗口 5、`basis=payout`（AC-1）。
- 单年异常摊薄：2024 ROE 15→60 时平滑 SGR +4.5pp，单年口径 +22.5pp，比例 1/5（AC-2）。
- 3 年 / 4 年使用实际年度（窗口 3/4）；6 个候选年只取最近 5 年（2019 与 2025 均不纳入，SGR 复算为 5.0）。
- 不足 3 年回落单年：窗口记 1、警告含「按最近一年计算」；回落仍不可用 → 窗口 0、`basis=unavailable`、`ok=false`。
- 基期年亏损但历史 3 个有效年 → 继续平滑（窗口 3、SGR 10.0），不标记不可用（AC-4）。
- 聚合方式确认为「平均 ROE × 平均留存率」：构造 ROE 10/20/30、留存率 1/0.5/0 的样本，SGR=10.0，而非逐年 SGR 平均的 6.667。
- ROE 与留存率共用同一有效年度集合：仅 ROE 可算、留存率不可算的年度被整体剔除（窗口 3 而非 4）。
- `retention_basis` 正确区分 `payout` / `equity_growth` / `mixed` / `unavailable`。

### B. 稳定度推导 —— 通过（手算复算）

- `stability = 1 − min(0.8, c)`；`c = 0.50×行业 + 0.30×FCF + 0.20×盈利周期`。
- 行业分量：cyclical 0.85 / general 0.15 / utility 0.05 / 缺失 0.30。
- FCF 分量：CV 0.15→0、0.375→0.5、0.60→1；不可评估按缺失；符号翻转 ≥2 → `max(c, 0.80)`（CV=0 时为 0.80）。
- 盈利周期分量：极差 3→0、9→0.5、15→1；`profitCycle` 命中且极差 4 时为 0.80；样本不足按缺失。
- 权重归一化：general + FCF 0.5、盈利缺失 → `c = 0.225/0.80 = 0.28125`；仅行业 general → 0.15；全缺失 → 0.30（稳定度 0.70）。
- 成长性否决且非 cyclical → `c ≤ 0.15`（稳定度 0.85，g∞ 4.0）；`industry_type=cyclical` 时否决不覆盖（深度周期仍 0.20）。
- 封顶：cyclical + CV 0.8 + 盈利命中 → `c_raw=0.885` → 封顶 0.80 → 稳定度 0.20。

### C. 终值连续化 —— 通过（手算复算）

- 公式 `cap = 2% + (宏观锚 − 2%) × stability`、`g∞ = max(0, floorHalf(min(cap, r−1pp, SGR)))` 与代码一致。
- 深度周期 stability 0.20 → cap 2.50% → g∞ 2.5%；稳定消费 0.925 → cap 4.3125% → 4.0%；中间态 0.7417 → cap 3.854% → 3.5%；stability 0.9 → 4.25% → 4.0%。
- 宏观锚 < 2%（1.0%）+ stability 0.5 → cap 1.5%，不抬高。
- 硬约束不放松：SGR 1.8（cap 4.31）→ 1.5 且约束 `sgr`；r=3.0（r−1=2.0）→ 2.0 且约束 `discount`。
- 并列：三约束同为 3.5% → 主约束 `sgr`，依据句含「与折现率−1pp、稳定度 0.60 对应的长期上限相同。」；无 SGR 时 discount/stability 并列 → 主约束 `discount`。
- 依据句洁净：stability / sgr（近 N 年、按最近一年）/ discount / zero 四个分支均不含 `cap`、`stability`、`macro`、`sgr`；稳定度上限未生效时不出现「稳定度」；稳定度句使用最终 g∞ 数值。
- `gRaw ∈ (0, 0.5)` 时向下取整为 0 且非负（沿用 R20 行为，见遗留风险）。
- `r20CyclicalTerminalPP` 全仓无引用（`grep` 为空）。

## 4. 遗留问题与风险

1. **`0 < gRaw < 0.5` 的零值文案**：例如 SGR=0.3% 时 `g∞=0` 但 `terminal_constraint=sgr`、依据句为「终值受长期内生增速 0.3%（近 5 年平均）约束。」，未使用「终值按 0。」。这是 R20 起既有行为（`gRaw<=0` 才进入 zero 分支），R22 未改动；数值本身正确，仅与需求 FR-3「g∞ 取 0 时沿用『终值按 0』」的字面存在解释空间。影响低，未作为缺陷回传；如需严格对齐可另开小修。
2. **稳定度权重/阈值为初始校准值**，未做样本回归（需求已列为已知限制）；本次只验证映射与边界，不代表长期最优。
3. **端到端为合成 fixture**：R22 计算全部在 `service` 纯函数层、无新增 IO/AI/网络请求；未启动服务走真实行情。沙箱网络受限，未做在线数据端到端验证。
4. **移动端 375px**：本次无前端结构改动，`terminal_note` 复用既有渲染位；未做浏览器实测。
5. **平滑忽略 ROE 与留存率协方差**（平均乘积 ≠ 乘积平均），对强负相关公司可能略高估，需求已确认为可接受近似。

# 估值参数平滑与终值连续化

> 需求编号：R22
> 状态：需求分析完成，待用户确认「待确认问题」后进入技术设计
> 修订关系：本文档只修订 R19/R20/R21 中的两条口径——**SGR 的多年平滑**与**终值增长率上限的连续化**。R19、R20、R21 的其余全部口径继续有效；冲突时以本文档对这两条的修订为准，其余以 R19/R20/R21 为准。

## 1. 背景与目标

### 1.1 背景

R19 已完成估值参数重构：取消保守/基准/乐观三档，只输出单一「适中基准」参数，并统一了 WACC/CAPM、复合锚 A、Capex 覆盖率、FCF/净利润、风险溢价等口径。R20 把 g1 收口到 SGR + 1pp，并把周期/商品股终值上限压到长期通胀。R21 把周期股终值上限由 2.0% 调整为 2.5%，并新增公司估值敏感性矩阵。此后「g1 上限重纳前瞻锚 `min(30%, max(前瞻锚, SGR) + 1pp)`」与「AI 参数自动应用」也已落地。

用户反馈：终值选取「有时候偏乐观，有时候偏保守」，希望更「适中」。经确认，问题不是某一个常量取高了或取低了，而是两条口径的**摆动**：

1. **SGR 用单年数据，单年噪声会硬传导到 g1 与终值**。某一年 ROE 偏高/偏低、留存率因分红节奏或权益变动异常，都会让 SGR 大幅跳动；SGR 又同时参与 g1 上限与终值上限，于是同一家公司换一年基期就可能得到明显不同的 g1 与 g∞。
2. **终值上限是「周期 2.5% / 非周期 GDP 约 4.5%」的硬二分**。判定信号轻微变化（AI 行业分类改变、FCF 变异系数跨过阈值、盈利周期命中/不命中）就会让终值上限跳变约 2pp；在永续乘数 `1 ÷ (r − g∞)` 下，2pp 的跳变会被放大成估值结果的明显摆动。

用户已拍板两条一起做：**平滑 SGR** 与 **终值连续化**。

### 1.2 现状与根因（已核对代码与文档）

**现状代码事实**：

- **SGR**：`internal/service/growth.go` 的 `sustainableGrowthR18` 按**基期单年**计算 `SGR = 单年 ROE × 单年留存率`。
  - ROE 分子优先取归母净利润 `PARENT_NETPROFIT`，缺失/非正时回落重构净利润；分母取 `TOTAL_EQUITY`。
  - 留存率优先现金分红口径 `1 − 现金分红 ÷ 净利润`，否则用权益增长口径 `(期末权益 − 期初权益) ÷ 净利润`，均 clamp 到 [0,1]。
  - SGR 同时用于 `growthG1` 的上限与 `terminalGrowth` 的终值上限。
- **终值**：`terminalGrowth` 为二元口径——`isCyclical=true` 时 `g∞ = max(0, floor0.5(min(2.5%, r − 1pp, SGR)))`；否则 `g∞ = max(0, floor0.5(min(宏观锚, r − 1pp, SGR)))`。宏观锚为动态 GDP TTM 同比，不可用时 4.5%。
- **周期判定**：`detectCyclical` 返回二元 `isCyclical`，优先级为「AI 行业分类 `industry_type=cyclical` → 成长性否决 → FCF 强周期（变异系数/符号翻转）→ 盈利周期」；同一结果还用于 β 档位、周期位置修正与负增长归因。
- **g1 上限**：`growthG1` 使用 `capG1 = min(30%, max(前瞻锚, SGR) + 1pp)`，前瞻锚仍参与取较高者；本次只替换其中的 SGR 口径，不改该结构。

**根因**：

1. **单年 SGR 噪声硬传导**。SGR 是 g1 上限与终值上限的共同输入，单年 ROE 或留存率的异常会直接改变这两个参数。尤其留存率的权益增长口径对增发、回购、少数股东权益变动、会计重述都很敏感，单年值可能在 0 与 1 之间跳变。
2. **终值硬二分造成 2pp 跳变**。周期与非周期使用两套上限，判定是二元的；判定边界附近的公司会因一个信号跨阈值而得到完全不同的终值。连续化后，终值上限应随「经营稳定度」平滑变化，而不是在两个点之间切换。
3. **两条摆动叠加**。SGR 低时终值受 SGR 约束、SGR 高时终值受上限约束，约束项切换本身也会造成结果不连续；SGR 平滑后，约束切换的频率和幅度都会下降。

### 1.3 目标

- **G1 SGR 更稳定**：SGR 改用**多年平均 ROE × 多年平均留存率**（默认 5 年窗口，至少 3 个有效年度），替代单年口径；单年异常不再主导 SGR。
- **G2 终值连续化**：取消「周期 2.5% / 非周期 GDP」硬二分，改为由现有周期判定信号推导连续稳定度 `stability ∈ [0.2, 1.0]`，终值上限 `cap = 2% + (宏观锚 − 2%) × stability`；深度周期约 2.5%，稳定消费股约 4.2%（按 0.5pp 网格输出约 4.0%），中间态约 3.5%。
- **G3 约束不放松**：终值仍取 `g∞ = max(0, floor0.5(min(cap, r − 1pp, SGR)))`；SGR 与 `r − 1pp` 仍是硬约束，稳定度只决定上限，不得绕过两者。
- **G4 可复算、输出洁净**：用户能凭「近 N 年平均」、稳定度与终值三个数字手工复算；不新增推导表、公式行、阈值表或内部变量名。
- **G5 不回归**：FCF 口径、WACC/CAPM、复合锚 A、模型分类与降级链、n1 规则、敏感性矩阵结构、单一适中基准、三档已废除等均不变。

可衡量的达成标准：

- 任一有 5 个有效年度的公司，单年 ROE 或留存率异常对平滑 SGR 的影响不超过其单年口径影响的 1/5（按算术平均权重）。
- 任一公司的终值上限由稳定度连续决定；在宏观锚 4.5% 下，稳定度 0.2 / 0.6 / 0.9 分别对应上限约 2.5% / 3.5% / 4.25%，最终按 0.5pp 网格向下取整。
- 任一公司仍满足 `g∞ ≤ r − 1pp`、`g∞ ≤ SGR`（SGR 可用时）、`g∞ ≥ 0`。
- 同一输入多次调用结果完全一致；不新增任何取数请求或 AI 调用。

### 1.4 非目标

- **不改 FCF 口径**：基期自由现金流仍为「经营活动现金流量净额 − 保全性资本支出」，五种基期 FCF 选取方式与研发扩张加回不变。
- **不改 WACC/CAPM**：β 档位、股权风险溢价、公司特定风险溢价、市值权重、折现率取整与区间约束不变。
- **不改复合锚 A**：历史锚、前瞻锚、宏观锚的构成、权重、周期位置修正、取整与区间约束不变；前瞻锚的噪声不在本次处理范围。
- **不改模型分类与 n1**：`gap = A − g∞` 的定义、模型分类阈值、三级降级链、`n1 = clamp(round((g1 − g∞)/1.5), 3, 10)` 不变。因 g∞ 变化导致模型升级/降级属于规则内结果，不做额外抑制。
- **不改敏感性矩阵结构**：仍为 5 行 × 3 列，行 = 终值增长率基准 ±1pp，列 = 折现率基准 ±0.5pp；中心值自动使用新的 g∞，表结构、交互与展示不变。
- **不恢复三档情景**：不新增保守/乐观/基准档，不做概率加权、带宽或情景叙事。
- **不新增数据源**：不接动态通胀、不新增行业关键词表、不新增 AI 调用；稳定度只用链路中已有的 `industry_type`、FCF 序列、盈利周期信号。
- **不改 2% 通胀常量与 4.5% GDP 兜底**：2% 为固定长期通胀假设；宏观锚仍为动态 GDP TTM，不可用时 4.5%。
- **不改输出洁净原则**：不新增推导表、公式行、内部字段名、函数名、规则元语言或工具说明。

## 2. 用户故事 / 使用场景

- 作为使用 AI 估值参数的投资者，我希望 SGR 用最近几年的平均水平而不是某一年的数据，以便换一个基期年份时 g1 和终值不会大幅跳动。
- 作为分析周期股的投资者，我希望终值上限随公司的周期性强弱平滑变化，而不是因为一个判定信号跨过阈值就从 2.5% 跳到 4.5%，以便估值结果不会「一会儿偏乐观、一会儿偏保守」。
- 作为核对参数的投资者，我希望看到「近 5 年平均」「稳定度 0.20」「终值上限 2.5%」这类可复算的数字，以便判断参数是怎么来的，而不用面对推导表或工具话术。

## 3. 功能需求

### FR-1 SGR 改为多年平滑（P0）

**触发**：每次生成 AI 估值参数、计算 SGR 时。

**窗口与样本**：

- 默认窗口为**最近 5 个年度**（含基期年），只取年报（报告期以 `12-31` 结尾），与现有增长窗口 `valGrowthWindowYears = 5` 保持一致。
- 候选年度 = 资产负债表与利润表均有数据的年度，且 `≤ 基期年`，按年升序取最近 5 个。
- 一个年度为**有效年度**，当且仅当：股东权益 > 0、净利润 > 0、且该年度留存率可计算（分红口径或权益增长口径至少一种可用）。
- 有效年度数至少 **3 个**才启用平滑；有效年度为 3 或 4 个时使用实际可用年度；不足 3 个时按本节「缺失、非正与回落」规则回落单年。

**单年口径不变**（只改聚合方式，不改分子分母）：

- `ROE_t = 净利润_t ÷ 股东权益_t × 100`。净利润优先取 `PARENT_NETPROFIT`；缺失或非正时回落重构净利润并标注「归母净利润缺失或非正，ROE 与留存率按重构净利润近似」。
- 留存率 `ret_t`：
  - 优先现金分红口径：`ret_t = clamp(1 − 该年度现金分红 ÷ 净利润_t, 0, 1)`；分红超过净利润时留存率按 0 计并标注。
  - 否则权益增长口径：`ret_t = clamp((权益_t − 权益_{t−1}) ÷ 净利润_t, 0, 1)`；要求权益_t、权益_{t−1} 均 > 0。
  - 单年口径、clamp 区间与分母选择均沿用现有 `sustainableGrowthR18` / `retentionRate`，本次不修改。
- 有效年度集合对 ROE 与留存率**使用同一年度集合**：某年度只有 ROE 可算、留存率不可算时，该年度整体不计入，避免两个平均值样本不一致。

**聚合方式（推荐并默认）**：

```
ROE_avg = 有效年度 ROE_t 的算术平均
ret_avg = 有效年度 ret_t 的算术平均
SGR     = ROE_avg × ret_avg
```

- 选择「平均 ROE × 平均留存率」而不是「逐年 SGR 再平均」，理由：
  1. 与用户已定方向一致，口径可直接表述为「近 5 年平均 ROE × 近 5 年平均留存率」。
  2. 两个经济驱动因素分别平滑；单年留存率被 clamp 到 0 或 1 的极端值不会以乘积形式放大。
  3. 逐年 SGR 再平均仍会保留单年「低净利润 + 高留存率」的乘积噪声，平滑效果较弱。
- 已知近似：乘积的平均不等于平均的乘积，忽略了两者的协方差；对 ROE 与留存率强负相关的公司可能略有高估。该影响为二阶，作为单一适中基准可接受；若用户要求更严格，可按 Q2 改为逐年 SGR 再平均。

**缺失、非正与回落**：

- 净利润 ≤ 0、股东权益 ≤ 0、留存率不可计算的年度**不计入平均值**，但不因此直接让整个 SGR 不可用；只要窗口内仍有 ≥3 个有效年度，就用有效年度计算。
- 基期年净利润 ≤ 0 时，基期年不计入；若此前仍有 ≥3 个有效年度，SGR 仍按这些年度平滑计算。这是相对单年口径的有意变化，用于避免周期低谷年直接把 SGR 打成不可用。
- 有效年度不足 3 个时，**回落到现有单年口径**：用基期年按 `sustainableGrowthR18` 计算；基期年也不可用时，SGR 标记为不可用，终值不施加 SGR 约束。
- 回落时输出「可用年度不足 3 年，自筹资金可持续增速按最近一年计算」类说明；该说明只在回落发生时出现，不逐家公司输出。
- 平滑 SGR 的取值范围为 `SGR ≥ 0`（因为只纳入净利润 > 0 的年度）；留存率平均值为 0 时 SGR 为 0，沿用现有「SGR 为 0 → g∞=0、g1 ≤ 1pp」的处理。
- 不对单年 ROE 做额外 winsorize；单年 ROE 的极端值仍可能通过平均值产生影响，但权重被窗口年数摊薄。这是本次有意保留的简化。

**输出与口径**：

- `sgr` 字段的语义由「基期单年 SGR」变为「近 N 年平均 SGR」，字段名不变；`retention_rate` 同理为平均留存率。
- 新增可选字段 `sgr_window_years`（整数，实际使用的有效年度数；回落时为 1），用于复算与展示「近 N 年平均」。
- `retention_basis` 取值扩展：有效年度全部用分红口径为 `payout`，全部用权益增长口径为 `equity_growth`，两者混用为 `mixed`，不可用为 `unavailable`。
- 现有「`sgr` / `retention_rate` 只在终值受 SGR 约束时输出」的洁净规则不变；g1 受 SGR 约束时，依据句中带出平滑 SGR 数值与窗口年数。
- 平滑 SGR 同时供 `growthG1` 与 `terminalGrowth` 使用，二者必须使用同一个值，不得一处单年、一处多年。

### FR-2 稳定度连续映射（P0）

**触发**：每次生成 AI 估值参数、计算终值时，与 SGR 同一处计算一次。

**输入与复用原则**：

- 稳定度只使用链路中**已经计算**的信号：归一化后的 `industry_type`、FCF 周期结果（变异系数 CV、符号翻转次数）、盈利周期结果（毛利率极差、`profitCycle` 布尔值）、成长性否决 `gp.Veto`。
- 不新增第二套周期判定，不重新拉取 FCF/利润表，不调用 `detectCyclical` 之外的判定逻辑。`detectCyclical` 的二元 `isCyclical` 继续用于 β 档位、周期位置修正与负增长归因；稳定度是**新增的连续量**，不替代、不修改 `isCyclical`。
- 允许 `isCyclical` 与稳定度不完全一致：二元判定回答「是否按周期股处理其他参数」，稳定度回答「终值上限应该有多高」。两者使用同一组输入，但不强行对齐。

**原始周期强度 `c_raw ∈ [0,1]`**（越高越不稳定；最终 `c = min(0.8, c_raw)`）：

| 分量 | 取值 | 权重 |
|---|---|---|
| 行业分量 `c_industry` | `cyclical=0.85`；`general=0.15`；`utility=0.05`；缺失=0.30 | 0.50 |
| FCF 分量 `c_fcf` | CV ≤ 0.15 → 0；CV ≥ 0.60 → 1；中间线性 `(CV−0.15)/(0.60−0.15)`；符号翻转 ≥2 次时取 `max(c_fcf, 0.80)` | 0.30 |
| 盈利周期分量 `c_profit` | 毛利率极差 ≤3pp → 0；≥15pp → 1；中间线性 `(极差−3)/12`；`profitCycle=true` 时取 `max(c_profit, 0.80)` | 0.20 |

- **成长性否决覆盖**：若 `gp.Veto=true` 且归一化行业类型不是 `cyclical`，则 `c = min(c, 0.15)`，对应稳定度 ≥0.85、终值上限 ≥4.1%（按 0.5pp 网格约 4.0%）。理由：成长性否决已经表示公司不是周期型，不应再因 FCF 波动被压低终值。若 `industry_type=cyclical`，按现有优先级，AI 行业分类优先，否决不覆盖稳定度。
- **权重归一化**：FCF 分量不可评估（年度不足 3 年或 FCF 均值 ≤0）时，剔除该分量并对剩余权重归一化；盈利周期分量无有效毛利率样本时同理。行业分量始终存在（缺失按 0.30）。
- **全部量化信号缺失**：仅行业分量可用。行业缺失时 `c=0.30`，稳定度 0.70，终值上限约 3.75%，按网格约 3.5%，作为「中间态」兜底。
- **不引入随机、时间或 AI 参与**：阈值与权重为固定常量，同一输入结果完全一致。

**稳定度**：

```
c         = min(0.8, 加权平均周期强度)   // 上限 0.8，对应深度周期
stability = 1 − c                        // 取值域 [0.2, 1.0]
```

- `c=0` → 稳定度 1.0；`c=0.5` → 稳定度 0.5；`c=0.8` → 稳定度 0.2。
- `c` 上限 0.8 对应「深度周期」锚点：在宏观锚 4.5% 下，`cap = 2% + 2.5% × 0.2 = 2.5%`，与 R21 的周期股基准衔接。该下限是映射结果，不是额外的硬编码终值下限；若未来认为深度周期还需更低终值，应另行确认是否放宽 `c` 的上限或增加终值下限。
- `industry_type=cyclical` 只提高行业分量，不直接锁定 2.5%；只有同时命中高 FCF 波动/盈利周期时，稳定度才会接近 0.2。仅有周期行业标签而财务信号平稳的公司，稳定度会高于 0.2，终值也会高于 2.5%，这是连续化的预期行为。

### FR-3 终值上限连续化（P0）

**公式**：

```
cap = 2.0% + (宏观锚 − 2.0%) × stability
g∞  = max(0, floor0.5(min(cap, r − 1.0pp, SGR)))
```

- `宏观锚` 仍为动态 GDP TTM 同比（不可用时 4.5%）；`2.0%` 为固定长期通胀假设。
- `cap` 在 `[2%, 宏观锚]` 之间连续取值；当前宏观锚 4.5% 时，稳定度 0.2 / 0.6 / 0.9 分别对应 `cap` 约 2.5% / 3.5% / 4.25%。
- 最终 `g∞` 仍按 **0.5pp 网格向下取整**。连续化体现在 `cap` 的计算与 `2.5%–4.5%` 之间多档可取值（如 3.0%、3.5%、4.0%），最终输出不是连续小数。这是为了保持 R19/R20 的可复算性、g1 网格与敏感性矩阵结构。
- 若宏观锚 < 2%，`cap` 会低于 2%，公式仍成立（在宏观锚与 2% 之间插值），不另行抬高。
- SGR 可用时仍作为上限参与取 min；SGR 不可用时只受 `cap` 与 `r − 1.0pp` 约束。
- `r − 1.0pp ≤ 0` 时 `g∞ = 0`，不得为负。
- 该上限作用于最终永续段：永续模型的 g、两阶段的 g2、三阶段的 g3；三阶段中间段 g2 的构造规则不变。

**约束与生效判定**：

- 保持 R20/R21 的约束优先级：SGR > 折现率−1pp > 稳定度上限；并列时按现有方式注明并列项。
- `terminal_constraint` 新增枚举值 `stability`：当稳定度上限是真正生效的最小约束时返回 `stability`。
- 新计算不再返回 `cyclical` 或 `macro` 作为终值约束；`cyclical` / `macro` 仅作为历史快照的兼容值保留，前端与 API 不得因旧值报错。
- `terminal_stability` 新增可选字段（0–1，保留 2 位小数），无论稳定度上限是否生效都输出，便于复算与展示。
- 稳定度上限未生效（SGR 或 `r−1pp` 更低）时，不得写成「受稳定度约束」，仍只显示真正生效的约束项。

**依据句（输出洁净）**：

- 稳定度上限生效时：
  - 「终值增长率按稳定度 0.20 对应的长期上限 2.5% 封顶。」
  - 或等价表述，必须同时包含稳定度数值与最终终值数值，不使用 `cap`、`stability`、`macro` 等内部键名。
- SGR 生效时：
  - 「终值受长期内生增速 10.0%（近 5 年平均）约束。」
- 折现率−1pp 生效时：沿用现有「终值受折现率−1pp 约束」类文案，可带最终值。
- `g∞` 取 0 时：沿用「终值按 0。」。
- 约束并列时：沿用现有并列说明方式，不新增公式行或约束表。
- 回落单年 SGR 时：依据句写「按最近一年」，不得写「近 5 年平均」。

**示例（宏观锚 4.5%）**：

| 情形 | 周期强度 c | 稳定度 | cap | 0.5pp 取整后 | 说明 |
|---|---:|---:|---:|---:|---|
| 深度周期（铝/钢/煤，高 CV + 盈利周期） | 0.885（封顶 0.80） | 0.20 | 2.50% | 2.5% | 与 R21 周期股基准衔接 |
| 中间态（一般行业，中等波动） | 0.258 | 0.742 | 3.86% | 3.5% | 不再二选一 |
| 稳定消费（一般行业，低 CV、低毛利极差） | 0.075–0.125 | 0.875–0.925 | 4.19%–4.31% | 4.0% | 连续化后的稳定股上限 |

示例中的「稳定消费 4.19%–4.31%」在最终输出时按 0.5pp 网格向下取整为 4.0%，这是网格口径的结果，不是稳定度映射错误。

### FR-4 g1 上限的传导（P0）

- `growthG1` 的结构不变，仍为：

  ```
  capG1 = min(30%, max(0, max(前瞻锚, SGR) + 1pp))
  g1    = floor0.5(clamp(A, g∞, capG1))
  ```

- 本次只把其中的 `SGR` 替换为 FR-1 的**平滑 SGR**；前瞻锚是否可用、前瞻锚数值、1pp 缓冲、30% 上限、0.5pp 网格、`g1 ≥ g∞` 收口规则均不变。
- 前瞻锚与 SGR 都可用时仍取较高者作为上限锚；依据句指向真正绑定的那一项。SGR 绑定时，依据句带出平滑 SGR 与「近 N 年平均」；前瞻锚绑定时沿用现有文案。
- SGR 不可用时的兜底不变：前瞻锚可用时按 `min(30%, max(0, 前瞻锚) + 1pp)`；前瞻锚也不可用时只受 30% 上限约束。兜底不得反向影响 SGR 可用时的主路径。
- 平滑 SGR 降低了 SGR 的年度噪声，因此当 SGR 是绑定项时 g1 更稳定；若前瞻锚高于 SGR 并成为绑定项，g1 仍可能随一致预期变化，这是本次非目标（不改前瞻锚）的已知结果。

### FR-5 输出、接口与兼容（P0）

- **字段兼容**：`sgr`、`retention_rate`、`terminal_constraint`、`terminal_note`、`growth_terminal` 字段名与既有含义保留；`sgr` / `retention_rate` 的数值语义变为多年平均，依据句用「近 N 年平均」消除歧义。
- **新增字段**：`sgr_window_years`（int）、`terminal_stability`（number）、`retention_basis=mixed`。均为附加字段，旧客户端忽略后仍可正常工作。
- **历史记录兼容**：R16 历史快照中的旧 `sgr`、`retention_rate`、`terminal_constraint=cyclical/macro` 仍可正常打开、回填与展示；不得因新枚举或新字段缺失而报错。历史快照不重算、不改写。
- **敏感性矩阵兼容**：矩阵仍由单点估值结果的实际 g∞ 与 r 生成，结构、行列步长、基准格高亮、无效格规则均不变；新的 g∞（如 3.0%/3.5%/4.0%）自然成为新的基准中心，不需要额外改造。基准格仍须与单点「每股股权价值」一致。
- **前端展示**：稳定度只通过 `terminal_note` 与可选 `terminal_stability` 展示；不新增推导表、公式行、稳定度雷达图或信号明细。SGR 窗口只通过「近 N 年平均」与可选 `sgr_window_years` 展示。
- **AI 卡片与公司估值卡片**：参数应用逻辑不变；AI 卡片展示的 g1、g∞、依据句随新口径更新；公司估值卡片的手工参数与敏感性矩阵结构不变。

### FR-6 异常与边界处理（P0）

- **SGR 不可用**：终端只受 `cap` 与 `r−1pp` 约束；g1 按 FR-4 兜底；不得把兜底说成「受 SGR 约束」。
- **SGR=0 或接近 0**：`g∞=max(0, floor0.5(min(cap, r−1, 0)))=0`；g1 按现有规则收口到 0 或 1pp 上限内，不出现负 g1。
- **有效年度不足**：按 FR-1 的回落规则改用单年；回落仍不可用则 SGR 不可用。
- **基期年亏损但历史年度有效**：按 FR-1 的缺失/非正年度处理，用剩余有效年度平滑；若不足 3 年，回落单年（此时通常不可用）。
- **股东权益为负、归母净利润连续亏损**：相关年度不计入；有效年度不足 3 年时回落单年，单年不可用则 SGR 不可用。
- **稳定度信号缺失**：FCF 或盈利周期分量缺失时按 FR-2 归一化权重；行业缺失按 0.30；全部缺失时稳定度 0.70、终值上限约 3.75%（按网格 3.5%）。
- **宏观锚异常/不可用**：沿用现有 4.5% 兜底；不得因连续化新增宏观数据请求。
- **`r − 1pp ≤ 0`**：`g∞=0`；依据句按「终值按 0」处理。
- **A 为负**：结构性负增长仍走零增长模型；周期性负增长仍走永续且终值取 0；稳定度上限不改变这两条路径。
- **模型分类变化**：g∞ 变化导致 `gap` 变化、模型在两阶段/三阶段/永续之间切换时，按 R19 规则处理并允许降级标注；不得为保持模型名称而额外限制 `gap`。
- **0.5pp 网格**：最终 g∞ 仍向下取整；稳定度上限的连续值可能在取整后与相邻档位相同，这是预期结果，不得改成四舍五入或改成 0.1pp 网格（除非 Q5 确认）。
- **取整导致 g∞ 低于 0**：按 0 收口，不输出负终值。

## 4. 非功能需求

- **确定性**：同一公司、同一期财报、同一行业分类、同一快照，任何时候输出完全一致；不引入随机数、当前时间或 AI 参与计算。
- **性能**：SGR 平滑最多遍历 5 个年度，稳定度只做常数次比较与插值；不新增 IO、网络或 AI 调用，单次参数推导的额外开销可忽略。
- **兼容性**：不改变既有字段语义（`sgr` 语义变化通过「近 N 年平均」说明）；新增字段均为附加性；R16 历史记录、R11 搜索、三大报表、六维分析、公司估值卡片均不受影响。
- **移动端**：新增依据句控制在 1–2 行，375px 宽度下正常换行，不出现横向滚动；不新增表格或折叠推导区。
- **输出洁净**：估值参数区只保留参数、口径、数据年份与材料性依据；不出现 `cap`、`stability`、`macro`、`sgr` 等内部键名，不出现公式行、阈值表、规则元语言或工具说明。
- **可复算**：用户能用「近 N 年平均 SGR」「稳定度」「终值」三个数字手工验证 `g∞ ≤ cap`、`g∞ ≤ SGR`、`g∞ ≤ r−1pp`。
- **可维护性**：稳定度的权重、阈值、成长性否决覆盖值集中为常量，便于后续用样本校准，不散落在多个函数中。

## 5. 边界与约束

- **不做**：把扩张性资本支出从 FCF 中扣除；用扩张后 FCF 重算增长；新增动态通胀数据源；新增行业名称关键词表；对公用事业/金融业单独设定终值；恢复三档；新增终值占比面板；改造敏感性矩阵结构。
- **依赖**：
  - SGR 依赖现有 `sustainableGrowthR18` 与 `retentionRate` 的单年口径，本次只替换聚合窗口。
  - 稳定度依赖现有 `assessGrowthPattern`、`detectFCFCycle`、`detectProfitCycle` 与 `normalizeIndustryType` 的中间结果。
  - 终值依赖现有 `terminalGrowth` 与 `floorHalf` 取整规则。
  - 敏感性矩阵依赖现有四种 DCF 公式与公司估值卡片，本次不改其结构。
- **已知限制**：
  - 平滑 SGR 是历史平均，不是对公司未来增长能力的预测；对刚上市、历史年度不足 3 年的公司会回落单年，平滑效果有限。
  - 留存率的权益增长口径仍可能被增发、回购、少数股东权益变动、会计重述影响；多年平均只能降低单年影响，不能消除口径本身的近似。
  - 「平均 ROE × 平均留存率」忽略两者协方差；对强负相关公司可能略有高估，作为单一适中基准可接受。
  - 稳定度的权重与阈值是初始校准值，尚未用大量样本回归；后续如发现系统性偏差，可在独立需求中校准，不在本次范围。
  - 2.5% 不再是硬编码的周期股常量，而是「稳定度 0.2 + 当前宏观锚 4.5%」的结果；若未来动态 GDP 明显低于 2.5%，深度周期的终值上限也会相应低于 2.5%。
  - 终值最终仍按 0.5pp 网格输出，连续化体现在档位增多（2.5/3.0/3.5/4.0/4.5），不是连续小数。
  - 前瞻锚未平滑；当前瞻锚成为 g1 上限的绑定项时，g1 仍可能随一致预期变化。

## 7. 待确认问题

以下问题均已给出推荐默认值，可先按推荐推进；如用户有不同意见，再在技术设计前调整。

- **Q1 SGR 平滑窗口取几年、最少几个有效年度？**
  - 影响：平滑程度、历史年度不足公司的可用性、与现有 5 年增长窗口的一致性。
  - 推荐：**默认 5 年，至少 3 个有效年度；3–4 个有效年度时使用实际年度，不足 3 个回落单年**。理由：5 年覆盖一个较完整的经营周期，与现有增长窗口一致；3 年下限保证新上市公司或数据缺失公司仍能计算；回落单年避免直接不可用。
  - 备选：固定 3 年（更贴近近期、平滑较弱）；或固定 5 年且不足 5 年即不可用（更严格，但会降低可用性）。

- **Q2 聚合方式用「平均 ROE × 平均留存率」还是「逐年 SGR 再平均」？**
  - 影响：SGR 水平与平滑效果，进而影响 g1 上限与终值。
  - 推荐：**平均 ROE × 平均留存率**。理由：与用户已定方向一致，两个驱动因素分别平滑，单年留存率被 clamp 到 0/1 的极端值不会以乘积形式放大；口径也更容易向用户解释。
  - 备选：逐年 SGR 再平均。它更贴近「平均可持续增速」的字面含义，但仍保留单年乘积噪声，且对低净利润年份更敏感。

- **Q3 净利润非正、权益非正、留存率不可计算的年度如何处理？**
  - 影响：周期低谷、亏损公司、增发/回购公司的 SGR 可用性与数值。
  - 推荐：**这些年度整体不计入平均值；只要窗口内仍有 ≥3 个有效年度就继续平滑；不足 3 个回落单年**。理由：负 ROE 或负留存率没有「可持续增长」含义，纳入平均会把 SGR 打成负值，进而把 g1 和终值压到 0，与周期恢复逻辑冲突；剔除后由有效年度平滑，既稳定又不至于不可用。
  - 备选：把负利润年度按 ROE=0 或按负值纳入平均。前者会系统性高估，后者会系统性低估；均不推荐。

- **Q4 稳定度的信号权重与阈值是否按本文取值？**
  - 影响：终值上限的档位分布，尤其是深度周期是否落在 2.5%、稳定消费是否落在 4.0%、中间态是否落在 3.5%。
  - 推荐：**行业 0.50 / FCF 0.30 / 盈利周期 0.20；CV 线性区间 0.15–0.60；毛利率极差线性区间 3–15pp；符号翻转 ≥2 次或盈利周期命中时对应分量至少 0.80；成长性否决覆盖为 `c ≤0.15`；行业缺失按 0.30；周期强度最终封顶 0.8（对应稳定度 0.2 与 2.5% 上限）**。理由：这组参数能让三个典型样本分别落在 2.5% / 4.0% / 3.5%，且全部复用现有信号，不新增判定。
  - 备选：先按本文推进，再用 10–20 家样本校准权重；若用户希望更保守，可提高 FCF 分量权重或降低稳定度上限。

- **Q5 终值最终是否保留 0.5pp 网格向下取整？**
  - 影响：连续化的「分辨率」。稳定消费的 cap 约 4.19%–4.31%，按 0.5pp 网格输出 4.0%；若改为 0.1pp 网格，可输出 4.2%。
  - 推荐：**保留 0.5pp 网格向下取整**。理由：与 g1、模型分类、敏感性矩阵和 R19/R20 的取整口径一致；连续化已经消除了 2.5% 与 4.5% 之间的 2pp 硬跳变，并提供 3.0%/3.5%/4.0% 中间档，足以满足「适中」目标。
  - 备选：终值改用 0.1pp 网格（或四舍五入到 0.1pp），更贴近连续 cap，但会引入新的取整规则，并与现有 0.5pp 敏感性矩阵和 g1 口径不完全一致；需另行确认。

- **Q6 是否新增 `terminal_stability`、`sgr_window_years` 与 `terminal_constraint=stability`？**
  - 影响：用户能否直接看到稳定度与平滑窗口；API 与历史记录的兼容性。
  - 推荐：**新增，均为附加性字段/枚举；`cyclical` 与 `macro` 仅保留为历史兼容值，新计算不再返回**。理由：稳定度与窗口是复算所需的最小信息；附加字段不破坏旧客户端；历史快照不需要重算或改写。
  - 备选：不新增字段，只把稳定度与窗口写进依据句。这样 API 更洁净，但用户无法结构化读取，复算与后续测试也更困难。

- **Q7 AI 明确分类为周期性行业的公司，是否仍要求终值锁定在 2.5%？**
  - 影响：行业标签与财务信号不一致时的终值水平。
  - 推荐：**不锁定，保持连续**。`industry_type=cyclical` 只把行业分量设为 0.85；只有同时命中高 FCF 波动/盈利周期时稳定度才接近 0.2、终值才落到 2.5%。仅有周期标签但财务平稳的公司可以高于 2.5%，这正是连续化要解决的问题。
  - 备选：若用户希望保留「AI 周期股 ≤2.5%」的硬约束，可在稳定度上再加一个行业上限（如稳定度 ≤0.35），但会削弱连续化效果，且与本次「不再硬二分」的方向部分冲突。

- **Q8 深度周期的稳定度下限是否设为 0.2（对应终值 2.5%）？**
  - 影响：极端周期公司（铝、钢、煤等）的终值是否可能低于 2.5%，以及连续化的下限。
  - 推荐：**设为 0.2**。将原始周期强度 `c_raw` 封顶在 0.8，使稳定度不低于 0.2；在宏观锚 4.5% 下对应 2.5%，与 R21 已确认的周期股基准衔接。理由：既保留「深度周期接近 2.5%」的锚点，又避免把极端周期压回 R20 的 2.0%，造成新的口径反复。
  - 备选：允许稳定度低至 0（终值 2.0%）。这会让极端周期公司回到 R20 口径，与 R21 的 2.5% 决策冲突；若用户希望「比 2.5% 更保守」，需要明确这是对 R21 的再次修订。

## 8. 与 R19/R20/R21 的对照摘要

| 项目 | R19/R20/R21 现行口径 | R22 修订后口径 | 是否变更 |
|---|---|---|---|
| SGR 窗口 | 基期单年 ROE × 单年留存率 | 最近 5 年有效年度平均 ROE × 平均留存率；至少 3 年，不足回落单年 | **是** |
| SGR 单年分子分母 | 归母净利润优先、回落重构；分红/权益增长留存率 | 同左 | 否 |
| 终值上限 | 周期 2.5% / 非周期宏观 GDP（约 4.5%）硬二分 | `cap = 2% + (宏观锚−2%) × stability`，稳定度 ∈[0.2,1.0] | **是** |
| 稳定度来源 | 无 | 行业类型 0.50 + FCF CV 0.30 + 盈利周期 0.20，成长性否决覆盖 | **新增** |
| 终值约束 | `min(上限, r−1pp, SGR)`，g∞≥0，0.5pp floor | 同左，上限改为连续 cap | 否（上限输入变） |
| g1 上限 | `min(30%, max(前瞻锚, SGR)+1pp)` | 同左，SGR 改为平滑值 | 否（SGR 输入变） |
| FCF 口径 | 经营现金流净额 − 保全性资本支出 | 同左 | 否 |
| WACC/CAPM、复合锚 A | R19 口径 | 同左 | 否 |
| 模型分类/降级/n1 | R19/R20 规则 | 同左；g∞ 变化导致的模型变化属规则内结果 | 否 |
| 敏感性矩阵 | 5×3，中心为实际 g∞ 与 r | 同左，中心自动使用新 g∞ | 否 |
| 输出洁净 | 只给参数、口径、依据 | 同左，新增稳定度/窗口两个可复算数字 | 否（新增依据） |
| 三档情景 | 已废除 | 仍废除 | 否 |
| 新增取数 | 无 | 无 | 否 |

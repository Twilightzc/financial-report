## 3. 六项正确性硬口径（A）验证结果

### A1 WACC 闭合 —— 通过

验证方法：代码审阅 + 96 组矩阵 + 复算。

- `Re = Rf + β×ERP + RP_company`，`Re` 保留 2 位小数；
- `E/V` 权重优先总市值 `MarketCap`，市值不可用时退回 `TOTAL_EQUITY`，并输出「市值不可用，E 按账面所有者权益（含少数股东）近似」的披露；
- `D = max(0, 有息债务)`，负债务告警并按 0；
- `Rd` 优先利息支出/平均有息债务，缺失时按 `Rf+2.0pp` 估计并限制在 `[3,8]`；
- 有效税率 `t = 所得税 / (利润总额 − 联营合营投资收益)`，基数 ≤0 默认 25%，结果夹在 `[0,1]`；
- `Rd_after = Rd_pre × (1 − t)`；
- `WACC` 由**展示值**复算：`round2(wE×Re + wD×Rd_after)`；
- 输出 `discount_base_value`（取整前 WACC）、`discount_rounded`（0.5pp 网格）、`discount_range_adjustment`（[8,15] 区间调整）；
- 恒等式 `round2(base + rounding_adjustment + range_adjustment) == discount_rate` 在全部 96 组成立；`wE + wD == 1`；未出现负权重；`equity ≤ 0`、`V ≤ 0`、`V < 1e6` 时回落 `Re` 且 `discount_reconcile_available=false`。

### A2 复合锚 A 构成表可加总 —— 通过

验证方法：代码审阅 + 2268 组矩阵。

- 每行 `value`、`weight`、`contribution` 均为 2 位小数，`contribution = round2(value × weight)`；
- `Σ contribution == raw`（2 位小数口径）；
- `raw + rounding_adjustment + range_adjustment == final`；
- 有效锚组合下 `weight_sum == 1.00` 且 `weight_ok=true`；
- 历史/前瞻/宏观权重按高/中可靠度与单锚场景切换，周期修正只作用于历史锚。

### A3 三档情景彻底删除 —— 通过

验证方法：源码 grep + 响应结构 + JSON 契约测试。

- `internal/` 非测试源码中 `scenario|Scenarios|band_|capped_by|conservative|optimistic|乐观|保守` 的命中仅为：
  - 注释；
  - 提示词中的禁用词清单；
  - `sanitizeRationale` / `cleanCompanyRiskNote` 的黑名单；
  - `attributeNegativeGrowth` 中未对外输出的 dead 返回值（调用处为 `negType, _, _ := ...`）。
- `model.AIValuation` 无 `scenarios` / `scenario_*` / `band_*` / `capped_by` 字段；
- 缓存 schema 为 `r19`，旧缓存不会复用；

- `TestApplyValuationRecommendation` 对响应 JSON 做禁用字段断言，通过。

### A4 Capex 覆盖率 —— 通过

验证方法：代码审阅 + 全链路临时测试 + 既有 `TestCapexCoverageDetail`。

- 分子：`Σ(CONSTRUCT_LONG_ASSET − DISPOSAL_LONG_ASSET)`（净额，处置收回按负项扣减）；
- 分母：`Σ preservationCapex`，与 FCF 使用同一个函数、同一窗口；
- 窗口与基期 FCF 完全一致（latest/average/median/trim_mean/custom）；
- custom 按最新年报，并在 note 中说明；
- 分母 ≤0 → `available=false` + `reason`，不静默显示 0；
- 临时测试按原始报表逐年手工复算分子/分母/比率，结果一致。

### A5 FCF / 净利润 —— 通过

验证方法：全链路临时测试 + 代码审阅 + 既有 `TestFCFProfitDetail`。

- 分子等于对外展示的 `fcf_base_value`（含基期选取、窗口、研发调整）；
- 分母为**同窗口、同聚合方式**的 `PARENT_NETPROFIT`；
- 归母净利润窗口内缺失或聚合后 ≤0 时，整窗口统一切换为重构净利润（`TOTAL_PROFIT − INCOME_TAX`），并在 `profit_basis` 与 note 中标注；
- 不剔除亏损年（既有用例 `(100−50+100)/3=50` 通过）；
- FCF ≤0 或净利润 ≤0 → `available=false` + 原因。

### A6 公司特定风险溢价 —— 通过

验证方法：临时测试 + 代码审阅。

- 默认 0；
- 只通过 `Re` 进入折现率：RP 增加 1.0pp 时 `ΔRe=1.0pp`，`ΔWACC≈wE×1.0pp`，不是直接加 1.0pp；
- 仅允许 5 类非财务风险：`governance`、`litigation`、`customer_concentration`、`liquidity`、`accounting_quality`；
- `medium=0.5pp`、`high=1.0pp`；
- 同一 type 去重保留较高 severity；
- 合计按溢价从高到低截断至 ≤3.0pp，并输出截断说明；
- `financial_leverage` 等财务类风险、非法 severity 被丢弃；
- note 含数字/百分号/过程话术时清空。

## 5. 发现并修复的问题

### 问题 1（正确性，已修复）：n1 按 `A−g∞` 而非 `g1−g∞` 计算

- 现象：`constructTwoStage` / `constructThreeStage` 使用调用方传入的 `gap = A − g∞` 计算回归年限，而需求 §5.5、技术设计 §5.5.4 要求 `nTotal = clamp(round((g1−g∞)/1.5), 3, 10)`。
- 触发条件：`growthG1` 因前瞻/SGR +2pp 上限把 `g1` 压到低于 `A` 时。
- 复现：
  - `constructTwoStage(A=20, g∞=4.5, gap=15.5, g1=17, r=8)` → `n1=10`；正确应为 `fadeYears(12.5)=8`。
  - `constructThreeStage(A=20, g∞=4.5, gap=15.5, g1=17, r=12)` → `nTotal=10`；正确应为 8。
- 影响：高增长期被拉长约一倍，估值偏高。
- 修复：`internal/service/growth.go` 两/三阶段改为 `fadeYears(g1 - gInf)`；`constructGrowthPath` 删除无用的 `gap` 参数；调用处同步；新增 `g1 < A` 的锁定用例。
- 复验：定向用例通过，全量测试通过。

### 问题 2（提示词一致性，已修复）：two_stage 事实块缺 g2

- 现象：`growthParamsText` 的 `valModelTwoStage` 分支只输出 `g1`、`n1`，未输出 `g2`。
- 依据：技术设计 §7 示例及参数清单要求 two_stage 给出 `g1`、`n1`、`g2`。
- 修复：two_stage 分支补 `g2`（取 `params` 中的 `g2`）。
- 复验：提示词相关测试通过。

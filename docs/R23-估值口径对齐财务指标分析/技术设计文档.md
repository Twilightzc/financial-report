# R23 估值口径对齐财务指标分析 技术设计

> 对应需求：`docs/R23-估值口径对齐财务指标分析/需求文档.md`。本文所有行号以改动前代码为基准。
>
> 核心设计：**全项目只保留 `internal/service/analysis.go:1843` 的 `maintenanceCapex(cf model.ReportRow)` 一套保全性资本支出实现**；估值链路的 FCF 扣减、Capex 覆盖率分母、逐年 FCF 保全列、公司价值卡片全部改为调用它；AI「FCF/净利润」分母固定为 `netProfitReconstructed(income)`。

## 1. 设计目标与影响面

### 1.1 目标

1. 删除估值侧第二套实现 `preservationCapex(income, cf)` 及其专用辅助 `disposalLongAssetLoss(cf)`，不保留任何别名/包装。
2. 四个使用点（DCF 逐年 FCF、Capex 覆盖率分母、`fcf_series[].preservation_capex`、公司价值卡片）对同一年报年度输出**同一浮点值**。
3. 「FCF/净利润」分母统一为重构净利润（税前利润 − 所得税，含少数股东损益），与 R3「净利润现金含量」同口径。
4. 不改 FCF 公式结构、不改 R19/R20/R21/R22 的 WACC、复合锚 A、g1、终值、敏感性矩阵、模型分类口径。

## 2. 总体架构

分层不变，仍为 `api → service / client → model`。本次只收敛 service 内部的口径调用关系：

```
DCF / 公司价值 / AI 估值（service 纯函数）
  ├─ operatingFreeCashFlow(cf)
  │     └─ v0(cf,"NETCASH_OPERATE") − maintenanceCapex(cf)   ← analysis.go，唯一权威
  ├─ capexCoverageDetail(cfByYear, years, mode)
  │     └─ Σ(CONSTRUCT_LONG_ASSET − DISPOSAL_LONG_ASSET) / Σ maintenanceCapex(cf)
  ├─ fcfSeries[].preservation_capex = maintenanceCapex(cf)
  └─ fcfProfitDetail(..., incomeByYear, years, mode)
        └─ aggregateProfit([netProfitReconstructed(income_y)], mode)
```

`maintenanceCapex` 保留在 `analysis.go`（R3 所属模块），估值侧仅调用、不复制公式。这样后续调整口径只需改一处。

## 3. 数据模型

无字段增删。仅更新注释，语义变化如下：

```go
// internal/model/ai.go:91
ProfitBasis string `json:"profit_basis"` // R23 起恒为 "reconstructed"（重构净利润，含少数股东损益）

// internal/model/ai.go:106
PreservationCapex float64 `json:"preservation_capex"` // 保全性资本支出（与 R3 财务指标分析同口径，正数）
```

`FCFProfitDetail.Profit` 的单位与含义不变（元，同窗口同聚合的重构净利润）。`CapexCoverageDetail.Denominator` 仍为窗口内保全性资本支出合计（元）。

## 4. 数据源与字段映射

**不新增任何东财字段，估值侧不再读取利润表减值字段。**

保全性资本支出（唯一公式，全部取现金流量表补充资料，`nil` 按 `v0` 计 0）：

```
maintenanceCapex(cf) =
      FA_IR_DEPR               固定资产折旧、油气资产折耗、生产性生物资产折旧
    + IA_AMORTIZE              无形资产摊销
    + LPE_AMORTIZE             长期待摊费用摊销
    + USERIGHT_ASSET_AMORTIZE  使用权资产摊销
    + ASSET_IMPAIRMENT         资产减值准备（现金流量表补充资料）
    + FA_SCRAP_LOSS            固定资产报废损失
```

明确排除（保留字段但**不参与** FCF/保全性资本支出）：

- 利润表 `ASSET_IMPAIRMENT_INCOME` / `ASSET_IMPAIRMENT_LOSS`、`CREDIT_IMPAIRMENT_INCOME` / `CREDIT_IMPAIRMENT_LOSS`（仍由 R3 其他指标使用，函数 `assetImpairmentLoss`/`creditImpairmentLoss` 保留）。
- 现金流量表 `DISPOSAL_LONGASSET_LOSS`（处置长期资产损失，R23 起不参与保全性资本支出）。

资本支出覆盖率分子不变：`CONSTRUCT_LONG_ASSET − DISPOSAL_LONG_ASSET`（净额，R19 口径）。

净利润分母：`netProfitReconstructed(income) = preTaxProfit(income) − v0(income,"INCOME_TAX")`，其中 `preTaxProfit` 为 R3 重构口径（`ebitTotal − realFinanceExpense`），见 `internal/service/analysis.go:978-989`。**不使用 `PARENT_NETPROFIT`。**

det := model.FCFProfitDetail{

## 11. 风险与回滚

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 所有依赖 FCF 的数值变化 | 基期 FCF、DCF 经营资产/公司/股权价值、AI 校验比值、告警触发、FCF 增速/周期判定派生结论变化 | 预期结果；文档明确；测试按新口径更新 |
| 旧 AI 缓存返回旧口径 | 10 分钟内结果不一致 | `aiCacheSchema` 升 `r23`，进程内缓存自然失效 |
| R16 历史快照与新口径混看 | 用户困惑 | 需求明确不迁移、不标注；快照保留计算时点原值 |
